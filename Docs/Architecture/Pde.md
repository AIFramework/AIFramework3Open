# Уравнения в частных производных `AI.Solvers.Pde` (AI.Solvers.Pde.dll)

Сборка **`AI.Solvers.Pde`** (`AI.Solvers.Pde.dll`, **.NET 9.0**) — краевые и начально-краевые
задачи: конечные разности, конечные элементы и разреженная линейная алгебра под них; плоская
теория упругости и уравнения Навье — Стокса в каверне. Зависит только от ядра **`AI`**.

---

## Отношение к `AI.Solvers.Math`

В `AI.Solvers.Math.Core.Solvers.NumericalPDESolver` уже есть численные схемы для тех же
уравнений — теплопроводности, волнового, Лапласа, диффузии с переносом, Бюргерса. Схемы там
верные, но это **демонстрации**: область, начальное условие и граничные значения зашиты
в код, а результат возвращается строкой с готовым отчётом. Получить поле для дальнейших
вычислений оттуда нельзя.

Поэтому здесь другое: те же уравнения с собственной областью, произвольными начальными
и граничными условиями, источником — и полем на выходе. Демонстрационные функции остались
на месте, они используются в консольных примерах.

## Состав

| Область | Тип | Назначение |
|---------|-----|------------|
| Сетки | **`Grid1D`**, **`Grid2D`** | Равномерные сетки на отрезке и прямоугольнике. |
| Алгебра | **`SparseMatrix`** | Разреженная матрица: сборка по элементам, строчный формат, исключение известных неизвестных. |
| Алгебра | **`IterativeSolvers`** | Сопряжённые градиенты с диагональным предобусловливателем; прогонка для трёхдиагональных систем. |
| Алгебра | **`BandedCholesky`** | Разложение Холецкого ленточной матрицы: одно разложение — сколько угодно правых частей. |
| Разности | **`HeatEquation1D`** | `u_t = α·u_xx + f` — явная схема и Кранк — Николсон. |
| Разности | **`WaveEquation1D`** | `u_tt = c²·u_xx` — явная трёхслойная схема с проверкой условия Куранта. |
| Разности | **`Poisson2D`** | `−Δu = f` на прямоугольнике, пятиточечный шаблон. |
| Разности | **`LidDrivenCavity`** | Навье — Стокс для несжимаемой жидкости в квадратной каверне с подвижной крышкой: функция тока и завихренность. |
| Элементы | **`Fem1D`** | `−(k·u′)′ + c·u = f` на отрезке, линейные элементы, условия первого и второго рода. |
| Элементы | **`Fem2D`**, **`TriangularMesh`** | `−Δu = f` на треугольной сетке, линейные элементы. Сетки: прямоугольник, четверть кольца, четверть пластины с отверстием со сгущением к контуру, любая триангуляция через `TriangularMesh.Create`; граничные рёбра с внешними нормалями. |
| Элементы | **`ElasticityProblem`**, **`ElasticitySolution`** | Плоская упругость — плоское напряжённое и плоское деформированное состояние, треугольники постоянной деформации. Закрепления, узловые силы, распределённые нагрузки и давление на границе, объёмные силы; перемещения, напряжения в элементах и узлах, реакции опор, энергия деформации. |

```csharp
using AI.Solvers.Pde;
using AI.Solvers.Pde.FiniteDifference;

var grid = new Grid1D(0, 1, 201);

HeatSolution heat = HeatEquation1D.Solve(
    grid, diffusivity: 0.5,
    initial: x => Math.Sin(Math.PI * x),
    leftBoundary: _ => 0, rightBoundary: _ => 0,
    finalTime: 0.1, steps: 200,
    scheme: TimeScheme.CrankNicolson);

Vector profile = heat.Values;
```

## Чем схемы отличаются друг от друга

**Явная схема** считает новый слой напрямую и потому требует шага `Δt ≤ h²/(2α)`: при
нарушении решение растёт экспоненциально. Решатель сообщает об этом свойством `IsStable`
и числом `Courant`, а не молча выдаёт мусор.

**Кранк — Николсон** устойчива при любом шаге и имеет второй порядок по времени, но требует
решения трёхдиагональной системы на каждом шаге — это прогонка, один проход вперёд и один
назад.

**Волновое уравнение** решается явно, и здесь условие Куранта `c·Δt/h ≤ 1` не смягчается
выбором схемы: при нарушении решатель отказывается считать. Первый временной слой берётся
отдельной формулой с учётом начальной скорости — иначе метод теряет второй порядок.

**Конечные элементы** отличаются от разностей не точностью на равномерной сетке (там схемы
совпадают), а тем, что формулируются через интеграл. Отсюда естественная работа с переменными
коэффициентами, условиями второго рода и — в двумерном случае — с областями произвольной
формы, которые прямоугольная сетка описать не может.

## Упругость и течение

**Плоская упругость.** Треугольник постоянной деформации — простейший элемент: перемещения
в нём линейны, деформации и напряжения постоянны. Матрица жёсткости собирается в ту же
`SparseMatrix`, закрепления исключаются тем же `EliminateKnown`, система решается теми же
сопряжёнными градиентами. Реакции опор — внутренние силы в закреплённых узлах за вычетом
приложенных нагрузок; их сумма обязана уравновесить нагрузку, и разбор результата показывает
невязку равновесия. Недозакреплённое тело — например, закреплённое только по x — имеет
перемещения как жёсткого целого, и матрица вырождена; решатель отказывается считать, а не
возвращает произвольное смещение.

```csharp
using AI.Solvers.Pde.FiniteElement;

// Четверть квадратной пластины 20×20 с отверстием радиуса 1, растяжение 1 МПа вдоль x
TriangularMesh mesh = TriangularMesh.QuarterPlateWithHole(1, 10, 32, 48, grading: 1.12);

ElasticitySolution plate = new ElasticityProblem(mesh, 70e9, 0.33)
    .FixWhere((_, y) => Math.Abs(y) < 1e-9, x: false, y: true)    // ось симметрии y = 0
    .FixWhere((x, _) => Math.Abs(x) < 1e-9, x: true, y: false)    // ось симметрии x = 0
    .AddTraction((x, _) => Math.Abs(x - 10) < 1e-9, (_, _) => (1e6, 0))
    .Solve();

Console.WriteLine(plate.Interpret());
```

Решатель полей принимает числа в СИ, как вся сборка, и от `AI.Physics` не зависит: замкнутые
решения — Ламе, Кирш, Герц — и материал с тензорами живут там. Связь проверяется в тестах:
конечные элементы обязаны сойтись к решениям, которые считает физика.

**Течение в каверне.** Функция тока и завихренность исключают давление, и несжимаемость
выполняется тождественно. Завихренность переносится явной схемой с центральными разностями
до установления, на стенках задаётся формулой Тома. Функция тока на каждом шаге — задача
Пуассона с той же пятиточечной матрицей, что в `Poisson2D`: сборка у них общая. Матрица от
шага к шагу не меняется, поэтому раскладывается по Холецкому один раз, и шаг стоит двух
подстановок в ленте шириной в сторону сетки. Первая версия решала её сопряжёнными градиентами
с тёплым стартом — от 40 до 95 итераций на каждом шаге; разложение дало тот же ответ до 10⁻¹¹
в 15–20 раз быстрее: сетка 41×41 при Re = 100 — 1,1 с вместо 23,5 в отладочной сборке,
65×65 — 9,6 с вместо 141.

## Граничные условия и симметрия

Условие Дирихле задаётся исключением известного неизвестного: строка **и столбец**
обнуляются, вклад известного значения переносится в правую часть. Обнулить одну строку
недостаточно — матрица потеряет симметрию, а метод сопряжённых градиентов на несимметричной
матрице расходится. Разложение Холецкого проверяет симметрию явно и отказывается раскладывать
несимметричную или не положительно определённую матрицу.

Ошибка коварна тем, что при нулевых граничных значениях она незаметна: неизвестные на границе
остаются нулевыми, и несимметричная часть ни на что не влияет. При ненулевых значениях решение
улетает на пятнадцать порядков. Первая версия `Poisson2D` содержала ровно эту ошибку, и нашёл
её тест с линейным граничным условием.

## Проверка

Совпадение с точным решением на одной сетке ничего не доказывает: оно случается и при неверной
схеме с удачно подобранным шагом. Поэтому решатели проверяются **порядком сходимости** —
измельчение сетки вдвое обязано уменьшать ошибку примерно вчетверо у схем второго порядка.

Кроме порядка проверяются:

* точные решения — стоячая волна, остывающая синусоида, `u = x(1−x)` для `−u″ = 2`;
* линейное поле как решение задачи Лапласа: гармоническая функция обязана воспроизводиться
  с машинной точностью и разностями, и элементами;
* узловая точность одномерных элементов на задаче Пуассона;
* отказ считать при нарушении условия Куранта;
* сохранение симметрии при исключении известных неизвестных;
* разложение Холецкого совпадает с сопряжёнными градиентами на случайной ленточной матрице
  и отказывает незнакоопределённой и несимметричной.

Упругость и течение:

* однородное растяжение на искажённой сетке воспроизводится до ошибки округления — напряжения,
  перемещения с поперечным сжатием, реакции и энергия деформации (patch-тест: элемент, который
  его не проходит, не сходится ни на какой сетке);
* труба под давлением сходится к решению Ламе со вторым порядком: ошибка радиального
  перемещения 2,8 % → 0,81 % → 0,23 % на сетках 8×16, 16×32 и 32×64; реакции на оси симметрии
  уравновешивают давление до 10⁻⁶;
* пластина с отверстием даёт узловую концентрацию 3,07–3,09 на трёх сетках против 3 у Кирша для
  бесконечной пластины; поправка Хейвуда на конечную ширину даёт около 3,03, а оставшиеся
  полтора процента с измельчением не уходят — по-видимому, это перенос напряжений из элементов
  в узел на контуре;
* каверна при Re = 100 сверена с таблицами Гиа, Гиа и Шина (1982): наибольшее отклонение u
  на вертикальной средней линии и v на горизонтальной — 0,0054 и 0,0034 на сетке 41×41,
  0,0027 и 0,0059 на 65×65; центр вихря (0,625; 0,75) против (0,6172; 0,7344), ψ = −0,1015 против
  −0,1034; расход через вертикальное сечение равен нулю;
* при Re → 0 течение зеркально симметрично относительно вертикали x = 0,5. При Re = 1
  асимметрия ещё около процента — инерция не пренебрежима, и тест берёт Re = 0,01.

## Границы применимости

Сетки равномерные и прямоугольные; треугольные сетки строятся для прямоугольника, четверти
кольца и четверти пластины с отверстием, а сборка работает с любой переданной триангуляцией.
Элементы линейные, квадратичных нет. Из нелинейных уравнений решаются только уравнения
Навье — Стокса в каверне; Бюргерса в общей постановке нет. Трёхмерных задач нет.

Треугольник постоянной деформации слишком жёсток при изгибе: тонкая балка из одного-двух слоёв
элементов прогибается в разы меньше, чем должна, а при ν около ½ в плоской деформации
жёсткость завышается ещё и запиранием. Упругость линейная и изотропная, деформации малые;
пластичности, контакта и больших перемещений нет.

Каверна — одна постановка: квадрат, неподвижные стенки, ламинарное установившееся течение.
Шаг явной схемы ограничен диффузией (`h²·Re/4`), поэтому число шагов растёт как квадрат числа
узлов на сторону, а сеточное число Рейнольдса `Re·h` должно оставаться меньше двух — при
больших Re нужна сетка мельче. Выше нескольких тысяч течение в каверне перестаёт быть
стационарным.

Предобусловливатель сопряжённых градиентов диагональный — простейший из возможных. На плохо
обусловленных задачах (сильно вытянутые области, разрывные коэффициенты) сходимость будет
медленной; неполное разложение Холецкого или многосеточный метод — отдельная работа. Ленточное
разложение выручает при хорошей нумерации узлов; упорядочения, сужающего ленту, нет.

## Результаты объясняют себя

Все решения — `PoissonSolution`, `HeatSolution`, `WaveSolution`, `Fem1DSolution`, `Fem2DSolution`,
`ElasticitySolution`, `CavityFlowSolution` и итог решателя системы `IterativeResult` — реализуют
`IInterpretable`. Интерпретация говорит то, что обычно остаётся за кадром и что без неё
приходится знать заранее:

| Решение | Что сообщает сверх чисел |
|---------|--------------------------|
| Пуассон | Где лежат экстремумы. У задачи Лапласа они обязаны быть на границе (принцип максимума); внутренний экстремум означает источник либо ошибку в данных. |
| Теплопроводность | Схему и её слабость: явная разваливается выше α·Δt/h² = 1/2, Кранк — Николсон устойчив всегда, но выше того же порога меняет знак коротких волн. |
| Волна | При числе Куранта ровно 1 схема точна; при малом — заметная численная дисперсия. |
| Конечные элементы | Погрешность потока на порядок хуже погрешности самого решения. |
| Упругость | Невязку равновесия реакций и нагрузок; что пик напряжений в концентраторах занижен, пока сетка там не измельчена; что треугольник слишком жёсток при изгибе и запирается при ν около ½. |
| Каверна | Сеточное число Рейнольдса и надёжность центральных разностей; что завихренность в верхних углах бесконечна по постановке; что выше нескольких тысяч Re стационарного течения может не быть. |
| Все сеточные | Невязка системы — не погрешность решения: дискретизация от неё не зависит. |

Где интерпретация утверждает проверяемое, тесты проверяют само утверждение: волна при числе
Куранта 1 к моменту t = 0.5 действительно обращается в нуль с точностью 1e-9, а максимум
одномерной задачи −u″ = 1 равен ровно 1/8 (`DomainInterpretationTests`).

`HeatSolution.Scheme` хранит использованную схему: без неё устойчивую явную схему нельзя было бы
отличить от Кранка — Николсон при том же сеточном числе, а их слабости разные.
