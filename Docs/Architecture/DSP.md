# Цифровая обработка сигналов — `AI.DSP`

Сборка **`AI.DSP`** (`AI.DSP.dll`, **.NET 9.0**) объединяет **обработку сигналов**, спектральный анализ и связанные алгоритмы, опираясь на машинное обучение и ядро линейной алгебры.

---

## Зависимости

| Проект | Зачем |
|--------|--------|
| **`AI.ML`** | Модели и тензорная/векторная математика в сценариях DSP+ML. |
| **`AI.KNN`** | k-ближайших соседей и смежные методы (цепочка: KNN → ML → ClassicMath → AI). |

Транзитивно доступны все типы **`AI`** (векторы, матрицы, статистика).

---

## Роль в решении

- Используется в **`AI.DataPrepaire`** для подготовки данных и признаков.
- Ядро **`AI.Charts`** ссылается на **`AI.DSP`** для построения спектров, окон Фурье и вспомогательных графиков в **`ChartView`**.
- В репозитории могут быть бэкенды на базе **NWaves** (см. благодарности в **[../INFO.md](../INFO.md)**).

---

## Пространства имён

Структура каталога `src/AI.DSP/` отражает подсистемы: ядро DSP, преобразования, фильтры, работа с сигналами в связке с `AI.DSP.DSPCore` и т.д. Точные пространства имён смотрите в файлах проекта.

---

## Сборка

```bash
dotnet build src/AI.DSP/AI.DSP.csproj -c Release
```

Обзор связки с графиками: [Charts.md](Charts.md). Узкий solution: **`SLNS/AIFramework(Сигналы).sln`**.
