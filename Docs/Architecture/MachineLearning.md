# Машинное обучение и смежные сборки

Ниже — связка **`AI.ClassicMath`** → **`AI.ML`** и модули, которые строятся поверх или рядом с ней.

---

## `AI.ClassicMath`

Сборка **`AI.ClassicMath`** (**.NET 9.0**) зависит только от **`AI`**. Содержит классическую математику для ML и сигналов: линейная алгебра поверх абстракций ядра, специализированные функции, заготовки под учебные задачи. Является **прямой базой** для **`AI.ML`**.

Нелинейные решатели лежат в `AI.MathUtils.Nonlinear`: метод Левенберга–Марквардта для наименьших квадратов с масштабированием Марквардта (`LevenbergMarquardt`, результат с якобианом и его рангом, чтобы видеть недоопределенную систему) и метод Ньютона для квадратных систем с поиском шага и обновлением Бройдена (`NewtonSystemSolver`). Якобиан можно не задавать: тогда он считается центральными разностями. Интеграторы ОДУ в `AI.MathUtils.ODE` дополнены адаптивным методом Дормана–Принса 5(4) с плотным выводом и поиском событий (`DormandPrince`, `OdeEvent`: касание земли, пересечение порога) и симплектическим скоростным методом Верле (`VelocityVerlet`), который сохраняет энергию на тысячах периодов.
Адаптивная квадратура Гаусса–Кронрода 7/15 (`AI.MathUtils.Integration.GaussKronrod`) делит худший отрезок, пока не
сойдется с относительной точностью около 10⁻¹⁰, и не вычисляет функцию на концах: ею пользуются меры кривых
в `AI.Geometry`, которой квадратура `AI.Solvers.Math` недоступна по направлению зависимостей. Сингулярное разложение
`Svd` останавливается, когда проход не сделал ни одного поворота: абсолютный порог на плохо масштабированных
матрицах недостижим, и раньше шли все 200 проходов.

## `AI.ML`

Сборка **`AI.ML`** (`AI.ML.dll`, **netstandard2.0**) ссылается на **`AI.ClassicMath`** (и транзитивно на **`AI`**).

Типичные области (по структуре `src/AI.ML/`):

| Направление | Примеры |
|-------------|---------|
| Нейросети и тензоры | Слои, обучение, сохранение весов, интеграция с классическими структурами данных ядра. |
| Регрессия и классификация | Многомерная регрессия, учебные классификаторы. |
| Нейро-символьные и гибридные сценарии | Пространства вроде **`AI.ML.Utils.NeuralSymbolic`** (файлы в репозитории). |
| Статистические модели | HMM и др. в связке с `AI`/`ClassicMath`. |

Точный перечень классов лучше смотреть в исходниках и XML-документации сборки.

## Смежные сборки

| Сборка | Связь с ML |
|--------|------------|
| **`AI.KNN`** | Зависит от **`AI.ML`**: k-ближайших соседей и родственные сценарии. |
| **`AI.Fuzzy`** | Содержит **`AI.ML.Classification.FuzzyClassifier`** и связанные типы; сборка ссылается на **`AI.ML`** и **`AI.KNN`**. Используется из **`AI.DataPrepaire`**, **`AI.ONNX`**, **`AI.ExplainitALL`** и др. |
| **`AI.DSP`** | Ссылается на **`AI.KNN`** и **`AI.ML`** — спектры, фильтры, признаки для последующего ML. |
| **`AI.ControlSystems`** | Обратные и прямые модели объектов через регрессию из **`AI.ML`** (см. [ControlSystems.md](ControlSystems.md)). |

## Сборка

```bash
dotnet build src/AI.ClassicMath/AI.ClassicMath.csproj -c Release
dotnet build src/AI.ML/AI.ML.csproj -c Release
```

Узкоспециализированные solution-файлы: **`SLNS/AIFramework(ML).sln`**.
