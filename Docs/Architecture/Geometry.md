# Вычислительная геометрия — `AI.Geometry`

Сборка **`AI.Geometry`** (`AI.Geometry.dll`, **.NET 9.0**) предоставляет примитивы, преобразования, тесты пересечений, параметрические кривые, подгонку и конические сечения для 2D/3D-задач. Опирается на матрично-векторные типы ядра и матричные разложения из **`AI.ClassicMath`**.

---

## Зависимости

| Проект | Зачем |
|--------|--------|
| **`AI`** | Векторы, матрицы (`AI.DataStructs.Algebraic`), статистика, расширения. |
| **`AI.ClassicMath`** | SVD, LU, Холецкий, псевдообратная — используются в подгонке и гомографии. Метод Левенберга–Марквардта из `AI.MathUtils.Nonlinear` решает систему геометрических ограничений, `Eigen.Symmetric` дает главные оси тензора инерции. |

Транзитивно доступны все типы **`AI`** (ядро).

---

## Ключевые области

| Область / пространство имён | Назначение |
|------------------------------|------------|
| **`Transforms`** | Аффинные 2D/3D (`Affine2D`, `Affine3D`), гомография DLT (`Homography`), кватернионы и SLERP (`Quaternion`), углы Эйлера (`EulerAngles`), однородные координаты (`HomogeneousCoords`). У кватерниона есть экспонента и логарифм (`FromRotationVector`, `ToRotationVector`), шаг вращения по угловой скорости (`Integrate`), разность ориентаций вектором поворота (`RotationVectorBetween`) и поворот `Vector3` без выделения памяти. |
| **`Intersections`** | Пересечения: луч–треугольник (Möller–Trumbore), луч–плоскость, луч–сфера, луч–AABB (Slab), луч–OBB, прямая–прямая, прямая–плоскость, отрезок–отрезок и их общий участок (`SegmentSegmentIntersection.CommonPart`), окружность–окружность, окружность–прямая и окружность–отрезок, плоскость–плоскость, три плоскости, сфера–сфера, AABB–AABB, OBB–OBB (SAT). |
| **`Distances`** | Расстояния и ближайшие точки: точка–прямая, точка–плоскость, точка–отрезок, точка–треугольник, точка–тетраэдр, точка–AABB, точка–OBB, прямая–прямая, отрезок–отрезок, треугольник–треугольник. |
| **`Primitives`** | Геометрические типы: `Vector3`, `Ray`, `Segment`, `Line2D`, `Line3D`, `Plane`, `Sphere`, `Circle`, `Ellipse`, `Triangle`, `Aabb`, `Obb`, `Tetrahedron`. |
| **`Polygons`** | Площадь по формуле шнурков (`ShoelaceArea`), принадлежность точки полигону — ray casting и winding number (`PointInPolygon`), центроид (`PolygonCentroid`), ближайшая точка в треугольнике по барицентрическим зонам (`ClosestInTriangle`), ориентация (`Orientation2D`). Выпуклая оболочка Эндрю (`ConvexHull`), отсечение Сазерленда–Ходжмана и полуплоскостью (`PolygonClipping`), сумма Минковского выпуклых многоугольников (`MinkowskiSum`), пересечение, объединение и разность простых многоугольников (`PolygonBoolean`), расстояние до многоугольника (`PolygonDistance`), многоугольник из окружности или эллипса (`Polygonization`). |
| **`Polylines`** | Длина, расстояние и ближайшая точка ломаной (`Polyline`), упрощение Дугласа–Пекера (`DouglasPeucker`). |
| **`Triangulation`** | Ушная триангуляция многоугольника с дырами (`EarClipping`), триангуляция Делоне Боуэра–Ватсона (`Delaunay`), ячейки Вороного, обрезанные прямоугольником (`Voronoi`). |
| **`Fitting`** | Подгонка прямой: OLS, TLS (ковариационная 2×2), RANSAC (`LineFit`). Подгонка окружности: алгебраический метод Kåsa, RANSAC (`CircleFit`). |
| **`Curves`** | Кривая Безье произвольной степени — алгоритм де Кастельжо (`BezierCurve`), кусочно-кубический сплайн Эрмита (`HermiteCurve`), центрипетальный Catmull–Rom (`CatmullRomCurve`). |
| **`Conics`** | Классификация конического сечения $Ax^2+Bxy+Cy^2+Dx+Ey+F=0$ по дискриминанту $B^2-4AC$ (`ConicSection`): окружность, эллипс, парабола, гипербола, вырожденное. Конвертация из `Ellipse`/`Circle`. |
| **`Numerics`** | Вспомогательные: компенсированное суммирование Кэхана (`KahanSum`), допуск сравнения (`Eps`). Надежные предикаты ориентации и «внутри окружности» (`RobustPredicates`): фильтр по оценке ошибки Шевчука, а где он не решает, точный счет в `BigInteger`. |
| **`Hull`** | Трехмерная выпуклая оболочка Quickhull (`ConvexHull3D`): вершины, треугольные грани с внешними нормалями, проверка принадлежности. |
| **`MassProperties`** | Объем, центр масс и тензор инерции замкнутой сетки по теореме о дивергенции (`MeshMass`, метод Эберли); тензоры коробки, шара, цилиндра и капсулы, перенос по Штейнеру, поворот $R I R^T$, главные оси (`InertiaTensor`). |
| **`Spatial`** | Динамическое дерево AABB для широкой фазы (`DynamicAabbTree<T>`): вставка, обновление с запасом, запрос по коробке и по лучу, все пересекающиеся пары. |
| **`Collision`** | Столкновения выпуклых тел с данными контакта: формы с опорной функцией (`IConvexShape`: шар, коробка, капсула, цилиндр, облако точек), GJK (пересечение и расстояние), EPA (глубина и нормаль), частные генераторы с пятном касания до 4 точек (шар, плоскость, коробка по SAT с отсечением граней, капсула), диспетчер (`CollisionDispatcher`) и время удара (`TimeOfImpact`). |
| **`Constraints`** | Решатель геометрических ограничений (`GeometricSketch`): точки, прямые, окружности и свободные параметры, около двадцати видов ограничений и ограничение выражением, решение методом Левенберга–Марквардта, все ветви решения, диагноз системы (недоопределена, избыточна, противоречива) и вычисление искомого на решении (`SketchSolution`). |
| **`Sampling`** | Равномерные выборки в круге, на окружности, в треугольнике, в многоугольнике с дырами (`PlaneSampling`, `PolygonSampler`), на сфере, в шаре и коробке, распределение фон Мизеса–Фишера (`SpaceSampling`). Каждый метод принимает `Random` или готовые равномерные числа, поэтому работает и с последовательностями Холтона и Соболя из ядра. |

**`Vector3`** — значимый тип трёхмерной точки. В отличие от `Vector`, он не размещается в куче, поэтому пригоден для координат атомов и кадров траекторий, где точек десятки тысяч; переход к `Vector` и обратно — через `ToVector()` и `FromVector()`. Тип общий для репозитория: им пользуются кристаллография и молекулярная динамика в `AI.Solvers.Chem`, а также столкновения, массовые свойства и движок твердых тел.

Геометрия задачи, сказанной словами, собирается в `GeometricSketch` из записей с именами: так ее удобно строить из структурированного ответа языковой модели. Пример: касательная из точки к окружности.

```csharp
var s = new GeometricSketch();
s.AddPoint("P", 0, 0, isFixed: true);
s.AddPoint("O", 13, 0, isFixed: true);
s.AddCircle("w", "O", 5, isRadiusFixed: true);
s.AddPoint("T", 10, 3);
s.AddLine("PT", "P", "T");
s.AddLine("OT", "O", "T");
s.PointOnCircle("T", "w");
s.Perpendicular("PT", "OT");
var branches = s.SolveAll();                // две ветви: T выше и ниже оси
double tangent = branches[0].Distance("P", "T"); // 12
```

## Роль в решении

- Демо-модуль **`GeometryModule`** визуализирует все перечисленные области, включая интерактивные примеры подгонки, кривых и пересечений.
- Раздел «Линейная алгебра» в демо использует разложения из **`AI.ClassicMath`** (SVD, LU, Холецкий, псевдообратная, Якоби) в связке с геометрической визуализацией.
- **`AI.ComputerVision`** опирается на примитивы и преобразования для задач обработки изображений (аффинные маппинги, гомографии).
- Кватернионы и аффинные матрицы переиспользуются в 3D-сценариях других модулей.

## Основные типы (выборка)

| Тип | Роль |
|-----|------|
| `Quaternion` | `readonly struct`, SLERP, конвертация axis-angle / Euler / матрица вращения 3×3. |
| `Affine2D` / `Affine3D` | Однородные матрицы 3×3 / 4×4, фабрики `Translation`, `Rotation`, `Scale`, `Shear`, композиция. |
| `Homography` | Проективная матрица 3×3, оценка DLT по 4 парам точек (Гаусс 8×8). |
| `LineFit` | Статические методы `Ols`, `Tls`, `Ransac` для аппроксимации прямой. |
| `CircleFit` | Алгебраический метод Kåsa и RANSAC для окружности. |
| `BezierCurve` | `Evaluate(t)` — де Кастельжо для произвольной степени. |
| `ConicSection` | `Classify()` → `ConicType`, параметрическая выборка `Sample(n)`. |
