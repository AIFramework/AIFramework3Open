# Вычислительная геометрия — `AI.Geometry`

Сборка **`AI.Geometry`** (`AI.Geometry.dll`, **.NET 9.0**) предоставляет примитивы, преобразования, тесты пересечений, параметрические кривые, подгонку и конические сечения для 2D/3D-задач. Опирается на матрично-векторные типы ядра и матричные разложения из **`AI.ClassicMath`**.

---

## Зависимости

| Проект | Зачем |
|--------|--------|
| **`AI`** | Векторы, матрицы (`AI.DataStructs.Algebraic`), статистика, расширения. |
| **`AI.ClassicMath`** | SVD, LU, Холецкий, псевдообратная — используются в подгонке и гомографии. |

Транзитивно доступны все типы **`AI`** (ядро).

---

## Ключевые области

| Область / пространство имён | Назначение |
|------------------------------|------------|
| **`Transforms`** | Аффинные 2D/3D (`Affine2D`, `Affine3D`), гомография DLT (`Homography`), кватернионы и SLERP (`Quaternion`), углы Эйлера (`EulerAngles`), однородные координаты (`HomogeneousCoords`). |
| **`Intersections`** | Пересечения: луч–треугольник (Möller–Trumbore), луч–плоскость, луч–сфера, луч–AABB (Slab), луч–OBB, прямая–прямая, прямая–плоскость, отрезок–отрезок, плоскость–плоскость, три плоскости, сфера–сфера, AABB–AABB, OBB–OBB (SAT). |
| **`Distances`** | Расстояния: точка–прямая, точка–плоскость, точка–отрезок, точка–треугольник, точка–тетраэдр, прямая–прямая. |
| **`Primitives`** | Геометрические типы: `Ray`, `Segment`, `Line2D`, `Line3D`, `Plane`, `Sphere`, `Circle`, `Ellipse`, `Triangle`, `Aabb`, `Obb`, `Tetrahedron`. |
| **`Polygons`** | Площадь по формуле шнурков (`ShoelaceArea`), принадлежность точки полигону — ray casting и winding number (`PointInPolygon`), центроид (`PolygonCentroid`), ближайшая точка в треугольнике по барицентрическим зонам (`ClosestInTriangle`), ориентация (`Orientation2D`). |
| **`Fitting`** | Подгонка прямой: OLS, TLS (ковариационная 2×2), RANSAC (`LineFit`). Подгонка окружности: алгебраический метод Kåsa, RANSAC (`CircleFit`). |
| **`Curves`** | Кривая Безье произвольной степени — алгоритм де Кастельжо (`BezierCurve`), кусочно-кубический сплайн Эрмита (`HermiteCurve`), центрипетальный Catmull–Rom (`CatmullRomCurve`). |
| **`Conics`** | Классификация конического сечения $Ax^2+Bxy+Cy^2+Dx+Ey+F=0$ по дискриминанту $B^2-4AC$ (`ConicSection`): окружность, эллипс, парабола, гипербола, вырожденное. Конвертация из `Ellipse`/`Circle`. |
| **`Numerics`** | Вспомогательные: компенсированное суммирование Кэхана (`KahanSum`), допуск сравнения (`Eps`). |

---

## Роль в решении

- Демо-модуль **`GeometryModule`** визуализирует все перечисленные области, включая интерактивные примеры подгонки, кривых и пересечений.
- Раздел «Линейная алгебра» в демо использует разложения из **`AI.ClassicMath`** (SVD, LU, Холецкий, псевдообратная, Якоби) в связке с геометрической визуализацией.
- **`AI.ComputerVision`** опирается на примитивы и преобразования для задач обработки изображений (аффинные маппинги, гомографии).
- Кватернионы и аффинные матрицы переиспользуются в 3D-сценариях других модулей.

---

## Основные типы (выборка)

| Тип | Роль |
|-----|------|
| `Quaternion` | `readonly struct`, SLERP, конвертация axis-angle / Euler / матрица вращения 3×3. |
| `Affine2D` / `Affine3D` | Однородные матрицы 3×3 / 4×4, фабрики `Translation`, `Rotation`, `Scale`, `Shear`, композиция. |
| `Homography` | Проективная матрица 3×3, оценка DLT по 4 парам точек (Гаусс 8×8). |
| `LineFit` | Статические методы `Ols`, `Tls`, `Ransac` для аппроксимации прямой. |
| `CircleFit` | Алгебраический метод Kåsa и RANSAC для окружности. |
| `BezierCurve` | `Evaluate(t)` — де Кастельжо для произвольной степени. |
| `ConicSection` | `Classify()` → `ConicType`, параметрическая выборка `Sample(n)`. |
