# Биология `AI.Biology` (AI.Biology.dll)

Сборка **`AI.Biology`** (`AI.Biology.dll`, **.NET 9.0**) — молекулярная биология,
популяционная генетика, динамика популяций, эпидемиология и экология сообществ.

Зависит от ядра **`AI`** (статистические критерии, контракт объяснимости) и от
**`AI.ClassicMath`** (интегрирование систем ОДУ).

---

## Что взято из репозитория, а не написано заново

| Нужное | Откуда берётся |
|--------|----------------|
| Интегрирование систем ОДУ для моделей популяций и эпидемий | `AI.MathUtils.ODE.RungeKutta.SolveSystem` |
| Критерий хи-квадрат для равновесия Харди — Вайнберга и расщепления по Менделю | `AI.Statistics.StatInference` |
| Фармакокинетика, ферментная кинетика, газы крови | `AI.Solvers.Chem/Processors/Medical` — эти расчёты уже есть в химии, здесь их нет |
| Анализ выживаемости: Каплан — Мейер, Кокс, конкурирующие риски | `AI.Economics/Survival` — методы общие, для клинических данных берите их |

Разделение по медицинской части намеренное: то, что считается через химию вещества
(концентрации, дозы, кислотно-щелочное равновесие), живёт в химическом модуле; то, что
считается через популяцию (заболеваемость, иммунная прослойка, наследование), — здесь.

## Состав

| Область | Тип | Назначение |
|---------|-----|------------|
| Последовательности | **`NucleotideSequence`** | ДНК и РНК: состав, доля G+C, обратный комплемент, транскрипция, k-меры, температура плавления. |
| Последовательности | **`GeneticCode`** | Стандартный код, трансляция по рамкам, поиск открытых рамок считывания, вырожденность. |
| Последовательности | **`Alignment`** | Глобальное выравнивание по Нидлману — Вуншу, локальное по Смиту — Уотерману, аффинный штраф за пропуск, расстояние Хэмминга. |
| Генетика | **`HardyWeinberg`** | Частоты аллелей, проверка равновесия, частота носителей. Реализует `IInterpretable`. |
| Генетика | **`Mendel`** | Моно- и дигибридное расщепление, проверка соответствия, частота рекомбинации и карта. |
| Популяции | **`PopulationGrowth`** | Экспоненциальный и логистический рост, время удвоения, точка перегиба. |
| Популяции | **`LotkaVolterra`** | Колебания «хищник — жертва», положение равновесия. |
| Эпидемии | **`EpidemicModels`** | Модель SIR, базовое репродуктивное число, порог коллективного иммунитета, итоговый размер вспышки. Результат реализует `IInterpretable`. |
| Экология | **`Diversity`** | Богатство, индексы Шеннона и Симпсона, выравненность Пиелу, оценка Чао, меры Жаккара и Брея — Кёртиса. |

```csharp
using AI.Biology.Sequences;

var gene = new NucleotideSequence("ATGGCCATTGTAATGGGCCGCTGA");
string protein = GeneticCode.Translate(gene.Transcribe());   // MAIVMGR

using AI.Biology.Populations;

EpidemicResult outbreak = EpidemicModels.Sir(transmissionRate: 0.4, recoveryRate: 0.1);
Console.WriteLine(outbreak.Interpret());   // R₀ = 4, пик, порог, итоговый охват
```

## Проверка

Тесты опираются на тождества и на данные, известные независимо от реализации:

* обратный комплемент — обратная сама себе операция, и доля G+C у обеих цепей одинакова;
* стандартный код переводит `AUGGCCAUUGUAAUGGGCCGCUGA` в `MAIVMGR`, лейцин кодируется
  шестью кодонами, метионин — одним;
* локальное выравнивание находит общий участок `GATTACA` в разном окружении;
* подлинные данные Менделя — 705 : 224 по одному признаку и 315 : 108 : 101 : 32 по двум —
  согласуются с ожидаемым расщеплением, а искусственное 500 : 500 отвергается;
* сумма долей в модели SIR сохраняется на всём протяжении счёта;
* итоговая доля переболевших, полученная численно, совпадает с корнем неявного уравнения
  `1 − R = exp(−R₀·R)`;
* система «хищник — жертва», запущенная из точки равновесия, в ней и остаётся;
* индекс Шеннона при равном обилии видов равен натуральному логарифму их числа.

## Границы применимости

Последовательности хранятся строкой и не допускают неоднозначных символов кода IUPAC:
для геномных данных с неопределёнными позициями нужен другой тип. Выравнивание требует
памяти и времени порядка произведения длин — для миллионов нуклеотидов нужны приближённые
методы на общих словах, которых здесь нет. Генетический код только стандартный:
митохондриальный и прочие варианты отличаются несколькими кодонами и дали бы неверный белок
молча.

Модели популяций и эпидемий детерминированы и предполагают однородную, хорошо перемешанную
среду. Для малых популяций, где важна случайность отдельных событий, и для сетей контактов
нужны стохастические и сетевые модели — это область фазы «симуляция», которой в репозитории
пока нет.

Из медицины здесь только популяционная часть. Клинических шкал, диагностических критериев
и рекомендаций по лечению нет и не планируется: такие расчёты требуют иной ответственности,
чем библиотека алгоритмов может нести.
