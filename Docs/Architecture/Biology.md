# Биология `AI.Biology` (AI.Biology.dll)

Сборка **`AI.Biology`** (`AI.Biology.dll`, **.NET 9.0**) — молекулярная биология, структурная
биология, филогения, популяционная генетика, динамика популяций и эпидемий, экология сообществ
и сетевые модели клетки.

Зависит от ядра **`AI`** (статистические критерии, контракт объяснимости), от **`AI.ClassicMath`**
(интегрирование ОДУ), **`AI.Geometry`** (трёхмерные векторы), **`AI.Solvers.Chem`** (структуры,
совмещение, кинетика) и **`AI.Solvers.Optimization`** (симплекс).

| Эпидемии на сетях контактов, агентные модели | `AI.Simulation.Space` — сети Эрдёша — Реньи, Уоттса — Строгаца, Барабаши — Альберт и модель Рида — Фроста |

Разделение по медицинской части намеренное: то, что считается через химию вещества
(концентрации, дозы, кислотно-щелочное равновесие), живёт в химическом модуле; то, что
считается через популяцию (заболеваемость, иммунная прослойка, наследование), — здесь.

## Состав

| Область | Тип | Назначение |
|---------|-----|------------|
| Последовательности | **`NucleotideSequence`** | ДНК и РНК: состав, доля G+C, обратный комплемент, транскрипция, k-меры, температура плавления. |
| Последовательности | **`GeneticCode`** | Стандартный код, трансляция по рамкам, поиск открытых рамок считывания, вырожденность. |
| Последовательности | **`Alignment`** | Нидлман — Вунш и Смит — Уотерман с аффинным штрафом по Гото, для нуклеотидов — совпадение и несовпадение, для белков — матрица замен. `AlignmentResult` реализует `IInterpretable`. |
| Последовательности | **`SubstitutionMatrix`**, **`AminoAcids`** | BLOSUM62; одно- и трёхбуквенные коды, гидропатичность Кайта — Дулиттла и её профиль. |
| Последовательности | **`ProgressiveAlignment`**, **`MultipleAlignment`** | Множественное выравнивание по дереву-ориентиру (UPGMA или присоединение соседей) с уточнением по разбиениям дерева; сумма по парам, точность относительно эталона (доли верных пар и столбцов), FASTA, переход к матрице расстояний. `MultipleAlignment` реализует `IInterpretable`. |
| Структуры | **`ProteinStructure`** | Белок из PDB по остаткам: последовательность, φ, ψ, ω, трасса Cα, радиус инерции, карта контактов, контактный порядок. |
| Структуры | **`BackboneBuilder`** | Идеальная основная цепь по двугранным углам (Энгх — Хубер, NeRF). |
| Структуры | **`SecondaryStructure`** | DSSP: водородные связи основной цепи, спирали H, G, I, β-лестницы и мостики, повороты и изгибы. Результат реализует `IInterpretable`. |
| Структуры | **`StructureComparison`** | RMSD после совмещения и TM-мера с поиском совмещения по фрагментам. |
| Структуры | **`RnaFolding`** | Укладка РНК по Нуссинову, скобочная запись, расстояние по парам оснований. |
| Филогения | **`EvolutionaryDistance`**, **`DistanceMatrix`** | p-расстояние, Джукс — Кантор, Кимура, пуассоновская поправка для белков; условия аддитивности и ультраметричности. |
| Филогения | **`PhylogeneticTree`** | Дерево, Newick, расстояния по дереву, разбиения, расстояние Робинсона — Фулдса, перенос корня. |
| Филогения | **`TreeBuilder`** | UPGMA и присоединение соседей. |
| Филогения | **`Parsimony`**, **`TreeLikelihood`** | Экономия по Фитчу — Хартигану; правдоподобие Фельзенштейна по JC69 и K80, подбор длин ветвей. |
| Филогения | **`SequenceEvolution`**, **`Bootstrap`** | Моделирование эволюции вдоль дерева — заменами, а также вставками и делециями с истинным выравниванием листьев; бутстреп-поддержка ветвей (`IInterpretable`). |
| Генетика | **`HardyWeinberg`**, **`Mendel`** | Частоты аллелей, проверка равновесия, частота носителей; расщепление, рекомбинация, карта. |
| Популяции | **`PopulationGrowth`**, **`LotkaVolterra`** | Экспоненциальный и логистический рост; «хищник — жертва». |
| Эпидемии | **`EpidemicModels`** | SIR, R₀, порог коллективного иммунитета, итоговый размер вспышки. |
| Экология | **`Diversity`** | Богатство, Шеннон, Симпсон, Пиелу, Чао, Жаккар, Брей — Кёртис. |
| Сети | **`BooleanNetwork`** | Булевы генные сети: правила формулами, аттракторы и бассейны полным перебором. |
| Сети | **`MetabolicNetwork`** | Балансовый анализ потоков, вариабельность потоков, незаменимые реакции. `FluxBalanceResult` реализует `IInterpretable`. |
| Сети | **`GeneExpression`** | Двухстадийная стохастическая экспрессия: схема, моделирование по Гиллеспи, стационарные моменты. |

## Проверка

Тесты — `BiologyTests`, `MultipleAlignmentTests`, `StructuralBiologyTests`, `PhylogenyTests`,
`BiologicalNetworksTests` (105 тестов с учётом вариантов), плюс тесты химии на разбор PDB и кинетику. Ответы сверяются с
тем, что известно независимо от реализации.

**Последовательности.** Выравнивание сверяется с полным перебором всех выравниваний коротких
строк при четырёх схемах счёта, а найденное выравнивание пересчитывается независимо и обязано
дать заявленный счёт; то же для белков с BLOSUM62 и для локального выравнивания по всем парам
подстрок. Итоговый размер вспышки сверяется с делением отрезка пополам при R₀ от 1,01 до 10.

**Множественное выравнивание.** Для двух последовательностей оно совпадает с попарным оптимумом,
для трёх — не превосходит точного оптимума суммы по парам, найденного трёхмерным
программированием, и достигает его в очевидном случае. Сумма по парам пересчитывается
независимо, уточнение её не уменьшает. На семействе из восьми последовательностей, смоделированном
со вставками и делециями, истинное выравнивание известно по построению: при идентичности около
80 % верно выровнено 98 % пар остатков и 94 % столбцов — намного больше, чем у последовательностей,
просто прижатых к левому краю; дерево, построенное по найденному выравниванию, совпадает с истинным.

**Структуры.** Цепь, построенная по случайным углам, при измерении даёт те же φ, ψ, ω с
точностью 10⁻⁶°, а длины связей — табличные. Идеальная α-спираль имеет расстояние Cα–Cα 3,80 Å,
связь O(i)–N(i+4) от 2,7 до 3,3 Å, подъём около 1,5 Å на остаток, и DSSP отмечает её как H;
β-цепь вытянута на 6–7 Å через остаток и не даёт ни H, ни E. DSSP на известных наборах
водородных связей даёт известные коды для α-спирали, спирали 3₁₀, поворота, параллельной и
антипараллельной лестниц и изолированного мостика. Файл PDB с двумя моделями, альтернативным
положением атома и водой читается в правильные остатки. TM-мера жёсткой копии равна единице, а на
структуре со сдвинутой половиной поиск находит совмещение по сохранной половине — лучше, чем
совмещение по всем остаткам. Укладка по Нуссинову сверяется с перебором всех структур.

**Филогения.** Расстояния, снятые со случайного дерева, аддитивны, и присоединение соседей
восстанавливает по ним топологию и длины ветвей точно; UPGMA точно восстанавливает
ультраметричные деревья и ошибается на дереве с неравными скоростями, где присоединение соседей
право. Экономия сверяется с перебором состояний внутренних узлов. Правдоподобие позиции
сверяется с суммой по всем состояниям внутренних узлов, где вероятности перехода считаются
экспонентой матрицы скоростей, а не формулой библиотеки; не меняется при переносе корня;
у двух таксонов совпадает с формулой. Длины ветвей, подобранные по смоделированным данным,
возвращают истинные с точностью 0,02, а истинная топология правдоподобнее обеих других.
Бутстреп на длинном выравнивании поддерживает все истинные ветви.

**Сети.** Переключатель из двух генов имеет две неподвижные точки и цикл длины два,
репрессилятор — циклы длины шесть и два без неподвижных точек; на случайных сетях аттракторы
и бассейны совпадают с прямым моделированием из каждого состояния. Балансовый анализ на
транспортной сети совпадает с максимальным потоком по алгоритму Диница из `AI.Algorithms`,
на игрушечной сети — с ручным расчётом оптимума, вариабельности и незаменимых реакций. Метод
Гиллеспи даёт для рождения и гибели распределение Пуассона (дисперсия равна среднему), для
димеризации — ожидание первого события 1/45 при десяти молекулах, для линейной схемы — среднее,
совпадающее с уравнениями скорости; шум белка в двухстадийной модели совпадает с формулой
Таттая — ван Ауденардена.

## Что было исправлено

- **Выравнивание.** Обратный ход шёл по наибольшему значению в клетке, а не по состояниям Гото,
  и при аффинном штрафе выравнивание могло не совпадать со своим счётом; переход «пропуск в одной
  строке — пропуск в другой» был запрещён, и оптимум иногда терялся.
- **Итоговый размер вспышки** искался простой итерацией с фиксированным числом шагов и вблизи
  порога не сходился: при R₀ = 1,01 ошибка превышала сам ответ. Теперь — метод Ньютона.
- **Модели с одной точкой вывода** делили на ноль и молча возвращали NaN.
- **Разбор PDB в химии** не читал остатки и цепи и складывал атомы всех моделей многомодельного
  файла в одну структуру.

## Границы применимости

Последовательности хранятся строкой и не допускают неоднозначных символов кода IUPAC.
Выравнивание требует памяти и времени порядка произведения длин. Множественное выравнивание
прогрессивное: без весов последовательностей и позиционных штрафов за пропуск, уточнение ведётся
по сумме по парам. На смоделированных семействах уточнение поднимает эту сумму, но точность
относительно истинного выравнивания меняет лишь на один-два процента в обе стороны; найденная
сумма по парам обычно ниже, чем у истинного выравнивания, — метод эвристический. У далёких
последовательностей с идентичностью около 60 % верно выравнивается около 85 % пар и лишь около
60 % столбцов.
Матрица замен одна — BLOSUM62 для двадцати стандартных аминокислот. Генетический код только
стандартный.

Структурная часть работает с основной цепью: боковых цепей, энергий, упаковки и предсказания
структуры нет. DSSP — правила 1983 года без β-выпячиваний. TM-мера требует известного
соответствия остатков: выравнивания структур (TM-align) нет. Укладка РНК по Нуссинову считает
пары, а не свободную энергию: параметров Тёрнера и алгоритма Цукера нет, псевдоузлов тоже.

Филогения — нуклеотидные модели JC69 и K80 с равными частотами; нет HKY, GTR, неоднородности
скоростей по позициям и поиска топологии по правдоподобию или экономии — деревья сравниваются,
но не ищутся перебором. Бутстреп — только для деревьев по расстояниям.

Булевы сети — синхронное обновление и полный перебор, генов не больше двадцати. Балансовый
анализ ограничен плотным симплексом: сеть на тысячи реакций решится, но медленно. Метод
Гиллеспи точен, но медленен на схемах с быстрыми и медленными реакциями: τ-скачков нет.

Модели популяций и эпидемий на ОДУ детерминированы и предполагают хорошо перемешанную среду;
стохастические и сетевые эпидемии — в `AI.Simulation`. Величины здесь — голые числа, слой
единиц `AI.Units` не подключён.

Из медицины здесь только популяционная часть. Клинических шкал, диагностических критериев
и рекомендаций по лечению нет и не планируется: такие расчёты требуют иной ответственности,
чем библиотека алгоритмов может нести.
