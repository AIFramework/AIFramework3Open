# Наблюдатель Люенбергера

**Пространство имён:** `AI.ControlSystems.Observers`  
**Класс:** `LuenbergerObserver`

---

## Теория

### Назначение наблюдателя

В реальных системах вектор состояния $x$ часто недоступен для непосредственного измерения — датчики формируют только выход $y = Cx + Du$. Наблюдатель восстанавливает оценку $\hat x$, которая экспоненциально сходится к истинному вектору состояния $x$.

### Уравнение наблюдателя

Дискретный наблюдатель Люенбергера:

$$\hat x[k+1] = A\hat x[k] + Bu[k] + L\bigl(y[k] - C\hat x[k] - Du[k]\bigr)$$

Разность $y - C\hat x - Du$ называется **инновацией** (невязкой). Матрица $L$ (n×p) — **матрица усиления наблюдателя** — определяет скорость сходимости.

### Ошибка наблюдения

Обозначим $\tilde x = x - \hat x$. Тогда:

$$\tilde x[k+1] = (A - LC)\,\tilde x[k]$$

Ошибка затухает, если все собственные значения $(A - LC)$ лежат внутри единичного круга. Матрицу $L$ выбирают так, чтобы полюса наблюдателя были **быстрее** полюсов регулятора (обычно в 2–5 раз).

### Выбор L

- Для SISO можно использовать формулу Аккермана (двойственная задача: заменить $A \to A^\top$, $B \to C^\top$).
- Для MIMO — решение уравнения Риккати (см. `KalmanFilter` — оптимальный выбор L).
- Эмпирически: разместить полюса $(A - LC)$ в желаемых точках.

---

## API

| Член | Описание |
|------|----------|
| `LuenbergerObserver(A, B, C, L)` | Без D, нулевая начальная оценка. |
| `LuenbergerObserver(A, B, C, L, x0)` | С начальной оценкой. |
| `LuenbergerObserver(A, B, C, D, L, x0)` | Полная форма с D. |
| `Step(u, y)` | Один шаг: обновляет `State` по управлению `u` и измерению `y`. |
| `State` | Текущая оценка $\hat x$. |
| `Reset()` | Сброс оценки в ноль. |

## Примеры

### Наблюдатель для двойного интегратора

```csharp
using AI.ControlSystems.Linear;
using AI.ControlSystems.Observers;
using AI.DataStructs.Algebraic;

// Дискретный двойной интегратор (dt = 0.01)
var A = new Matrix(new double[,] { { 1, 0.01 }, { 0, 1 } });
var B = new Matrix(new double[,] { { 0.00005 }, { 0.01 } });
var C = new Matrix(new double[,] { { 1, 0 } });  // измеряем только x1

// Матрица усиления наблюдателя (подобрана вручную)
// Полюса (A - LC) ≈ {0.5, 0.5} — быстрее объекта
var L = new Matrix(new double[,] { { 0.9 }, { 0.45 } });

var observer = new LuenbergerObserver(A, B, C, L);

// Симуляция
var plant = new DiscreteLtiModel(A, B, C);
var u = new Vector(new[] { 1.0 });

for (int k = 0; k < 100; k++)
{
    Vector y = plant.Step(u);          // истинный выход
    observer.Step(u, y);               // шаг наблюдателя

    Vector trueX  = plant.State;
    Vector estX   = observer.State;
    double err = trueX[1] - estX[1];  // ошибка оценки x2 (скорость)
    Console.WriteLine($"k={k:D3}  x2={trueX[1]:F4}  x̂2={estX[1]:F4}  err={err:F4}");
}
```

### Совместное использование с регулятором

```csharp
// Регулятор по оценке состояния: u = -K x̂
double k1 = 0.5, k2 = 0.1;

for (int step = 0; step < 200; step++)
{
    Vector xHat = observer.State;
    double uVal = -(k1 * xHat[0] + k2 * xHat[1]);
    var uVec = new Vector(new[] { uVal });

    Vector y = plant.Step(uVec);
    observer.Step(uVec, y);
}
```

## Замечания

- Матрица `L` должна быть n×p (строк — порядок системы, столбцов — число измерений).
- Если $D \ne 0$, используйте конструктор с явным `D`.
- При неизвестном начальном состоянии ошибка $\tilde x[0]$ может быть большой, но при правильно выбранной $L$ она экспоненциально убывает.
- Для оптимального выбора $L$ при шумных измерениях используйте `KalmanFilter`.
