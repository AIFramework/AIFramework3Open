# Регулятор скользящего режима

**Пространство имён:** `AI.ControlSystems.Nonlinear`  
**Класс:** `SlidingModeController`

---

## Теория

### Принцип скользящего режима

Скользящий режим (Sliding Mode Control, SMC) — нелинейный метод управления с высокой робастностью к неопределённостям модели и внешним возмущениям. Метод основан на выведении траектории системы на специальную поверхность в пространстве состояний и удержании её на этой поверхности.

### Поверхность скольжения

Для системы второго порядка (или SISO с ошибкой $e = r - y$) определяется поверхность:

$$s = e + \lambda\dot e$$

где $\lambda > 0$ — вес на производной ошибки. При $s = 0$ ошибка затухает с постоянной времени $1/\lambda$.

В дискретной реализации производная аппроксимируется разностью:

$$\dot e \approx \frac{e[k] - e[k-1]}{\Delta t}$$

### Релейный закон управления

$$u = -k \cdot \mathrm{sign}(s)$$

Знаковая функция обеспечивает «притяжение» к поверхности $s = 0$, но вызывает **чаттеринг** (высокочастотные переключения).

### Сглаживание (sat-функция)

Для уменьшения чаттеринга вместо $\mathrm{sign}(s)$ используется насыщение:

$$\mathrm{sat}\!\left(\frac{s}{\Phi}\right) = \begin{cases} 1, & s > \Phi \\ s/\Phi, & |s| \le \Phi \\ -1, & s < -\Phi \end{cases}$$

Параметр $\Phi$ — ширина «пограничного слоя». Внутри него управление линейное (как ПД-регулятор), снаружи — релейное.

---

## API

| Член | Описание |
|------|----------|
| `Lambda` | Вес производной ошибки в $s$ ($\lambda \ge 0$, по умолчанию 1). |
| `Gain` | Усиление $k > 0$ (по умолчанию 1). |
| `SmoothingBoundary` | Ширина пограничного слоя $\Phi$ (0 = чистый релейный закон). |
| `Compute(setpoint, measured, dt)` | Один шаг: возвращает $u$. |
| `Reset()` | Сброс истории. |

## Примеры

### Базовый скользящий режим

```csharp
using AI.ControlSystems.Nonlinear;

var smc = new SlidingModeController
{
    Lambda = 5.0,   // постоянная поверхности скольжения
    Gain   = 10.0   // усиление
};

double setpoint = 1.0;
double y = 0.0;
double dt = 0.001;

for (int k = 0; k < 2000; k++)
{
    double u = smc.Compute(setpoint, y, dt);
    // Простой объект первого порядка: dy/dt = -y + u
    y += (-y + u) * dt;

    if (k % 200 == 0)
        Console.WriteLine($"k={k:D4}  y={y:F4}  u={u:F4}");
}
```

### Со сглаживанием (без чаттеринга)

```csharp
var smc = new SlidingModeController
{
    Lambda             = 5.0,
    Gain               = 10.0,
    SmoothingBoundary  = 0.1   // пограничный слой ±0.1
};
```

### Нелинейный объект

```csharp
// Объект: ÿ = -0.5ẏ + u + 0.3*sin(t) (возмущение)
double y = 0, dy = 0, t = 0;
double dt = 0.001;

var smc = new SlidingModeController { Lambda = 3, Gain = 15, SmoothingBoundary = 0.05 };

for (int k = 0; k < 5000; k++)
{
    t += dt;
    double u = smc.Compute(setpoint: 1.0, measured: y, dt: dt);
    double ddy = -0.5 * dy + u + 0.3 * Math.Sin(t);
    dy += ddy * dt;
    y  += dy  * dt;

    if (k % 500 == 0)
        Console.WriteLine($"t={t:F2}  y={y:F4}  u={u:F4}");
}
```

## Замечания

- SMC робастен к ограниченным возмущениям и неточностям модели, но требует знания верхней границы возмущения для выбора $k$.
- Чаттеринг может повредить механические приводы — всегда используйте `SmoothingBoundary > 0` в реальных системах.
- При $\lambda = 0$ поверхность $s = e$ — это просто знаковый регулятор (релейный).
- Для систем высокого порядка поверхность скольжения можно обобщить: $s = e^{(n-1)} + c_{n-2}e^{(n-2)} + \cdots + c_0 e$.
