# Адаптивный регулятор с эталонной моделью (MRAC)

**Пространство имён:** `AI.ControlSystems.Adaptive`  
**Класс:** `ModelReferenceAdaptiveController`

---

## Теория

### Принцип MRAC

**Model Reference Adaptive Control (MRAC)** — класс адаптивных регуляторов, в которых желаемое поведение системы задаётся **эталонной моделью**. Параметры регулятора адаптируются так, чтобы выход объекта $y$ следовал выходу эталонной модели $y_m$.

### Эталонная модель

Желаемая динамика первого порядка:

$$\dot y_m = -a_m y_m + a_m r$$

где $r$ — задающее воздействие, $a_m > 0$ — полюс эталонной модели (скорость отклика). В дискретной форме:

$$y_m[k+1] = y_m[k] + (-a_m y_m[k] + a_m r[k])\,\Delta t$$

### Объект управления

Упрощённая модель первого порядка:

$$\dot y = a\,y + b\,u$$

где $a$, $b$ — неизвестные параметры. Управление: $u = \theta \cdot r$ (один адаптируемый параметр).

### Закон адаптации (MIT-правило)

Ошибка слежения: $e_m = y_m - y$. Параметр $\theta$ обновляется по градиентному правилу:

$$\dot\theta = -\gamma\,e_m\,\frac{\partial e_m}{\partial \theta} = -\gamma\,e_m\,r$$

В дискретной форме:

$$\theta[k+1] = \theta[k] - \gamma\,e_m[k]\,r[k]\,\Delta t$$

## API

| Член | Описание |
|------|----------|
| `AdaptationGain` | Коэффициент адаптации $\gamma > 0$ (по умолчанию 0.1). |
| `ReferencePole` | Полюс эталонной модели $a_m > 0$ (по умолчанию 1). |
| `Theta` | Текущий адаптируемый параметр $\theta$. |
| `ReferenceOutput` | Текущий выход эталонной модели $y_m$. |
| `Compute(r, y, dt)` | Один шаг: обновляет $y_m$ и $\theta$, возвращает $u = \theta \cdot r$. |
| `Reset(y0)` | Сброс эталонной модели в начальное значение. |

## Примеры

### Базовый MRAC

```csharp
using AI.ControlSystems.Adaptive;

var mrac = new ModelReferenceAdaptiveController
{
    AdaptationGain = 0.5,
    ReferencePole  = 2.0,   // эталон: постоянная времени 0.5 с
    Theta          = 1.0    // начальная оценка усиления
};

double y = 0.0;
double dt = 0.01;
double r = 1.0;  // ступенчатое задание

// Реальный объект: dy/dt = -1.5*y + 3*u (a=-1.5, b=3 — неизвестны регулятору)
for (int k = 0; k < 500; k++)
{
    double u = mrac.Compute(r, y, dt);
    y += (-1.5 * y + 3.0 * u) * dt;

    if (k % 50 == 0)
        Console.WriteLine($"k={k:D3}  y={y:F4}  ym={mrac.ReferenceOutput:F4}  theta={mrac.Theta:F4}");
}
```

### Адаптация при изменении объекта

```csharp
// Объект меняет усиление в середине эксперимента
for (int k = 0; k < 1000; k++)
{
    double b = k < 500 ? 3.0 : 1.5;  // усиление объекта изменилось
    double u = mrac.Compute(r, y, dt);
    y += (-1.5 * y + b * u) * dt;
}
// Theta адаптируется к новому усилению
```

### Влияние коэффициента адаптации

```csharp
// Малый gamma — медленная адаптация, устойчивая
mrac.AdaptationGain = 0.1;

// Большой gamma — быстрая адаптация, возможны колебания
mrac.AdaptationGain = 5.0;
```

## Замечания

- Реализация учебная: один адаптируемый параметр $\theta$ (масштаб входа). Для полного MRAC нужны дополнительные параметры.
- MIT-правило может быть нестабильным при большом $\gamma$ или изменяющемся $r$. Для гарантированной устойчивости используют нормализованное правило адаптации.
- `ReferencePole` $a_m$ задаёт желаемую скорость отклика: постоянная времени эталона $\tau_m = 1/a_m$.
- Для систем высокого порядка или MIMO необходимо расширение алгоритма.
