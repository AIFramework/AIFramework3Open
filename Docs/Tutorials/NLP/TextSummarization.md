# `TextSummarization.cs` — `TextSummarization` и `DataSummText`

## Теория

**Извлекательная суммаризация** на основе частот слов.

1. **Разбиение на предложения** (`GetSeqs`): эвристики для скобок, типичных сокращений, удаление паттернов (инициалы, сноски в квадратных скобках), приведение `!`/`?` к `.`, разрез по `.`, обрезка фрагментов и добавление точки в конец фрагмента (через `Transform` из `AI.Extensions`).

2. Для каждого предложения и для объединённого текста строятся таблицы **`ProbabilityDictionary`** (один и тот же экземпляр словаря в поле класса; при последовательных вызовах учитывайте сброс состояния внутри `Run`).

3. **Вес предложения** (внутренний `GetW`): для слов предложения сравниваются «локальные» вероятности в предложении и в целом тексте; используется схема вида среднего отношения глобальной частоты к локальной (при нулевой локальной вероятности возможны исключения — они подавляются в `Step2`).

4. Предложения сортируются по убыванию веса; в **`Summarization`** возвращаются первые `num` предложений (склеенные с `\n\n`).

Класс **`DataSummText`** хранит пару строка предложения и вес `W`.

## API

| Член | Описание | Пример |
|------|----------|--------|
| `TextSummarization()` | Конструктор. | `var s = new TextSummarization();` |
| `Summarization(text, num)` | Вернуть до `num` предложений-резюме. | `string r = s.Summarization(article, 3);` |
| `static GetSeqs(string text)` | Массив предложений после эвристик. | `string[] seqs = TextSummarization.GetSeqs(text);` |
| `DataSummText.Str`, `DataSummText.W` | Текст и вес (если используете `DataSummText` сами). | — |
