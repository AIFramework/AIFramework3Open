# `Stemmers/WordEndingsRU.cs` — `WordEndingsRU`

## Постановка задачи

Русский стеммер отсекает от словоформы изменяемую часть. Иногда нужен не
результат отсечения (основа), а **сама отсечённая часть** — «окончание» в
широком смысле: окончание вместе с формообразующими суффиксами.

Такой срез полезен, чтобы посмотреть, что именно стеммер считает
изменяемым: по распределению отсечённых хвостов сразу видно, где правила
`StemmerRus` срабатывают слишком агрессивно.

## Теория

Для каждого слова $w$ вычисляется разность с его основой:

$$
\mathrm{ending}(w) \;=\; w \setminus \mathrm{stem}(w),
$$

где $\mathrm{stem}$ — правиловый стеммер `StemmerRus.TransformingWord`, а
$\setminus$ — операция `Diff` из [StringExtention.md](StringExtention.md),
возвращающая хвост строки после общего префикса.

Порядок обработки:

1. `TextStandard.OnlyRusChars` — отбрасываются цифры, латиница и пунктуация;
2. разбиение по пробелам;
3. для каждого слова вычисляется `words[i].Diff(StemmerRus.TransformingWord(words[i]))`;
4. если `Diff` бросает исключение, подставляется пустая строка.

Это лингвистический инструмент для экспериментов и отладки стеммера, а не
морфологический анализатор: «окончание» здесь определено алгоритмически и
не обязано совпадать с грамматическим окончанием.

## Сложность

Время $O(L)$, где $L$ — суммарная длина текста в символах: и фильтрация, и
стемминг, и `Diff` линейны по длине слова. Память $O(k)$ по числу слов $k$.

## API

| Метод | Описание | Пример |
|-------|----------|--------|
| `static Endings(string text)` | Массив «окончаний» по словам строки | `WordEndingsRU.Endings("мышь бежит");` |

Исходник: `src/AI.NLP/Stemmers/WordEndingsRU.cs`.

## Код

```csharp
using AI.NLP.Stemmers;

string[] endings = WordEndingsRU.Endings("нейронные сети обучаются быстро");

foreach (string e in endings)
    Console.WriteLine($"«{e}»");   // «ые», «и», «аются», «о»
```

## Ограничения

- Результат целиком определяется правилами `StemmerRus`: для слов с
  чередованием в корне «окончание» захватит часть корня.
- Слова без изменяемой части дают пустую строку — отличить их от ошибки
  `Diff` по выходу нельзя.
- Работает только с кириллицей: латиница отбрасывается на первом шаге.
