# `TFIDF.cs` — класс `TFIDF`

## Теория

**TF‑IDF** комбинирует локальную частоту термина в документе (TF) и обратную документную частоту (IDF) по корпусу из $D$ документов.

- Для каждого документа строится нормированный частотный словарь через **`ProbabilityDictionaryHash`** (см. [ProbabilityDictionaryHash.md](ProbabilityDictionaryHash.md)).
- **TF** термина $t$ в документе $d$: значение из `pDs[d][t]`, либо 0, если терма нет.
- **IDF** в реализации:

$$\text{idf}(t) = \log_{10}\left(0.1 + \frac{D}{df(t) + 0.001}\right)$$

где $df(t)$ — число документов, в которых термин $t$ встречается хотя бы раз (по ключам словаря документа).

- **Скаляр по строке запроса** (`TF_IDF_Str`): токены запроса через `ProbabilityDictionary.GetWords(str, true)`; для каждого токена берётся `TF_IDF`, затем **среднее арифметическое** по токенам (пустой запрос → 0).

- **Поиск документа** (`Search`): для каждого документа вычисляется `TF_IDF_Str(req, d)`, возвращается индекс документа с максимальным значением (через `Vector.MaxElementIndex()`).

При сопоставлении терминов с ключами словарей важно использовать **те же** стеммированные формы, что и при индексации (см. примеры в `Tests/NLP/NlpExamples`).

## API: `TFIDF`

| Метод / поле | Описание | Пример |
|--------------|----------|--------|
| `pDs` (internal) | Массив словарей TF по документам; используется в `TFIDFDictionary`. | Доступ из того же сборочного модуля / обход в своём коде через рефлексию не рекомендуется. |
| `TFIDF(string[] docs)` | Индексация корпуса. | `var tfidf = new TFIDF(docs);` |
| `TFWord(t, dIndex)` | TF термина в документе. | `tfidf.TFWord("кошк", 0)` |
| `IDFWord(t)` | IDF по корпусу. | `tfidf.IDFWord("кошк")` |
| `TF_IDF(t, dIndex)` | Произведение TF и IDF. | `tfidf.TF_IDF("кошк", 0)` |
| `TF_IDF_Str(str, dIndex)` | Среднее TF‑IDF по токенам строки. | `tfidf.TF_IDF_Str("кошка спит", 0)` |
| `Search(req)` | Индекс наиболее релевантного документа. | `int i = tfidf.Search("кошка спит");` |
