# `Stemmers/Stemmer.cs` — `StemmerRus`

## Теория

**Стемминг русского языка** по схеме, восходящей к **алгоритму Портера** и адаптации для русского морфологии: выделение **RV** (часть слова после первой гласной в корне), последовательное снятие окончаний по группам (причастные/деепричастные, прилагательные, глаголы, существительные), дополнительные шаги для суффиксов вроде `-ость`, суперлативов и т.д. Регулярные выражения в коде соответствуют классам окончаний.

Исходная реализация взята из открытого репозитория (MIT); атрибуция в [../../INFO.md](../../INFO.md).

Стемминг **не гарантирует** лемму из словаря — это эвристическое усечение для снижения размерности признакового пространства.

## API: `StemmerRus`

| Метод | Описание | Пример |
|-------|----------|--------|
| `TransformingWord(string word)` | Стем одного слова (нижний регистр, `ё`→`е`). | `StemmerRus.TransformingWord("машинное");` |
| `TransformingWordsArray(string[] words)` | Покомпонентно для массива. | `StemmerRus.TransformingWordsArray(tokens);` |

Исходник: `src/AI.NLP/Stemmers/Stemmer.cs`.
