# Стемминг (AI.NLP)

## Что такое стемминг?

Стемминг — алгоритмическое отсечение окончаний и суффиксов слова для получения «стемма» (приближённой основы).

**Отличие от лемматизации:**
- Стемм — псевдооснова, может не совпадать с реальной словарной формой
- Лемма — словарная форма (нормальная форма)

| Слово | Стемм | Лемма |
|-------|-------|-------|
| учатся | уч | учиться |
| нейронных | нейрон | нейронный |
| разработчики | разработчик | разработчик |

## Алгоритм StemmerRus

`StemmerRus` реализует правиловый алгоритм (аналогичный алгоритму Снежный Ком — Snowball):
1. Определить регион RVOW (первая гласная + позиция)
2. Удалить окончания существительных/прилагательных
3. Удалить рефлексивные окончания (-ся, -сь)
4. Удалить деривационные суффиксы
5. Удалить финальные мягкие знаки

**Сложность:** $O(|w|)$ — линейно от длины слова.

## API

```csharp
using AI.NLP.Stemmers;

// Одно слово
string stem = StemmerRus.TransformingWord("учиться");   // → "уч"
string stem2 = StemmerRus.TransformingWord("нейронных"); // → "нейрон"

// Массив слов
string[] words  = { "разрабатывают", "обучаются", "предсказывают" };
string[] stems  = StemmerRus.TransformingWordsArray(words);
// → ["разрабатыва", "обуча", "предсказыва"]

// Интеграция с ProbabilityDictionary
var pd = new ProbabilityDictionary(isStem: true); // автоматически применяет StemmerRus
```
