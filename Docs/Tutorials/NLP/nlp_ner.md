# Распознавание именованных сущностей (NER)

**NER** (Named Entity Recognition) — задача обнаружения в тексте фрагментов, относящихся к предопределённым категориям: имена людей, организации, даты, адреса, телефоны, URL и т. д.

## Подходы к NER

| Подход | Принцип | Плюсы | Минусы |
|--------|---------|-------|--------|
| Словарный | Поиск известных сущностей по словарю | Детерминированность | Нельзя обнаружить неизвестные сущности |
| RegExp | Шаблоны регулярных выражений | Быстро, прозрачно | Хрупкость, много ручного труда |
| ML-модели (CRF, Bi-LSTM-CRF) | Обучение на размеченных данных | Высокая точность | Нужны корпус и вычисления |

## Реализация: CombineNerProcessor

`CombineNerProcessor` из `AI.DataPrepaire.NLPUtils.RegexpNLP.SimpleNER` объединяет несколько процессоров RegExp-NER в единый конвейер. Каждый процессор отвечает за свой тип сущности:

- **Время**: `14:30`, `09:15`
- **Email**: `user@example.com`
- **Телефон**: `+7 999 123-45-67`, `8 800 555 35 35`
- **URL**: `vkre.com/page`
- **Адрес**: `ул. Ленина, д. 5, кв. 12`
- **Аббревиатуры / сокращения**: `А.В. Александров`

### Алгоритм обработки

1. **Маскирование**: каждый RegExp-процессор заменяет найденные сущности плейсхолдерами вида `__NER_0__`, `__NER_1__` и сохраняет исходные значения.
2. **Дальнейшая обработка**: токенизация и анализ проводятся на маскированном тексте, что исключает ложные разбиения (например, точка в `д.` не является концом предложения).
3. **Восстановление**: плейсхолдеры заменяются обратно на исходные значения.

## Разбиение на предложения

`SentencesTokenizer` из `AI.DataPrepaire` реализует интеллектуальное разбиение по правилам:

- Точка, восклицательный и вопросительный знаки — стандартные разделители.
- **Сокращения** (д., ул., т. е., и т. д.) и **инициалы** (А.В.) не принимаются за конец предложения.
- Маскированный текст значительно улучшает качество разбиения: сокращения внутри маскированных сущностей игнорируются автоматически.

## Параметры демо

| Параметр | Смысл |
|----------|-------|
| _text    | Текст для анализа. Если оставить пустым — используется встроенный пример с именами, адресом, телефоном, URL и временем |

## Что показывает демо

1. Исходный текст.
2. Маскированный вариант (плейсхолдеры вместо сущностей).
3. Восстановленный текст (должен совпасть с исходным).
4. Таблица найденных сущностей: тип → значение.
5. Разбиение на предложения **без** NER-маскирования.
6. Разбиение на предложения **с** NER-маскированием.

## API

```csharp
using AI.DataPrepaire.NLPUtils.RegexpNLP.SimpleNER;
using AI.DataPrepaire;

string text = "Позвоните по номеру +7 999 123-45-67 или напишите на user@mail.com.";

var ner = new CombineNerProcessor();
string masked = ner.Mask(text);               // __NER_0__ и __NER_1__ вставлены
string restored = ner.Restore(masked);        // возвращает исходный текст

var entities = ner.GetEntities(text);         // List<(string Type, string Value)>
foreach (var (type, value) in entities)
    Console.WriteLine($"{type}: {value}");

// Разбиение на предложения с учётом NER
var tokenizer = new SentencesTokenizer();
List<string> sentences = tokenizer.Tokenize(masked);
```
