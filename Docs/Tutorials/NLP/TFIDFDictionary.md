# `TFIDFDictionary.cs` — класс `TFIDFDictionary`

## Теория

**Корпус из файлов.** Каждый файл в указанном каталоге читается целиком как один документ; на массиве текстов строится **`TFIDF`**. По произвольному «слову» (строке запроса) строится **вектор длины $D$** ($D$ — число файлов): компонента $i$ — это `TF_IDF_Str(word, i)` (среднее TF‑IDF по токенам строки для документа $i$).

**Нормализация** (`ToVect`): покомпонентное деление на максимум компонент, если максимум **строго положителен**; иначе вектор возвращается без масштабирования (избегание деления на ноль).

**Сходство слов** (`Sim`): коэффициент корреляции Пирсона между двумя такими векторами (`Statistics.Statistic.CorrelationCoefficient`).

**Словарь векторов** (`VectorDictionary`): для каждого термина, встретившегося хотя бы в одном документе (по ключам внутренних словарей TF), строится `ToVect(term)`; дубликаты терминов не добавляются.

## API: `TFIDFDictionary`

| Член | Описание | Пример |
|------|----------|--------|
| `TfIdf` | Экземпляр `TFIDF` после загрузки каталога. | `dict.TfIdf.Search("...")` |
| `TFIDFDictionary(string pathToDir)` | Читает все файлы каталога (без рекурсии в подпапки — см. `Directory.GetFiles`). | `var dict = new TFIDFDictionary(@"C:\corpus");` |
| `ToVect(string word)` | Вектор профиля слова/запроса по документам. | `Vector v = dict.ToVect("запрос");` |
| `Sim(word1, word2)` | Корреляция между векторами. | `double s = dict.Sim("кот", "кошка");` |
| `VectorDictionary()` | Словарь термин → вектор по корпусу. | `var m = dict.VectorDictionary();` |
