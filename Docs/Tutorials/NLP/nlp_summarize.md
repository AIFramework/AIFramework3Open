# Суммаризация текста (AI.NLP)

## Экстрактивная суммаризация

`TextSummarization` реализует **экстрактивный** подход: выбирает наиболее значимые предложения из исходного текста, не генерируя новый.

**Алгоритм:**
1. Разбить текст на предложения (`GetSeqs`)
2. Для каждого предложения вычислить вес — сумму TF-IDF его слов
3. Выбрать топ-$N$ предложений по весу
4. Восстановить исходный порядок

## Вес предложения

$$
\text{score}(s) = \sum_{w \in s} \text{TF-IDF}(w, s)
$$

Предложения с редкими, но тематически значимыми словами получают высокий вес.

## Применение

| | Экстрактивная (TextSummarization) | Абстрактивная (LLM) |
|-|----------------------------------|-------------------|
| Метод | Выбор предложений | Генерация нового текста |
| Качество | Умеренное | Высокое |
| Скорость | Мгновенно | Медленно |
| Точность фактов | 100% (из оригинала) | Может галлюцинировать |
| Ресурсы | Минимум | GPU |

## API

```csharp
using AI.NLP;

var ts = new TextSummarization();

// Суммаризация: топ-2 предложения
string summary = ts.Summarization(text, num: 2);

// Разбивка на предложения (статический)
string[] sentences = TextSummarization.GetSeqs(text);

// Использование в пайплайне
foreach (string doc in documents)
{
    string brief = ts.Summarization(doc, num: 3);
    Console.WriteLine(brief);
}
```

## Советы по использованию

- Оптимальный `num` ≈ 20–30% от числа исходных предложений
- Для коротких текстов (< 5 предложений) суммаризация не даёт выигрыша
- Для улучшения результата предварительно примените `TextStandard.Normalize`
