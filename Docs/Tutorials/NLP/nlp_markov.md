# Марковские цепи и генерация текста (HMMFast)

**Марковская цепь** — вероятностная модель, в которой следующее состояние зависит только от текущего (свойство Маркова). Применительно к тексту: следующее слово зависит лишь от $n-1$ предыдущих (так называемая **n-граммная модель**).

## Формальное определение

Пусть $w_1, w_2, \ldots, w_T$ — последовательность слов. N-граммная модель оценивает вероятность слова $w_t$ через условную вероятность:

$$
P(w_t \mid w_{t-n+1}, \ldots, w_{t-1})
$$

При $n = 2$ модель называется **биграммной**, при $n = 3$ — **триграммной** и т. д.

## Обучение (подсчёт частот)

Из обучающего корпуса извлекаются все n-граммы. Вероятность перехода оценивается методом максимального правдоподобия:

$$
P(w_t \mid \text{контекст}) = \frac{\text{count}(\text{контекст}, w_t)}{\sum_{w'} \text{count}(\text{контекст}, w')}
$$

Результат — таблица переходов: каждый контекст (ключ словаря) хранит список возможных продолжений с их весами.

## Генерация

1. Берётся начальная фраза (seed) из $n-1$ слов.
2. По текущему контексту семплируется следующее слово пропорционально накопленным частотам.
3. Контекст сдвигается на одно слово, шаг повторяется до достижения нужной длины.

$$
w_t \sim P(\,\cdot\mid w_{t-n+1}, \ldots, w_{t-1})
$$

## Класс HMMFast

`HMMFast` из пространства `AI.DataPrepaire.NLPUtils.TextGeneration` реализует n-граммную модель на основе хеш-таблицы контекст → список продолжений. Обучение и генерация работают за $O(T)$ и $O(\text{gen\_len})$ соответственно.

## Параметры демо

| Параметр   | Смысл |
|------------|-------|
| ngram      | Размер контекста $n$ (2 = биграммы, 3 = триграммы и т. д.) |
| genLength  | Максимальное число слов в сгенерированном тексте |
| textId     | Встроенный обучающий корпус (технический / новостной / научный) |
| _corpus    | Произвольный пользовательский текст вместо встроенного |
| _seed      | Начальная фраза для запуска генерации |

## Компромисс при выборе n

| n   | Связность | Разнообразие | Риск дословного копирования |
|-----|-----------|--------------|-----------------------------|
| 2   | Слабая    | Высокое      | Низкий                      |
| 3   | Средняя   | Среднее      | Средний                     |
| 4–5 | Высокая   | Низкое       | Высокий                     |

## Ограничения

- Текст за пределами обучающего корпуса невозможен (замкнутый словарь).
- При малом корпусе большие $n$ дают мало уникальных контекстов → повторения.
- Нет семантического понимания: модель не знает значений слов.

## API

```csharp
using AI.DataPrepaire.NLPUtils.TextGeneration;

var model = new HMMFast(n: 3);
model.Train("нейронные сети обучаются на данных. сети помогают решать задачи.");

string text = model.Generate(seed: "нейронные сети", maxWords: 50);
Console.WriteLine(text);
```
