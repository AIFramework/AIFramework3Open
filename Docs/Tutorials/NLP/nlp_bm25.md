# BM25 (AI.NLP)

## Okapi BM25 — вероятностная модель ранжирования

BM25 (Best Match 25) — вероятностная модель информационного поиска, разработанная Стивеном Робертсоном и Карен Спарк Джонс. Превосходит классический TF-IDF благодаря двум улучшениям: **насыщению частот** (TF не растёт бесконечно) и **нормализации длины документа**.

## Формулы

**Скор документа $D$ относительно запроса $Q = \{q_1, q_2, \ldots\}$:**

$$
\text{BM25}(D, Q) = \sum_{i=1}^{n} \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot \left(1 - b + b \cdot \dfrac{|D|}{\text{avgdl}}\right)}
$$

где:
- $f(q_i, D)$ — количество вхождений термина $q_i$ в документ $D$
- $|D|$ — длина документа (число слов)
- $\text{avgdl}$ — средняя длина документа в корпусе
- $k_1$ — параметр насыщения TF (рекомендуется $1{,}2$–$2{,}0$)
- $b$ — параметр нормализации длины (рекомендуется $0{,}75$)

**IDF (сглаженная формула Robertson-Sparck Jones):**

$$
\text{IDF}(q_i) = \ln\!\left(\frac{N - n(q_i) + 0{,}5}{n(q_i) + 0{,}5} + 1\right)
$$

где $N$ — число документов в корпусе, $n(q_i)$ — число документов, содержащих термин $q_i$.

## Параметры

| Параметр | Диапазон | По умолчанию | Эффект |
|----------|----------|-------------|--------|
| $k_1$ | $1{,}2$–$2{,}0$ | $1{,}5$ | Контролирует насыщение TF. При $k_1=0$ частота не учитывается; при $k_1 \to \infty$ модель ведёт себя как бинарный IDF. |
| $b$ | $0{,}0$–$1{,}0$ | $0{,}75$ | Степень нормализации длины. При $b=0$ длина документа игнорируется; при $b=1$ — полная нормализация. |

## BM25 vs TF-IDF

| Свойство | TF-IDF | BM25 |
|----------|--------|------|
| Насыщение TF | Нет (линейный рост) | Да (сигмоидоподобное насыщение) |
| Нормализация длины | Нет | Да (параметр $b$) |
| Параметры | Нет | $k_1$, $b$ |
| Интерпретация | Вес термина | Вклад термина в релевантность |

## API

```csharp
using AI.NLP;

string[] documents =
{
    "нейронная сеть глубокое обучение",
    "рынок акции экономика",
    "спорт футбол чемпионат"
};

var bm25 = new BM25(documents, k1: 1.5, b: 0.75);

// Скор документа относительно запроса
double score = bm25.Score("нейронная сеть", docIndex: 0);

// IDF и TF для конкретного термина
double idf = bm25.IDFWord("нейронная");
int    tf  = bm25.TFWord("нейронная", docIndex: 0);

// Поиск: индекс наиболее релевантного документа
int bestDoc = bm25.Search("нейронная обучение");

// Топ-N результатов с оценками
(int index, double score)[] top = bm25.SearchTopN("нейронная", n: 3);
```
