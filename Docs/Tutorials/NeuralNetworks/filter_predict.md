# Фильтр MLP для прогноза временных рядов

**Фильтр MLP** (многослойный перцептрон без рекуррентности) — простейшая нейросетевая базовая линия для задачи прогнозирования. Модель воспринимает фиксированное окно прошлых значений как плоский вектор и предсказывает одно следующее значение.

## Архитектура

$$
\hat x_{t+1} = W_3 \cdot \text{ReLU}(W_2 \cdot \text{ReLU}(W_1 \cdot \mathbf{x}_t + b_1) + b_2) + b_3
$$

где $\mathbf{x}_t = (x_{t-w+1}, \ldots, x_t)^{\top}$ — входное окно длины $w$, $W_1 \in \mathbb{R}^{h \times w}$, $W_2 \in \mathbb{R}^{h \times h}$, $W_3 \in \mathbb{R}^{1 \times h}$.

Структура слоёв: `Linear(w, h) → ReLU → Linear(h, h) → ReLU → Linear(h, 1)`.

## MLP vs рекуррентные модели

| Свойство | MLP (Фильтр) | RNN / GRU / LSTM |
|----------|--------------|------------------|
| Зависимость от прошлого | Фиксированное окно $w$ | Теоретически неограниченная |
| Параметры | $O(w \cdot h + h^2)$ | $O(h^2)$ на шаг |
| Скорость обучения | Быстрее | Медленнее |
| Качество при длинных зависимостях | Хуже | Лучше |
| Интерпретируемость | Выше | Ниже |

## Когда MLP достаточен

- Ряд не имеет длинных зависимостей (корреляции сосредоточены в окне $w$).
- Важна скорость инференса (нет состояния между шагами).
- Используется как базовая линия для оценки выигрыша от рекуррентности.

## Параметры демо

| Параметр | Смысл |
|----------|-------|
| trainLen | Длина обучающего ряда |
| window   | Размер входного окна $w$ |
| predLen  | Горизонт прогноза |
| freq     | Частота базовой синусоиды |
| hidden   | Число нейронов в скрытом слое $h$ |
| epochs   | Эпохи обучения |
| lr       | Learning rate (Adam) |

## Ограничения

- Невозможно уловить зависимости длиннее окна $w$.
- При нестационарном ряде переобучается быстрее рекуррентных моделей.
- Параметры $W_1$ не разделяются по шагам (в отличие от RNN/LSTM).

## API

```csharp
using AI.ML.NeuralNetworks.V2.Nn;

// Модель: Linear(window, hidden) → ReLU → Linear(hidden, hidden) → ReLU → Linear(hidden, 1)
var model = new Sequential(
    new Linear(window, hidden),
    new ReLU(),
    new Linear(hidden, hidden),
    new ReLU(),
    new Linear(hidden, 1)
);

var optimizer = new Adam(model.Parameters(), lr: 0.005f);
// ... обучение на скользящих окнах
```
