# Сравнение архитектур нейронных сетей для временных рядов

Данное демо обучает пять архитектур на одинаковых данных и сравнивает их по **MSE**, времени обучения и скорости инференса.

## Сравниваемые архитектуры

### 1. Фильтр (MLP)

Полносвязная сеть без рекуррентности. Видит только фиксированное окно $w$:

$$
\hat x = W_3 \cdot \text{ReLU}(W_2 \cdot \text{ReLU}(W_1 \mathbf{x} + b_1) + b_2) + b_3
$$

- Базовая линия: быстрее всех обучается, но не видит зависимостей длиннее $w$.

### 2. Vanilla RNN

Классическая рекуррентная сеть с одним затвором:

$$
h_t = \tanh(W_h x_t + U_h h_{t-1} + b_h)
$$

- Теоретически захватывает неограниченную историю, но на практике страдает от затухания градиентов.

### 3. LSTM

Long Short-Term Memory с явной ячейкой памяти $c_t$ и тремя затворами ($f_t, i_t, o_t$). Лучше всего сохраняет долгосрочные зависимости, но медленнее GRU из-за большего числа параметров.

### 4. GRU

Gated Recurrent Unit с двумя затворами ($z_t, r_t$). Компромисс между LSTM (качество) и RNN (скорость).

### 5. Transformer

Self-attention + позиционное кодирование. Обрабатывает всё окно параллельно; наиболее эффективен при больших данных и длинных окнах.

## Метрики сравнения

**MSE (среднеквадратическая ошибка) на тестовом горизонте:**

$$
\text{MSE} = \frac{1}{n} \sum_{k=1}^{n} (\hat x_{t+k} - x_{t+k})^2
$$

**Время обучения** — суммарное время всех эпох на обучающем ряде.

**Время инференса** — время генерации прогноза на горизонте `predLen`.

## Рекомендации по выбору архитектуры

| Сценарий | Рекомендация |
|----------|--------------|
| Мало данных, простые зависимости | MLP (Фильтр) |
| Средние зависимости, скорость важна | GRU |
| Длинные зависимости, точность важна | LSTM |
| Большой датасет, длинное окно | Transformer |
| Нужна интерпретируемость | MLP |

## Параметры демо

| Параметр | Смысл |
|----------|-------|
| trainLen | Длина общего обучающего ряда |
| predLen  | Горизонт прогноза для всех моделей |
| window   | Размер входного окна (одинаков для всех) |
| epochs   | Число эпох обучения (одинаково для всех) |
