# Автоэнкодер

**Автоэнкодер** (Autoencoder, AE) — нейронная сеть, обучаемая без учителя восстанавливать собственный вход. В её структуре имеется «бутылочное горлышко» — скрытый слой малой размерности, через который необходимо пропустить информацию. Это заставляет сеть выучить компактное **представление** (encoding) данных.

## Архитектура

$$
z = f_{\text{enc}}(x), \qquad \hat x = f_{\text{dec}}(z)
$$

$$
\dim(z) \ll \dim(x)
$$

В `AI.ML.DataHandling.FeaturesTransforms.AutoEncoder` по умолчанию используется:

- Encoder: `FeedForwardLayer(2·latent, ReLU) → FeedForwardLayer(latent, ReLU)`
- Decoder: `FeedForwardLayer(inputDim, linear)`

## Функция потерь

Обучение происходит **путём минимизации ошибки реконструкции**:

$$
\mathcal{L}(\theta) = \frac{1}{N}\sum_{i=1}^{N} \| x_i - f_{\text{dec}}(f_{\text{enc}}(x_i)) \|^2
$$

То есть вход и цель совпадают — это обучение без учителя.

## Применения

1. **Снижение размерности** (нелинейный аналог PCA).
2. **Извлечение признаков** для последующей классификации/кластеризации.
3. **Шумоподавление** (обучение на чистых данных → применение к зашумлённым).
4. **Обнаружение аномалий** (точки с большой ошибкой реконструкции).

## Геометрия скрытого пространства

Если данные лежат на одномерном многообразии (кольцо, спираль, эллипс), то **латентная размерность = 1** достаточна для корректного восстановления. В демо можно убедиться, что при обучении на кольце точки в исходном пространстве автоматически упорядочиваются по значению латента (цветовая шкала).

## Сравнение с PCA

| Свойство | PCA | Autoencoder |
|----------|-----|-------------|
| Линейность         | линейный | нелинейный |
| Вычисление         | SVD      | градиентный спуск |
| Обучаемость        | аналитически | итеративно |
| Применимость к нелинейным многообразиям | нет | да |
| Повторяемость      | детерминирована | зависит от инициализации |

## Примеры

```csharp
using AI.ML.DataHandling.FeaturesTransforms;

var ae = new AutoEncoder(inpDim: 2, outpDim: 1);
var info = ae.Train(data, epoch: 80, lr: 0.01);

Vector z = ae.Transform(new Vector(new[] { 1.2, 0.8 })); // сжатие
Console.WriteLine($"Потеря после {info.TrainLoss.Count} эпох: {info.TrainLoss[^1]:F5}");
```
