# GRU-прогноз временного ряда

**GRU** (Gated Recurrent Unit) — рекуррентная нейронная сеть с управляемыми затворами, введённая К. Чо в 2014 г. Она предназначена для моделирования последовательностей и решает проблему затухающих градиентов классического RNN.

## Уравнения ячейки GRU

Для входа $x_t$ и скрытого состояния $h_{t-1}$ на предыдущем шаге:

$$
z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z) \quad \text{(затвор обновления)}
$$

$$
r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r) \quad \text{(затвор сброса)}
$$

$$
\tilde h_t = \tanh(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)
$$

$$
h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde h_t
$$

где $\sigma$ — сигмоид, $\odot$ — поэлементное умножение.

## Схема прогноза

Класс `GRUPredict` обучается в режиме **одношагового прогноза**: по окну длины $w$ последних значений ряда $x_{t-w+1}, \ldots, x_t$ предсказывается следующий элемент $x_{t+1}$.

$$
\hat x_{t+1} = f_{\text{GRU}}(x_{t-w+1}, \ldots, x_t)
$$

Для долгосрочного прогноза на $n$ шагов применяется **автокорреляционная схема**: предсказанное значение возвращается на вход.

$$
\hat x_{t+k} = f_{\text{GRU}}(\hat x_{t+k-w}, \ldots, \hat x_{t+k-1}), \quad k = 1, \ldots, n
$$

## Нормализация

Ряд масштабируется внутри `Train`:

$$
\tilde x_i = \frac{x_i - \bar x}{\sigma_x}
$$

а после прогноза проводится обратное преобразование.

## Параметры демо

| Параметр | Смысл |
|----------|-------|
| trainLen | длина обучающего ряда (должна быть ≥ 150) |
| window   | размер контекстного окна $w$ для GRU |
| predLen  | число шагов прогноза вперёд |
| freq     | частота несущей синусоиды (базовый сигнал: $\sin(2\pi f t) + 0.3\sin(6\pi f t)$) |

## Ограничения метода

- **Рост ошибки** с горизонтом прогноза (ошибка автокорреляционно накапливается).
- **Затухание** предсказаний при малой ёмкости скрытого слоя (в демо hidden-size = 4).
- **Плохое восстановление** для рядов с сильным шумом или нестационарных.

## Пример

```csharp
using AI.ML.SequenceAnalysis.SeqPredict;

var gru = new GRUPredict(w: 8);
gru.Train(trainSeries);
Vector forecast = gru.Predict(trainSeries, n: 40);
```
