# LSTM-прогноз временного ряда

**LSTM** (Long Short-Term Memory) — рекуррентная архитектура, предложенная Хохрайтером и Шмидхубером в 1997 г. Ключевое отличие от классического RNN — явная **ячейка памяти** $c_t$, которая позволяет запоминать информацию на сотни шагов и преодолевает проблему затухающих градиентов.

## Уравнения ячейки LSTM

Для входа $x_t$ и скрытого состояния $h_{t-1}$:

$$
f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f) \quad \text{(затвор забывания)}
$$

$$
i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) \quad \text{(затвор входа)}
$$

$$
o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) \quad \text{(затвор выхода)}
$$

$$
\tilde c_t = \tanh(W_c x_t + U_c h_{t-1} + b_c) \quad \text{(кандидат на обновление)}
$$

$$
c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t \quad \text{(ячейка памяти)}
$$

$$
h_t = o_t \odot \tanh(c_t) \quad \text{(скрытое состояние)}
$$

где $\sigma$ — сигмоид, $\odot$ — поэлементное умножение.

## LSTM vs GRU

| Характеристика | LSTM | GRU |
|----------------|------|-----|
| Параметров | Больше (4 матрицы весов) | Меньше (3 матрицы) |
| Ячейка памяти | Явная ($c_t$) | Отсутствует |
| Длинные зависимости | Лучше | Хуже на очень длинных рядах |
| Скорость обучения | Медленнее | Быстрее |

## Схема прогноза

Аналогично GRU используется **скользящее окно** длины $w$: на вход LSTM подаётся последовательность из $w$ значений, на выходе — предсказание одного следующего шага. Для многошагового горизонта применяется **автокорреляционный режим**: предсказанные значения возвращаются на вход.

$$
\hat x_{t+k} = f_{\text{LSTM}}(\hat x_{t+k-w}, \ldots, \hat x_{t+k-1}), \quad k = 1, \ldots, n
$$

## Параметры демо

| Параметр | Смысл |
|----------|-------|
| trainLen | Длина обучающего ряда |
| window   | Размер входного окна $w$ |
| predLen  | Горизонт прогноза (шагов вперёд) |
| freq     | Частота синусоиды базового ряда |
| epochs   | Число эпох обучения |
| lr       | Learning rate (оптимизатор Adam) |

## Ограничения

- Накопление ошибки при большом горизонте прогноза.
- Требует больше памяти и времени обучения по сравнению с GRU.
- На коротких рядах преимущество ячейки памяти не проявляется.

## API

```csharp
using AI.ML.SequenceAnalysis.SeqPredict;

var lstm = new LstmPredictor(window: 8, hiddenSize: 16);
lstm.Train(trainSeries, epochs: 80, lr: 0.005f);
float[] forecast = lstm.Predict(trainSeries, steps: 40);
```
