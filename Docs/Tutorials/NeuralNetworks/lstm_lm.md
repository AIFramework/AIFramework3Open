# LSTM языковая модель

**Языковая модель** (Language Model, LM) оценивает вероятность текстовой последовательности. Нейросетевые LM на основе LSTM обучаются предсказывать следующий токен по предыстории и используются для **генерации текста**, оценки **перплексии** и перенесения знаний.

## Принцип

Для последовательности токенов $w_1, w_2, \ldots, w_T$ языковая модель оценивает:

$$
P(w_1, \ldots, w_T) = \prod_{t=1}^{T} P(w_t \mid w_1, \ldots, w_{t-1})
$$

Каждый шаг — задача классификации: выбор токена из словаря $V$.

## Архитектура

```
Токен w_t → Embedding(|V|, emb_dim) → LSTMCell(emb_dim, hidden)
    → Linear(hidden, |V|) → Softmax → P(w_{t+1})
```

1. **Embedding** — обучаемая матрица $E \in \mathbb{R}^{|V| \times d_e}$: каждый токен получает плотный вектор.
2. **LSTMCell** — рекуррентная ячейка с памятью $c_t$ и скрытым состоянием $h_t$.
3. **Linear** — проекция скрытого состояния в вектор логитов размера $|V|$.
4. **CrossEntropy** — функция потерь на каждом шаге.

## Функция потерь

**Перекрёстная энтропия** (Cross-Entropy Loss):

$$
\mathcal{L} = -\frac{1}{T} \sum_{t=1}^{T} \log P(w_{t+1} \mid w_1, \ldots, w_t)
$$

## Перплексия

Перплексия (Perplexity, PPL) — стандартная метрика качества LM:

$$
\text{PPL} = e^{\mathcal{L}}
$$

Чем ниже перплексия, тем лучше модель предсказывает текст. Случайная модель с равномерным распределением по словарю $V$ даёт $\text{PPL} = |V|$.

## Генерация текста

После обучения модель генерирует текст **автокорреляционно**:

1. Задаётся начальный токен (промпт).
2. Вычисляется распределение над следующим токеном.
3. Семплируется (или выбирается argmax) следующий токен.
4. Он добавляется в контекст, шаг повторяется.

**Температурный семплинг** ($T > 0$):

$$
P'(w) = \frac{\exp(\text{logit}(w) / T)}{\sum_{w'} \exp(\text{logit}(w') / T)}
$$

При $T \to 0$ — жадный поиск (детерминированный), при $T = 1$ — стандартный семплинг, при $T > 1$ — разнообразный, но менее связный текст.

## Параметры демо

| Параметр   | Смысл |
|------------|-------|
| epochs     | Число эпох обучения |
| hiddenSize | Размер скрытого состояния LSTM |
| embDim     | Размер эмбеддинга токена |
| maxTokens  | Максимум токенов в генерации |
| _corpus    | Обучающий корпус (собственный или встроенный) |
| _prompt    | Начальная фраза для генерации |

## Что показывает демо

- Сгенерированный текст по промпту.
- Финальная перплексия на обучающем тексте.
- Кривая потерь (loss по эпохам).

## Ограничения

- Качество генерации напрямую зависит от размера и разнообразия корпуса.
- Малый словарь (собственный текст) = малое разнообразие.
- Языковая модель на основе одной LSTMCell мощнее Марковской цепи, но уступает современным трансформерным LM.
