# Статистика изображений

Статистические методы обработки изображений опираются на анализ распределения интенсивностей пикселей. Пусть $I$ — исходное изображение с уровнем яркости $r \in [0, L-1]$, где $L=256$ для 8-битного изображения.

## Эквализация гистограммы (Histogram Equalization)

Метод контрастирования изображения, основанный на преобразовании гистограммы яркости к равномерному распределению. Реализован в методе `ImageHistogram.Equalize`.

### Математическое описание алгоритма

Пусть $n_k$ — количество пикселей с интенсивностью $k$, а $N$ — общее количество пикселей в изображении ($N = \sum_{k=0}^{L-1} n_k$).

**1. Построение нормированной гистограммы (вероятности)**

Вероятность появления уровня яркости $r_k = k$:
$$
p_r(r_k) = \frac{n_k}{N}, \quad k = 0, 1, \dots, L-1
$$

**2. Вычисление кумулятивной функции распределения (CDF)**

Кумулятивная сумма вероятностей для уровня $k$:
$$
CDF(k) = \sum_{j=0}^{k} p_r(r_j) = \sum_{j=0}^{k} \frac{n_j}{N}
$$

Свойства $CDF(k)$:
- $CDF(0) = p_r(r_0)$
- $CDF(L-1) = 1$
- Функция монотонно не убывает.

**3. Преобразование интенсивностей**

Новое значение яркости $s_k$ для пикселя с исходной яркостью $r_k$ вычисляется путем отображения CDF на полный динамический диапазон $[0, L-1]$:

$$
s_k = T(r_k) = \text{round}\left( (L - 1) \cdot CDF(k) \right)
$$

Для $L=256$:
$$
s_k = \text{round}\left( 255 \cdot \sum_{j=0}^{k} \frac{n_j}{N} \right)
$$

где $\text{round}(\cdot)$ — операция округления до ближайшего целого.

### Свойства и ограничения

1. **Линейность растяжения:** Алгоритм автоматически растягивает наиболее часто встречающиеся диапазоны интенсивностей, повышая локальный контраст в областях с высокой плотностью гистограммы.
2. **Глобальный характер:** Классическая эквализация применяется ко всему изображению целиком. Это может приводить к чрезмерному усилению шума в однородных областях и потере деталей в тенях или светах, если гистограмма имеет узкие пики.
3. **Необратимость:** Поскольку преобразование дискретно и использует округление, несколько различных исходных уровней яркости могут быть отображены в один новый уровень. Восстановить исходное изображение точно невозможно.

### Адаптивная эквализация (CLAHE)

*Примечание:* Для улучшения результатов на изображениях с неравномерным освещением часто используется **CLAHE** (Contrast Limited Adaptive Histogram Equalization), где изображение разбивается на тайлы, и эквализация применяется локально с ограничением контраста для подавления шума.
