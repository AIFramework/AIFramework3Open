# Сравнение трёх схем под одно ТЗ

Рупор, зеркало и линза считаются разными формулами, но возвращают один и
тот же тип результата. Это и есть смысл общего контракта: варианты можно
сравнить построчно и увидеть, чем каждый платит за усиление.

## Постановка задачи

Дано одно техническое задание: частота, мощность, требуемая ширина луча и
уровень боковых лепестков. Требуется получить три конструкции, проверить
каждую на соответствие ТЗ и выбрать компромисс.

## Теория

Все три схемы формируют луч одной и той же апертурой, и все три подчиняются
$G = 4\pi A \eta / \lambda^2$. Различаются они тем, **чем платят** за
нужную площадь апертуры:

| Схема | Платит | Масштаб платы |
|-------|--------|---------------|
| Рупор | длиной | $L \sim A/\lambda$, десятки длин волн |
| Зеркало | поперечником и точностью | $m \sim A$, лист плюс рёбра |
| Линза | массой диэлектрика | $m \sim A^{3/2}$, толщина растёт с апертурой |

Для типового задания 2.45 ГГц / 900 Вт / 5° это выглядит так:

| | Рупор | Парабола | Линза |
|---|---|---|---|
| Усиление, дБи | 29.7 | 31.4 | 31.2 |
| КИП | 0.50 | 0.71 | 0.68 |
| УБЛ, дБ | −13.3 | −22.7 | −24.1 |
| Масса (алюминий), кг | 126 | 10 | 949 |
| Длина, м | 7.40 | 0.73 | 2.35 |

Рупор не проходит по УБЛ — не из-за плохого расчёта, а потому что
равномерное распределение поля в E-плоскости физически даёт −13.3 дБ.
Линза проходит по электрике, но проигрывает по массе на порядок.

**Общая для всех точка отказа.** Наиболее нагруженное место тракта у всех
трёх схем одно и то же — горловина питающего волновода, а не раскрыв.
Запас в раскрыве рупора примерно в 30 раз больше, чем в горловине,
поэтому проверка по раскрыву даёт ложное чувство безопасности.

## Сложность

Три независимых расчёта по $O(1)$ каждый; линза дополнительно
интегрирует профиль численно.

## API

| Член | Назначение |
|------|------------|
| `IAntennaCalculator` | Общий контракт всех схем |
| `IAntennaCalculator.Calculate(p)` | Расчёт по общему заданию |
| `AntennaDesignResult.MeetsAllRequirements` | ШДН, УБЛ и запас одновременно |
| `AntennaDesignResult.HotSpot` | Наиболее нагруженная точка тракта |
| `AntennaDesignResult.SpecificParameters` | Величины, специфичные для схемы |

## Код

```csharp
using AI.Microwave.Calculators;
using AI.Microwave.Models;

var prm = new AntennaParameters
{
    FrequencyMHz = 2450,
    PowerWatts = 900,
    RequiredBeamwidthDegrees = 5,
    RequiredSidelobeLevelDb = -20,
    Material = MaterialProperties.GetStandardMaterials()[1],
};

IAntennaCalculator[] calcs =
[
    new HornAntennaCalculator(),
    new ParabolicAntennaCalculator(),
    new HornWithLensCalculator(),
];

foreach (var c in calcs)
{
    var r = c.Calculate(prm);
    Console.WriteLine($"{c.AntennaType,-34} G={r.GainDbi,6:F2} дБи  " +
                      $"m={r.WeightKg,8:F1} кг  L={r.TotalLengthM,5:F2} м  " +
                      $"ТЗ: {(r.MeetsAllRequirements ? "да" : "нет")}");

    foreach (var w in r.Warnings) Console.WriteLine("    ! " + w);
}
```

## Ограничения

- Сравниваются только три реализованные схемы. Офсетная парабола,
  двухзеркальные системы Кассегрена и Грегори, фазированные решётки и
  зонированные линзовые антенны как самостоятельные варианты не
  рассчитываются.
- Стоимость — относительная, по массе и коэффициенту материала; она не
  учитывает трудоёмкость изготовления, которая у зеркала и линзы разная.
- Все расчёты — на одной частоте. Полосовые свойства (у линзы они заметно
  хуже) в сравнение не входят.
