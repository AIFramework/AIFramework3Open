# Электрическая прочность и пропускная способность

Сколько мощности можно пропустить через тракт, прежде чем воздух в нём
пробьётся. Условия среды — давление, температура, влажность — меняют порог
в разы, а высота над уровнем моря делает это заметнее всего.

## Постановка задачи

Дано: геометрия тракта, передаваемая мощность и условия эксплуатации.
Требуется найти порог пробоя, поле в наиболее нагруженной точке и запас
между ними; либо, наоборот, предельную мощность при заданном запасе.

## Теория

**Порог пробоя.** Для непрерывного СВЧ-разряда в воздухе при нормальных
условиях порог составляет около 3 МВ/м (30 кВ/см). Он подчиняется закону
подобия по приведённому полю $E/N$, то есть пропорционален плотности газа:

$$E_{bd} = E_0 \cdot \frac{p}{p_0}\cdot\frac{T_0}{T}\cdot k_{hum}$$

Температура входит в знаменатель в кельвинах, давление — в числитель.

**Высота.** Абсолютное давление падает по барометрической формуле с
высотой однородной атмосферы 8500 м:

$$p(h) = p_{sea}\exp\left(-\frac{h}{8500}\right)$$

На 5 км порог падает примерно на 45 % — это главная причина, по которой
бортовые тракты наддувают.

**Влажность.** Водяной пар электроотрицателен: он захватывает свободные
электроны и слегка **повышает** порог, примерно на 2 % при 100 %
относительной влажности. Реальная опасность влаги другая — конденсат на
диэлектрике, после которого пробой идёт по поверхности, а не по объёму.
Поэтому вместе с порогом считается точка росы по приближению Магнуса.

**Где искать максимум поля.** Поле максимально там, где минимально
сечение — в горловине питающего волновода. Для TE10

$$E_0 = \sqrt{\frac{4 P Z_{TE10}}{a b}}$$

Отсюда предельная мощность при требуемом запасе $m$:

$$P_{max} = \frac{(E_{bd}/m)^2\,ab}{4 Z_{TE10}}$$

Для WR-340 при трёхкратном запасе это около 2 МВт — на три порядка выше
типичной мощности магнетрона, что и объясняет, почему бытовые тракты
пробоя не боятся, а бортовые на большой высоте — боятся.

## Сложность

Замкнутые формулы, $O(1)$.

## API

| Член | Назначение |
|------|------------|
| `EnvironmentalConditions.GetBreakdownFieldStrength()` | Порог пробоя, В/м |
| `EnvironmentalConditions.GetAbsolutePressureAtm()` | Давление с поправкой на высоту |
| `EnvironmentalConditions.GetDewPoint()` | Точка росы, °C |
| `RectangularWaveguide.PeakElectricField(P, f)` | Поле в горловине |
| `AntennaDesignResult.HotSpot` | Где именно расположена худшая точка |
| `AntennaDesignResult.SafetyMargin` | Запас в этой точке, раз |

## Код

```csharp
using AI.Microwave.Models;

var env = new EnvironmentalConditions
{
    Altitude = 5000,
    Temperature = -20,
    Humidity = 30,
};

var wg = RectangularWaveguide.Find("WR-340")!;
double f = 2.45e9;
double threshold = env.GetBreakdownFieldStrength();
double field = wg.PeakElectricField(900, f);

Console.WriteLine($"Давление      {env.GetAbsolutePressureAtm():F3} атм");
Console.WriteLine($"Порог пробоя  {threshold / 1e6:F3} МВ/м");
Console.WriteLine($"Поле при 900 Вт {field / 1000:F1} кВ/м");
Console.WriteLine($"Запас         {threshold / field:F0} раз");
Console.WriteLine($"Точка росы    {env.GetDewPoint():F1} C");
```

## Ограничения

- Модель для непрерывного режима. Импульсная мощность допускает поле в
  разы выше, потому что разряд не успевает развиться, — этот случай не
  рассчитывается.
- Не моделируется мультипактор — вторично-электронный резонансный разряд,
  критичный в вакууме и при очень низких давлениях.
- Не учитывается влияние размера промежутка: при зазоре, сравнимом с
  диффузионной длиной, порог заметно выше объёмного.
- Поверхностный пробой по загрязнённому или увлажнённому диэлектрику
  оценивается только косвенно, через точку росы.
- Локальные концентраторы поля — заусенцы, острые кромки, стыки
  фланцев — не моделируются; на практике они и определяют реальный порог.
