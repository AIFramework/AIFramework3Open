# Параболическая антенна

Параболоид вращения с рупорным облучателем в фокусе. Самая выгодная схема
по массе на децибел усиления: та же ширина луча, что у рупора, достигается
при в десять раз меньшей длине конструкции.

## Постановка задачи

Дано: частота, мощность, требуемая ШДН, относительный фокус $f/D$, спад
поля на кромке и допуск на профиль. Требуется найти диаметр зеркала,
геометрию облучателя, бюджет КИП, УБЛ, массу и запас по пробою.

## Теория

**Диаметр.** Ширина луча круглой апертуры $\theta = k\lambda/D$, где
коэффициент $k$ зависит от того, насколько равномерно освещена апертура:
58.4 при равномерном освещении, 70 при классическом спаде −10 дБ на кромке.
Тот же спад определяет КИП и УБЛ — см. [апертурную теорию](aperture.md).

**Геометрия.** Глубина $h = D^2/(16f)$. Край зеркала виден из фокуса под
половинным углом

$$\theta_0 = 2\arctan\frac{D}{4f}$$

Множитель два принципиален: при $f/D = 0.4$ это 64°, а не 32°. Площадь
отражающей поверхности берётся точно, а не приближением конусом:

$$S = \frac{8\pi f^2}{3}\left[\left(1 + \frac{D^2}{16 f^2}\right)^{3/2} - 1\right]$$

**Облучатель.** Его ДН подбирается так, чтобы на угле $\theta_0$ поле
спадало ровно на заданную величину $T$:

$$\theta_{0.5}^{feed} = \frac{\theta_0}{\sqrt{T/12}}$$

Дальше облучатель синтезируется как [пирамидальный рупор](horn.md).

**Бюджет КИП** — произведение независимых сомножителей:

$$\eta = \eta_{taper}\,\eta_{spill}\,\eta_{block}\,\eta_{Ruze}\,\eta_{misc}\,\eta_{cond}\,\eta_{mismatch}$$

где затенение $\eta_{block} = (1-b)^2$ при доле затенения по мощности $b$,
а потери на неточность профиля даёт формула Рузе
$\eta_{Ruze} = \exp\left[-(4\pi\varepsilon/\lambda)^2\right]$.

**Поле в фокусе.** Распространённая ошибка — подставить в фокус
дальнезонное выражение $P G/(4\pi f^2)$: фокус лежит глубоко в ближней
зоне зеркала, граница которой $2D^2/\lambda$ составляет десятки метров.
Поле в районе фокуса — это поле раскрыва **облучателя**, ограниченное его
апертурой, а абсолютный максимум по тракту всё равно в горловине волновода.

## Сложность

Замкнутые формулы, $O(1)$ на расчёт.

## API

| Член | Назначение |
|------|------------|
| `Paraboloid.RimHalfAngleDeg` | Половинный угол на кромку из фокуса |
| `Paraboloid.SurfaceAreaM2` | Точная площадь параболоида |
| `Paraboloid.WeightKg(t, rho, ribs)` | Масса листа плюс рёбра жёсткости |
| `ParabolicAntennaCalculator.Calculate(p)` | Полный расчёт |

## Код

```csharp
using AI.Microwave.Calculators;
using AI.Microwave.Models;

var prm = new AntennaParameters
{
    FrequencyMHz = 2450,
    PowerWatts = 900,
    RequiredBeamwidthDegrees = 5,
    ReflectorFocalToDiameterRatio = 0.40,
    EdgeTaperDb = 10,
    SurfaceToleranceMm = 0.5,
    Material = MaterialProperties.GetStandardMaterials()[1], // алюминий
};

var r = new ParabolicAntennaCalculator().Calculate(prm);

Console.WriteLine($"D = {r.SpecificParameters["Diameter_m"]:F2} м");
Console.WriteLine($"G = {r.GainDbi:F1} дБи при КИП {r.Efficiency:F2}");
Console.WriteLine($"Масса {r.WeightKg:F0} кг, УБЛ {r.SideLobeLevel:F1} дБ");
```

## Ограничения

- Только осесимметричная (не офсетная) схема: затенение облучателем
  учитывается, но устранить его в рамках модели нельзя.
- Затенение стойками отдельно не моделируется, оно входит в общий
  множитель прочих потерь.
- При очень широкой требуемой ШДН зеркало становится соизмеримо с
  облучателем; расчёт выдаёт предупреждение и переходит в оценочный режим.
- ДН облучателя аппроксимируется гауссовой, реальный рупор имеет разные
  ширины луча в E- и H-плоскостях.
- Перелив (около 10 % мощности при спаде −10 дБ) считается как потеря, но
  его угловое распределение не рассчитывается.

- [Рупор](horn.md) — облучатель считается тем же кодом
