# Аппликатор бегущей волны

Материал проходит через волновод и поглощает мощность за один проход.
Схема непрерывных линий: сушки, пастеризации, вулканизации,
размораживания. В отличие от резонансной камеры картина поля здесь
предсказуема, а плата за это — мощность, уходящая в балласт.

## Постановка задачи

Дан волновод, слой материала известной толщины и требуемый подъём
температуры. Требуется найти баланс мощности (сколько поглощено,
отражено и потеряно), равномерность прогрева по толщине,
производительность линии и потребную мощность генератора.

## Теория

**Баланс мощности.** Часть падающей волны отражается от границы
воздух-материал:

$$R = \left(\frac{n-1}{n+1}\right)^2, \qquad n = \sqrt{\varepsilon'}$$

Прошедшая часть затухает по экспоненте с глубиной проникновения $D_p$.
За один проход слоя толщиной $t$ поглощается

$$\eta_{abs} = (1 - R)\left(1 - e^{-t/D_p}\right)$$

Остаток доходит до дальнего конца и сбрасывается в балластную нагрузку —
это прямой убыток КПД, которого в резонансной камере нет.

**Равномерность.** Тепловыделение падает вглубь по тому же закону,
поэтому перекос между поверхностью и серединой слоя равен
$\exp(t/2D_p)$. При двустороннем облучении вклады с обеих граней
складываются, и середина догоняет поверхность.

Отсюда основной компромисс схемы: толстый слой поглощает больше, но
прогревается неравномернее. Оптимум лежит там, где кривые поглощения и
неравномерности расходятся.

**Производительность.** При требуемом подъёме температуры $\Delta T$
линия пропускает

$$\dot{m} = \frac{3600\, P\, \eta_{abs}}{c_p \Delta T + L}$$

где $L$ — скрытая теплота, если в процессе есть фазовый переход
(например, испарение влаги при сушке).

## Сложность

Замкнутые формулы, $O(1)$ на конфигурацию.

## API

| Член | Назначение |
|------|------------|
| `TravelingWaveApplicator.AbsorbedFraction(lambda)` | Доля, поглощённая за проход |
| `TravelingWaveApplicator.ReflectedFraction` | Отражение от поверхности |
| `TravelingWaveApplicator.TransmittedFraction(lambda)` | Уход в балласт |
| `TravelingWaveApplicator.UniformityRatio(lambda)` | Перекос по толщине |
| `TravelingWaveApplicator.MaxThicknessM(lambda, k)` | Предельная толщина слоя |
| `TravelingWaveApplicator.ThroughputKgPerHour(...)` | Производительность |
| `TravelingWaveApplicator.RequiredPowerW(...)` | Потребная мощность |
| `TravelingWaveApplicator.FieldInLoadVPerM(...)` | Поле в материале |

## Код

```csharp
using AI.Microwave.Heating;
using AI.Microwave.Models;

var applicator = new TravelingWaveApplicator
{
    Waveguide = RectangularWaveguide.Find("WR-340")!,
    Load = DielectricMaterial.GetStandardLoads()[4],   // древесина 20 % влаги
    ThicknessM = 0.03,
    InteractionLengthM = 1.5,
};

double lambda = 0.1224;

Console.WriteLine($"Поглощено  {applicator.AbsorbedFraction(lambda) * 100:F1} %");
Console.WriteLine($"Отражено   {applicator.ReflectedFraction * 100:F1} %");
Console.WriteLine($"В балласт  {applicator.TransmittedFraction(lambda) * 100:F1} %");
Console.WriteLine($"Перекос    {applicator.UniformityRatio(lambda):F2}x");
Console.WriteLine($"6 кВт, нагрев 60 К: {applicator.ThroughputKgPerHour(6000, lambda, 60):F1} кг/ч");

applicator.TwoSided = true;
Console.WriteLine($"Двусторонне: перекос {applicator.UniformityRatio(lambda):F2}x");
```

## Ограничения

- Модель одномерная: поле считается плоской волной, падающей нормально на
  слой. Неоднородность по ширине волновода (косинусное распределение
  TE₁₀) не учитывается, а она даёт заметный перекос поперёк ленты.
- Обратное влияние загрузки на распространение в волноводе не
  моделируется: реальный загруженный волновод меняет постоянную
  распространения и требует пересогласования.
- Многократные переотражения между слоем и стенками не учитываются.
- Изменение свойств материала по мере обработки (сушка снижает влажность
  и вместе с ней поглощение) не отслеживается — расчёт стационарный.
- Температура материала задаётся одним числом на весь проход.
