# Пирамидальный рупор

Плавно расширяющийся отрезок прямоугольного волновода. Простейшая
апертурная антенна: высокая допустимая мощность, широкая полоса, но
узкий луч даётся ценой длины в десятки длин волн.

## Постановка задачи

Дано: частота, подводимая мощность, требуемая ширина луча по уровню
−3 дБ, питающий волновод и материал. Требуется найти размеры раскрыва,
осевую длину, усиление, уровень боковых лепестков, запас по
электрической прочности, массу и тепловой режим.

Встречается везде, где нужен эталонный или мощный излучатель:
измерительные стенды, промышленный нагрев, облучатели зеркал.

## Теория

**Синтез апертуры.** Ширина луча оптимального рупора связана с раскрывом
в каждой плоскости своим коэффициентом:

$$\theta_E = \frac{56\,\lambda}{b_1}, \qquad \theta_H = \frac{67\,\lambda}{a_1}$$

Коэффициенты разные, поэтому раскрыв под симметричный луч получается
**неквадратным**: $a_1 / b_1 = 67/56 \approx 1.2$. Синтез идёт теми же
формулами, что и проверка, поэтому требование выполняется точно.

**Оптимальная длина.** Максимум усиления при заданном раскрыве достигается,
когда квадратичная фазовая ошибка на кромке равна $s = 1/4$ в E-плоскости
и $t = 3/8$ в H-плоскости, что даёт расстояния до вершины клина

$$\rho_E = \frac{b_1^2}{2\lambda}, \qquad \rho_H = \frac{a_1^2}{3\lambda}$$

Осевая длина — не $\rho$, а проекция: если вершина отстоит от центра
апертуры на $\rho$, то

$$L = \sqrt{\rho^2 - \frac{A^2}{4}} \cdot \frac{A - a}{A}$$

где $A$ — раскрыв, $a$ — размер волновода. Обе плоскости обязаны иметь
общую длину, поэтому берётся большая из двух: вторая получается длиннее
оптимума, то есть с меньшей фазовой ошибкой.

**Усиление.** КИП оптимального пирамидального рупора $\eta_{ap} = 0.51$;
полный КИП дополнительно учитывает потери в стенках и рассогласование:

$$G = \frac{4\pi a_1 b_1}{\lambda^2}\,\eta_{ap}\,\eta_{cond}\,\eta_{mismatch}$$

**Боковые лепестки.** Распределение поля в раскрыве разное по плоскостям:
равномерное по E даёт −13.3 дБ, косинусное по H — −23 дБ. Требование ТЗ
проверяется по **худшей** плоскости, поэтому чистый рупор не выходит на
−20 дБ без гофрирования или поглощающей кромки.

**Электрическая прочность.** Поле максимально там, где сечение минимально —
в горловине волновода, а не в раскрыве. Для TE₁₀

$$E_0 = \sqrt{\frac{4 P Z_{TE10}}{a b}}, \qquad Z_{TE10} = \frac{\eta_0}{\sqrt{1 - (f_c/f)^2}}$$

## Сложность

Замкнутые формулы, $O(1)$ на расчёт. Численные методы не используются.

## API

| Член | Назначение |
|------|------------|
| `PyramidalHorn.ForBeamwidth(bw, throat, lambda)` | Синтез геометрии под требуемую ШДН |
| `PyramidalHorn.AxialLengthM` | Осевая длина оптимального рупора |
| `PyramidalHorn.PhaseErrorE` / `PhaseErrorH` | Фактические фазовые ошибки $s$ и $t$ |
| `PyramidalHorn.WallAreaM2` | Площадь четырёх стенок: масса и теплосъём |
| `HornAntennaCalculator.Calculate(p)` | Полный расчёт: усиление, ДН, пробой, масса |

## Код

```csharp
using AI.Microwave.Calculators;
using AI.Microwave.Models;

var prm = new AntennaParameters
{
    FrequencyMHz = 2450,
    PowerWatts = 900,
    RequiredBeamwidthDegrees = 5,
    Waveguide = RectangularWaveguide.Find("WR-340")!,
};

var result = new HornAntennaCalculator().Calculate(prm);

Console.WriteLine($"Раскрыв {result.ApertureWidthM:F3} x {result.ApertureHeightM:F3} м");
Console.WriteLine($"Длина   {result.AxialLengthM:F2} м");
Console.WriteLine($"G = {result.GainDbi:F1} дБи, ШДН = {result.BeamwidthEPlane:F2} град");
Console.WriteLine($"Запас по пробою {result.SafetyMargin:F0} ({result.HotSpot})");

foreach (var w in result.Warnings) Console.WriteLine("! " + w);
```

## Ограничения

- Модель диссипативных потерь берёт погонное затухание TE₁₀ и умножает на
  длину рупора. Это оценка **сверху**: по мере расширения сечения потери
  падают. На очень длинных рупорах (десятки метров) оценка заметно
  пессимистична.
- КИП фиксирован на 0.51 — значении оптимального рупора. Пересчёт КИП
  через интегралы Френеля по фактическим $s$ и $t$ не выполняется, поэтому
  для сильно неоптимальных рупоров усиление занижено.
- Уровень боковых лепестков берётся из распределения поля в раскрыве и не
  учитывает дополнительного заплывания лепестков от фазовой ошибки.
- КСВ оценивается эмпирической таблицей по крутизне раскрыва.
