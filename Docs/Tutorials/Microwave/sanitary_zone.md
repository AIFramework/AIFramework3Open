# Санитарные зоны излучающей площадки

Границы, за которыми облучение укладывается в норматив. Практический
результат расчёта площадки: именно эти цифры попадают в паспорт объекта
и в проект санитарно-защитной зоны.

## Постановка задачи

Дана площадка с несколькими излучателями: секторные антенны сотовой
базовой станции, радиорелейные пролёты, спутниковые терминалы. У каждого
своя частота, мощность, азимут, наклон и диаграмма. Требуется найти
границы зоны на заданной высоте и проверить характерные точки — уровень
земли, соседние кровли, площадки обслуживания.

## Теория

**Суммирование.** Плотности потока в ваттах между диапазонами складывать
нельзя: у каждой частоты свой предел. Норматив выполнен, когда не
превышает единицы сумма долей:

$$\rho(\mathbf{r}) = \sum_i \frac{S_i(\mathbf{r})}{S_{ПДУ}(f_i)} \le 1$$

**Граница зоны** по лучу азимута $\alpha$ на высоте $h$ — корень
уравнения $\rho(R) = 1$. Функция монотонно убывает с расстоянием, поэтому
корень единственный и находится бисекцией.

**Где максимум.** Распространённое заблуждение — что наибольшее облучение
у подножия мачты. Это не так: наблюдатель под антенной находится глубоко
в провале вертикальной диаграммы. Наклонённый вниз луч кладёт пятно на
землю на расстоянии примерно

$$R_{max} \approx \frac{h_{ант} - h_{набл}}{\tan \theta_{tilt}}$$

и именно там ищется максимум. Расчёт, который перебирает только
расстояние, не учитывая высоту и наклон, этот максимум пропускает.

**Две разные зоны.** На уровне земли норматив обычно выполняется с
большим запасом, а превышение сосредоточено на высоте подвеса — там, где
работает обслуживающий персонал. Поэтому контур считают минимум на двух
отметках.

## Сложность

Бисекция $O(\log(1/\varepsilon))$ на луч, контур — $O(360/\Delta\alpha)$
лучей. Практически миллисекунды на площадку.

## API

| Член | Назначение |
|------|------------|
| `ExposureScene.Add(source)` | Добавить излучатель на площадку |
| `ExposureScene.ExposureRatioAt(point)` | Суммарная доля от ПДУ |
| `ExposureScene.AssessAt(point)` | Полная оценка: ППЭ, поле, доля, запас |
| `ExposureScene.BoundaryDistance(az, h)` | Граница зоны по лучу |
| `ExposureScene.BoundaryContour(h, step)` | Контур по азимутам |
| `ExposureScene.MaxBoundaryDistance(h)` | Наибольшая дальность границы |
| `ExposureScene.Profile(az, h, from, to, n)` | Профиль вдоль луча |

## Код

```csharp
using AI.Microwave.Safety;

var scene = new ExposureScene { Standard = ExposureStandard.Sanpin };

for (int i = 0; i < 3; i++)
{
    scene.Add(new RadiationSource
    {
        Name = $"сектор {i * 120}",
        Position = new SitePoint(0, 0, 30),
        AzimuthDeg = i * 120,
        DowntiltDeg = 4,
        FrequencyHz = 1800e6,
        TransmitPowerW = 40,
        GainDbi = 18,
        Pattern = new GaussianPattern { AzimuthBeamwidthDeg = 65, ElevationBeamwidthDeg = 7 },
    });
}

Console.WriteLine($"Граница на 2 м:  {scene.MaxBoundaryDistance(2):F1} м");
Console.WriteLine($"Граница на 30 м: {scene.MaxBoundaryDistance(30):F1} м");

var atRoof = scene.AssessAt(new SitePoint(0, 5, 30));
Console.WriteLine($"В 5 м перед антенной: доля {atRoof.Ratio:F1}");
```

## Ограничения

- Отражения от земли и застройки не учитываются. В реальных замерах они
  дают локальные всплески, которых расчёт в свободном пространстве не
  показывает.
- Рельеф плоский, препятствия не затеняют.
- Контур строится на одной высоте: полноценная трёхмерная зона требует
  расчёта на нескольких отметках.
- Все источники считаются работающими одновременно на максимальной
  мощности. Для сетей с динамическим управлением это заведомо
  консервативно, а учёт статистики требует коэффициентов из методики.
- Результат — инженерная оценка. Границы зон, оформляемые официально,
  подтверждаются инструментальными замерами.
