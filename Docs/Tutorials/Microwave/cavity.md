# Многомодовая рабочая камера

Основная схема промышленных и бытовых СВЧ-установок. Поле в ней
принципиально пятнистое, и равномерность нагрева определяется не
геометрией, а числом одновременно возбуждённых мод.

## Постановка задачи

Дана прямоугольная камера, загрузка и источник с известной полосой.
Требуется найти спектр резонансов, добротность пустой и нагруженной
камеры, долю мощности, попадающую в продукт, и оценить равномерность.

## Теория

**Резонансы.** Прямоугольный объём поддерживает моды с частотами

$$f_{mnp} = \frac{c}{2}\sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2 + \left(\frac{p}{d}\right)^2}$$

Семейство TE требует $p \ge 1$ и хотя бы один ненулевой из $m, n$;
семейство TM требует $m \ge 1$ и $n \ge 1$. Вырожденные моды с
совпадающими частотами считаются по отдельности — это независимые
степени свободы поля.

**Плотность мод.** Асимптотика Вейля даёт быструю оценку без перебора:

$$\frac{dN}{df} = \frac{8\pi V f^2}{c^3}$$

Для камеры 27 литров на 2.45 ГГц это около 0.15 моды на мегагерц.

**Добротность.** Потери в стенках дают

$$Q_c \approx \frac{2V}{\delta S}$$

где $\delta$ — глубина скин-слоя. Для стальной камеры это тысячи. Потери
в загрузке дают $Q_d = 1/(\eta_{fill}\tan\delta)$, и они на порядки
меньше: нагруженная добротность падает до единиц. Отсюда же следует КПД —
доля мощности, ушедшая в продукт, а не в стенки:

$$\eta = \frac{Q_L}{Q_d}$$

у загруженной камеры она превышает 99 %.

**Равномерность.** Ширина резонансной кривой моды равна $f/Q$. У пустой
камеры это сотни килогерц: моды узкие, магнетрон попадает в единицы из
них, поле стоячее и пятнистое. Загрузка сбивает добротность, моды
расплываются на сотни мегагерц и перекрываются — поле выравнивается
само. Поэтому эффективное число возбуждённых мод считается по полосе

$$\Delta f_{эфф} = \Delta f_{ист} + \frac{f}{Q_L}$$

Твердотельный источник добивается того же качанием частоты, но
управляемо и на любой загрузке — в этом его главное преимущество перед
магнетроном.

## Сложность

Перебор мод $O(m n p)$ по границам полосы; асимптотика Вейля $O(1)$.
Сверка перебора с Вейлем на широких полосах даёт совпадение в пределах
двух процентов.

## API

| Член | Назначение |
|------|------------|
| `MultimodeCavity.ResonantFrequencyHz(m, n, p)` | Частота моды |
| `MultimodeCavity.Modes(fMin, fMax)` | Перечисление мод в полосе |
| `MultimodeCavity.ModeDensityPerHz(f)` | Плотность мод по Вейлю |
| `MultimodeCavity.WallQualityFactor(f, sigma)` | Добротность пустой камеры |
| `MultimodeCavity.LoadedQualityFactor(...)` | Нагруженная добротность |
| `MultimodeCavity.HeatingEfficiency(...)` | Доля мощности в продукт |
| `MultimodeCavity.EffectiveModeCount(f, bw, Q)` | Реально возбуждаемые моды |

## Код

```csharp
using AI.Microwave.Heating;
using AI.Microwave.Models;

var cavity = new MultimodeCavity { WidthM = 0.33, HeightM = 0.23, DepthM = 0.35 };
var steel = MaterialProperties.GetStandardMaterials()[5];
var water = DielectricMaterial.GetStandardLoads()[0];

double qEmpty = cavity.WallQualityFactor(2.45e9, steel.Conductivity);
double qLoaded = cavity.LoadedQualityFactor(2.45e9, steel.Conductivity, 1e-3, water);

Console.WriteLine($"Q пустой {qEmpty:F0}, с литром воды {qLoaded:F1}");
Console.WriteLine($"КПД по загрузке {cavity.HeatingEfficiency(2.45e9, steel.Conductivity, 1e-3, water) * 100:F2} %");
Console.WriteLine($"Магнетрон (15 МГц): {cavity.EffectiveModeCount(2.45e9, 15e6, qLoaded)} мод");
Console.WriteLine($"Качание 100 МГц:    {cavity.EffectiveModeCount(2.45e9, 100e6, qLoaded)} мод");
```

## Ограничения

- Считается спектр резонансов, а не само поле: где именно окажутся
  пучности, модель не говорит. Для этого нужен полноволновой расчёт.
- Стенки идеально плоские и прямоугольные; вращающийся стол, мешалка
  поля и оснастка не моделируются, хотя на практике именно они добивают
  равномерность.
- Добротность стенок оценивается по отношению объёма к поверхности без
  геометрического множителя конкретной моды.
- Коэффициент заполнения по энергии — грубая оценка: реальное
  распределение поля концентрируется в загрузке с высокой проницаемостью
  сильнее, чем даёт объёмная доля.
- Связь камеры с источником через волноводное окно и её согласование не
  рассматриваются.
