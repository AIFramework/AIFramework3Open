# Диэлектрический нагрев

Как поле превращается в тепло внутри материала, почему толстый продукт
не прогревается добавлением мощности и когда процесс уходит вразнос.

## Постановка задачи

Дан материал с известной комплексной проницаемостью и теплофизикой,
частота и подведённая мощность. Требуется найти объёмное тепловыделение,
скорость нагрева, равномерность по толщине, производительность линии и
устойчивость процесса.

## Теория

**Тепловыделение.** Поле греет материал через фактор потерь $\varepsilon''$:

$$P_v = 2\pi f \varepsilon_0 \varepsilon'' E^2 \quad [\text{Вт/м}^3]$$

где $E$ — действующее значение поля. Отсюда скорость нагрева:

$$\frac{dT}{dt} = \frac{P_v}{\rho c_p}$$

**Глубина проникновения** — расстояние, на котором поглощаемая мощность
падает в $e$ раз:

$$D_p = \frac{\lambda_0}{2\pi\sqrt{2\varepsilon'}\left[\sqrt{1+\tan^2\delta}-1\right]^{1/2}}$$

Для воды на 2.45 ГГц это около 14 мм. Величина **не зависит от
мощности**: толстый кусок нельзя прогреть, добавив киловатт — можно
только сжечь поверхность. Обходы: двустороннее облучение, понижение
частоты (на 915 МГц проникновение глубже) или пауза на выравнивание
теплопроводностью.

**Неравномерность.** Отношение тепловыделения на поверхности к
тепловыделению в середине слоя толщиной $t$:

$$k = \exp\left(\frac{t}{2 D_p}\right)$$

При двустороннем облучении вклады складываются, и та же толщина даёт
заметно меньший перекос.

**Тепловой разгон.** У воды $\varepsilon''$ с нагревом падает — процесс
сам себя стабилизирует. У многих полимеров, керамик и влажной древесины
растёт, и тогда более горячий участок поглощает сильнее, разогревается
быстрее и прожигает материал. Разгон начинается, когда прирост
тепловыделения обгоняет прирост теплоотвода:

$$2\pi f \varepsilon_0 E^2 \frac{d\varepsilon''}{dT} > h \frac{A}{V}$$

Отношение правой части к левой и есть запас устойчивости: больше
единицы — процесс управляем.

## Сложность

Замкнутые формулы, $O(1)$ на расчёт.

## API

| Член | Назначение |
|------|------------|
| `DielectricMaterial.PenetrationDepthM(lambda, T)` | Глубина проникновения |
| `DielectricMaterial.LossFactorAt(T)` | Фактор потерь при температуре |
| `DielectricMaterial.IsRunawayProne` | Растёт ли поглощение с нагревом |
| `DielectricHeating.VolumetricPowerWPerM3(f, eps, E)` | Объёмное тепловыделение |
| `DielectricHeating.HeatingRateKPerS(pv, material)` | Скорость нагрева |
| `DielectricHeating.SurfaceToCenterRatio(t, Dp)` | Неравномерность по толщине |
| `DielectricHeating.MaxThicknessForUniformity(Dp, k)` | Предельная толщина |
| `DielectricHeating.ThroughputKgPerHour(...)` | Производительность линии |
| `DielectricHeating.ThermalRunawayMargin(...)` | Запас устойчивости |

## Код

```csharp
using AI.Microwave.Heating;

var water = DielectricMaterial.GetStandardLoads()[0];
double lambda = 0.1224;                       // 2.45 ГГц

double depth = water.PenetrationDepthM(lambda);
Console.WriteLine($"Глубина проникновения {depth * 1000:F1} мм");

double pv = 900 / 1e-3;                       // литр воды под 900 Вт
Console.WriteLine($"Поле {DielectricHeating.FieldForVolumetricPower(2.45e9, water.LossFactor, pv):F0} В/м");
Console.WriteLine($"Скорость {DielectricHeating.HeatingRateKPerS(pv, water):F3} К/с");
Console.WriteLine($"Нагрев на 80 К за {DielectricHeating.HeatingTimeS(1.0, water, 80, 900):F0} с");

Console.WriteLine($"Слой 50 мм: перекос {DielectricHeating.SurfaceToCenterRatio(0.05, depth):F2}x");
Console.WriteLine($"Толщина при перекосе 2x: " +
                  $"{DielectricHeating.MaxThicknessForUniformity(depth, 2.0) * 1000:F0} мм");
```

## Ограничения

- Поле считается однородным по объёму: реальное распределение в камере
  пятнистое, и локальные перегревы возникают там, где стоит пучность.
- Теплопроводность внутри материала не моделируется — считается только
  распределение тепловыделения, а не установившееся поле температур.
- Фазовые переходы учитываются как скрытая теплота одним числом; резкий
  скачок $\varepsilon''$ при плавлении льда на два порядка не
  отслеживается, а именно он вызывает лавинообразный перегрев талых пятен
  в замороженном продукте.
- Зависимость $\varepsilon''(T)$ линеаризована. У реальных материалов она
  нелинейна и зависит ещё и от влажности, которая при сушке падает.
- Табличные значения проницаемости — типовые литературные. Для
  проектирования установки их измеряют на конкретном сырье.
