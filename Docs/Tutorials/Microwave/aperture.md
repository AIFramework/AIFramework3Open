# Апертурная теория: спад к краю

Один параметр — насколько поле облучателя ослабевает на кромке апертуры —
задаёт КИП, коэффициент перехвата, уровень боковых лепестков и коэффициент
в формуле ширины луча. Поэтому зеркало и линза в AI.Microwave считаются
одним и тем же кодом.

## Постановка задачи

Апертура (зеркало или линза) освещается из фокуса. Освещать равномерно —
значит терять мощность мимо краёв; освещать узким лучом — значит не
использовать периферию апертуры. Требуется связать эти два эффекта с
измеримыми характеристиками антенны и найти компромиссную точку.

## Теория

ДН облучателя аппроксимируется гауссовой, тогда спад в децибелах на угле
$\theta$ от оси

$$T(\theta) = 12\left(\frac{\theta}{\theta_{0.5}}\right)^2$$

Множитель 12 подобран так, что на $\theta = \theta_{0.5}/2$ спад ровно
3 дБ. Дальше всё выражается через спад на кромке $T$.

**КИП по спаданию.** Амплитуда $A(\rho) = e^{-\beta\rho^2}$ с $\beta = T\ln10/20$:

$$\eta_{taper} = \frac{2\left(1 - e^{-\beta}\right)^2}{\beta\left(1 - e^{-2\beta}\right)}$$

Равен единице при равномерном освещении и монотонно падает с ростом спада.

**Коэффициент перехвата** — доля мощности облучателя, попавшая на апертуру:

$$\eta_{spill} = 1 - \exp\left(-\frac{4\ln 2}{12}\,T\right)$$

Растёт с $T$: чем уже луч облучателя, тем меньше проливается мимо.

**Компромисс.** Произведение $\eta_{taper}\eta_{spill}$ имеет максимум
около 11 дБ — отсюда и берётся классическая рабочая точка −10 дБ.

**Боковые лепестки** круглой апертуры аппроксимируются линейно:

$$\text{УБЛ} \approx -(17.6 + 0.65\,T)\ \text{дБ}$$

что даёт −17.6 дБ при равномерном освещении и −24.1 дБ при спаде 10 дБ.

**Ширина луча.** Коэффициент в $\theta_{0.5} = k\lambda/D$ тоже функция спада:

$$k = 58.4 + 1.16\,T$$

При $T = 10$ получается $k = 70$, то есть привычная формула
$\theta = 70\lambda/D$.

**Затенение.** Затеняющий диск снимает с апертуры равномерную
составляющую, поднимая боковой лепесток на пьедестал амплитудой $b$
(доля затенения по мощности):

$$\text{УБЛ}_{block} = 20\lg\left(10^{\text{УБЛ}/20} + b\right)$$

## Сложность

Все соотношения замкнутые, $O(1)$.

## API

| Метод | Возвращает |
|-------|-----------|
| `ApertureIllumination.EdgeTaperDb(theta, hpbw)` | Спад на угле от оси |
| `ApertureIllumination.FeedBeamwidthForTaper(theta, T)` | ШДН облучателя под заданный спад |
| `ApertureIllumination.TaperEfficiency(T)` | КИП по спаданию |
| `ApertureIllumination.SpilloverEfficiency(T)` | Коэффициент перехвата |
| `ApertureIllumination.SidelobeLevelDb(T)` | Уровень первого бокового лепестка |
| `ApertureIllumination.BeamwidthFactor(T)` | Коэффициент $k$ в формуле ШДН |
| `ApertureIllumination.SidelobeWithBlockageDb(sll, b)` | УБЛ с учётом затенения |

## Код

```csharp
using AI.Microwave.Physics;

for (double taper = 0; taper <= 20; taper += 5)
{
    double et = ApertureIllumination.TaperEfficiency(taper);
    double es = ApertureIllumination.SpilloverEfficiency(taper);

    Console.WriteLine(
        $"спад {taper,4:F0} дБ:  КИП {et:F3}  перехват {es:F3}  " +
        $"итого {et * es:F3}  УБЛ {ApertureIllumination.SidelobeLevelDb(taper):F1} дБ  " +
        $"k = {ApertureIllumination.BeamwidthFactor(taper):F1}");
}
```

## Ограничения

- Гауссова аппроксимация ДН облучателя не описывает боковые лепестки
  самого облучателя, поэтому перехват слегка завышен.
- Формула УБЛ — линейная аппроксимация табличных данных, справедлива до
  спада порядка 25 дБ; дальше значение ограничивается.
- Соотношения выведены для круглой апертуры. Прямоугольная (рупор)
  считается отдельно, по распределению поля в каждой плоскости.
- Фазовые ошибки не учитываются: предполагается синфазная апертура.
