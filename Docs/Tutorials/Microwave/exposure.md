# Пределы облучения и плотность потока энергии

Сколько радиочастотной энергии попадает в точку пространства и как это
соотносится с нормативом. Основа любого расчёта санитарных зон и
паспорта излучающего объекта.

## Постановка задачи

Дан излучатель: мощность, усиление, диаграмма направленности, высота
подвеса и наклон луча. Требуется найти плотность потока энергии в
произвольной точке и сравнить её с предельно допустимым уровнем по
выбранному документу.

Расчёт обязателен перед вводом каждого излучающего объекта и повторно
после любого изменения мощности или конфигурации антенны.

## Теория

**ЭИИМ.** Эквивалентная изотропно излучаемая мощность учитывает потери
тракта и режим работы:

$$P_{EIRP} = P_{tx} \cdot 10^{-L_f/10} \cdot D \cdot k_{PRF} \cdot G$$

где $D$ — доля времени излучения (для TDD — доля нисходящих слотов), а
$k_{PRF}$ — статистический коэффициент снижения для антенн с
формированием луча: массивная MIMO-антенна не светит максимальной ЭИИМ
во все стороны одновременно.

**Дальняя зона.** Плотность потока спадает по обратному квадрату:

$$S = \frac{P_{EIRP} \cdot F(\theta,\varphi)}{4\pi R^2}$$

где $F$ — нормированная диаграмма по мощности.

**Три зоны апертуры.** Вблизи излучателя обратный квадрат неприменим:
поле ещё не сформировано. Модель FCC OET-65 делит пространство на три
области с границами $R_{nf} = D^2/4\lambda$ и $R_{ff} = 0.6 D^2/\lambda$:

$$S = \begin{cases}
\dfrac{16\eta P}{\pi D^2}, & R \le R_{nf} \[2ex]
S_{nf}\dfrac{R_{nf}}{R}, & R_{nf} < R < R_{ff} \[2ex]
\dfrac{P G}{4\pi R^2}, & R \ge R_{ff}
\end{cases}$$

В ближней зоне плотность выходит на полку: подходя ближе, облучение
уже не растёт.

**Суммирование источников.** Ватты между диапазонами складывать нельзя —
у каждой частоты свой предел. Складываются доли:

$$\sum_i \frac{S_i}{S_{ПДУ}(f_i)} \le 1$$

**Нормативы.** Российский СанПиН задаёт 10 мкВт/см² для населения на
всех частотах выше 300 МГц и не зависит от частоты. ICNIRP и FCC
поднимают предел с ростом частоты и в диапазоне сотовой связи мягче на
один-два порядка.

## Сложность

Замкнутые формулы, $O(1)$ на точку и $O(N)$ по числу источников.

## API

| Член | Назначение |
|------|------------|
| `ExposureLimits.PowerDensityLimit(std, f, cat)` | ПДУ по ППЭ, Вт/м² |
| `ExposureLimits.ElectricFieldLimit(std, f, cat)` | ПДУ по напряжённости поля |
| `ExposureLimits.Custom` | Замена встроенных таблиц своими |
| `RadiationSource.EirpW` | ЭИИМ с учётом фидера и режима |
| `RadiationSource.NearFieldBoundaryM` | Граница ближней зоны |
| `RadiationSource.PowerDensityAt(point, model)` | ППЭ в точке |
| `AntennaPattern` | Диаграмма: изотропная, гауссова, табличная |
| `TabulatedPattern.ParseMsi(text)` | Разбор паспортной ДН формата MSI Planet |

## Код

```csharp
using AI.Microwave.Safety;

var source = new RadiationSource
{
    Position = new SitePoint(0, 0, 30),
    AzimuthDeg = 0,
    DowntiltDeg = 4,
    FrequencyHz = 1800e6,
    TransmitPowerW = 40,
    FeederLossDb = 2,
    GainDbi = 18,
    Pattern = new GaussianPattern { AzimuthBeamwidthDeg = 65, ElevationBeamwidthDeg = 7 },
};

Console.WriteLine($"ЭИИМ {source.EirpW:F0} Вт ({source.EirpDbm:F1} дБм)");
Console.WriteLine($"Ближняя зона до {source.NearFieldBoundaryM:F2} м");

double limit = ExposureLimits.PowerDensityLimit(ExposureStandard.Sanpin, source.FrequencyHz);
foreach (double r in new[] { 5.0, 50.0, 200.0, 400.0 })
{
    double s = source.PowerDensityAt(new SitePoint(0, r, 2));
    Console.WriteLine($"r = {r,5:F0} м: {s * 100:F3} мкВт/см²  " +
                      $"доля от ПДУ {s / limit:F3}");
}
```

## Ограничения

- **Значения ПДУ в коде — рабочая заготовка, а не выписка из официального
  текста.** Перед выпуском документа, имеющего юридическую силу, таблицы
  обязаны быть сверены с действующей редакцией: пределы пересматриваются,
  а для импульсных режимов и локального облучения действуют свои нормы.
- Расчёт ведётся в свободном пространстве: отражения от земли, зданий и
  металлоконструкций не учитываются, а они способны дать локальное
  усиление в разы.
- Рельеф и затенение препятствиями не моделируются.
- Полная ДН собирается сложением двух сечений в децибелах: точно в
  плоскостях сечений, консервативно между ними.
- Ближнезонная модель применима к апертурным антеннам; для решёток с
  сильно разнесёнными элементами она занижает поле вблизи полотна.
