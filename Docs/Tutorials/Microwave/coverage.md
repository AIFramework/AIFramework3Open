# Покрытие сети связи

Сколько площади сеть базовых станций накрывает уверенным сигналом, где абоненты упираются в помехи соседей и какую
скорость получат на краю соты. Карта считается по сетке точек: от каждого сектора — потери на трассе по выбранной модели,
от его антенны — усиление в направлении точки, от приёмника — шум. Модель потерь бывает статистической (формулы 3GPP,
Окумура — Хата) или привязанной к местности — по рельефу SRTM и ITU-R P.1812.

## Постановка задачи

Даны секторы сети — положение, высота, азимут, наклон, мощность, диаграмма, частота, — приёмник абонента и модель
распространения. Требуется для каждой точки области найти обслуживающий сектор, мощность сигнала, помеху, SINR,
вероятность покрытия с учётом затенения и скорость, а по площади — долю покрытия, распределение SINR и скорость на краю соты.

## Теория

**Бюджет линии.** Мощность от сектора k в точке: $P_k = \text{ЭИИМ}_k − A_k(\varphi, \theta) + G_{rx} − L_k − L_{\text{пр}}$, где
A — ослабление диаграммы в направлении точки, L — потери на трассе, $L_{\text{пр}}$ — проникновение в здание или машину
(TR 38.901, раздел 7.4.3: стена из стекла и бетона складывается по мощности, внутри ещё 0,5 дБ/м). Шум —
$N = 10\lg(kTB) + NF$, при 290 К это −174 дБм/Гц.

**SINR и обслуживающий сектор.** Обслуживает сектор с наибольшей мощностью, помеха — сумма секторов той же несущей с долей
нагрузки η: $\text{SINR} = P_s / (\eta \sum_{k \ne s} P_k + N)$. Скорость — ослабленная формула Шеннона TR 36.942:
$\eta_{\text{сп}} = \min(\alpha \log_2(1 + \text{SINR}), \eta_{\max})$ выше порога и ноль ниже.

**Затенение и вероятность покрытия.** Потери логнормальны: $L + \sigma z$. У моделей 3GPP два состояния — с прямой
видимостью и без, со своими медианами и σ, — поэтому вероятность, что сигнал выше порога T, — смесь:
$P = p\,\Phi\big((P_{\text{LOS}} − T)/\sigma_{\text{LOS}}\big) + (1 − p)\,\Phi\big((P_{\text{NLOS}} − T)/\sigma_{\text{NLOS}}\big)$. Средняя по кругу соты
вероятность — классическая формула Джейкса; её карта воспроизводит с точностью полпроцента.

**Моделирование.** Карта по средним не видит, что затенение соседних сайтов частично общее. Моделирование разыгрывает
затенение как пространственно коррелированные поля (корреляция $e^{−r/d}$): у каждого сайта своё поле, смешанное с общим
так, что межсайтовая корреляция равна ρ = 0,5 (TR 36.942), секторы одного сайта затенены одинаково. Состояние видимости —
тоже поле, пороговое по вероятности сценария. По розыгрышам копится распределение SINR по площади — «геометрия», которой
в 3GPP сравнивают конфигурации сетей.

**Рельеф: ITU-R P.1812.** Профиль трассы снимается с цифровой модели рельефа, к высотам добавляются помехи — застройка
и лес. Потери — свободное пространство и дифракция «дельта-Буллингтон»: препятствия профиля сводятся к одному
эквивалентному краю (метод Буллингтона) с поправкой на протяжённость трассы, выпуклость Земли — дифракцией на гладкой
сфере первым членом ряда вычетов, а чтобы гладкая Земля не считалась дважды,
$L_d = L_{\text{bulla}} + \max(L_{\text{dsph}} − L_{\text{bulls}}, 0)$. Эффективный радиус Земли — 6371·157/(157 − ΔN) км. Плитки SRTM
(формат HGT, шаг 1″ или 3″) скачиваются из открытого набора AWS Terrain Tiles с кэшем на диске и переводятся в
локальные метры через проекцию UTM.

**Застройка: ITU-R P.2108.** Классы помех — вода, открытая местность, пригород, город, лес, плотная застройка — с
представительными высотами 10, 10, 10, 15, 15 и 20 м. В профиле трассы P.1812 они прибавляются к рельефу. У концов
трассы антенна ниже крыш теряет дополнительно (раздел 3.1, 30 МГц — 3 ГГц): на воде и открытой местности как
высотный множитель $−K_{h2}\lg(h/R)$, $K_{h2} = 21{,}8 + 6{,}2\lg f$, в застройке и лесу — огибая край крыши,
$J(\nu) − 6{,}03$ с $\nu = 0{,}342\sqrt{f}\sqrt{h_{\text{dif}}\theta_{\text{clut}}}$, $\theta_{\text{clut}} = \arctg(h_{\text{dif}}/w_s)$. Когда застройка не описана
поимённо, её потери для абонента в городе дают статистически (раздел 3.2, 0,5–67 ГГц): трасса с прямой видимостью и
трасса по улицам складываются по мощности, разброс по местам нормален с σ от 4 до 6 дБ, дальше 2 км потери не растут.

## Сложность

- Карта по средним: O(N·S) вычислений модели для N точек и S сайтов — секторы одного сайта на одной несущей делят потери.
- Моделирование: O(R·(N·K + F·(n + m))) для R розыгрышей, K секторов и F полей на сетке n × m; поле раскладывается
  по осям, поэтому тригонометрия не зависит от числа точек.
- Потери по рельефу: O(M) на трассу из M точек профиля — два прохода Буллингтона, сглаживание и сферическая дифракция.
- Замер на сетке 100 × 100 точек: сеть 3GPP UMa из 57 секторов — 0,1 с по средним и 1,1 с на 20 розыгрышей;
  21 сектор по рельефу с шагом профиля 30 м — 0,5 с.

## API

| Член | Назначение |
|------|------------|
| `CoverageScene` | Сеть и расчёт: `Add`, `AddHexagonalNetwork`, `Evaluate`, `Compute`, `Simulate`; пороги, нагрузка, корреляция затенения |
| `CoverageMap`, `CoverageSimulation` | Итоги: `AreaCoverage`, `SinrCoverage`, `SinrPercentileDb`, `CellEdgeThroughputBps`, `ServingShare`, `Layer`, `Interpret` |
| `CoverageGrid`, `CoverageReceiver`, `PointCoverage` | Сетка точек, приёмник (высота, шум, полоса, где абонент), результат в точке |
| `ThroughputMapping` | SINR → спектральная эффективность: Шеннон, LTE по TR 36.942, NR с 256-QAM |
| `IPropagationModel`, `LinkLoss` | Модель потерь для карт: одно или два состояния с медианой и затенением |
| `FreeSpaceModel`, `LogDistanceModel`, `HataModel`, `Tr38901Scenario` | Статистические модели |
| `TerrainPropagationModel`, `ItuP1812`, `P1812Loss` | Потери по рельефу: Буллингтон, сферическая Земля, дельта-Буллингтон |
| `GridTerrain`, `FlatTerrain`, `SrtmTile`, `TerrainProfile` | Рельеф с картой классов помех, плитки SRTM и перевод в локальные метры, профиль трассы |
| `SrtmDownloader` | Загрузка плиток из AWS Terrain Tiles с кэшем: `GetTileAsync`, `GetTilesAsync`, `LoadTerrainAsync`, `TilesAround` |
| `ItuP2108`, `ClutterCategory`, `ClutterLossModel` | Застройка: поправка на окружение антенны, статистические потери, модель потерь с застройкой поверх другой |
| `PenetrationLoss`, `LinkBudget.ThermalNoiseDbm` | Проникновение в здания и машины по TR 38.901, тепловой шум |

## Код

```csharp
using AI.Earth.Geodesy;
using AI.Microwave.Coverage;
using AI.Microwave.Propagation;
using AI.Microwave.Safety;
using Vector3 = AI.Geometry.Primitives.Vector3;

// Сеть 5G на 3,5 ГГц: 7 сайтов по 3 сектора, расстояние между сайтами 500 м, городская макросота 3GPP
var sector = new RadiationSource
{
    Position = new SitePoint(0, 0, 25),
    FrequencyHz = 3.5e9,
    TransmitPowerW = 80,
    FeederLossDb = 0,
    GainDbi = 17,
    DowntiltDeg = 8,
    Pattern = new GaussianPattern { AzimuthBeamwidthDeg = 65, ElevationBeamwidthDeg = 10, FrontToBackDb = 30 },
};

var city = new CoverageScene(Tr38901Scenario.UrbanMacro)
{
    Receiver = new CoverageReceiver { BandwidthHz = 100e6, NoiseFigureDb = 9 },
    SignalThresholdDbm = -110,
    SinrThresholdDb = -6,
    Throughput = ThroughputMapping.Nr256Qam,
};
city.AddHexagonalNetwork(rings: 1, interSiteDistanceM: 500, template: sector);

CoverageGrid area = CoverageGrid.Square(0, 0, 600, 20);
CoverageMap map = city.Compute(area);
CoverageSimulation simulation = city.Simulate(area, drops: 20, new Random(1));

Console.WriteLine($"Покрытие по сигналу {map.AreaCoverage:P1}, по SINR {simulation.AreaSinrCoverage:P1}");
Console.WriteLine($"SINR: медиана {simulation.SinrPercentileDb(0.5):F1} дБ, край соты {simulation.SinrPercentileDb(0.05):F1} дБ");
Console.WriteLine($"Скорость на краю соты {simulation.CellEdgeThroughputBps / 1e6:F1} Мбит/с");
Console.WriteLine(simulation.Interpret());

// Сельская местность: рельеф SRTM скачивается из открытого набора AWS и кэшируется на диске,
// потери — ITU-R P.1812 с поправкой P.2108 на окружение антенн
var downloader = new SrtmDownloader(Path.Combine(Path.GetTempPath(), "srtm"));
GridTerrain terrain = await downloader.LoadTerrainAsync(new GeoPoint(55.5, 37.5), halfSizeM: 10_000, spacingM: 90);
var model = new TerrainPropagationModel(terrain) { ProfileStepM = 90, TerminalClutter = true };

P1812Loss path = model.Analyze(new Vector3(0, 0, 40), new Vector3(6000, 2500, 1.5), 900e6);
Console.WriteLine(path.Interpret());

var rural = new CoverageScene(model) { SignalThresholdDbm = -100 };
rural.Add(new RadiationSource { Position = new SitePoint(0, 0, 40), FrequencyHz = 900e6, TransmitPowerW = 40, GainDbi = 15, AzimuthDeg = 90, DowntiltDeg = 2 });
CoverageMap ruralMap = rural.Compute(CoverageGrid.Square(0, 0, 8000, 200));
Console.WriteLine($"Покрытие по рельефу {ruralMap.AreaCoverage:P1}");
```

## Ограничения

- Мощность — средняя по полосе и времени: быстрые замирания, планировщик и формирование луча не моделируются,
  а вся полоса отдаётся одному абоненту. Для канала во времени есть `Tr38901Channel`.
- Карта по средним считает SINR без затенения и вероятность покрытия только по обслуживающему сектору; распределение
  SINR с затенением даёт моделирование.
- Секторы на разных несущих не мешают друг другу, соседние каналы не учитываются. Для покрытия берётся пиковая ЭИИМ:
  доля времени излучения и снижение мощности из санзон здесь не действуют.
- P.1812 реализована для 50 % времени и 50 % мест по дифракционному пути: тропосферное рассеяние и волноводное
  распространение, важные на трассах в сотни километров, не считаются. Постоянная 92,4 дБ в формуле свободного
  пространства P.1812 на 0,05 дБ меньше точной.
- Высоты помех в профиле по классам взяты из таблицы P.2108 (так заданы и проверочные трассы МСЭ-R); над водой — 0.
  Собственной таблицы P.1812 в коде нет. Карту классов нужно задать самому: из SRTM её не получить.
- Поправка на окружение антенны определена на 30 МГц — 3 ГГц, выше модель отказывает, а не продолжает формулу.
  Статистические потери застройки ближе 250 м продолжены за пределы рекомендации; поверх сценариев 3GPP и модели Хаты
  их не добавляют — застройка там уже учтена.
- Разброс по местам по умолчанию — формула P.1812 для области 100 м, около 2 дБ; для планирования вещания обычно
  берут 5,5 дБ.
- Загрузчик берёт плитки из открытого набора AWS Terrain Tiles (высоты над геоидом EGM96, условия использования —
  на странице набора AWS Open Data); другой источник задаётся шаблоном адреса. Сеточный север UTM отличается от
  истинного на доли градуса.
