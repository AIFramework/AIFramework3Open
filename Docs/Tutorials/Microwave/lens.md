# Рупор с диэлектрической линзой

Плосковыпуклая линза с гиперболической преломляющей поверхностью
выпрямляет сферический фронт облучателя, поэтому апертура работает
синфазно при коротком рупоре. Схема короче зеркальной и не имеет
затенения, но платит за это массой диэлектрика.

## Постановка задачи

Дано: частота, мощность, требуемая ШДН, относительный фокус линзы и
материал. Требуется найти диаметр и профиль линзы, толщину в центре,
массу, потери, КСВ и выигрыш от зонирования.

## Теория

**Профиль.** Точка поверхности, для которой оптический путь от фокуса до
плоскости раскрыва одинаков, лежит на гиперболе. В полярных координатах
с началом в фокусе

$$r(\theta) = \frac{(n-1)\,f}{n\cos\theta - 1}, \qquad n = \sqrt{\varepsilon_r}$$

В вершине $r = f$; при $\theta \to \arccos(1/n)$ радиус уходит в
бесконечность. Половинный угол на кромку $\theta_{max}$ находится из
уравнения $r(\theta)\sin\theta = D/2$ численно, **бисекцией**.

**Толщина в центре** — не функция фокуса, а следствие геометрии профиля:

$$t_c = r(\theta_{max})\cos\theta_{max} - f + t_{edge}$$

Отсюда важный вывод: толщина растёт вместе с апертурой, а масса — как её
куб. Линза диаметром 1.7 м из фторопласта весит около тонны, тогда как
зеркало той же апертуры — десятки килограммов.

**Объём** берётся интегрированием профиля адаптивной квадратурой:

$$V = \int_0^{D/2} t(\rho)\,2\pi\rho\,d\rho$$

**Зонирование по Френелю.** Срез профиля на ступень

$$\Delta = \frac{\lambda}{n-1}$$

не меняет фазу на выходе, но снимает материал. Объём зонированной линзы
получается точно, без повторного интегрирования: из полного объёма
вычитаются цилиндры над границами зон.

**Потери.** Пропускание пластины с учётом обеих границ и многократных
переотражений $T = (1-R)/(1+R)$, где $R = ((n-1)/(n+1))^2$. Отражения от
двух граней могут сложиться в фазе, давая КСВ до 2 у непросветлённого
фторопласта. Погонное затухание в теле $\alpha = \pi n \tan\delta / \lambda$.

**Поле в диэлектрике.** Вопреки интуиции, поле в теле линзы **слабее**, а
не сильнее: при том же потоке мощности $E = \sqrt{2 S \eta_0 / n}$.
Опасны воздушные поры: на границе непрерывна нормальная составляющая $D$,
поэтому в поре поле в $\varepsilon_r$ раз выше окружающего.

## Сложность

Бисекция $O(\log(1/\varepsilon))$ на каждый радиус, адаптивная квадратура
Симпсона поверх неё. Практически единицы миллисекунд на линзу.

## API

| Член | Назначение |
|------|------------|
| `DielectricLens.CenterThicknessM` | Толщина в центре из геометрии профиля |
| `DielectricLens.ThicknessAt(rho)` | Толщина на радиусе (бисекция по профилю) |
| `DielectricLens.VolumeM3` | Объём сплошной линзы (квадратура) |
| `DielectricLens.ZoneCount` | Число зон Френеля в профиле |
| `DielectricLens.ZonedVolumeM3` | Объём после срезания зон |
| `DielectricProperties.SlabTransmittance` | Пропускание с учётом обеих границ |
| `HornWithLensCalculator.Calculate(p)` | Полный расчёт антенны |

## Код

```csharp
using AI.Microwave.Geometry;
using AI.Microwave.Models;

var ptfe = DielectricProperties.GetStandardDielectrics()[0];
double lambda = 0.1224;                 // 2.45 ГГц

var lens = new DielectricLens(ptfe, diameterM: 1.71, focalLengthM: 1.71,
                              lambdaM: lambda, edgeThicknessM: 0.01);

Console.WriteLine($"Толщина в центре {lens.CenterThicknessM * 100:F1} см");
Console.WriteLine($"Кромка под углом {lens.RimHalfAngleDeg:F1} град");
Console.WriteLine($"Масса сплошной   {lens.WeightKg:F0} кг");
Console.WriteLine($"Зон {lens.ZoneCount}, зонированная {lens.ZonedWeightKg:F0} кг");
```

## Ограничения

- Модель геометрической оптики: дифракция на кромке линзы и на ступенях
  зонирования не учитывается, поэтому реальный УБЛ зонированной линзы выше
  расчётного.
- Просветляющее покрытие не моделируется, КСВ даётся для непросветлённой
  линзы в худшем (синфазном) случае.
- Зонирование резко сужает полосу: ступень компенсирует фазу только на
  расчётной частоте.
- Зависимость проницаемости от температуры не учитывается.
- Считается только плосковыпуклая линза с выпуклостью к облучателю.
