# Линейная и сферическая интерполяция

Интерполяция позволяет получить промежуточное значение между двумя заданными.
Линейная интерполяция (lerp) работает в евклидовом пространстве, сферическая (slerp) — на единичной сфере.
Slerp незаменим для плавной интерполяции вращений и единичных направлений.

## Линейная интерполяция (lerp)

$$\text{lerp}(a, b, t) = (1 - t)\,a + t\,b, \quad t \in [0, 1]$$

- При $t = 0$ результат равен $a$, при $t = 1$ — равен $b$.
- Скорость движения по отрезку постоянна.

## Сферическая интерполяция (slerp)

Пусть $\theta = \arccos(a \cdot b)$ — угол между единичными векторами $a$ и $b$. Тогда:

$$\text{slerp}(a, b, t) = \frac{\sin\bigl((1-t)\,\theta\bigr)}{\sin\theta}\,a + \frac{\sin(t\,\theta)}{\sin\theta}\,b$$

- Результат всегда лежит на единичной сфере.
- Угловая скорость постоянна (в отличие от нормализованного lerp).

## Вырожденные случаи

| Условие | Рекомендация |
|---------|-------------|
| $\theta \approx 0$ | Используйте lerp — slerp численно нестабилен |
| $\theta \approx \pi$ | Путь не единственный; выберите промежуточную ось |

## Числовые замечания

- Порог переключения slerp → lerp обычно $\sin\theta < 10^{-6}$.
- Для кватернионов: проверяйте знак $a \cdot b$; если отрицателен, инвертируйте один из кватернионов, чтобы идти по короткой дуге.

## API

Класс `AI.Geometry.Interpolation` — методы `Lerp`, `Slerp`.
