# Псевдообратная Мура–Пенроуза

Псевдообратная матрица обобщает понятие обратной на произвольные (в том числе прямоугольные и вырожденные) матрицы.
Единственна для любой матрицы и удовлетворяет четырём условиям Мура–Пенроуза.
Основной инструмент для решения переопределённых и недоопределённых систем.

## Определение

Для $A \in \mathbb{R}^{m \times n}$ псевдообратная $A^+$ — единственная матрица, удовлетворяющая:

1. $A\,A^+\,A = A$
2. $A^+\,A\,A^+ = A^+$
3. $(A\,A^+)^T = A\,A^+$
4. $(A^+\,A)^T = A^+\,A$

## Вычисление через SVD

$$A = U\,\Sigma\,V^T \implies A^+ = V\,\Sigma^+\,U^T$$

где $\Sigma^+ $ получается транспонированием $\Sigma$ и заменой каждого ненулевого $\sigma_i$ на $1/\sigma_i$.

## Решение линейных систем

### Переопределённая система ($m > n$)

$$x = A^+ b = \arg\min_x \|Ax - b\|_2$$

Решение в смысле наименьших квадратов.

### Недоопределённая система ($m < n$)

$$x = A^+ b = \arg\min_x \|x\|_2 \quad \text{при}\quad Ax = b$$

Решение с минимальной нормой.

## Частные случаи

| Условие | Формула |
|---------|---------|
| $A$ — полного столбцового ранга ($m \geq n$) | $A^+ = (A^T A)^{-1} A^T$ |
| $A$ — полного строкового ранга ($m \leq n$) | $A^+ = A^T (A A^T)^{-1}$ |
| $A$ — обратима | $A^+ = A^{-1}$ |

## Числовые замечания

- Малые сингулярные числа ($\sigma_i < \varepsilon \cdot \sigma_1$) следует обнулять в $\Sigma^+$, иначе результат будет неустойчив.
- Порог отсечения: $\varepsilon \cdot \sigma_1 \cdot \max(m, n)$, где $\varepsilon \approx 2.2 \times 10^{-16}$ для `double`.
- Не вычисляйте $A^+$ явно, если нужно только $x = A^+ b$; используйте SVD-решатель напрямую.
