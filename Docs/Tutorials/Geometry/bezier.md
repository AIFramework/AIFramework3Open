# Кривые Безье

Кривая Безье — параметрическая кривая, определяемая набором контрольных точек.
Широко применяется в компьютерной графике, шрифтах (TrueType), CAD и анимации.
Кривая проходит через первую и последнюю контрольные точки, остальные «притягивают» кривую.

## Определение (формула Бернштейна)

Кривая Безье степени $n$ с контрольными точками $P_0, P_1, \ldots, P_n$:

$$B(t) = \sum_{i=0}^{n} \binom{n}{i}\,t^i\,(1-t)^{n-i}\,P_i, \quad t \in [0, 1]$$

### Частные случаи

| Степень | Формула |
|---------|---------|
| $n=1$ (линейная) | $B(t) = (1-t)P_0 + tP_1$ |
| $n=2$ (квадратичная) | $B(t) = (1-t)^2 P_0 + 2t(1-t)P_1 + t^2 P_2$ |
| $n=3$ (кубическая) | $B(t) = (1-t)^3 P_0 + 3t(1-t)^2 P_1 + 3t^2(1-t)P_2 + t^3 P_3$ |

## Алгоритм де Кастельо

Рекурсивная линейная интерполяция:

$$P_i^{(r)}(t) = (1-t)\,P_i^{(r-1)} + t\,P_{i+1}^{(r-1)}, \quad r = 1,\ldots,n$$

Начальные значения: $P_i^{(0)} = P_i$. Результат: $B(t) = P_0^{(n)}$.

### Преимущества

- Численно устойчивее прямого вычисления формулы Бернштейна.
- Естественным образом делит кривую на две (subdivision).

## Свойства

- Кривая лежит внутри выпуклой оболочки контрольных точек.
- $B(0) = P_0$, $B(1) = P_n$.
- Касательная в $t=0$: $B'(0) = n(P_1 - P_0)$.
- **Инвариантность** к аффинным преобразованиям: достаточно преобразовать контрольные точки.

## Числовые замечания

- Для степеней $n > 10$ используйте кусочные кубические кривые вместо одной кривой высокой степени.
- Адаптивная рекурсивная subdivision лучше равномерной дискретизации по $t$.

## API

Пространство имён `AI.Geometry.Curves`. Методов `DeCasteljau` и `Split` в публичном API **нет**: доступны вычисление точки и равномерная выборка.

| Член | Описание |
|------|----------|
| `new BezierCurve(Vector[] controlPoints)` | Кривая степени `controlPoints.Length − 1` |
| `.Evaluate(double t)` | Точка при $t \in [0, 1]$ |
| `.Sample(int n)` | `Vector[]` из `n` точек, равномерно по параметру |

Равномерность по параметру $t$ — не равномерность по длине дуги: на участках большой кривизны точки сгущаются.

Исходник: `src/AI.Geometry/Curves/BezierCurve.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Geometry.Curves;

// Кубическая кривая: четыре контрольные точки
var control = new[]
{
    new Vector(new[] { 0.0, 0.0 }),
    new Vector(new[] { 1.0, 3.0 }),
    new Vector(new[] { 4.0, 3.0 }),
    new Vector(new[] { 5.0, 0.0 }),
};

var curve = new BezierCurve(control);

// Кривая проходит через первую и последнюю контрольные точки,
// но не через промежуточные — это её определяющее свойство
var start = curve.Evaluate(0);
var end   = curve.Evaluate(1);
var mid   = curve.Evaluate(0.5);

Console.WriteLine($"t=0.0 -> ({start[0]:F3}, {start[1]:F3})");
Console.WriteLine($"t=0.5 -> ({mid[0]:F3}, {mid[1]:F3})");
Console.WriteLine($"t=1.0 -> ({end[0]:F3}, {end[1]:F3})");

// Выборка для отрисовки
var pts = curve.Sample(50);
double length = 0;
for (int i = 1; i < pts.Length; i++)
    length += (pts[i] - pts[i - 1]).NormL2();
Console.WriteLine($"Длина ломаной по 50 точкам: {length:F4}");
```
