# Принадлежность точки полигону

Определение, лежит ли точка внутри полигона — классическая задача вычислительной геометрии.
Два основных метода: ray casting (подсчёт пересечений) и winding number (число обходов).
Оба работают за $O(n)$ для полигона из $n$ рёбер.

## Ray Casting (чётность пересечений)

Из точки $P$ проводим луч (обычно вправо, $+x$). Считаем число пересечений с рёбрами полигона.

- **Чётное** число пересечений → точка **снаружи**.
- **Нечётное** → точка **внутри**.

### Обработка граничных случаев

| Случай | Решение |
|--------|---------|
| Луч проходит через вершину | Считать ребро пересечённым, если его концы по разные стороны луча |
| Точка на ребре | Отдельная проверка расстояния до ребра |
| Горизонтальное ребро | Не считать пересечением |

## Winding Number (число обходов)

Подсчитывается, сколько раз контур полигона обходит вокруг точки $P$.

$$w = \frac{1}{2\pi}\sum_{i=1}^{n} \Delta\theta_i$$

где $\Delta\theta_i$ — изменение угла при переходе от вершины $i$ к $i+1$ (с учётом знака).

- $w = 0$ → точка **снаружи**.
- $w \neq 0$ → точка **внутри**.

### Преимущество

Winding number корректно работает для **несамопересекающихся и самопересекающихся** полигонов, тогда как ray casting корректен только для простых полигонов.

## Целочисленный winding number

Вместо вычисления углов можно подсчитать число пересечений вверх/вниз, аналогично ray casting, но со знаком. Это даёт целое $w$ без тригонометрии.

## Числовые замечания

- Для робастности сдвиньте луч на $\varepsilon$ при попадании в вершину.
- При использовании `float` возможны ложные срабатывания для точек вблизи рёбер; используйте `double`.

## API

Класс `AI.Geometry.Polygon` — методы `ContainsRayCast(Point p)`, `ContainsWinding(Point p)`.
