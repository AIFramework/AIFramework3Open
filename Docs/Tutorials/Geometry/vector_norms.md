# Нормы и нормализация векторов

Норма — функция, сопоставляющая вектору неотрицательное число («длину»).
Нормализация превращает вектор в единичный, сохраняя направление.
Разные нормы полезны в разных задачах: L2 — евклидово расстояние, L1 — робастная метрика, L∞ — ограничение по максимальной компоненте.

## Определения

### L1-норма (манхэттенская)

$$\|x\|_1 = \sum_{i=1}^{n} |x_i|$$

### L2-норма (евклидова)

$$\|x\|_2 = \sqrt{\sum_{i=1}^{n} x_i^2}$$

### L∞-норма (чебышёвская)

$$\|x\|_\infty = \max_{i} |x_i|$$

### Lp-норма (обобщённая)

$$\|x\|_p = \left(\sum_{i=1}^{n} |x_i|^p\right)^{1/p}, \quad p \geq 1$$

## Нормализация (единичный вектор)

$$\hat{x} = \frac{x}{\|x\|_2}$$

После нормализации $\|\hat{x}\|_2 = 1$. Если $\|x\|_2 = 0$, нормализация не определена.

## Числовые замечания

- При вычислении L2 возможно переполнение при суммировании $x_i^2$. Используйте масштабирование: разделите на $\max|x_i|$ перед возведением в квадрат.
- Для проверки $\|a\| < \|b\|$ можно сравнивать квадраты норм, избегая `sqrt`.

## API

Отдельного класса `VectorNorms` нет: нормы — **методы самого вектора** `AI.DataStructs.Algebraic.Vector`.

| Член | Описание |
|------|----------|
| `v.NormL1()` | $\|v\|_1 = \sum_i \|v_i\|$ |
| `v.NormL2()` | $\|v\|_2 = \sqrt{\sum_i v_i^2}$ |
| `v.MaxAbs()` | $\|v\|_\infty = \max_i \|v_i\|$ |
| `v.GetUnitVector()` | $v / \|v\|_2$ — новый вектор, исходный не меняется |

Исходники: `src/AI/DataStructs/Algebraic/Vector.Statistics.cs`, `Vector.Operations.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;

var v = new Vector(new[] { 3.0, -4.0, 12.0 });

Console.WriteLine($"‖v‖₁ = {v.NormL1():F4}");    // 19
Console.WriteLine($"‖v‖₂ = {v.NormL2():F4}");    // 13
Console.WriteLine($"‖v‖∞ = {v.MaxAbs():F4}");    // 12

var unit = v.GetUnitVector();
Console.WriteLine($"‖v̂‖₂ = {unit.NormL2():F6}");  // 1

// Неравенство норм ‖v‖∞ ≤ ‖v‖₂ ≤ ‖v‖₁ выполняется для любого вектора
Console.WriteLine(v.MaxAbs() <= v.NormL2() && v.NormL2() <= v.NormL1());
```
