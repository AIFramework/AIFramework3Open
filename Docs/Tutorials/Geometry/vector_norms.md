# Нормы и нормализация векторов

Норма — функция, сопоставляющая вектору неотрицательное число («длину»).
Нормализация превращает вектор в единичный, сохраняя направление.
Разные нормы полезны в разных задачах: L2 — евклидово расстояние, L1 — робастная метрика, L∞ — ограничение по максимальной компоненте.

## Определения

### L1-норма (манхэттенская)

$$\|x\|_1 = \sum_{i=1}^{n} |x_i|$$

### L2-норма (евклидова)

$$\|x\|_2 = \sqrt{\sum_{i=1}^{n} x_i^2}$$

### L∞-норма (чебышёвская)

$$\|x\|_\infty = \max_{i} |x_i|$$

### Lp-норма (обобщённая)

$$\|x\|_p = \left(\sum_{i=1}^{n} |x_i|^p\right)^{1/p}, \quad p \geq 1$$

## Нормализация (единичный вектор)

$$\hat{x} = \frac{x}{\|x\|_2}$$

После нормализации $\|\hat{x}\|_2 = 1$. Если $\|x\|_2 = 0$, нормализация не определена.

## Числовые замечания

- При вычислении L2 возможно переполнение при суммировании $x_i^2$. Используйте масштабирование: разделите на $\max|x_i|$ перед возведением в квадрат.
- Для проверки $\|a\| < \|b\|$ можно сравнивать квадраты норм, избегая `sqrt`.
