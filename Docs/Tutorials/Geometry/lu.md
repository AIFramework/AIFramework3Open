# LU-разложение с частичным выбором

LU-разложение представляет квадратную матрицу как произведение нижней и верхней треугольных матриц.
С частичным выбором ведущего элемента (pivoting) метод численно устойчив.
Используется для решения СЛАУ, вычисления определителя и обратной матрицы.

## Определение

$$PA = LU$$

- $P$ — матрица перестановок (перестановка строк).
- $L$ — нижняя треугольная матрица с единицами на диагонали.
- $U$ — верхняя треугольная матрица.

## Алгоритм

На шаге $k$:

1. **Выбор ведущего элемента**: найти $\max_{i \geq k} |a_{ik}|$ и переставить строки.
2. **Элиминация**: для $i > k$:
   $$l_{ik} = \frac{a_{ik}}{a_{kk}}, \quad a_{ij} \leftarrow a_{ij} - l_{ik}\,a_{kj}, \quad j > k$$

Сложность: $\frac{2}{3}n^3$ операций.

## Решение СЛАУ $Ax = b$

$$PAx = Pb \Rightarrow LUx = Pb$$

1. Прямая подстановка: $Ly = Pb$ → $O(n^2)$.
2. Обратная подстановка: $Ux = y$ → $O(n^2)$.

Для нескольких правых частей $b$ разложение выполняется один раз.

## Определитель

$$\det(A) = (-1)^s \prod_{i=1}^{n} u_{ii}$$

где $s$ — число перестановок строк (чётность перестановки $P$).

## Обратная матрица

Решаем $AX = I$ по столбцам: каждый столбец $X$ — решение СЛАУ с единичным вектором.

## Числовые замечания

- Без выбора ведущего элемента метод неустойчив (даже для хорошо обусловленных матриц).
- Если $u_{kk} = 0$ — матрица вырождена.
- Полный выбор (по строкам и столбцам) используется редко; частичный достаточен для большинства задач.
- Для ленточных/разреженных матриц существуют специализированные варианты.

## API

Класс `LU` лежит в `AI.ClassicMath.MatrixUtils` и **статичен**: разложение не сохраняется между вызовами, поэтому `Solve` и `Determinant` принимают матрицу заново.

| Член | Описание |
|------|----------|
| `LU.Decompose(Matrix A)` | `(Matrix L, Matrix U, int[] perm)` — вектор перестановки строк |
| `LU.Solve(Matrix A, Vector b)` | Решение $Ax = b$ |
| `LU.Determinant(Matrix A)` | Определитель |

При решении нескольких систем с одной и той же матрицей `Solve` каждый раз раскладывает её заново — выигрыш от повторного использования разложения здесь не получить.

Исходник: `src/AI.ClassicMath/MatrixUtils/LU.cs`.

## Код

```csharp
using AI.ClassicMath.MatrixUtils;
using AI.DataStructs.Algebraic;

var A = new Matrix(3, 3);
A[0, 0] = 2; A[0, 1] = 1; A[0, 2] = -1;
A[1, 0] = -3; A[1, 1] = -1; A[1, 2] = 2;
A[2, 0] = -2; A[2, 1] = 1; A[2, 2] = 2;

var b = new Vector(new[] { 8.0, -11.0, -3.0 });

var x = LU.Solve(A, b);
Console.WriteLine($"x = [{x[0]:F4}, {x[1]:F4}, {x[2]:F4}]");   // [2, 3, -1]

Console.WriteLine($"det(A) = {LU.Determinant(A):F4}");

// Разложение с частичным выбором ведущего элемента
var (L, U, perm) = LU.Decompose(A);
Console.WriteLine($"Перестановка строк: [{string.Join(", ", perm)}]");

// Проверка невязки
var residual = (A * x).LikeVector() - b;
Console.WriteLine($"‖Ax − b‖ = {residual.NormL2():E3}");
```
