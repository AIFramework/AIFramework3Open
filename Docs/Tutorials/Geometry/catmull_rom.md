# Сплайн Catmull–Rom

Сплайн Catmull–Rom — частный случай сплайна Эрмита с автоматическим вычислением касательных.
Кривая проходит через все заданные точки (интерполирующий сплайн).
Параметр $\alpha$ управляет параметризацией: равномерная, хордальная или центрипетальная.

## Касательные

Для точки $P_k$ касательная вычисляется по соседним точкам:

$$m_k = \frac{P_{k+1} - P_{k-1}}{2}$$

На границах (первая/последняя точка) можно использовать:
- $m_0 = P_1 - P_0$ (линейная экстраполяция)
- Задать явно
- Дублировать крайнюю точку

## Формула сегмента

Между точками $P_1$ и $P_2$ (с соседями $P_0$ и $P_3$) и параметром $s \in [0,1]$:

$$q(s) = \frac{1}{2}\begin{pmatrix}s^3 & s^2 & s & 1\end{pmatrix}\begin{pmatrix}-1 & 3 & -3 & 1\\2 & -5 & 4 & -1\\-1 & 0 & 1 & 0\\0 & 2 & 0 & 0\end{pmatrix}\begin{pmatrix}P_0\\P_1\\P_2\\P_3\end{pmatrix}$$

## Центрипетальная параметризация

Вместо равномерной параметризации ($\alpha = 0$) используется:

$$t_{k+1} = t_k + \|P_{k+1} - P_k\|^{\alpha}$$

| $\alpha$ | Тип | Свойство |
|----------|-----|----------|
| 0 | Равномерная | Простота |
| 0.5 | Центрипетальная | Без петель и самопересечений |
| 1 | Хордальная | Пропорциональна длине хорды |

Центрипетальная ($\alpha = 0.5$) рекомендуется как универсальный выбор.

## Свойства

- $C^1$-непрерывность (непрерывная первая производная).
- Не гарантируется $C^2$ (в отличие от натурального кубического сплайна).
- Локальность: изменение одной точки влияет только на 4 соседних сегмента.

## Числовые замечания

- Минимум 4 точки для одного сегмента.
- При $\|P_{k+1} - P_k\| \approx 0$ центрипетальная параметризация может давать деление на ноль — объединяйте совпадающие точки.

## API

Пространство имён `AI.Geometry.Curves`, класс называется `CatmullRomCurve`.

| Член | Описание |
|------|----------|
| `new CatmullRomCurve(Vector[] points, double alpha = 0.5)` | Кривая через все точки; $\alpha$ — параметризация |
| `.Evaluate(double t)` | Точка при $t \in [0, 1]$ |
| `.Sample(int n)` | `Vector[]` из `n` точек |

Значение $\alpha$: 0 — равномерная, 0.5 — центростремительная (по умолчанию), 1 — хордовая. Центростремительная — единственная, гарантированно свободная от петель и самопересечений на близко расположенных точках.

Исходник: `src/AI.Geometry/Curves/CatmullRomCurve.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Geometry.Curves;

var points = new[]
{
    new Vector(new[] { 0.0, 0.0 }),
    new Vector(new[] { 1.0, 2.0 }),
    new Vector(new[] { 3.0, 1.5 }),
    new Vector(new[] { 4.0, 3.0 }),
    new Vector(new[] { 6.0, 2.0 }),
};

// Касательные вычисляются по соседям автоматически — задавать их не нужно
var curve = new CatmullRomCurve(points, alpha: 0.5);
var samples = curve.Sample(100);

double length = 0;
for (int i = 1; i < samples.Length; i++)
    length += (samples[i] - samples[i - 1]).NormL2();

Console.WriteLine($"Длина кривой: {length:F4}");
```

Сравнение параметризаций на одних данных — именно так выбирают $\alpha$ под задачу:

```csharp
foreach (double alpha in new[] { 0.0, 0.5, 1.0 })
{
    var c = new CatmullRomCurve(points, alpha);
    var s = c.Sample(200);

    double len = 0;
    for (int i = 1; i < s.Length; i++) len += (s[i] - s[i - 1]).NormL2();

    string name = alpha switch
    {
        0.0 => "равномерная",
        1.0 => "хордовая",
        _   => "центростремительная",
    };
    Console.WriteLine($"α={alpha:F1} ({name,-20}) длина={len:F4}");
}
```
