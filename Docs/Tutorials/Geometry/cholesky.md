# Разложение Холецкого

Разложение Холецкого — факторизация симметричной положительно определённой (SPD) матрицы.
Вдвое быстрее LU-разложения и требует вдвое меньше памяти.
Применяется в решении СЛАУ, регуляризации и генерации коррелированных случайных величин.

## Определение

Для SPD-матрицы $A$:

$$A = L\,L^T$$

где $L$ — нижняя треугольная матрица с положительными диагональными элементами.

## Алгоритм

$$l_{jj} = \sqrt{a_{jj} - \sum_{k=1}^{j-1} l_{jk}^2}$$

$$l_{ij} = \frac{1}{l_{jj}}\left(a_{ij} - \sum_{k=1}^{j-1} l_{ik}\,l_{jk}\right), \quad i > j$$

Сложность: $\frac{1}{3}n^3$ операций (вдвое меньше LU).

## Решение СЛАУ $Ax = b$

$$LL^T x = b$$

1. Прямая подстановка: $Ly = b$.
2. Обратная подстановка: $L^T x = y$.

## Проверка положительной определённости

Если в процессе разложения $a_{jj} - \sum l_{jk}^2 \leq 0$, матрица **не является SPD**. Разложение Холецкого служит одновременно тестом на положительную определённость.

## Применения

### Регуляризация (Тихонов)

$$(A^T A + \lambda I)\,x = A^T b$$

Матрица $A^T A + \lambda I$ — SPD при $\lambda > 0$. Холецкий — оптимальный метод решения.

### Генерация коррелированных случайных величин

Пусть $\Sigma = LL^T$ — ковариационная матрица. Тогда $x = L\,z$, где $z \sim \mathcal{N}(0, I)$, даёт $x \sim \mathcal{N}(0, \Sigma)$.

## Числовые замечания

- Не требует выбора ведущего элемента (для SPD-матриц алгоритм безусловно устойчив).
- Для почти вырожденных матриц добавьте малую регуляризацию $\varepsilon I$.
- Существует вариант $LDL^T$ без извлечения корня.
