# Разложение Холецкого

Разложение Холецкого — факторизация симметричной положительно определённой (SPD) матрицы.
Вдвое быстрее LU-разложения и требует вдвое меньше памяти.
Применяется в решении СЛАУ, регуляризации и генерации коррелированных случайных величин.

## Определение

Для SPD-матрицы $A$:

$$A = L\,L^T$$

где $L$ — нижняя треугольная матрица с положительными диагональными элементами.

## Алгоритм

$$l_{jj} = \sqrt{a_{jj} - \sum_{k=1}^{j-1} l_{jk}^2}$$

$$l_{ij} = \frac{1}{l_{jj}}\left(a_{ij} - \sum_{k=1}^{j-1} l_{ik}\,l_{jk}\right), \quad i > j$$

Сложность: $\frac{1}{3}n^3$ операций (вдвое меньше LU).

## Решение СЛАУ $Ax = b$

$$LL^T x = b$$

1. Прямая подстановка: $Ly = b$.
2. Обратная подстановка: $L^T x = y$.

## Проверка положительной определённости

Если в процессе разложения $a_{jj} - \sum l_{jk}^2 \leq 0$, матрица **не является SPD**. Разложение Холецкого служит одновременно тестом на положительную определённость.

## Применения

### Регуляризация (Тихонов)

$$(A^T A + \lambda I)\,x = A^T b$$

Матрица $A^T A + \lambda I$ — SPD при $\lambda > 0$. Холецкий — оптимальный метод решения.

### Генерация коррелированных случайных величин

Пусть $\Sigma = LL^T$ — ковариационная матрица. Тогда $x = L\,z$, где $z \sim \mathcal{N}(0, I)$, даёт $x \sim \mathcal{N}(0, \Sigma)$.

## Числовые замечания

- Не требует выбора ведущего элемента (для SPD-матриц алгоритм безусловно устойчив).
- Для почти вырожденных матриц добавьте малую регуляризацию $\varepsilon I$.
- Существует вариант $LDL^T$ без извлечения корня.

## API

Класс `Cholesky` лежит в `AI.ClassicMath.MatrixUtils` и статичен: свойства `L` нет — множитель возвращает сам `Decompose`.

| Член | Описание |
|------|----------|
| `Cholesky.Decompose(Matrix A)` | `Matrix L` — нижнетреугольный множитель, $A = LL^{\top}$ |
| `Cholesky.Solve(Matrix A, Vector b)` | Решение $Ax = b$ для симметричной положительно определённой $A$ |

Матрица обязана быть симметричной и положительно определённой. На неподходящей матрице разложение не имеет смысла — проверяйте это до вызова, а не по результату.

Исходник: `src/AI.ClassicMath/MatrixUtils/Cholesky.cs`.

## Код

```csharp
using AI.ClassicMath.MatrixUtils;
using AI.DataStructs.Algebraic;

// Надёжный способ получить SPD-матрицу: A = RᵀR + λI
var R = new Matrix(3, 3);
R[0, 0] = 1; R[0, 1] = 2; R[0, 2] = 0;
R[1, 0] = 0; R[1, 1] = 1; R[1, 2] = 1;
R[2, 0] = 1; R[2, 1] = 0; R[2, 2] = 2;

var A = R.Transpose() * R;
for (int i = 0; i < 3; i++) A[i, i] += 3;   // диагональное преобладание

var L = Cholesky.Decompose(A);

// Проверка A = LLᵀ
var restored = L * L.Transpose();
double err = 0;
for (int r = 0; r < 3; r++)
    for (int c = 0; c < 3; c++)
        err += Math.Pow(A[r, c] - restored[r, c], 2);
Console.WriteLine($"‖A − LLᵀ‖²F = {err:E3}");

var b = new Vector(new[] { 1.0, 2.0, 3.0 });
var x = Cholesky.Solve(A, b);
Console.WriteLine($"x = [{x[0]:F4}, {x[1]:F4}, {x[2]:F4}]");
Console.WriteLine($"Невязка: {((A * x).LikeVector() - b).NormL2():E3}");
```
