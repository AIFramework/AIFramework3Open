# Метод Якоби для собственных значений

Метод Якоби — итеративный алгоритм нахождения всех собственных значений и собственных векторов симметричной матрицы.
Основан на последовательных вращениях Гивенса, обнуляющих внедиагональные элементы.
Отличается простотой реализации и безусловной сходимостью для симметричных матриц.

## Идея

Применяем ортогональные вращения $G_{pq}$, чтобы обнулить элемент $a_{pq}$:

$$A' = G_{pq}^T\,A\,G_{pq}$$

Матрица вращения Гивенса $G_{pq}$ отличается от единичной в позициях $(p,p)$, $(q,q)$, $(p,q)$, $(q,p)$:

$$g_{pp} = g_{qq} = \cos\theta, \quad g_{pq} = -\sin\theta, \quad g_{qp} = \sin\theta$$

## Вычисление угла

Для обнуления $a_{pq}$:

$$\tan 2\theta = \frac{2\,a_{pq}}{a_{qq} - a_{pp}}$$

Если $a_{pp} = a_{qq}$, то $\theta = \pi/4$.

## Алгоритм

1. Найти наибольший по модулю внедиагональный элемент $a_{pq}$.
2. Вычислить угол $\theta$ и применить вращение $G_{pq}$.
3. Повторять до $\max_{p \neq q}|a_{pq}| < \varepsilon$.

Собственные значения — диагональные элементы итоговой матрицы. Собственные векторы — произведение всех вращений: $V = G_1 G_2 \cdots G_k$.

## Сходимость

- Квадратичная сходимость (при классической стратегии выбора максимального элемента).
- Сумма квадратов внедиагональных элементов $\text{off}(A)^2$ строго убывает на каждом шаге.
- Типичное число итераций: $\sim 5n^2$ вращений.

## Циклическая стратегия

Вместо поиска максимума (стоимость $O(n^2)$) можно перебирать пары $(p,q)$ по порядку (row-sweep). Сходимость сохраняется, но может потребоваться больше проходов.

## Числовые замечания

- Метод устойчив и прост, но медленнее QR-алгоритма для больших матриц.
- Оптимален для малых и средних матриц ($n \lesssim 100$).
- Для избежания потери ортогональности периодически переортогонализируйте $V$.
