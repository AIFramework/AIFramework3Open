# Сингулярное разложение (SVD)

Сингулярное разложение — одна из важнейших факторизаций в линейной алгебре.
Существует для любой матрицы (не обязательно квадратной или симметричной).
Применяется в PCA, вычислении псевдообратной, сжатии данных, TLS и решении гомогенных систем.

## Определение

Для матрицы $A \in \mathbb{R}^{m \times n}$:

$$A = U\,\Sigma\,V^T$$

- $U \in \mathbb{R}^{m \times m}$ — ортогональная матрица (левые сингулярные векторы).
- $\Sigma \in \mathbb{R}^{m \times n}$ — диагональная матрица с $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$.
- $V \in \mathbb{R}^{n \times n}$ — ортогональная матрица (правые сингулярные векторы).

## Геометрический смысл

Линейное преобразование $A$ раскладывается на три шага:

1. **Поворот** (или отражение) $V^T$ в пространстве $\mathbb{R}^n$.
2. **Масштабирование** $\Sigma$ вдоль координатных осей.
3. **Поворот** (или отражение) $U$ в пространстве $\mathbb{R}^m$.

## Основные применения

| Задача | Использование SVD |
|--------|-------------------|
| PCA | Правые сингулярные векторы $V$ — главные компоненты |
| Псевдообратная | $A^+ = V\Sigma^+ U^T$ |
| Ранг матрицы | Число ненулевых $\sigma_i$ |
| Наименьшие квадраты (TLS) | Правый сингулярный вектор, соответствующий наименьшему $\sigma$ |
| Низкоранговое приближение | $A_k = \sum_{i=1}^{k}\sigma_i\,u_i\,v_i^T$ (теорема Эккарта–Янга) |

## Усечённое SVD

Для $k \ll \min(m,n)$ достаточно вычислить $k$ наибольших сингулярных чисел и соответствующих векторов. Это экономит память и время.

## Числовые замечания

- Сложность полного SVD: $O(\min(mn^2, m^2n))$.
- Сингулярные числа всегда неотрицательны.
- Отношение $\sigma_1 / \sigma_{\min}$ — число обусловленности матрицы.
- Порог отсечения малых $\sigma_i$: обычно $\varepsilon \cdot \sigma_1 \cdot \max(m,n)$, где $\varepsilon$ — машинная точность.

## API

Класс `AI.Geometry.SVD` — метод `Decompose(Matrix A)`, свойства `U`, `S`, `V`.
