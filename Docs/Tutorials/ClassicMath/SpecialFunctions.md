## Полный эллиптический интеграл первого рода K(k)

### Определение

Полный эллиптический интеграл первого рода определяется как:

$$K(k) = \int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - k^2 \sin^2\!\theta}}, \quad k \in [0,\, 1)$$

Параметр \(k\) называется **модулем** интеграла. При \(k \to 1\) интеграл расходится: \(K(k) \to +\infty\).

### Метод вычисления: алгоритм AGM

Наиболее эффективный алгоритм вычисления \(K(k)\) основан на итерациях **арифметико-геометрического среднего (AGM)**:

1. Начальные значения: \(a_0 = 1\), \(g_0 = \sqrt{1 - k^2}\).
2. На каждой итерации:

$$a_{n+1} = \frac{a_n + g_n}{2}, \quad g_{n+1} = \sqrt{a_n g_n}$$

3. При сходимости \(a_n \to g_n \to M(1, \sqrt{1-k^2})\) результат:

$$K(k) = \frac{\pi}{2\,M(1,\, \sqrt{1-k^2})}$$

Алгоритм AGM имеет квадратичную скорость сходимости: каждая итерация удваивает количество верных знаков. Достаточно 10–15 итераций для точности двойной точности IEEE 754.

### Частные значения

| \(k\) | \(K(k)\) |
|--------|----------|
| 0 | \(\pi/2 \approx 1.5708\) |
| \(1/\sqrt{2}\) | \(\Gamma(1/4)^2 / (4\sqrt{\pi}) \approx 1.8541\) |
| \(\to 1\) | \(\to +\infty\) |

### Приложения

- Период нелинейного математического маятника: \(T = 4\sqrt{L/g}\,K(\sin(\theta_0/2))\).
- Конформные отображения и задачи электростатики.
- Теория эллиптических кривых в криптографии.

---

## API

| Метод | Описание |
|-------|----------|
| `EllipticIntegral.CompleteEllipticIntegral_I(k)` | Возвращает \(K(k)\) для \(k \in [0, 1)\). |

---

## Примеры

```csharp
using AI.ClassicMath;

// K(0) = π/2
double k0 = EllipticIntegral.CompleteEllipticIntegral_I(0.0);
Console.WriteLine($"K(0)     = {k0:F6}");  // ≈ 1.570796

// K(0.5)
double k05 = EllipticIntegral.CompleteEllipticIntegral_I(0.5);
Console.WriteLine($"K(0.5)   = {k05:F6}"); // ≈ 1.685750

// K(0.99)
double k99 = EllipticIntegral.CompleteEllipticIntegral_I(0.99);
Console.WriteLine($"K(0.99)  = {k99:F6}"); // ≈ 3.356556
```

---

## Замечания

- При \(k \ge 1\) интеграл не определён; метод возвращает `NaN` или выбрасывает исключение.
- При \(k\) близком к единице рекомендуется использовать логарифмическое приближение для контроля точности: \(K(k) \approx \ln(4/k') + O(k'^2 \ln k')\), где \(k' = \sqrt{1-k^2}\).
