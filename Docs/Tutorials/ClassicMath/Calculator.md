# Вычислитель математических выражений (AdvancedCalculator / Processor)

**Пространство имён:** `AI.ClassicMath.Calculator`  
**Классы:** `AdvancedCalculator`, `Processor`, `ExecutionContext`

---

## Назначение

`AdvancedCalculator` выполняет разбор и вычисление одиночных математических выражений.  
`Processor` — полноценный интерпретатор скриптов: поддерживает переменные, ветвление, циклы, функции и комментарии.

## 5. Условный оператор (if / elif / else)

**C-style:**
```
if (x > 0) {
    y = 1
} else {
    y = -1
}
```

**Python-style (отступы):**
```
if x > 0:
    y = 1
elif x == 0:
    y = 0
else:
    y = -1
```

**Тернарный оператор:**
```
y = x > 0 ? 1 : -1
```

## 6. Циклы

**`for` Python-style (рекомендуется):**
```
s = 0
for i = 1 to 10:
    s += i
s    // → 55
```

С шагом:
```
for i = 10 to 1 step -2:
    i    // 10, 8, 6, 4, 2
```

**`for` C-style:**
```
for(i = 0; i < 5; i++) {
    i
}
```

**`while`:**
```
n = 1
while (n < 100) {
    n = n * 2
}
n    // → 128
```

**`break` и `continue`:**
```
for i = 1 to 20:
    if i == 5:
        break
    if i % 2 == 0:
        continue
    i    // выводит нечётные до 5
```

## 9. Пример скрипта

```
// Числа Фибоначчи
a = 0
b = 1
for i = 1 to 15:
    c = a + b
    a = b
    b = c
b    // → 987

// Факториал
n = 10
f = 1
for i = 2 to n:
    f *= i
f    // → 3628800

// Простые числа до 30
for n = 2 to 30:
    isPrime = 1
    for d = 2 to n-1:
        if n % d == 0:
            isPrime = 0
            break
    if isPrime == 1:
        n
```

---

## Замечания

- Выражения внутри блоков (`if`, `for`, `while`) выполняются в тихом режиме — результат не выводится автоматически. Для вывода нужна отдельная строка с именем переменной.
- Деление на ноль возвращает `∞` в соответствии со стандартом IEEE 754.
- Числа, являющиеся простыми дробями, автоматически отображаются с представлением `[числитель/знаменатель]`.
