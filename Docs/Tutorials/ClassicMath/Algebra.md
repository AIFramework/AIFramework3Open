**Пространство имён:** `AI.ClassicMath`  
**Классы:** `Gauss`, `Kramer`, `QR`, `EigenValuesVectors`

## 1. Метод Гаусса

### Теоретическое обоснование

Метод Гаусса решает систему линейных алгебраических уравнений (СЛАУ) вида

$$A x = b, \quad A \in \mathbb{R}^{n \times n},\; b \in \mathbb{R}^n$$

посредством последовательного приведения расширенной матрицы \([A \mid b]\) к верхнетреугольному виду (прямой ход) с последующей обратной подстановкой.

**Прямой ход** (с частичным выбором главного элемента по столбцу):

На шаге \(k = 0, \ldots, n-2\):

1. Находим строку \(r \ge k\) с максимальным \(|a_{rk}|\) и переставляем строки \(r \leftrightarrow k\).
2. Для каждой строки \(i > k\) вычисляем множитель \(m_{ik} = a_{ik} / a_{kk}\) и вычитаем:

$$\text{строка}_i \;\leftarrow\; \text{строка}_i - m_{ik} \cdot \text{строка}_k$$

**Обратная подстановка:**

$$x_k = \frac{b_k - \displaystyle\sum_{j=k+1}^{n-1} a_{kj}\,x_j}{a_{kk}}, \quad k = n-1, \ldots, 0$$

Выбор главного элемента обеспечивает численную устойчивость и уменьшает ошибки округления.

### API

| Метод | Описание |
|-------|----------|
| `Gauss.SolvingEquations(A, b)` | Возвращает вектор \(x\) решения СЛАУ. |

### Пример

```csharp
using AI.ClassicMath;
using AI.DataStructs.Algebraic;

var A = new Matrix(new double[,]
{
    { 2, 1, -1 },
    { -3, -1, 2 },
    { -2, 1, 2 }
});
var b = new Vector(new[] { 8.0, -11.0, -3.0 });

Vector x = Gauss.SolvingEquations(A, b);
// Ожидаемый результат: x ≈ [2, 3, -1]
Console.WriteLine(x);
```

## 2. Метод Крамера

### Теоретическое обоснование

Метод Крамера применим для невырожденных квадратных систем (\(\det A \ne 0\)). Каждая компонента решения вычисляется через определитель:

$$x_k = \frac{\det A_k}{\det A}, \quad k = 0, \ldots, n-1$$

где \(A_k\) — матрица \(A\) с заменой \(k\)-го столбца на вектор \(b\).

Алгоритмическая сложность составляет \(\mathcal{O}(n \cdot n!)\) при вычислении определителей наивным разложением по строке, поэтому на практике метод применяют преимущественно для систем малого порядка (\(n \le 4\)).

### API

| Метод | Описание |
|-------|----------|
| `Kramer.SolvingEquations(A, b)` | Возвращает вектор \(x\) решения СЛАУ. |

### Пример

```csharp
var A = new Matrix(new double[,] { { 3, 1 }, { 1, 2 } });
var b = new Vector(new[] { 9.0, 8.0 });

Vector x = Kramer.SolvingEquations(A, b);
// Ожидаемый результат: x ≈ [2, 3]
```

## 3. QR-разложение (процедура Грама — Шмидта)

### Теоретическое обоснование

QR-разложение представляет матрицу \(A \in \mathbb{R}^{n \times m}\) в виде произведения:

$$A = Q R$$

где \(Q \in \mathbb{R}^{n \times m}\) — матрица с ортонормированными столбцами (\(Q^\top Q = I\)), а \(R \in \mathbb{R}^{m \times m}\) — верхнетреугольная матрица.

**Классическая процедура Грама — Шмидта:**

Для каждого столбца \(a_j\) матрицы \(A\):

$$u_j = a_j - \sum_{i=0}^{j-1} \mathrm{proj}_{q_i} a_j, \quad q_j = \frac{u_j}{\|u_j\|}$$

$$R_{ij} = q_i^\top a_j \;(i < j), \quad R_{jj} = \|u_j\|$$

Разложение применяется для решения МНК-задач, вычисления собственных значений (QR-алгоритм) и ортогонализации базиса.

### API

| Метод | Описание |
|-------|----------|
| `QR.GetQ(A)` | Возвращает матрицу \(Q\). |
| `QR.GetR(A)` | Возвращает матрицу \(R\). |

### Пример

```csharp
var A = new Matrix(new double[,]
{
    { 1, 1, 0 },
    { 1, 0, 1 },
    { 0, 1, 1 }
});

Matrix Q = QR.GetQ(A);
Matrix R = QR.GetR(A);

// Проверка: Q * R ≈ A
```

## 4. Собственные значения и собственные векторы

### Теоретическое обоснование

Собственное значение \(\lambda\) и соответствующий собственный вектор \(v \ne 0\) квадратной матрицы \(A\) удовлетворяют уравнению:

$$A v = \lambda v \quad \Longleftrightarrow \quad (A - \lambda I)\,v = 0$$

Реализован итерационный **QR-алгоритм без сдвига**:

1. Начальное приближение: \(A_0 = A\).
2. На каждой итерации: разложить \(A_k = Q_k R_k\), затем \(A_{k+1} = R_k Q_k\).
3. Повторять до сходимости: матрица \(A_k\) сходится к верхнетреугольной (или блочно-треугольной при комплексных парах), собственные значения — на главной диагонали.

Порядок алгоритма: \(\mathcal{O}(n^3)\) на итерацию, сходимость кубическая для вещественных собственных значений при стандартных сдвигах (здесь без сдвига — линейная).

Параметр `eigenIter` задаёт максимальное число итераций; значение 80–100 достаточно для матриц порядка до 10×10.

### API

| Метод | Описание |
|-------|----------|
| `EigenValuesVectors.Eigenvalues(A, maxIter)` | Возвращает вектор собственных значений. |

### Пример

```csharp
var A = new Matrix(new double[,]
{
    {  4, -2 },
    {  1,  1 }
});

Vector eigenvalues = EigenValuesVectors.Eigenvalues(A, maxIter: 100);
// Ожидаемый результат: λ ≈ [3, 2]
Console.WriteLine(eigenvalues);
```

## Замечания

- Метод Гаусса является предпочтительным для систем порядка \(n > 3\) ввиду сложности \(\mathcal{O}(n^3)\) против \(\mathcal{O}(n \cdot n!)\) у метода Крамера.
- При \(\det A = 0\) (вырожденная матрица) метод Гаусса сообщит об ошибке, метод Крамера выполнит деление на ноль.
- QR-алгоритм для собственных значений предполагает вещественную матрицу; комплексные пары могут потребовать специального разбиения (блоки 2×2).
