# Обыкновенные дифференциальные уравнения

**Пространство имён:** `AI.ClassicMath`  
**Класс:** `RungeKutta`

---

## Назначение

Решение задачи Коши для обыкновенного дифференциального уравнения (ОДУ) первого порядка:

$$\frac{dy}{dx} = f(x,\, y), \quad y(x_0) = y_0$$

на отрезке \([x_0,\, x_f]\) с постоянным шагом \(h\).

---

## Метод Рунге — Кутты 4-го порядка (RK4)

### Алгоритм

На каждом шаге \(x_n \to x_{n+1} = x_n + h\) вычисляются четыре промежуточных наклона:

$$k_1 = h \cdot f(x_n,\; y_n)$$

$$k_2 = h \cdot f\!\left(x_n + \tfrac{h}{2},\; y_n + \tfrac{k_1}{2}\right)$$

$$k_3 = h \cdot f\!\left(x_n + \tfrac{h}{2},\; y_n + \tfrac{k_2}{2}\right)$$

$$k_4 = h \cdot f(x_n + h,\; y_n + k_3)$$

Обновление:

$$y_{n+1} = y_n + \frac{k_1 + 2k_2 + 2k_3 + k_4}{6}$$

Коэффициенты \(1, 2, 2, 1\) являются весами составного правила Симпсона, применённого к оценке интеграла.

### Порядок точности

- **Локальная погрешность** одного шага: \(\mathcal{O}(h^5)\).
- **Глобальная погрешность** на конечном интервале: \(\mathcal{O}(h^4)\).

Метод является явным — не требует решения нелинейных уравнений на каждом шаге, прост в реализации и обеспечивает хорошее соотношение точности и вычислительных затрат (4 вычисления \(f\) на шаг).

### Устойчивость

Для тестового уравнения \(y' = \lambda y\) (\(\lambda \in \mathbb{C}\)) область абсолютной устойчивости RK4 охватывает часть левой полуплоскости. Для вещественного отрицательного \(\lambda\) условие устойчивости:

$$|h \lambda| \le 2.785$$

При жёстких уравнениях (large \(|\lambda|\)) следует использовать неявные методы.

---

## API

| Метод | Описание |
|-------|----------|
| `RungeKutta.Solve(f, x0, y0, xf, h)` | Решает ОДУ \(y' = f(x, y)\) на отрезке \([x_0, x_f]\) с шагом \(h\). Возвращает вектор значений \(y\). |

---

## Примеры

### Экспоненциальный распад

Уравнение: \(y' = -k y\), точное решение: \(y(x) = y_0 e^{-k x}\).

```csharp
using AI.ClassicMath;
using AI.DataStructs.Algebraic;

double k = 0.7, x0 = 0, y0 = 1.0, xf = 5.0, h = 0.05;

// Правая часть ОДУ
Func<double, double, double> f = (x, y) => -k * y;

Vector y = RungeKutta.Solve(f, x0, y0, xf, h);

// Проверка конечного значения
double yExact = y0 * Math.Exp(-k * xf);
Console.WriteLine($"y({xf}) ≈ {y[^1]:F6}  (точное: {yExact:F6})");
```

### Уравнение гармонического осциллятора

Уравнение второго порядка \(\ddot{x} + \omega^2 x = 0\) сводится к системе первого порядка:

$$\dot{x}_1 = x_2, \quad \dot{x}_2 = -\omega^2 x_1$$

Используйте RK4 для каждой компоненты состояния \([x_1,\, x_2]\) покомпонентно или решайте систему ОДУ.

---

## Замечания

- Уменьшение шага \(h\) вдвое уменьшает глобальную погрешность приблизительно в 16 раз (\(2^4\)).
- Для контроля точности используйте сравнение с результатом при \(h/2\) (правило Рунге).
- При жёстких ОДУ (например, системах с большим разбросом собственных значений) рекомендуется метод Дормана — Принса (RK45) или неявный метод трапеций.
