# Комбинаторика

**Пространство имён:** `AI.ClassicMath`  
**Класс:** `CombinatoricsBaseFunction`

---

## 1. Размещения без повторений

### Определение

Размещение без повторений из \(n\) элементов по \(k\) — это упорядоченная выборка \(k\) различных элементов из множества мощности \(n\). Порядок следования элементов **существенен**.

### Формула

$$A_n^k = \frac{n!}{(n - k)!} = n \cdot (n-1) \cdot (n-2) \cdots (n-k+1)$$

**Условие применимости:** \(0 \le k \le n\).

### API

| Метод | Тип результата | Описание |
|-------|----------------|----------|
| `PlacingWithoutRepetition(n, k)` | `double` | Число размещений \(A_n^k\). |

### Примеры

```csharp
using AI.ClassicMath;

// Сколькими способами можно расставить 3 книги на 10 имеющихся?
double a = CombinatoricsBaseFunction.PlacingWithoutRepetition(n: 10, k: 3);
// A(10, 3) = 10 * 9 * 8 = 720
Console.WriteLine(a);  // 720
```

## 2. Сочетания без повторений

### Определение

Сочетание без повторений из \(n\) элементов по \(k\) — это неупорядоченная выборка \(k\) различных элементов из множества мощности \(n\). Порядок следования элементов **несущественен**.

### Формула

$$C_n^k = \binom{n}{k} = \frac{n!}{k!\,(n - k)!}$$

**Рекуррентное соотношение (треугольник Паскаля):**

$$\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}, \quad \binom{n}{0} = \binom{n}{n} = 1$$

**Симметрия:** \(\binom{n}{k} = \binom{n}{n-k}\).

**Условие применимости:** \(0 \le k \le n\).

### API

| Метод | Тип результата | Описание |
|-------|----------------|----------|
| `NumberOfCombinations(n, k)` | `double` | Число сочетаний \(C_n^k\) (тип `double`). |
| `Combinations(n, k)` | `long` | Число сочетаний \(C_n^k\) (тип `long`). |

Метод `Combinations` вычисляет результат итеративно без явного вычисления факториалов, что исключает переполнение на промежуточных шагах при умеренных значениях \(n\).

### Примеры

```csharp
// Сколькими способами можно выбрать комиссию из 4 человек из 12?
double c = CombinatoricsBaseFunction.NumberOfCombinations(n: 12, k: 4);
// C(12, 4) = 495
Console.WriteLine(c);  // 495

long cLong = CombinatoricsBaseFunction.Combinations(n: 20, k: 10);
// C(20, 10) = 184 756
Console.WriteLine(cLong);  // 184756
```

## Сравнение понятий

| Характеристика | Размещение \(A_n^k\) | Сочетание \(C_n^k\) |
|----------------|---------------------|---------------------|
| Учитывается ли порядок? | Да | Нет |
| Повторения элементов | Нет | Нет |
| Формула | \(n!/(n-k)!\) | \(n!/(k!(n-k)!)\) |
| Пример (n=4, k=2) | AB ≠ BA → 12 | {A,B} = {B,A} → 6 |

---

## Замечания

- При \(k = 0\): \(A_n^0 = 1\), \(C_n^0 = 1\) (пустая выборка).
- При \(k = n\): \(A_n^n = n!\) (перестановки), \(C_n^n = 1\).
- Для больших значений \(n\) результат типа `double` может потерять точность из-за ограничений представления числа с плавающей точкой. Используйте `Combinations` (тип `long`) при \(n \le 66\).
