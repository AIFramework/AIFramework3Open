# Система Такаги–Сугено (Takagi–Sugeno, T–S)

## Теория

В **системе Такаги–Сугено** предпосылки правил остаются нечёткими (как в Мамдани), а **следствие** задаётся **чёткой функцией** входов (или константой).

### Нулевой порядок (singleton fuzzy model)

Следствие — **константа** $c_i$. После вычисления степени срабатывания $w_i$ (часто с нормализацией) выход:

```math
z = \frac{\sum_i w_i c_i}{\sum_i w_i}.
```

Это **взвешенное среднее** синглтонов; нечёткое множество на выходе не агрегируется в виде $\mu_{\mathrm{agg}}(y)$, если не вводится дополнительная постановка.

### Первый порядок

Следствие — **аффинная форма** от входного вектора $\mathbf{x}$:

```math
z_i = a_{i0} + \mathbf{a}_i^\top \mathbf{x},
```

после чего снова применяют взвешенное среднее:

```math
z = \frac{\sum_i w_i z_i}{\sum_i w_i}.
```

Теоретически порядок может быть выше; в репозитории реализованы **нулевой** и **первый** порядок.

## Соответствие коду (сборка `AI.Fuzzy`)

| Назначение | Тип |
|------------|-----|
| Взвешенное среднее синглтонов | `FuzzySugenoInference.WeightedAverageSingletons` |
| Первый порядок (константа + скалярное произведение с $\mathbf{x}$) | `FuzzySugenoInference.TakagiSugenoOrder1` |
| Матрица $m_{ij} = \texttt{if}[i]\cdot\texttt{then}[j]$ (вспомогательно) | `FuzzySugenoInference.GetProductImplicationMatrix` |

Пространство имён: **`AI.Fuzzy.Inference`**. Вектор входов: `AI.DataStructs.Algebraic.Vector`; скалярное произведение — `Vector.Dot`.

## Связь с другими схемами

- **Мамдани / Ларсен**: выход — нечёткое множество на $Y$, затем дефаззификация.
- **Сугено**: выход — **число** $z$ без построения $\mu_{\mathrm{agg}}(y)$ в явном виде (при стандартной формулировке).

## Замечания

- Веса $w_i$ в коде приводятся к неотрицательным; при нулевой сумме весов возвращается 0 (см. порог `AI.AISettings.GlobalEps`).
- Нечёткий регулятор `FuzzyPIDController` в режиме `FuzzyPIDOutputMode.Sugeno` использует синглтоны на встроенной таблице правил; см. `src/AI.Fuzzy/Control/FuzzyPIDController.cs`.
