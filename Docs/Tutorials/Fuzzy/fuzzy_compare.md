# Сравнение четырёх схем нечёткого вывода

## Постановка задачи

Мамдани, Ларсен, Сугено и Цукамото решают одну задачу — превратить набор
правил «если … то …» в чёткое число. Отличаются они двумя операциями:
**импликацией** (что делает степень срабатывания с термом следствия) и
**дефаззификацией** (как из нескольких следствий получается одно число).

Вопрос, на который отвечает это демо: насколько велика разница на
практике и где она максимальна.

Чтобы ответ был честным, все четыре схемы прогоняются через **одну и ту же
базу правил** нечёткого термостата:

| Правило | Если температура | То мощность |
|---------|------------------|-------------|
| R1 | Холодно | Высокая |
| R2 | Норма   | Средняя |
| R3 | Жарко   | Низкая  |

## Теория

Обозначим $w_i$ — степень срабатывания правила $i$, $\mu_{C_i}$ — функцию
принадлежности его следствия, $U$ — универсум выхода.

| Схема | Импликация | Агрегирование | Дефаззификация |
|-------|-----------|---------------|----------------|
| Мамдани | $\min(w_i,\ \mu_{C_i}(u))$ | $\max_i$ | центр тяжести |
| Ларсен | $w_i \cdot \mu_{C_i}(u)$ | $\max_i$ | центр тяжести |
| Сугено | — (следствие уже чёткое) | — | $\dfrac{\sum_i w_i z_i}{\sum_i w_i}$ |
| Цукамото | $z_i = \mu_{C_i}^{-1}(w_i)$ | — | $\dfrac{\sum_i w_i z_i}{\sum_i w_i}$ |

**Мамдани** срезает терм следствия горизонтально на уровне $w_i$ — у
результата появляется плато. **Ларсен** умножает терм на $w_i$: форма
сохраняется, меняется высота. На этом их различие исчерпывается, поэтому
характеристики двух методов обычно лежат близко.

**Сугено** обходится без построения нечёткого множества на выходе: каждое
правило сразу даёт число $z_i$ (константу в 0-м порядке или линейную форму
$z_i = c_i + \mathbf{k}_i^{\top}\mathbf{x}$ в 1-м). Отсюда его главное
свойство — дешевизна: нет ни сетки универсума, ни интегрирования.

**Цукамото** требует, чтобы $\mu_{C_i}$ была **монотонна** — тогда обратная
функция однозначна и $z_i = \mu_{C_i}^{-1}(w_i)$ определено. В библиотеке
обратная функция ищется бисекцией за 48 итераций.

### Что порождает расхождение

Общий центр тяжести у Мамдани и Ларсена смещается по-разному, когда правила
срабатывают несимметрично: срезанный терм теряет больше площади на вершине,
масштабированный — равномерно. Сугено вообще игнорирует форму следствия,
поэтому его характеристика самая гладкая. Цукамото зависит от крутизны
монотонного следствия и в пределе пологих сигмоид даёт наиболее сглаженный
отклик.

Максимальное расхождение возникает не в середине диапазона, где все
правила симметричны, а на переходах между зонами — там, где одно правило
затухает, а другое разгорается.

## Сложность

| Схема | Время на один вход |
|-------|--------------------|
| Мамдани, Ларсен | $O(R \cdot G)$ — $R$ правил на $G$ узлов сетки |
| Сугено | $O(R)$ |
| Цукамото | $O(R \cdot B)$ — $B$ итераций бисекции (по умолчанию 48) |

Для управления в реальном времени это решающий аргумент: Сугено на два
порядка дешевле Мамдани при $G \sim 200$.

## API

| Метод | Схема |
|-------|-------|
| `FuzzyMamdaniInference.InferCentroid(w, terms, universe)` | Мамдани целиком |
| `FuzzyLarsenInference.InferCentroid(w, terms, universe)` | Ларсен целиком |
| `FuzzySugenoInference.WeightedAverageSingletons(w, z)` | Сугено 0-го порядка |
| `FuzzySugenoInference.TakagiSugenoOrder1(inputs, rules)` | Сугено 1-го порядка |
| `FuzzyTsukamotoInference.Infer(w, memberships, zMin, zMax, monotonicity)` | Цукамото |
| `FuzzyMamdaniInference.DefuzzifyCentroid(universe, mu)` | Общая дефаззификация COG |

Исходники: `src/AI.Fuzzy/Inference/`.

## Код

```csharp
using AI.Fuzzy.Inference;
using AI.DataStructs.Algebraic;

double[] w = { 0.6, 0.3, 0.0 };            // степени срабатывания правил

// Сетка универсума выхода и термы следствий на ней
var universe = new Vector(201);
for (int i = 0; i < universe.Count; i++) universe[i] = i * 100.0 / 200;

var terms = new List<Vector>();
foreach (double centre in new[] { 90.0, 50.0, 10.0 })
{
    var t = new Vector(universe.Count);
    for (int i = 0; i < universe.Count; i++)
        t[i] = FuzzyMembershipShapes.Triangular(universe[i], centre - 40, centre, centre + 40);
    terms.Add(t);
}

double mamdani = FuzzyMamdaniInference.InferCentroid(w, terms, universe);
double larsen  = FuzzyLarsenInference.InferCentroid(w, terms, universe);
double sugeno  = FuzzySugenoInference.WeightedAverageSingletons(w, new[] { 90.0, 50.0, 10.0 });

Console.WriteLine($"Мамдани {mamdani:F2}, Ларсен {larsen:F2}, Сугено {sugeno:F2}");
```

## Ограничения

- Если не сработало ни одно правило ($\sum_i w_i = 0$), все схемы вернут 0 —
  это не «нулевая мощность», а отсутствие ответа. Проверяйте сумму весов
  отдельно и предусматривайте правило по умолчанию.
- Сравнивать абсолютные выходы схем осмысленно только на одной базе правил
  и одинаковых термах: при разных настройках разница ничего не говорит о
  самих методах.
- Цукамото не применим к немонотонным следствиям: обратная функция станет
  неоднозначной, а бисекция сойдётся к произвольному корню.
- Точность Мамдани и Ларсена ограничена шагом сетки: на 21 узле центр
  тяжести заметно смещён относительно значения на 401 узле.
