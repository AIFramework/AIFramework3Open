# Метод Ларсена (импликация через произведение)

## Теория

В **схеме Ларсена** (в русскоязычной литературе часто противопоставляют методу Мамдани) **импликация** между степенью срабатывания правила $w_i$ и функцией принадлежности следствия $B_i$ задаётся **произведением** (алгебраическим произведением как $t$-нормой), а не минимумом:

```math
\mu_{B_i'}(y) = w_i \cdot \mu_{B_i}(y).
```

**Агрегирование** по правилам, как и в типичной конфигурации Мамдани–типа, выполняют через **максимум**:

```math
\mu_{\mathrm{agg}}(y) = \max_i \bigl(w_i \cdot \mu_{B_i}(y)\bigr).
```

**Дефаззификация** может выполняться теми же методами, что и после Мамдани (в частности, **центр тяжести** на дискретной сетке). Различие между схемами проявляется в форме $\mu_{B_i'}$, а не в обязательной смене оператора агрегирования.

Для двух дискретных векторов степеней принадлежности «если» и «то» импликация Ларсена на узлах соответствует покомпонентному произведению; см. `FLV.LarsenImplication`.

## Соответствие коду (сборка `AI.Fuzzy`)

| Назначение | Тип |
|------------|-----|
| Скаляр «импликация Ларсена» | `FLV.LarsenImplication(double, double)` |
| Матрица $m_{ij} = \texttt{if}[i]\cdot\texttt{then}[j]$ | `FuzzyLarsenInference.GetImplicationMatrixLarsen` |
| Обёртка в `FuzzyAnalogyInference` | `FuzzyAnalogyInference.GetImplicationMatrixLarsen` |
| Агрегирование max–product на сетке | `FuzzyLarsenInference.AggregateMaxProduct` |
| Агрегирование + COG | `FuzzyLarsenInference.InferCentroid` (дефаззификация через `FuzzyMamdaniInference.DefuzzifyCentroid`) |

Пространство имён: **`AI.Fuzzy.Inference`**.

## Замечания

- Произведение $w_i \mu_{B_i}(y)$ быстрее «сжимает» хвосты нечёткого следствия по сравнению с $\min(w_i,\mu)$, что меняет форму $\mu_{\mathrm{agg}}$ и итоговое $y^*$ при том же наборе правил.
- Матрица произведений `FuzzySugenoInference.GetProductImplicationMatrix` служит **иному** сценарию (вспомогательное формирование весов); для схемы Ларсена на уровне следствий используйте **`FuzzyLarsenInference`**.
