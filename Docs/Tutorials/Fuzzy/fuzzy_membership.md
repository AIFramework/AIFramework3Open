# Функции принадлежности и фаззификация

## Постановка задачи

Нечёткая логика работает не с истиной «да/нет», а со степенью
принадлежности $\mu \in [0, 1]$. Первый шаг любой нечёткой системы —
**фаззификация**: перевод чёткого числа (температура 12 °C) в набор
степеней принадлежности лингвистическим термам («Холодно» на 0.6,
«Норма» на 0.3, «Жарко» на 0).

Где встречается: нечёткие регуляторы, экспертные системы, системы
поддержки принятия решений — всюду, где правила формулируются словами
человека, а не порогами.

## Теория

**Треугольная** функция принадлежности задаётся тройкой $(a, b, c)$:
носитель $[a, c]$, вершина в $b$.

$$
\mu_{\triangle}(x; a, b, c) =
\begin{cases}
0, & x \le a \text{ или } x \ge c,\\[2pt]
\dfrac{x - a}{b - a}, & a < x < b,\\[6pt]
\dfrac{c - x}{c - b}, & b \le x < c.
\end{cases}
$$

**Трапециевидная** задаётся четвёркой $(a, b, c, d)$ и отличается плато
$[b, c]$, на котором $\mu = 1$:

$$
\mu_{\sqcap}(x; a, b, c, d) =
\begin{cases}
0, & x \le a \text{ или } x \ge d,\\[2pt]
\dfrac{x - a}{b - a}, & a < x < b,\\[6pt]
1, & b \le x \le c,\\[2pt]
\dfrac{d - x}{d - c}, & c < x < d.
\end{cases}
$$

Трапеция выражает «диапазон значений одинаково типичен», треугольник —
«есть ровно одно самое типичное значение».

### Перекрытие термов

Ключевой параметр разбиения универсума — насколько соседние термы заходят
друг на друга. При нулевом перекрытии в каждой точке активен ровно один
терм: система вырождается в набор порогов и выход скачкообразен. При
разумном перекрытии (обычно вершина соседа приходится на край текущего
терма) одновременно срабатывают два правила, и выход становится
непрерывным — это и есть главное практическое преимущество нечёткого
управления перед релейным.

Сумма $\sum_i \mu_i(x)$ **не обязана** равняться единице: это не
распределение вероятностей. Требование $\sum_i \mu_i = 1$ — отдельное
свойство (нечёткое разбиение), которое выполняется лишь для специально
подобранных термов.

## Сложность

Вычисление одной функции принадлежности — $O(1)$: несколько сравнений и
одно деление. Фаззификация входа по $m$ термам — $O(m)$, независимо от
формы.

## API

| Метод | Описание |
|-------|----------|
| `FuzzyMembershipShapes.Triangular(x, a, b, c)` | Треугольная $\mu$: носитель $[a,c]$, вершина $b$ |
| `FuzzyMembershipShapes.Trapezoidal(x, a, b, c, d)` | Трапециевидная $\mu$: плато $[b,c]$, скаты $[a,b]$ и $[c,d]$ |

Исходник: `src/AI.Fuzzy/Inference/FuzzyMembershipShapes.cs`.

Смежные типы: `LingVarGaussian` (гауссовы термы), `SigmoidVectorFuzzyficator`
(сигмоидная фаззификация вектора признаков), `FuzzySetGenerator` (построение
нечёткого множества по функции $\mu$).

## Код

```csharp
using AI.Fuzzy.Inference;

// Три терма на универсуме температуры [0, 40] °C
double cold = FuzzyMembershipShapes.Triangular(12, a: -6.7, b:  6.7, c: 20);
double norm = FuzzyMembershipShapes.Triangular(12, a:  6.7, b: 20,   c: 33.3);
double hot  = FuzzyMembershipShapes.Triangular(12, a: 20,   b: 33.3, c: 46.7);

Console.WriteLine($"Холодно {cold:F2}, Норма {norm:F2}, Жарко {hot:F2}");

// Трапеция: «комфортная температура» — диапазон, а не точка
double comfort = FuzzyMembershipShapes.Trapezoidal(22, a: 18, b: 20, c: 24, d: 26);
```

## Ограничения

- Обе функции возвращают 0 вне носителя: если входное значение вышло за
  универсум, все степени принадлежности обнулятся и вывод даст 0 —
  проверяйте диапазон входа отдельно.
- `Triangular` при $b = a$ или $c = b$ делит на ноль: вырожденные термы
  (полутреугольники на краях универсума) нужно задавать трапецией.
- Кусочно-линейные функции недифференцируемы в узлах — для градиентного
  обучения параметров термов берите гауссовы или сигмоидные формы.
