# Метод Цукамото (Yasuhiko Tsukamoto; вывод через обращение монотонного следствия)

## Теория

В **методе Цукамото** каждое правило $i$ имеет нечёткое следствие $B_i$ на универсуме выхода, но в отличие от Мамдани **не строят** объединённое нечёткое множество $\mu_{\mathrm{agg}}(y)$ для последующей дефаззификации COG. Вместо этого:

1. Вычисляют степень срабатывания правила $\alpha_i$ (как и в других системах).
2. Для следствия $B_i$ требуют, чтобы функция принадлежности $\mu_{B_i}(y)$ на выбранном отрезке $[y_{\min},y_{\max}]$ была **строго монотонной** (неубывающей или невозрастающей), чтобы существовало **обратное** отображение уровня $\alpha_i$ в точку $y_i$:

   ```math
   y_i = \mu_{B_i}^{-1}(\alpha_i).
   ```

3. Чёткий выход получают **взвешенным средним**:

   ```math
   y^* = \frac{\sum_i \alpha_i\, y_i}{\sum_i \alpha_i}.
   ```

Если $\mu_{B_i}$ немонотонна (например, «колокол» на всём универсуме), обратное неоднозначно; классическая постановка Цукамото к таким термам неприменима без сужения области или замены модели следствия.

## Соответствие коду (сборка `AI.Fuzzy`)

| Назначение | Тип |
|------------|-----|
| Обращение $\mu(y)\approx \alpha$ бисекцией | `FuzzyTsukamotoInference.InverseMonotoneMembership` |
| Перечисление монотонности | `TsukamotoOutputMonotonicity` (`Increasing`, `Decreasing`) |
| Полный цикл: обращение для каждого правила + взвешенное среднее | `FuzzyTsukamotoInference.Infer` |
| Взвешенное среднее (повторное использование слоя Сугено-0) | внутри вызывается `FuzzySugenoInference.WeightedAverageSingletons` |

Пространство имён: **`AI.Fuzzy.Inference`**.

## Замечания

- Уровень $\alpha$ в `InverseMonotoneMembership` приводится к $[0,1]$ (`Clamp01`).
- Граничные случаи (цель $\alpha$ вне достижимого диапазона $\mu$ на отрезке) обрабатываются возвратом $y_{\min}$ или $y_{\max}$ в зависимости от монотонности; при некорректной $\mu$ результат может быть математически нежелателен — ответственность за монотонность и гладкость лежит на пользователе.
- Для разных правил с **разной** монотонностью следствий единый вызов `Infer` с одним значением `TsukamotoOutputMonotonicity` не подходит: используйте отдельные обращения `InverseMonotoneMembership` и затем объединяйте веса вручную либо расширяйте обёртку под предметную область.
