# Метод Мамдани (Ebrahim H. Mamdani, 1974; min-импликация и max-агрегирование)

## Теория

В классической **системе нечёткого вывода Мамдани** каждое правило имеет вид:

> **Если** $x_1$ есть $A_1$ **и** … **и** $x_n$ есть $A_n$, **то** $y$ есть $B$,

где $A_i$, $B$ — нечёткие множества на соответствующих универсумах. Для правила с индексом $i$:

1. **Степень срабатывания (firing strength)** $w_i$ получают из степеней принадлежности предпосылок (часто через $t$-норму, напр. минимум или произведение).
2. **Импликация** задаётся операцией **минимума** между $w_i$ и функцией принадлежности следствия $B_i$ на универсуме выхода $Y$:

   ```math
   \mu_{B_i'}(y) = \min\bigl(w_i,\; \mu_{B_i}(y)\bigr).
   ```

3. **Агрегирование** правил — объединение (обычно **максимум** по всем правилам):

   ```math
   \mu_{\mathrm{agg}}(y) = \max_i \mu_{B_i'}(y) = \max_i \min\bigl(w_i,\; \mu_{B_i}(y)\bigr).
   ```

4. **Дефаззификация** переводит $\mu_{\mathrm{agg}}$ в чёткое значение $y^*$. В библиотеке для дискретной сетки реализован метод **центра тяжести (center of gravity, COG)**:

   ```math
   y^* = \frac{\sum_k y_k\,\mu_{\mathrm{agg}}(y_k)}{\sum_k \mu_{\mathrm{agg}}(y_k)}.
   ```

Для пары дискретных нечётких векторов «условие / следствие» импликация Мамдани на узлах сетки сводится к покомпонентному минимуму; это согласовано с `FLV.MamdaniImplication`.

## Соответствие коду (сборка `AI.Fuzzy`)

| Назначение | Тип |
|------------|-----|
| Скалярная импликация Мамдани | `FLV.MamdaniImplication` (`src/AI.Fuzzy/Core/FLV.cs`) |
| Матрица импликаций по двум векторам | `FuzzyMamdaniInference.GetImplicationMatrixMamdani` |
| То же через обёртку вывода по аналогии | `FuzzyAnalogyInference.GetImplicationMatrixMamdani` |
| Агрегирование max–min на сетке | `FuzzyMamdaniInference.AggregateMaxMin` |
| Дефаззификация COG | `FuzzyMamdaniInference.DefuzzifyCentroid` |
| Полный шаг: агрегирование + COG | `FuzzyMamdaniInference.InferCentroid` |
| Шаг вывода по матрице и вектору условий (иной контекст) | `FuzzyAnalogyInference.Inference` |

Пространство имён: **`AI.Fuzzy.Inference`**, при необходимости **`AI.Fuzzy`** для `FLV` и **`FuzzyAnalogyInference`**.

## Замечания

- Непрерывный универсум в реализации задаётся **дискретной сеткой**; точность определяется шагом по $y$.
- Импликация Гогена (`FLV.GImplication`, матрицы `FuzzyAnalogyInference.GetImplicationMatrixG`) — **другая** т-норма; не смешивайте её с агрегированием Мамдани без явной постановки задачи.
