# Самоорганизующаяся карта Кохонена (SOM)

## Назначение

**Самоорганизующаяся карта Кохонена** (SOM — Self-Organizing Map) — нейронная сеть с конкурентным обучением без учителя. Применяется для визуализации многомерных данных, топологического упорядочивания кластеров и обнаружения структуры в данных.

## Архитектура

Сеть состоит из $K$ нейронов, каждый из которых имеет вектор весов $w_k \in \mathbb{R}^d$. Нейроны конкурируют за право активации: побеждает тот, чьи веса наиболее близки к входному вектору.

## Алгоритм обучения

**Инициализация:** веса $w_k$ инициализируются случайно из равномерного распределения.

**Для каждого образца $x$ в эпохе:**

1. Найти нейрон-победитель (BMU — Best Matching Unit):

$$
k^* = \arg\min_k \|x - w_k\|
$$

2. Обновить вес победителя с убыванием скорости обучения $\eta(t)$:

$$
w_{k^*}(t+1) = \eta(t) \cdot x + (1 - \eta(t)) \cdot w_{k^*}(t)
$$

3. Все остальные нейроны слегка смещаются в противоположную сторону:

$$
w_k(t+1) = (1 - \eta(t)) \cdot w_k(t) - 0{,}1 \cdot \eta(t) \cdot x, \quad k \neq k^*
$$

**Скорость обучения** убывает линейно по числу шагов: $\eta(t) = \eta_0 - \Delta\eta \cdot t$.

## Классификация (вывод)

После обучения классификация объекта $x$ выполняется через скалярное произведение:

$$
k^*(x) = \arg\max_k \left( w_k^T x + b_k \right)
$$

где $b_k$ — смещение, вычисленное из среднего обучающей выборки.

## Параметры класса `KohonenNet`

| Параметр конструктора | Тип | Описание |
|---|---|---|
| `clusters` | `int` | Число нейронов $K$ |
| `inpDim` | `int` | Размерность входного вектора |
| `seed` | `int` | Начальное значение ГПСЧ |

| Свойство | Описание |
|---|---|
| `Steps` | Число шагов (делитель длины датасета) |
| `Centroids` | Итоговые векторы весов нейронов |

## Пример использования

```csharp
using AI.ML.Clustering;

var som = new KohonenNet(clusters: 4, inpDim: 2, seed: 1);
som.Steps = 50;
som.Train(data, param: 0);

int label = som.Classify(newPoint);
int[] labels = som.Classify(data);
```

## Отличие от K-Means

| Критерий | K-Means | Kohonen SOM |
|---|---|---|
| Тип обучения | жёсткое назначение (EM) | мягкое онлайн-обучение |
| Обновление | все нейроны одновременно | по одному примеру |
| Топология | нет | сохраняется (в полной SOM) |
| Чувствительность к порядку | нет | умеренная |

## Достоинства и ограничения

**Достоинства:**
- Онлайн-обучение (потоковые данные).
- Хорошо работает при постепенно меняющемся распределении.

**Ограничения:**
- Число нейронов задаётся заранее.
- Результат зависит от порядка подачи примеров.
- Классическая SOM предполагает топологию на решётке нейронов — в данной реализации топология не используется.
