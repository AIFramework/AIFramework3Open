# Алгоритм FOREL

## Назначение

**FOREL** (FORmal ELements) — алгоритм кластеризации, не требующий предварительного задания числа кластеров. Метод последовательно выделяет плотные группы точек, используя гиперсферы уменьшающегося радиуса.

## Математическая постановка

Пусть задана выборка $X = \{x_1, \ldots, x_n\}$, $x_i \in \mathbb{R}^d$. Начальный радиус гиперсферы:

$$
R_0 = \max_{x_i \in X}\, \|x_i - \bar{x}\|, \quad \bar{x} = \frac{1}{n}\sum_{i=1}^n x_i
$$

## Алгоритм

1. Установить $R \leftarrow 0{,}9 \cdot R_0$.
2. Выбрать случайную нераспределённую точку $c_0 \in X_{\text{free}}$.
3. Повторять до стабилизации центра:

$$
S(c, R) = \{x_i \in X_{\text{free}} \mid \|x_i - c\| \leq R\}
$$

$$
c_{\text{new}} = \frac{1}{|S|} \sum_{x_i \in S} x_i, \quad R \leftarrow 0{,}9 \cdot R
$$

4. Зафиксировать кластер $C = S(c_{\text{new}}, R)$, удалить точки кластера из $X_{\text{free}}$.
5. Перейти к шагу 2, пока $X_{\text{free}} \neq \emptyset$.

## Свойства

| Свойство | Значение |
|---|---|
| Число кластеров | определяется автоматически |
| Форма кластеров | сферическая |
| Чувствительность к порядку | умеренная |
| Сложность | $O(n^2 \cdot d)$ в худшем случае |

## Параметры класса `Forel`

| Параметр | Тип | Описание |
|---|---|---|
| `DistanceFunction` | `Func<Vector,Vector,double>` | Метрика расстояния |
| `Clusters` | `Cluster[]` | Результирующие кластеры (центроид + данные) |

## Примеры

```csharp
using AI.ML.Clustering;

var forel = new Forel();
forel.Train(data);

int numClusters = forel.Clusters.Length;
int label = forel.Classify(newPoint);
```

## Сравнение с K-Means

| Критерий | K-Means | FOREL |
|---|---|---|
| Число кластеров | задаётся вручную | определяется автоматически |
| Скорость | выше | ниже |
| Форма кластеров | сферическая | сферическая |
| Обработка выбросов | слабая | умеренная |
