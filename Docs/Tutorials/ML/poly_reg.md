# Полиномиальная регрессия

## Назначение

**Полиномиальная регрессия** аппроксимирует нелинейную зависимость $y = f(x)$ полиномом степени $p$:

$$
y = w_0 + w_1 x + w_2 x^2 + \ldots + w_p x^p
$$

## Математическая основа

Метод сводится к линейной регрессии в расширенном признаковом пространстве. Для каждой точки $x_i$ формируется вектор полиномиальных признаков:

$$
\phi(x_i) = \begin{bmatrix}1 & x_i & x_i^2 & \cdots & x_i^p\end{bmatrix}^T
$$

Параметры $w$ находятся из системы нормальных уравнений:

$$
\Phi^T \Phi \, w = \Phi^T y
$$

где $\Phi$ — матрица Вандермонда (строки: $\phi(x_i)^T$).

## Масштабирование данных

Внутри класса `PolynomialRegression` применяется стандартизация признаков:

$$
\tilde{\phi}_j = \frac{\phi_j - \mu_j}{\sigma_j}
$$

Это существенно улучшает обусловленность системы нормальных уравнений при высоких степенях полинома.

## Выбор степени полинома

| Степень $p$ | Описание |
|---|---|
| 1 | Линейная модель |
| 2–3 | Умеренно нелинейная зависимость |
| 4–6 | Высокая гибкость; риск переобучения |

> **Предупреждение.** При высоких степенях полинома возможно **переобучение** (overfitting): модель точно воспроизводит обучающие данные, но плохо обобщается на новые.

## Параметры класса `PolynomialRegression`

| Параметр конструктора | Тип | Описание |
|---|---|---|
| `inp` | `Vector` | Входные значения $x$ |
| `outp` | `Vector` | Целевые значения $y$ |
| `nPoly` | `int` | Степень полинома $p$ |

Обучение выполняется в конструкторе.

## Примеры

```csharp
using AI.ML.Regression;
using AI.DataStructs.Algebraic;

var poly = new PolynomialRegression(xTrain, yTrain, nPoly: 3);

double y = poly.Predict(2.5);           // одна точка
Vector ys = poly.Predict(xTest);        // вектор точек
```

## Достоинства и ограничения

**Достоинства:**
- Аналитическое решение — точное и быстрое.
- Хорошо аппроксимирует гладкие нелинейные зависимости.

**Ограничения:**
- Высокая степень требует большего объёма обучающих данных.
- Плохое поведение вне диапазона обучающих данных (экстраполяция ненадёжна).
- Чувствителен к выбросам при высоких $p$.
