# Байесовский классификатор

## Назначение

**Байесовский классификатор** — вероятностный метод классификации, основанный на теореме Байеса. Реализация в `AI.ML` предполагает статистическую независимость признаков (наивный Байес) и гауссово распределение признаков внутри каждого класса.

## Теоретическая основа

По теореме Байеса:

$$
P(C_k \mid x) = \frac{P(x \mid C_k)\, P(C_k)}{P(x)}
$$

Для многомерного случая с некоррелированными признаками плотность правдоподобия:

$$
P(x \mid C_k) = \prod_{j=1}^d \frac{1}{\sqrt{2\pi\sigma_{kj}^2}} \exp\!\left(-\frac{(x_j - \mu_{kj})^2}{2\sigma_{kj}^2}\right)
$$

Решающее правило:

$$
\hat{c} = \arg\max_k P(C_k) \cdot P(x \mid C_k)
$$

## Обучение

На этапе обучения по каждому классу $C_k$ вычисляются:

- **Среднее** по признакам: $\mu_k = \frac{1}{n_k}\sum_{i \in C_k} x_i$
- **Стандартное отклонение**: $\sigma_k = \sqrt{\frac{1}{n_k}\sum_{i \in C_k}(x_i - \mu_k)^2}$
- **Априорная вероятность**: $P(C_k) = \frac{n_k}{n}$

## Параметры класса `BayesianClassifier`

| Параметр конструктора | Тип | Описание |
|---|---|---|
| `nInp` | `int` | Размерность признакового вектора |
| `nOutp` | `int` | Число классов |

## Пример использования

```csharp
using AI.ML.Classification;
using AI.DataStructs.Algebraic;

var cls = new BayesianClassifier();
cls.Train(features, labels);        // Vector[], int[]

int predicted = cls.Classify(x);
Vector probs  = cls.ClassifyProbVector(x);  // вероятности по классам
```

## Достоинства и ограничения

**Достоинства:**
- Вычислительно эффективен.
- Хорошо работает при малых выборках.
- Выдаёт апостериорные вероятности классов.

**Ограничения:**
- Предположение о независимости признаков нарушается на реальных данных.
- Предполагает гауссово распределение каждого признака.
- Чувствителен к значительному перекрытию классов в признаковом пространстве.
