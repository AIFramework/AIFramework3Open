# Классификатор по ближайшему эталону (NN)

## Назначение

**NN-классификатор** (Nearest Neighbor / Nearest Centroid) присваивает объекту метку того класса, эталонный вектор которого ближе всего к анализируемому объекту. В `AI.ML` в роли эталона выступает **прототип класса** — центр масс всех объектов этого класса.

## Математическая основа

Пусть задано $K$ классов. Прототип (центроид) класса $k$:

$$
\mu_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i
$$

Решающее правило (метрика — квадрат евклидова расстояния):

$$
\hat{c}(x) = \arg\min_{k} \|x - \mu_k\|^2
$$

## Алгоритм обучения

1. Разбить обучающую выборку по меткам классов.
2. Для каждого класса вычислить центроид $\mu_k$.
3. Сохранить массив центроидов для последующей классификации.

Сложность обучения: $O(n \cdot d)$.  
Сложность классификации: $O(K \cdot d)$.

## Параметры класса `NN`

| Метод | Описание |
|---|---|
| `Train(Vector[] features, int[] classes)` | Обучение по массиву признаков и меток |
| `Train(VectorDataset dataset)` | Обучение по датасету |
| `AddClass(Vector[] features, int label)` | Добавление нового класса без переобучения |
| `Classify(Vector x)` | Классификация объекта |
| `ClassifyProbVector(Vector x)` | Вектор one-hot уверенности |

## Примеры

```csharp
using AI.ML.Classification;
using AI.DataStructs.Algebraic;

var nn = new NN();
nn.Train(features, labels);

int predicted = nn.Classify(testPoint);
```

## Характеристики метода

| Характеристика | Значение |
|---|---|
| Тип обучения | контролируемое |
| Параметры настройки | нет (непараметрический метод) |
| Устойчивость к шуму | умеренная |
| Работа с несбалансированными классами | удовлетворительная |

## Достоинства и ограничения

**Достоинства:**
- Отсутствие настраиваемых гиперпараметров.
- Устойчивость к случайным выбросам (используется центроид, а не отдельные точки).
- Возможность инкрементального добавления классов (`AddClass`).
- Детерминированное поведение.

**Ограничения:**
- Работает хуже при непересекающихся, но нелинейно разделимых классах.
- Предполагает, что форма каждого класса — выпуклое облако точек.
- Один прототип на класс — недостаточно для многомодальных распределений.
