# Множественная линейная регрессия

## Назначение

**Множественная линейная регрессия** моделирует линейную зависимость целевой переменной $y$ от нескольких факторов $x_1, x_2, \ldots, x_d$:

$$
y = w_0 + w_1 x_1 + w_2 x_2 + \cdots + w_d x_d
$$

## Математическая основа

В матричной форме (с добавлением столбца единиц для свободного члена):

$$
\mathbf{y} = \mathbf{X} \mathbf{w} + \varepsilon
$$

Оценка параметров методом наименьших квадратов:

$$
\hat{\mathbf{w}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}
$$

В реализации `AI.ML` это уравнение решается методом Гаусса (`Gauss.SolvingEquations`).

## Стандартизация признаков

При флаге `isScale = true` все признаки нормируются перед обучением:

$$
\tilde{x}_j = \frac{x_j - \mu_j}{\sigma_j}
$$

Стандартизация улучшает численную устойчивость и сходимость альтернативного градиентного метода.

## Метрики качества

**Среднеквадратическая ошибка (MSE):**

$$
\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
$$

**Коэффициент детерминации:**

$$
R^2 = 1 - \frac{\sum_i(y_i - \hat{y}_i)^2}{\sum_i(y_i - \bar{y})^2}
$$

## Параметры класса `MultipleRegression`

| Параметр | Тип | Описание |
|---|---|---|
| `isScale` | `bool` | Нормировать признаки перед обучением |

| Метод | Описание |
|---|---|
| `Train(Vector[] data, Vector targets)` | Аналитическое обучение (нормальные уравнения) |
| `TrainGrad(...)` | Обучение методом упругой регуляризации (Elastic Net) |
| `Predict(Vector)` | Прогноз для одного объекта |
| `Predict(Vector[])` | Прогноз для набора объектов |

## Примеры

```csharp
using AI.ML.Regression;
using AI.DataStructs.Algebraic;

var reg = new MultipleRegression(isScale: true);
reg.Train(features, targets);   // Vector[], Vector

double y = reg.Predict(newX);
```

## Применения

- Анализ влияния нескольких факторов на целевой показатель.
- Финансовое и физическое моделирование.
- Предсказание непрерывных величин в задачах автоматизации и управления.
