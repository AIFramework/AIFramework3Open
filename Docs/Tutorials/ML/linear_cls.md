# Линейный бинарный классификатор

## Назначение

**Линейный бинарный классификатор** разделяет пространство признаков гиперплоскостью на два класса. Обучение выполняется методом **градиентного спуска** с минимизацией среднего **отступа** (margin).

## Математическая основа

Линейная модель:

$$
f(x) = w^T x + b
$$

Классификация:

$$
\hat{c}(x) = \begin{cases} 1, & f(x) \geq 0 \\ 0, & f(x) < 0 \end{cases}
$$

## Функция потерь и отступ

Отступ объекта $i$ с меткой $y_i \in \{-1, +1\}$:

$$
M_i = y_i \cdot f(x_i)
$$

Потеря на основе отступа (Hinge-подобная):

$$
L = \frac{1}{n} \sum_{i=1}^{n} \max(0, \delta - M_i)
$$

где $\delta$ — минимальный требуемый отступ (`MinimalMargin`).

## Обновление параметров

Параметры обновляются методом градиентного спуска с регуляризацией Elastic Net (L1 + L2):

$$
w \leftarrow w - \alpha \left(\nabla_w L + \lambda_1 \cdot \mathrm{sign}(w) + \lambda_2 \cdot w\right)
$$

$$
b \leftarrow b - \alpha \cdot \nabla_b L
$$

## Параметры класса `LinearClassifierBinarry`

| Параметр | Тип | Описание |
|---|---|---|
| `dim` | `int` | Размерность входного вектора |
| `LearningRate` | `double` | Скорость обучения $\alpha$ (по умолчанию: 0.01) |
| `EpochesToPass` | `int` | Число эпох (по умолчанию: 10) |
| `L1` | `double` | Коэффициент L1-регуляризации |
| `L2` | `double` | Коэффициент L2-регуляризации |
| `MinimalMargin` | `double` | Минимальный требуемый отступ $\delta$ |
| `C` | `double` | Параметр штрафа за нарушение отступа |

## Примеры

```csharp
using AI.ML.Classification;

var cls = new LinearClassifierBinarry(dim: 2)
{
    EpochesToPass = 50,
    LearningRate  = 0.01,
    L2            = 0.001
};
cls.Train(features, labels);    // int[] labels: 0 или 1

int predicted = cls.Classify(x);
Vector probs  = cls.ClassifyProbVector(x);  // Softmax по двум логитам
```

## Достоинства и ограничения

**Достоинства:**
- Высокая скорость обучения и классификации.
- Поддержка регуляризации для борьбы с переобучением.
- Детерминированный и воспроизводимый результат.

**Ограничения:**
- Применим только к линейно разделимым или приближённо линейно разделимым данным.
- Требует ручной настройки гиперпараметров (скорость обучения, число эпох).
- Бинарный: для нескольких классов необходима стратегия «один против всех».
