# Машина опорных векторов — бинарная (SVM)

## Назначение

**SVM** (Support Vector Machine) — алгоритм бинарной классификации, ищущий разделяющую гиперплоскость с **максимальным зазором** (margin) между классами. В отличие от простого линейного классификатора, SVM явно выделяет наиболее информативные точки — **опорные векторы**.

## Математическая основа

Задача оптимизации:

$$
\min_{w, b} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^n \max(0,\; 1 - y_i(w^T x_i + b))
$$

где:
- $\|w\|^2$ — регуляризатор (контролирует ширину зазора);
- $C$ — штраф за нарушение зазора;
- $y_i \in \{-1, +1\}$ — метки классов.

Ширина зазора равна $\dfrac{2}{\|w\|}$.

## Опорные векторы

Опорные векторы — это точки выборки, нарушающие зазор или лежащие точно на его границе:

$$
M_i = y_i(w^T x_i + b) \leq 1
$$

В реализации `SVMBinary` на каждой эпохе выбираются `NumSupportVectors` точек с наименьшим отступом. Обновление весов производится только по этим точкам.

## Алгоритм (итерационный)

На каждой эпохе:
1. Найти `NumSupportVectors` опорных векторов (наименьший отступ $M_i$).
2. Вычислить средний градиент потери по опорным векторам:

$$
\nabla_w L = \frac{1}{n_{sv}} \sum_{i \in SV} \left(-y_i x_i \cdot \mathbf{1}[M_i < 1]\right) + \lambda_1 + \lambda_2 w
$$

3. Обновить $w$ и $b$ градиентным спуском.

## Параметры класса `SVMBinary`

| Параметр | Тип | Описание |
|---|---|---|
| `dim` | `int` | Размерность входного вектора |
| `LearningRate` | `double` | Скорость обучения (по умолчанию: 0.01) |
| `EpochesToPass` | `int` | Число эпох (по умолчанию: 10) |
| `NumSupportVectors` | `int` | Число опорных векторов на итерацию |
| `C` | `double` | Параметр штрафа за нарушение зазора |
| `L1`, `L2` | `double` | Коэффициенты регуляризации |

## Пример использования

```csharp
using AI.ML.Classification;

var svm = new SVMBinary(dim: 2)
{
    EpochesToPass    = 50,
    LearningRate     = 0.01,
    NumSupportVectors = 8,
    C = 1.0
};
svm.Train(features, labels);

int predicted = svm.Classify(x);
```

## Сравнение с `LinearClassifierBinarry`

| Критерий | LinearClassifier | SVMBinary |
|---|---|---|
| Обучение по | всей выборке | только опорным векторам |
| Устойчивость к выбросам | умеренная | выше |
| Скорость итерации | медленнее | быстрее (при малом $n_{sv}$) |
| Максимальный зазор | не гарантируется | приближённо гарантируется |
