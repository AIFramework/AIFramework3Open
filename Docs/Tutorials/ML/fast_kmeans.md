# Fast K-Means (BallTree + k-means++)

## Назначение

**Fast K-Means** — ускоренная реализация алгоритма k-средних, использующая структуру данных **BallTree** для быстрого поиска ближайших соседей. На больших выборках даёт значительное ускорение по сравнению с классическим K-Means за счёт снижения числа операций сравнения.

## Принцип ускорения: BallTree

**BallTree** (дерево шаров) — иерархическая структура данных для поиска в метрическом пространстве. Пространство рекурсивно разбивается на гиперсферы (шары), что позволяет отсекать большие области при поиске ближайшего соседа.

Сложность запроса:
- Построение: $O(n \log n \cdot d)$
- Запрос k ближайших соседей: $O(\log n \cdot d)$ (в среднем)

В сравнении с наивным перебором $O(n \cdot d)$ за каждый запрос.

## Инициализация k-means++

Центроиды инициализируются по алгоритму **k-means++**, минимизируя начальную ошибку:

$$
P(x_i) = \frac{D(x_i)^2}{\sum_j D(x_j)^2}
$$

где $D(x_i)$ — расстояние до ближайшего уже выбранного центроида. BallTree используется для ускорения вычисления $D(x_i)$ через `NearestDistanceToCentroids`.

## Параметры класса `FastKMeans`

| Параметр | Тип | Описание |
|---|---|---|
| `groupCount` | `int` | Число кластеров $K$ |
| `MaxCount` | `int` | Максимальное число итераций |
| `Centroids` | `Vector[]` | Итоговые центроиды |

> **Примечание.** Свойства `Clusters` и `DistanceFunction` в текущей реализации `FastKMeans` не поддерживаются (бросают `NotImplementedException`). Для классификации используется метод `Classify(Vector)`.

## Сравнение с K-Means

| Критерий | K-Means | Fast K-Means |
|---|---|---|
| Поиск ближайшего центроида | $O(K \cdot d)$ на точку | $O(\log K \cdot d)$ через BallTree |
| Инициализация | k-means++ | k-means++ через BallTree |
| Точность | идентична | идентична |
| Эффективность | умеренная | высокая при больших $n$ |

## Пример использования

```csharp
using AI.ML.Clustering;

var fkm = new FastKMeans(k: 4);
fkm.Train(data, seed: 42);

int label    = fkm.Classify(newPoint);
var centroids = fkm.Centroids;
```

## Применение

- Кластеризация больших наборов данных (тысячи и более точек).
- Интерактивные системы с требованиями к скорости обучения.
- Предварительная сегментация изображений.
