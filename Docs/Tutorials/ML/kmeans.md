# Алгоритм K-Means

## Назначение

Алгоритм **K-Means** (метод k-средних) — один из наиболее распространённых методов кластерного анализа. Предназначен для разбиения набора наблюдений на $K$ непересекающихся групп (кластеров) по принципу минимизации внутрикластерной дисперсии.

## Математическая постановка

Пусть задана обучающая выборка $X = \{x_1, x_2, \ldots, x_n\}$, где $x_i \in \mathbb{R}^d$. Требуется найти разбиение $\{C_1, C_2, \ldots, C_K\}$ и центроиды $\{\mu_1, \mu_2, \ldots, \mu_K\}$, минимизирующие суммарную внутрикластерную сумму квадратов расстояний:

$$
J = \sum_{k=1}^{K} \sum_{x_i \in C_k} \|x_i - \mu_k\|^2 \to \min
$$

## Алгоритм (k-means++)

Реализация в `AI.ML` использует улучшенную инициализацию **k-means++**, снижающую чувствительность к выбору начальных центроидов.

**Шаг 1 — Инициализация центроидов (k-means++):**

1. Выбрать случайную точку $\mu_1 \sim \mathcal{U}(X)$.
2. Для каждой следующей точки $\mu_{k+1}$ вычислить вероятность выбора пропорционально квадрату расстояния до ближайшего уже выбранного центроида:

$$
P(x_i) = \frac{D(x_i)^2}{\sum_{j} D(x_j)^2}, \quad D(x_i) = \min_{k} \|x_i - \mu_k\|
$$

**Шаг 2 — Назначение:**

$$
c_i = \arg\min_{k} \|x_i - \mu_k\|^2
$$

**Шаг 3 — Обновление центроидов:**

$$
\mu_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i
$$

**Шаги 2–3 повторяются** до сходимости (отсутствия изменений в назначениях).

## Сложность

| Параметр | Значение |
|---|---|
| Одна итерация | $O(n \cdot K \cdot d)$ |
| Сходимость | обычно за 10–100 итераций |
| Гарантии оптимальности | локальный минимум $J$ |

## Параметры класса `KMeans`

| Параметр | Тип | Описание |
|---|---|---|
| `clasterCount` | `int` | Число кластеров $K \geq 2$ |
| `MaxCount` | `int` | Максимальное число итераций |
| `DistanceFunction` | `Func<Vector,Vector,double>` | Метрика расстояния (по умолчанию — евклидова) |

## Примеры

```csharp
using AI.ML.Clustering;
using AI.DataStructs.Algebraic;

// Создание и обучение
var km = new KMeans(k: 3);
km.Train(data, seed: 42);

// Классификация
int label = km.Classify(newPoint);
Vector[] centroids = km.Centroids;
```

## Достоинства и ограничения

**Достоинства:**
- Высокая скорость работы при умеренном числе кластеров и точек.
- Простота реализации и интерпретации результатов.
- Эффективная инициализация k-means++ снижает число итераций.

**Ограничения:**
- Число кластеров $K$ задаётся заранее.
- Чувствителен к выбросам и шуму в данных.
- Предполагает сферическую форму кластеров равного размера.
- Может сходиться к локальному минимуму.
