# Линейная регрессия

## Назначение

**Линейная регрессия** (однофакторная) — метод нахождения параметров линейной зависимости между одной независимой переменной $x$ и зависимой переменной $y$:

$$
y = k \cdot x + b
$$

## Математическая основа

Задача оценки параметров решается методом наименьших квадратов (МНК). Функционал ошибки:

$$
J(k, b) = \sum_{i=1}^{n}\bigl(y_i - k x_i - b\bigr)^2 \to \min
$$

Аналитическое решение:

$$
k = \frac{\mathrm{Cov}(X, Y)}{\mathrm{Var}(X)}, \quad b = \bar{Y} - k\,\bar{X}
$$

где:

$$
\mathrm{Cov}(X, Y) = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{X})(y_i - \bar{Y}), \quad \mathrm{Var}(X) = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{X})^2
$$

## Оценка качества модели

**Коэффициент детерминации** $R^2$ (доля объяснённой дисперсии):

$$
R^2 = 1 - \frac{\sum_i(y_i - \hat{y}_i)^2}{\sum_i(y_i - \bar{Y})^2}
$$

Значение $R^2 = 1$ соответствует идеальной аппроксимации; $R^2 = 0$ — модель не лучше среднего.

## Параметры класса `LinearRegression`

| Параметр конструктора | Тип | Описание |
|---|---|---|
| `X` | `Vector` | Вектор независимой переменной |
| `Y` | `Vector` | Вектор зависимой переменной |

Обучение происходит в конструкторе. Результат доступен через свойство `Lrm` (тип `LinearRegressionModel`).

## Примеры

```csharp
using AI.ML.Regression;
using AI.DataStructs.Algebraic;

var reg = new LinearRegression(X, Y);

Console.WriteLine(reg);           // f(x) = k*x+(b)
double y = reg.Predict(3.5);      // прогноз для x = 3.5
Vector ys = reg.Predict(xVect);   // прогноз для вектора x
```

## Применения

- Аппроксимация физических зависимостей (закон Гука, закон Ома и др.).
- Прогнозирование числовых показателей при наличии линейного тренда.
- Первичный анализ данных перед применением более сложных моделей.
