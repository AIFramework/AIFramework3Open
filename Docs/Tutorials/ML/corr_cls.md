# Корреляционный классификатор

## Назначение

**Корреляционный классификатор** относит объект к тому классу, с эталонами которого он имеет наибольший коэффициент корреляции. Применяется для распознавания образцов, сигналов и паттернов, где форма вектора важнее его масштаба.

## Математическая основа

Коэффициент корреляции Пирсона между вектором $x$ и эталоном $e_k$:

$$
r(x, e_k) = \frac{\sum_{j=1}^d (x_j - \bar{x})(e_{kj} - \bar{e}_k)}{\sqrt{\sum_j(x_j - \bar{x})^2} \cdot \sqrt{\sum_j(e_{kj} - \bar{e}_k)^2}}
$$

Значение $r \in [-1, 1]$. При $r = 1$ — полное совпадение формы.

Решающее правило:

$$
\hat{c}(x) = \arg\max_k \max_{e \in E_k} r(x, e)
$$

где $E_k$ — множество эталонов класса $k$.

## Особенности реализации

- Каждый обучающий пример сохраняется как отдельный эталон (шаблон класса).
- При классификации вычисляется корреляция с **каждым** эталоном.
- Метод инвариантен к масштабированию признаков (коэффициент корреляции нормирован).

## Параметры класса `CorrelationClassifier`

| Метод | Описание |
|---|---|
| `Train(Vector[] features, int[] classes)` | Обучение по массиву признаков и меток |
| `Train(VectorDataset dataset)` | Обучение по датасету |
| `AddClass(Vector features, int num)` | Добавление одного эталона |
| `Classify(Vector x)` | Возвращает метку класса |
| `ClassifyProbVector(Vector x)` | Нормированный вектор корреляций по классам |
| `Save(string path)` / `Load(string path)` | Сохранение и загрузка модели |

## Пример использования

```csharp
using AI.ML.Classification;
using AI.DataStructs.Algebraic;

var cls = new CorrelationClassifier();
cls.Train(features, labels);

int predicted = cls.Classify(testVector);
Vector corrVec = cls.ClassifyProbVector(testVector);  // нормированные корреляции
```

## Применение

- Распознавание сигналов и временных рядов по форме.
- Идентификация паттернов в спектральном анализе.
- Сравнение изображений по текстуре или форме (после выравнивания масштаба).

## Достоинства и ограничения

**Достоинства:**
- Инвариантность к линейному масштабированию.
- Хорошая интерпретируемость — коэффициент корреляции имеет понятный физический смысл.
- Простота добавления новых эталонов без переобучения (`AddClass`).

**Ограничения:**
- Память растёт с числом обучающих примеров (хранятся все эталоны).
- Время классификации $O(n \cdot d)$ при $n$ эталонах.
- Чувствителен к сдвигу по времени или пространству — пространственная инвариантность не гарантируется.
