# Метод главных компонент (PCA)

## Назначение

**PCA** (Principal Component Analysis, метод главных компонент) — линейный метод снижения размерности. Применяется для:

- Устранения мультиколлинеарности признаков.
- Визуализации многомерных данных.
- Компрессии данных с контролируемой потерей информации.
- Предварительной обработки перед обучением классификаторов и регрессоров.

## Математическая основа

Пусть задана матрица данных $\mathbf{X} \in \mathbb{R}^{n \times d}$ (центрированная: $\bar{x} = 0$). Ковариационная матрица:

$$
\mathbf{C} = \frac{1}{n-1}\,\mathbf{X}^T\mathbf{X}
$$

Спектральное разложение:

$$
\mathbf{C}\,\mathbf{V} = \mathbf{\Lambda}\,\mathbf{V}
$$

где $\mathbf{V}$ — матрица собственных векторов (главных направлений), $\mathbf{\Lambda} = \mathrm{diag}(\lambda_1, \ldots, \lambda_d)$ — матрица собственных значений, $\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_d \geq 0$.

## Доля объяснённой дисперсии

Для первых $k$ главных компонент:

$$
\eta_k = \frac{\sum_{j=1}^{k} \lambda_j}{\sum_{j=1}^{d} \lambda_j}
$$

Рекомендуется выбирать $k$ так, чтобы $\eta_k \geq 0{,}95$.

## Проекция данных

$$
\mathbf{Z} = \mathbf{X}\,\mathbf{V}_k
$$

где $\mathbf{V}_k$ — первые $k$ столбцов $\mathbf{V}$.

## Параметры класса `PCA`

| Метод | Описание |
|---|---|
| `Train(Matrix data)` | Обучение по матрице данных |
| `Train(Vector[] data)` | Обучение по массиву векторов |
| `Transform(Vector[] data)` | Проекция выборки на главные компоненты |
| `Transform(Matrix data)` | Проекция матрицы данных |

| Свойство | Описание |
|---|---|
| `EigenValues` | Собственные значения (дисперсии компонент) |
| `EigenVectors` | Матрица главных направлений |

## Примеры

```csharp
using AI.ML.DataHandling;
using AI.DataStructs.Algebraic;

var pca = new PCA();
pca.Train(data);           // Vector[] data

// Проекция на 2 главные компоненты
var proj = pca.Transform(data);
```

## Достоинства и ограничения

**Достоинства:**
- Аналитическое решение — однозначно и воспроизводимо.
- Максимальное сохранение дисперсии при заданном числе компонент.
- Устраняет мультиколлинеарность входных признаков.

**Ограничения:**
- Линейный метод — не улавливает нелинейные структуры данных.
- Интерпретация главных компонент не всегда очевидна.
- Чувствителен к масштабу признаков (рекомендуется предварительная стандартизация).
