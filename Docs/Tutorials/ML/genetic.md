# Генетический алгоритм

## Назначение

**Генетический алгоритм** (ГА) — эвристический метод глобальной оптимизации, вдохновлённый биологической эволюцией. Применяется для поиска параметров модели в задачах, где градиентные методы неприменимы или неэффективны.

## Биологические аналогии

| Термин ГА | Биологический аналог | В задаче оптимизации |
|---|---|---|
| Популяция | Поколение организмов | Набор кандидатных решений |
| Особь (Cell) | Организм | Вектор параметров |
| Хромосома | Генотип | Вектор параметров модели |
| Приспособленность | Выживаемость | Значение целевой функции (MSE) |
| Скрещивание | Половое размножение | Обмен частями параметров |
| Мутация | Случайное изменение | Случайный шум в параметрах |

## Схема одного поколения

$$
\text{Популяция} \xrightarrow{\text{Оценка}} \text{Сортировка} \xrightarrow{\text{Отбор лидеров}} \text{Скрещивание} \xrightarrow{\text{Мутация}} \text{Новая популяция}
$$

1. **Оценка (SortCells):** для каждой особи вычисляется MSE на обучающих парах $(x_i, y_i)$.
2. **Отбор:** отбираются `LiderCount` лучших особей.
3. **Центральная особь:** строится взвешенное среднее лидеров (RBF-веса).
4. **Скрещивание:** первые `k` параметров — от одного родителя, остальные — от другого.
5. **Мутация:** с вероятностью `mutProb` один параметр сдвигается на случайную величину.

## Функция модели

В демо подбираются коэффициенты квадратичной функции:

$$
f(x, \mathbf{p}) = p_0 x^2 + p_1 x + p_2
$$

Целевая функция: $y = 2x^2 - x + 0{,}5$ (параметры: $p_0 = 2$, $p_1 = -1$, $p_2 = 0{,}5$).

Функция потерь (MSE):

$$
\text{MSE}(\mathbf{p}) = \frac{1}{n}\sum_{i=1}^n \bigl(f(x_i, \mathbf{p}) - y_i\bigr)^2 \to \min
$$

## Параметры класса `Population`

| Параметр | Тип | Описание |
|---|---|---|
| `countCell` | `int` | Размер популяции |
| `countParam` | `int` | Число параметров особи |
| `function` | `Func<Vector, Vector, Vector>` | Модель: `f(x, params) → y` |
| `inp`, `outp` | `Vector[]` | Обучающие пары |
| `valDown`, `valUp` | `double` | Диапазон инициализации параметров |

| Свойство | Тип | Описание |
|---|---|---|
| `mutProb` | `double` | Вероятность мутации особи |
| `MutationValue` | `double` | Масштаб мутации |
| `LiderCount` | `int` | Число лидеров для размножения |

| Метод | Описание |
|---|---|
| `Epoch(count)` | Одно поколение: оценка → скрещивание → мутация |
| `SortCells()` | Оценка и сортировка особей по приспособленности |

## Примеры

```csharp
using AI.ML.Genetic.GeneticCore;
using AI.DataStructs.Algebraic;

// Модель: f(x, p) = p[0]*x^2 + p[1]*x + p[2]
Func<Vector, Vector, Vector> model = (x, p) =>
    new Vector(new[] { p[0]*x[0]*x[0] + p[1]*x[0] + p[2] });

var pop = new Population(
    countCell: 30, countParam: 3,
    function: model,
    inp: inpVectors, outp: targetVectors,
    valDown: -6, valUp: 6);

for (int epoch = 0; epoch < 100; epoch++)
    pop.Epoch(30);

pop.SortCells();
var bestParams = pop[0].Parametrs;  // лучшие параметры
```

## Демонстрации

**Кривая сходимости:** показывает, как лучший MSE убывает от поколения к поколению.

**Подбор параметров:** показывает три кривые:
- Целевая функция $y = 2x^2 - x + 0{,}5$.
- Начальное случайное приближение (до эволюции).
- Лучший результат после N поколений.

## Достоинства и ограничения

**Достоинства:**
- Не требует дифференцируемости целевой функции.
- Хорошо находит глобальный минимум в пространствах с несколькими локальными минимумами.
- Легко параллелизуется.

**Ограничения:**
- Вычислительно дорог по сравнению с градиентными методами.
- Настройка гиперпараметров (размер популяции, вероятность мутации) требует экспериментов.
- Не гарантирует нахождение глобального оптимума.
