# Авторегрессионное прогнозирование (AR)

## Назначение

**Авторегрессионная модель** (AR — AutoRegressive) описывает временной ряд как линейную комбинацию его собственных прошлых значений. Модель применяется для краткосрочного прогнозирования стационарных временных рядов.

## Математическая модель AR(p)

Модель порядка $p$ задаётся уравнением:

$$
y_t = c + \sum_{j=1}^{p} w_j\,y_{t-j} + \varepsilon_t
$$

где:
- $p$ — порядок (ширина окна);
- $w_j$ — коэффициенты авторегрессии;
- $c$ — свободный член;
- $\varepsilon_t \sim \mathcal{N}(0, \sigma^2)$ — белый шум.

## Метод оценки параметров

В классе `AR` параметры находятся методом наименьших квадратов через `MultipleRegression`. Формируется матрица лагов:

$$
\mathbf{X} = \begin{bmatrix}
y_{p}   & y_{p-1} & \cdots & y_1 \\
y_{p+1} & y_{p}   & \cdots & y_2 \\
\vdots  & \vdots  & \ddots & \vdots \\
y_{n-1} & y_{n-2} & \cdots & y_{n-p}
\end{bmatrix}, \quad
\mathbf{y} = \begin{bmatrix}y_{p+1} \\ y_{p+2} \\ \vdots \\ y_n\end{bmatrix}
$$

## Итеративный прогноз

При прогнозировании на $h$ шагов вперёд используется рекуррентная формула:

$$
\hat{y}_{n+k} = c + \sum_{j=1}^{p} w_j\,\hat{y}_{n+k-j}, \quad k = 1, 2, \ldots, h
$$

Каждый новый прогноз добавляется в окно и используется для следующего шага. Это приводит к **накоплению ошибки** при увеличении горизонта прогнозирования.

## Параметры класса `AR`

| Параметр | Тип | Описание |
|---|---|---|
| `windowLenght` | `int` | Порядок авторегрессии $p$ |

| Метод | Описание |
|---|---|
| `Train(Vector data)` | Оценка коэффициентов AR по обучающему ряду |
| `Predict(Vector data, int n)` | Прогноз на $n$ шагов вперёд |

## Пример использования

```csharp
using AI.ML.SequenceAnalysis.SeqPredict;
using AI.DataStructs.Algebraic;

var ar = new AR(windowLenght: 5);
ar.Train(trainSeries);             // Vector

Vector forecast = ar.Predict(trainSeries, n: 20);
```

## Условия стационарности

Модель AR(p) стационарна, если все корни характеристического многочлена:

$$
z^p - w_1 z^{p-1} - \cdots - w_p = 0
$$

лежат **вне** единичного круга на комплексной плоскости. В противном случае прогноз расходится.

## Достоинства и ограничения

**Достоинства:**
- Простота реализации и интерпретации.
- Высокая скорость обучения.
- Хорошие результаты для стационарных рядов с выраженной автокорреляцией.

**Ограничения:**
- Не подходит для нестационарных рядов без предобработки (дифференцирования).
- Качество прогноза резко снижается на большом горизонте.
- Не учитывает сезонные составляющие (требуется SARIMA или аналог).
