# Преобразование Гильберта и аналитический сигнал

**Пространство имён:** `AI.DSP.DSPCore`  
**Класс:** `FastHilbert` (статический)

---

## 1. Аналитический сигнал

Для вещественного сигнала \(x(t)\) **аналитический сигнал** строится как:

\[
z(t) = x(t) + j\,\hat{x}(t)
\]

где \(\hat{x}(t)\) — **преобразование Гильберта** от \(x(t)\):

\[
\hat{x}(t) = \frac{1}{\pi} \int_{-\infty}^{+\infty} \frac{x(\tau)}{t - \tau}\, d\tau
\]

В частотной области: умножение спектра положительных частот на \(-j\), отрицательных — на \(+j\).

---

## 2. Огибающая (мгновенная амплитуда)

Мгновенная амплитуда (огибающая):

\[
A(t) = |z(t)| = \sqrt{x^2(t) + \hat{x}^2(t)}
\]

**Применение:**
- Демодуляция АМ-сигналов.
- Вибродиагностика (огибающая ударных импульсов).
- Выявление нестационарностей и транзиентов.

```csharp
Vector envelope = FastHilbert.Envelope(signal);
```

---

## 3. Мгновенная фаза и частота

Мгновенная фаза:

\[
\varphi(t) = \arg z(t) = \arctan\!\left(\frac{\hat{x}(t)}{x(t)}\right)
\]

Мгновенная частота (производная фазы):

\[
f_i(t) = \frac{1}{2\pi} \frac{d\varphi}{dt}
\]

```csharp
// Мгновенная фаза
Vector phase = FastHilbert.Phase(signal);

// Мгновенная частота (производная фазы, нормированная на fd)
Vector instFreq = FastHilbert.Frequency(signal) * fd / (2 * Math.PI);
```

**Применение мгновенной частоты:**
- Анализ частотно-модулированных (ЧМ) сигналов.
- Оценка мгновенного тона речи.
- Контроль ЛЧМ-генераторов (линейность развёртки).

---

## 4. Квадратурная обработка (IQ-демодуляция)

```csharp
// I и Q компоненты (демодуляция на несущей f0)
(Vector I, Vector Q) = FastHilbert.IQ(signal, fd, f0);

// Огибающая через I/Q
Vector envelopeIQ = FastHilbert.EnvelopeIQ(signal, fd, f0);
```

---

## Замечания

- Длина сигнала автоматически дополняется до ближайшей степени 2 (нулевое дополнение).
- Мгновенная частота нестабильна в зонах низкой амплитуды (близко к нулю), поэтому перед анализом рекомендуется полосовая фильтрация.
- Для короткого сигнала преобразование Гильберта может давать краевые эффекты.
