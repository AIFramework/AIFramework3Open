# Свёртка и корреляция

**Пространство имён:** `AI.DSP.DSPCore`  
**Класс:** `FastConv` (статический)

---

## 1. Свёртка (линейная)

Линейная свёртка двух сигналов \(x[n]\) и \(h[n]\):

\[
y[n] = (x * h)[n] = \sum_{k=-\infty}^{+\infty} x[k]\, h[n-k]
\]

Длина результата: \(N_x + N_h - 1\).

### Быстрая свёртка через БПФ

Вместо прямого суммирования \(O(N^2)\) используется теорема о свёртке:

\[
Y[k] = X[k] \cdot H[k] \implies y = \text{ОБПФ}(Y)
\]

Сложность: \(O(N \log N)\).

```csharp
// Быстрая свёртка (результат нормирован на 1/fd)
Vector result = FastConv.FastConvolution(signal, ht, fd);

// Без нормировки
Vector result = FastConv.FastConvolution(signal, ht);

// Секционная свёртка (для очень длинных сигналов)
Vector result = FastConv.SectionalConvolution(ht, signal);
```

**Применение:**
- Цифровая фильтрация (КИХ-фильтры).
- Имитация акустики помещений (свёртка с импульсным откликом).
- Корреляционная обработка в радиолокации.

---

## 2. Взаимная корреляция

Взаимная корреляция \(R_{xy}[\tau]\):

\[
R_{xy}[\tau] = \sum_{n} x[n]\, y[n + \tau]
\]

Связана со свёрткой: \(R_{xy}[\tau] = x[-\tau] * y[\tau]\).

**Применение:**
- Оценка задержки между двумя сигналами (Time Delay Estimation).
- Обнаружение сигнала на фоне шума.

```csharp
Vector crossCorr = FastConv.FastCorrelation(signalX, signalY);
```

---

## 3. Автокорреляция

При \(x = y\) получается автокорреляция — мера «памяти» сигнала:

\[
R_{xx}[\tau] = \sum_{n} x[n]\, x[n + \tau]
\]

Свойства:
- \(R_{xx}[0] = \|x\|^2\) — максимум при нулевом сдвиге.
- Для периодического сигнала \(R_{xx}\) тоже периодична с тем же периодом.
- Шум имеет \(R_{xx}[\tau] \approx 0\) при \(\tau \neq 0\).

```csharp
Vector autoCorr = FastConv.FastCorrelation(signal);
```

**Применение:**
- Определение периода (частоты) сигнала в зашумлённых условиях.
- Оценка ширины полосы сигнала.
- Вычисление спектральной плотности мощности (теорема Винера–Хинчина).

---

## 4. Нормированная взаимокорреляционная функция

```csharp
Vector normCorr = FastConv.FastNormCrossCorrelation(signalX, signalY);
```

Диапазон значений: \([-1, 1]\). Значение 1 означает идеальное совпадение формы.
