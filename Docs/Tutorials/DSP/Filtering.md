# Цифровые фильтры

**Пространство имён:** `AI.DSP.DSPCore`, `AI.DSP.FIR`, `AI.DSP.IIR`  
**Классы:** `Filters` (статический), `FIRFilter`, `IIRFilter`

---

## 1. Классификация цифровых фильтров

```
Цифровые фильтры
├── КИХ (FIR) — конечная импульсная характеристика
│   ├── Линейная фаза
│   ├── Безусловная устойчивость
│   └── FIRFilter (AI.DSP.FIR)
└── БИХ (IIR) — бесконечная импульсная характеристика
    ├── Меньший порядок для той же АЧХ
    ├── Нелинейная фаза
    └── Реализованы через Filters (спектральный подход)
```

---

## 2. ФНЧ Баттерворта (`Filters.FilterLowButterworthAFH`)

АЧХ фильтра Баттерворта \(n\)-го порядка:

\[
|H(j\omega)|^2 = \frac{1}{1 + \left(\dfrac{\omega}{\omega_c}\right)^{2n}}
\]

- Максимально плоская АЧХ в полосе пропускания.
- Монотонная характеристика без выбросов.
- Скорость спада: −20·n дБ/дек.

```csharp
// Фильтрация через АЧХ Баттерворта (частотная область)
Vector filtered = Filters.FilterLowButterworthAFH(signal, cutoffFreq: 300, fd: 2000, order: 4);

// Через КЧХ (фазовый сдвиг)
Vector filteredCfh = Filters.FilterLowButterworthCFH(signal, cutoffFreq: 300, fd: 2000, order: 4);
```

---

## 3. Полосовой фильтр (`Filters.FilterBand`)

Пропускает частоты в полосе \([f_1, f_2]\), прямоугольная АЧХ:

```csharp
Vector filtered = Filters.FilterBand(signal, sr1: 80, sr2: 200, fd: 2000);
```

---

## 4. Режекторный (заграждающий) фильтр (`Filters.FilterRezector`)

Подавляет полосу \([f_1, f_2]\) — применяется для подавления сетевой помехи 50/60 Гц:

```csharp
Vector filtered = Filters.FilterRezector(signal, sr1: 45, sr2: 55, fd: 2000);
```

---

## 5. КИХ-фильтр (`FIRFilter`)

Реализация через прямую свёртку или БПФ:

\[
y[n] = \sum_{k=0}^{M} h[k] \cdot x[n - k]
\]

Импульсная характеристика идеального ФНЧ (sinc-функция с окном):

\[
h[k] = \frac{\omega_c}{\pi} \cdot \text{sinc}\!\left(\frac{\omega_c}{\pi}(k - M/2)\right) \cdot w[k]
\]

```csharp
// Создание КИХ-фильтра
var ht = ComputeSincWindow(order: 64, cutoff: 300, fd: 2000);
var fir = new FIRFilter(ht, fd: 2000, FIRCalcConvType.WithFFT);
Vector filtered = fir.FilterOutp(signal);
```

## 6. Сравнение подходов к фильтрации

| Характеристика | КИХ (FIR) | Баттерворт (IIR-подобный) | Прямоугольный спектр |
|---|---|---|---|
| Фаза | Линейная | Нелинейная | Нелинейная |
| Порядок | Высокий (десятки) | Низкий (2–8) | — |
| Устойчивость | Безусловная | Условная | Безусловная |
| Переходная полоса | Управляемая (по окну) | Зависит от порядка | Отсутствует |
| Задержка | Постоянная (M/2) | Частотно-зависимая | Нет задержки |
