# Многоскоростная обработка: полифазные фильтры, ИГФ, Фэрроу, Q16

Пространство имён `AI.DSP.Multirate` собирает преобразователь частоты дискретизации из блоков одного
интерфейса: полифазного КИХ-фильтра, интегрально-гребенчатого фильтра (ИГФ, CIC), корректора и фильтра
Фэрроу. Каждый блок считает в `double` или в фиксированной точке Q16 и сообщает своё число операций.

## Постановка задачи

Дан сигнал с частотой $F_S$ и полосой $B$. Нужно получить тот же сигнал с частотой $F_T$: 384 → 48 кГц,
384 → 44,1 кГц, 48 → 44,1 кГц, 44,1 → 48 кГц. Эталон — стандартная схема: вставка $P-1$ нулей, ФНЧ
с окном Кайзера на частоте $P F_S$ и прореживание в $Q$ раз, $P/Q = F_T/F_S$. Она точна, но при
$P/Q = 147/1280$ фильтр длиной 138 159 отсчётов дорог даже в полифазной форме. Синтезированная схема
(ИГФ, корректор, Фэрроу) даёт то же качество в полосе за десятки раз меньше умножений.

## Теория

**Полифазный фильтр.** Выход $m$: $t = mQ + D$,
$y[m] = \sum_j h[t \bmod P + jP]\, x[\lfloor t/P \rfloor - j]$. Нули не умножаются, считаются только
нужные выходы; $D = (L-1)/2$ компенсирует задержку.

**ИГФ** из $K$ каскадов длины $N$:

$$H(\omega) = \frac{1}{N^K}\left(\frac{\sin(\omega N/2)}{\sin(\omega/2)}\, e^{-j\omega (N-1)/2}\right)^{K}.$$

По Хогенауэру он не умножает вовсе: $K$ интеграторов, прореживание, $K$ гребенок. В 64-битных целых по
модулю $2^{64}$ расчёт точен. Минимальное число каскадов по допустимому уровню наложений
$K_{\min} = \lceil A_{\text{нал}} / A_1(b) \rceil$, где
$A_1(b) = -20\lg\left|\sin(\pi(1-b)) / (k \sin(\pi(1-b)/k))\right|$.

**Корректор** компенсирует спад АЧХ ИГФ в полосе:
$A_{\text{кор}}(\omega) = \left|N\sin(\omega/2R)/\sin(\omega N/2R)\right|^K$ при $|\omega| \le \omega_0$,
импульсная характеристика ограничивается окном Кайзера с
$I_0(x) = \sum_k (x/2)^{2k}/(k!)^2$.

**Фильтр Фэрроу** вычисляет полином Лагранжа степени $p$ по схеме Горнера
$y = ((v_3\mu + v_2)\mu + v_1)\mu + v_0$; положение отсчёта хранит фазовый накопитель с 32 дробными
битами. Второе ядро того же интерфейса — интерполяция Акимы.

**Q16.** Число $v$ хранится как $\lfloor 2^{16} v \rfloor$. Произведение считается в 64 битах и
сдвигается вниз (как умножение автора) или округляется к ближайшему (рекомендуется: нет смещения
$-L\Delta/2$ в длинных фильтрах).

**Показатели.** Качество — максимум нормированной ВКФ $Q$ между выходами стандартной и исследуемой
схемы, эквивалентное ОСШ $10\lg(Q^2/(1-Q^2))$; шум квантования — дисперсия разности выходов Q16 и
`double`.

## Сложность

Полифазный фильтр: $\lceil L/P \rceil$ умножений на выходной отсчёт. ИГФ: $K(R+1)$ сложений на выход
дециматора, без умножений. Корректор: $O$ умножений на отсчёт средней частоты. Кубический Фэрроу:
12 умножений и 11 сложений на выход независимо от коэффициента. Для 384 → 44,1 кГц синтезированная
схема делает 2,02 млн умножений в секунду против 41,45 млн у полифазной стандартной.

## API

| Тип | Назначение |
|-----|------------|
| `IMultirateBlock` | общий интерфейс: `Process`, `Flush`, `Reset`, `ProcessBlock`, `RateFactor`, `Delay`, `OperationsPerOutput` |
| `PolyphaseResampler` | КИХ в $P/Q$ раз (повышение, понижение, рациональный коэффициент) |
| `CicDecimator`, `CicInterpolator` | ИГФ по Хогенауэру, нормировка сдвигом или делением |
| `CicDesign` | АЧХ ИГФ, корректор, `MinimumStages`, `MaximumStages` |
| `FarrowResampler` | дробная задержка и произвольный коэффициент |
| `LagrangeKernel`, `AkimaKernel` | ядра фильтра Фэрроу |
| `MovingSourceResampler` | передискретизация движущегося источника по траектории (3 сложения на отсчёт) |
| `KaiserFir` | КИХ по ТЗ окном Кайзера: `Length`, `Beta`, `Window`, `LowPass` |
| `MultirateChain` | цепочка блоков, сама является блоком |
| `ResamplerDesign` | `Standard` — эталонная схема, `CicCorrectorFarrow` — схема ИГФ + корректор + Фэрроу |
| `ResamplingMetrics` | ВКФ, ОСШ, дисперсия шума квантования |
| `Q16`, `Q16Options` | фиксированная точка: округление вниз или к ближайшему, насыщение по выбору |

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.DSP.Multirate;

int fs = 384000, ft = 44100;
var x = new Vector(Enumerable.Range(0, fs).Select(i => 0.18 * Math.Cos(2 * Math.PI * 5000 * i / (double)fs)));

// Эталон: вставка нулей, ФНЧ Кайзера на 80 дБ, прореживание (в полифазной форме)
PolyphaseResampler standard = ResamplerDesign.Standard(fs, ft, band: 20000);

// ИГФ (K = 4) + корректор (31 отсчёт) + кубический Фэрроу, в Q16
MultirateChain chain = ResamplerDesign.CicCorrectorFarrow(fs, ft, band: 20000,
    arithmetic: Arithmetic.Q16, options: Q16Options.Recommended);

Vector reference = standard.ProcessBlock(x);
Vector y = chain.ProcessBlock(x);

double q = ResamplingMetrics.MaxNormalizedCrossCorrelation(reference, y);
Console.WriteLine($"ОСШ {ResamplingMetrics.SnrFromCorrelation(q):F1} дБ, " +
                  $"умножений на отсчёт {chain.OperationsPerOutput.Multiplications:F1}");

// Потоковая обработка: фрагментами любой длины, хвост — Flush
chain.Reset();
Vector part1 = chain.Process(new Vector(x.Take(1000)));
Vector part2 = chain.Process(new Vector(x.Skip(1000)));
Vector tail = chain.Flush();
```

## Ограничения

- ИГФ в `double` считается каскадом скользящих сумм: интеграторы Хогенауэра в `double` растут как $n^K$ и
  теряют точность; в Q16 он точен по модулю $2^{64}$.
- Корректор задаётся нечётным числом коэффициентов.
- В схеме ИГФ + корректор + Фэрроу узким местом широкополосного сигнала (до 0,42 $F$) становится
  кубический Фэрроу: ОСШ около 13 дБ. Для узкополосного сигнала (до 4 кГц) — 60–70 дБ.
- Ядро Акимы нелинейно: в Q16 наклоны делятся, а не умножаются.
