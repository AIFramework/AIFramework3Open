# Спектральный анализ (FFT, Welch, Кепстр)

**Пространство имён:** `AI.DSP.DSPCore`, `AI.DSP.Analyse`  
**Классы:** `FFT`, `Welch`, `Cepstrum`, `WindowForFFT`

---

## 1. Быстрое преобразование Фурье (БПФ)

### Принцип

Дискретное преобразование Фурье (ДПФ) сигнала \(x[n]\) длиной \(N\):

\[
X[k] = \sum_{n=0}^{N-1} x[n] \, e^{-j 2\pi k n / N}, \quad k = 0,\ldots,N-1
\]

Амплитудный спектр: \(|X[k]|\). Полоса частот от \(0\) до \(f_д / 2\) (теорема Котельникова-Найквиста).

### Применения

- Определение частотного состава сигнала.
- Основа для цифровой фильтрации в частотной области.
- Анализ гармонических искажений.

### API

```csharp
// Статический метод — быстро, без предварительного объекта
ComplexVector spectrum = FFT.CalcFFT(signal);

// Амплитудный спектр
Vector amplitude = spectrum.MagnitudeVector;

// Вектор частот для оси X
Vector freqs = Signal.Frequency(signal.Count, fd);
```

## 2. Метод Уэлча (Welch PSD)

### Принцип

Устойчивая оценка спектральной плотности мощности (СПМ) через усреднение периодограмм перекрывающихся сегментов, обычно не более 50% перекрытие:

\[
S[k] = \frac{1}{K} \sum_{m=0}^{K-1} |X_m[k]|^2
\]

где \(X_m\) — ДПФ \(m\)-го сегмента с окном взвешивания (для избежания растекания спектра). Снижает дисперсию оценки, повышая стат. значимости, по сравнению с одной периодограммой.

### Параметры

| Параметр | Описание |
|----------|----------|
| Окно (window) | Размер сегмента в отсчётах (степень 2 для БПФ) |
| Перекрытие (overlap) | Доля перекрытия сегментов (0,5 — 50%) |
| Функция окна | Хэмминг, Ханн, Блэкман — подавляют боковые лепестки |

### API

```csharp
int windowSize = 256;
Vector hannWin = WindowForFFT.HannWindow(windowSize);
Vector psd = Welch.WelchRun(signal, windowSize, overlap: 0.5, hannWin);
```

## 3. Кепстральный анализ

### Принцип

Кепстр — обратное преобразование Фурье от логарифма спектра мощности или дискретно-косинусного преобразования (чаще ДКП2):

\[
c[n] = \text{ОБПФ}\bigl\{ \ln|X[k]|^2 \bigr\}
\]

Позволяет разделить возбуждающий сигнал (источник) и канал (огибающую спектра). В речи используется для выделения **частоты основного тона (ЧОТ)** и формант.

### Применения

- Выявление периодичности в сигнале (периодичность → пик в кепстре на частоте F0).
- Разделение возбуждения и речевого тракта в обработке голоса.
- Диагностика вращающихся механизмов (зубчатые передачи, подшипники).

### API

```csharp
// Кепстр одного сегмента
Vector cepstrum = Cepstrum.FKT(signal);

// Кепстр на основе Welch (более устойчив к шуму)
Vector cepstrumWelch = Cepstrum.WelchFKT(signal, windowSize: 256);
```

## Функции весового окна (`WindowForFFT`)

| Функция | Особенность |
|---------|-------------|
| `HannWindow(n)` | Хорошее подавление боковых лепестков, умеренное расширение главного |
| `HammingWindow(n)` | Первый боковой лепесток −43 дБ |
| `BlackmanWindow(n)` | Лучшее подавление боковых лепестков (−58 дБ), более широкий главный лепесток |
| `RectWindow(n)` | Прямоугольное окно — без взвешивания, максимальное разрешение |
