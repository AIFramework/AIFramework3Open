# Кооперативный A*: WHCA* и HCA*

## Постановка задачи

Дан граф $G$ и $k$ агентов. Требуется найти бесконфликтные пути с использованием кооперативного подхода — агенты планируют с учётом путей, уже запланированных другими. Кооперативный A* основан на резервировании позиций во времени.

## Reservation Table

Таблица резервирования — структура данных, хранящая занятые ячейки пространства-времени $(v, t)$:

$$\text{RT} = \{(v, t) \mid \text{вершина } v \text{ занята в момент } t\}$$

Агент при планировании не может использовать зарезервированные ячейки.

## HCA* (Hierarchical Cooperative A*)

1. Вычислить эвристики для каждого агента (обратный BFS от целей)
2. Для каждого агента по очереди найти путь с помощью пространственно-временного A*
3. Зарезервировать найденный путь в RT

Пространственно-временной A* работает в расширенном графе $G' = (V \times T, E')$, где рёбра соединяют состояния $(v, t)$ и $(v', t+1)$.

## WHCA* (Windowed HCA*)

Ограничивает горизонт планирования окном $w$ шагов:

- Каждый агент планирует только на $w$ шагов вперёд
- Периодически перепланирует по мере продвижения
- Значительно ускоряет планирование для большого числа агентов

### Параметр окна

$$f(n) = g(n) + h(n), \quad g(n) \leq w$$

## Сложность

На каждого агента: $O(bw \log(bw))$ для WHCA* (вместо полного A*), где $b$ — фактор ветвления, $w$ — размер окна.

## Ограничения

- Неполнота: при неудачном порядке агентов решение может не быть найдено
- Неоптимальность: зависимость от порядка планирования

## API (C#)

Классы `CooperativeAStar`, `WHCAStar` в пространстве имён `AI.MAPF`. Метод `Solve(graph, agents, windowSize)` принимает размер окна планирования.
