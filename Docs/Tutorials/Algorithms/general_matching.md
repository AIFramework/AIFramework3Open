# Edmonds Blossom: паросочетание в произвольных графах

## Постановка задачи

Дан произвольный (не обязательно двудольный) неориентированный граф $G = (V, E)$. Требуется найти максимальное паросочетание. В отличие от двудольного случая, нечётные циклы создают дополнительные трудности для поиска увеличивающих путей.

## Теория

Алгоритм Эдмондса (1965) решает проблему нечётных циклов с помощью **сжатия цветков** (blossom contraction):

1. Искать увеличивающий путь с помощью BFS
2. При обнаружении нечётного цикла (цветка) — **сжать** его в одну псевдовершину
3. Продолжить поиск в сжатом графе
4. При нахождении увеличивающего пути — развернуть сжатые цветки

### Цветок (Blossom)

Нечётный цикл $B = (v_1, v_2, \ldots, v_{2k+1})$, в котором $k$ рёбер принадлежат текущему паросочетанию:

$$|B| = 2k + 1, \quad |M \cap B| = k$$

### Теорема Бержа

Паросочетание $M$ максимально тогда и только тогда, когда в графе нет $M$-увеличивающего пути.

## Сложность

$$O(V^3)$$

Наилучшая реализация (Micali—Vazirani) достигает $O(E\sqrt{V})$.

## Применения

- Планирование расписаний
- Химическая информатика (сопоставление молекул)
- Комбинаторная оптимизация

## API

Класс `EdmondsMatching` в пространстве имён `AI.Graphs`. Метод `FindMaxMatching(graph)` возвращает максимальное паросочетание. Поддерживает взвешенный вариант через `FindMaxWeightMatching(graph)`.
