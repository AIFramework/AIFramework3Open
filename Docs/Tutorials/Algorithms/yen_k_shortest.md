# K кратчайших путей (алгоритм Йена)

## Постановка задачи

Дан взвешенный ориентированный граф $G = (V, E)$ и пара вершин $(s, t)$. Требуется найти $K$ различных кратчайших простых путей от $s$ до $t$, упорядоченных по возрастанию длины. Задача возникает при планировании альтернативных маршрутов.

## Идея алгоритма (Yen, 1971)

1. Найти 1-й кратчайший путь алгоритмом Дейкстры.
2. Для каждого $k$-го пути ($k = 2, \ldots, K$):
   - Для каждой вершины-ответвления $s_i$ на $(k{-}1)$-м пути временно удалить рёбра, совпадающие с уже найденными путями.
   - Найти кратчайший путь от $s_i$ до $t$ в изменённом графе.
   - Добавить кандидатов в множество потенциальных путей.
3. Выбрать кандидата с минимальной стоимостью как $k$-й путь.

### Формула стоимости пути

$$\text{cost}(P) = \sum_{(u,v) \in P} w(u, v)$$

## Сложность

$$O(KV(V + E) \log V)$$

Внутренний цикл вызывает Дейкстру $O(V)$ раз для каждого из $K$ путей.

## Варианты

- **Алгоритм Эппштейна** — находит $K$ кратчайших (не обязательно простых) путей за $O(E + V\log V + K)$
- **Алгоритм Лоулера** — обобщение Йена для произвольных целевых функций

## API

Пространство имён `AI.Algorithms.EWG`. Пути ищутся в конструкторе.

| Член | Описание |
|------|----------|
| `YenKShortestPaths<Edge>(GraphW<Edge> g, int source, int target, int K)` | До `K` кратчайших путей |
| `.Paths` | `List<(List<int> Path, double Cost)>` в порядке возрастания стоимости |

Список может оказаться короче `K`: столько простых путей в графе может просто не быть.

Исходник: `src/AI.Algorithms/EWG/YenKShortest.cs`.

## Код

```csharp
using AI.Algorithms.EWG;

var g = new GraphW<Edge>(6);
g.AddEdge(0, 1, 3); g.AddEdge(0, 2, 2);
g.AddEdge(1, 3, 4); g.AddEdge(2, 3, 1);
g.AddEdge(2, 4, 3); g.AddEdge(3, 5, 2);
g.AddEdge(4, 5, 2);

var yen = new YenKShortestPaths<Edge>(g, source: 0, target: 5, K: 3);

foreach (var (path, cost) in yen.Paths)
    Console.WriteLine($"{cost,5:F1}  {string.Join("->", path)}");

// Запас по стоимости между лучшим и худшим из найденных маршрутов:
// на нём строится выбор резервного пути при отказе основного
if (yen.Paths.Count > 1)
    Console.WriteLine($"Запас: {yen.Paths[^1].Cost - yen.Paths[0].Cost:F1}");
```
