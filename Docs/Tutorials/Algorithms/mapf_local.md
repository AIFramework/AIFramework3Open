# Локальные MAPF-алгоритмы: Push and Swap, Push and Rotate

## Постановка задачи

Дан неориентированный связный граф $G = (V, E)$ и $k$ агентов с начальными и целевыми позициями. Требуется переместить всех агентов в целевые позиции, используя только локальные операции (перемещение, обмен). Локальные алгоритмы обеспечивают полноту без глобального планирования.

## Push and Swap (Luna & Bekris, 2011)

Два базовых действия:

- **Push**: переместить агента к его цели по кратчайшему пути, сдвигая блокирующих агентов на свободные вершины
- **Swap**: если push невозможен, два агента обмениваются позициями через серию ходов с использованием пустой вершины

### Условие полноты

Алгоритм полон, если в графе есть хотя бы **2 пустые вершины**.

## Push and Rotate (de Wilde, ter Mors & Witteveen, 2013)

Обобщение Push and Swap для графов с более сложной структурой:

1. Разбить граф на двусвязные компоненты
2. Внутри каждой компоненты использовать **ротации** — циклические перемещения агентов
3. Между компонентами — push через мосты

### Ротация

Циклическое перемещение $m$ агентов вдоль цикла $(v_1, v_2, \ldots, v_m)$:

$$v_1 \to v_2 \to \ldots \to v_m \to v_1$$

## Сложность

| Алгоритм | Время |
|----------|-------|
| Push and Swap | $O(V^3)$ на агента |
| Push and Rotate | $O(V^3)$ на агента |

Длина решения (суммарное число ходов) полиномиальна, но не оптимальна.

## Преимущества

- Полиномиальное время
- Гарантия полноты
- Простая реализация

## API (C#)

Классы `PushAndSwap`, `PushAndRotate` в пространстве имён `AI.MAPF`. Метод `Solve(graph, agents)` возвращает последовательность ходов.
