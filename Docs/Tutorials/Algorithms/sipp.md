# SIPP (Safe Interval Path Planning)

## Постановка задачи

Дан граф $G = (V, E)$ с динамическими препятствиями — объектами, занимающими вершины в определённые интервалы времени. Требуется найти кратчайший путь от старта $s$ до цели $g$, избегая столкновений с препятствиями. SIPP значительно эффективнее наивного пространственно-временного A*.

## Безопасные интервалы

Для каждой вершины $v$ вычисляется набор **безопасных интервалов** — максимальных непрерывных отрезков времени, в течение которых $v$ свободна:

$$\text{SI}(v) = \{[t_1^s, t_1^e],\; [t_2^s, t_2^e],\; \ldots\}$$

Состояние в SIPP — пара $(v, \text{interval})$ вместо $(v, t)$ в обычном пространственно-временном A*.

## Алгоритм

```
SIPP(s, g, obstacles):
  Вычислить безопасные интервалы SI(v) для всех v
  open ← {(s, SI_start(s), g=0)}
  while open не пуста:
    (v, I, g) ← open.extractMin() по f = g + h(v)
    if v = g и достигнута цель: return путь
    for v' ∈ neighbors(v):
      for I' ∈ SI(v'):
        t_arrive ← max(g + 1, I'.start)
        if t_arrive ≤ I'.end:
          обновить (v', I') с g' = t_arrive
```

### Ключевое преимущество

Число безопасных интервалов на вершину значительно меньше числа временных шагов:

$$|\text{SI}(v)| \ll T$$

что радикально сокращает пространство поиска.

## Сложность

На каждое расширение: $O(n \log n)$, где $n$ — суммарное число безопасных интервалов по всем соседям.

Общее число состояний: $O\!\left(\sum_{v \in V} |\text{SI}(v)|\right)$ вместо $O(|V| \cdot T)$.

## Применения

- MAPF (как нижний уровень в CBS)
- Планирование для роботов с динамическими препятствиями
- Навигация в складских системах

## API (C#)

Класс `SIPPPlanner` в пространстве имён `AI.MAPF`. Метод `FindPath(graph, start, goal, dynamicObstacles)` возвращает путь, избегающий всех динамических препятствий.
