# Венгерский алгоритм (Kuhn—Munkres)

## Постановка задачи

Дана матрица стоимостей $C = [c_{ij}]_{n \times n}$, где $c_{ij}$ — стоимость назначения работника $i$ на задачу $j$. Необходимо найти взаимно однозначное назначение (перестановку $\sigma$), минимизирующее суммарную стоимость:

$$\min_{\sigma} \sum_{i=1}^{n} c_{i,\sigma(i)}$$

## Теория

Алгоритм использует теорию двойственности линейного программирования. Поддерживаются потенциалы строк $u_i$ и столбцов $v_j$ такие, что $u_i + v_j \leq c_{ij}$. Оптимальное назначение проходит только по **плотным** рёбрам ($u_i + v_j = c_{ij}$).

### Основные шаги

1. Инициализация потенциалов: $u_i = \min_j c_{ij}$
2. Для каждой строки $i$ найти увеличивающий путь в графе плотных рёбер
3. Если путь не найден — обновить потенциалы:

$$\Delta = \min_{i \in S, j \notin T} (c_{ij} - u_i - v_j)$$

$$u_i \leftarrow u_i + \Delta \;\;(\text{для } i \in S), \quad v_j \leftarrow v_j - \Delta \;\;(\text{для } j \in T)$$

4. Повторить до нахождения полного паросочетания

## Сложность

$$O(n^3)$$

## Применения

- Распределение задач между агентами
- Отслеживание объектов (tracking)
- Задачи транспортной логистики

## API

Класс `HungarianAlgorithm` в пространстве имён `AI.Optimization`. Метод `Solve(costMatrix)` возвращает оптимальное назначение и минимальную стоимость.
