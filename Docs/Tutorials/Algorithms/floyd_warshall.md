# Алгоритм Флойда—Уоршелла

## Постановка задачи

Дан взвешенный граф $G = (V, E)$ с $n$ вершинами. Необходимо найти кратчайшие расстояния между **всеми парами** вершин. Граф может содержать рёбра с отрицательными весами (но без отрицательных циклов).

## Идея алгоритма

Алгоритм динамического программирования. На каждой итерации $k$ рассматривается возможность улучшить путь от $i$ до $j$, используя вершину $k$ как промежуточную.

### Основная формула

$$d^{(k)}[i][j] = \min\!\Big(d^{(k-1)}[i][j],\; d^{(k-1)}[i][k] + d^{(k-1)}[k][j]\Big)$$

### Псевдокод

```
FloydWarshall(W):
  d ← W   // матрица весов, d[i][j] = w(i,j) или ∞
  for k = 1 to n:
    for i = 1 to n:
      for j = 1 to n:
        d[i][j] ← min(d[i][j], d[i][k] + d[k][j])
```

## Сложность

| Параметр | Значение |
|----------|----------|
| Время | $O(V^3)$ |
| Память | $O(V^2)$ |

## Детекция отрицательных циклов

Если после выполнения алгоритма $d[i][i] < 0$ для какой-либо вершины $i$, граф содержит отрицательный цикл.

## Восстановление пути

Для восстановления пути используется матрица предшественников $\text{next}[i][j]$, которая обновляется при каждой успешной релаксации.

## API (C#)

Класс `FloydWarshall` в пространстве имён `AI.Graphs`. Метод `ComputeAllPairs(adjacencyMatrix)` возвращает матрицу расстояний. Метод `GetPath(i, j)` восстанавливает кратчайший путь.
