# Транспортная задача

## Постановка задачи

Имеется $m$ поставщиков с запасами $a_i$ и $n$ потребителей с потребностями $b_j$.
Стоимость перевозки единицы груза от поставщика $i$ к потребителю $j$ равна $c_{ij}$.

Необходимо найти план перевозок $x_{ij} \geq 0$, минимизирующий суммарные затраты:

$$
\min \sum_{i=1}^{m}\sum_{j=1}^{n} c_{ij}\, x_{ij}
$$

при ограничениях:

$$
\sum_{j=1}^{n} x_{ij} = a_i, \quad i = 1, \ldots, m
$$

$$
\sum_{i=1}^{m} x_{ij} = b_j, \quad j = 1, \ldots, n
$$

Задача сбалансирована, если $\sum a_i = \sum b_j$.

## Метод Фогеля (начальный опорный план)

Метод аппроксимации Фогеля строит начальный план, учитывая **штрафы** — разности между двумя минимальными стоимостями в каждой строке/столбце.

1. Для каждой строки и столбца вычислить штраф: $\Delta = c_{(2)} - c_{(1)}$.
2. Выбрать строку/столбец с максимальным штрафом.
3. В выбранной строке/столбце назначить максимально возможную перевозку в клетку с минимальной стоимостью.
4. Исключить исчерпанную строку или столбец.
5. Повторять до полного распределения.

**Сложность**: $O(m \cdot n \cdot (m + n))$

## Метод потенциалов (оптимизация)

Метод потенциалов — итеративная процедура улучшения опорного плана до оптимального.

1. Для базисных клеток ($x_{ij} > 0$) найти потенциалы $u_i$, $v_j$ из условия: $u_i + v_j = c_{ij}$.
2. Для свободных клеток вычислить оценки: $\delta_{ij} = c_{ij} - u_i - v_j$.
3. Если все $\delta_{ij} \geq 0$, план оптимален.
4. Иначе выбрать клетку с минимальной $\delta_{ij} < 0$, построить **цикл пересчёта** и перераспределить.

**Сложность**: $O(m^2 \cdot n^2)$ в худшем случае.
