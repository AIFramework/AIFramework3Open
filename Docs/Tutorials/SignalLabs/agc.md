# Автоматическая регулировка усиления (АРУ / AGC)

## Зачем нужна АРУ?

В системах связи, аудиообработки и радиоприёма входной сигнал может
изменяться по амплитуде в десятки раз — из-за замирания канала, удалённости
источника или динамики речи. АРУ выравнивает уровень сигнала так, чтобы
последующие блоки (демодулятор, АЦП, ухо слушателя) работали в своём
оптимальном диапазоне.

## Принцип работы DirectAGC

Оценивается локальное СКО сигнала через пару ИИР-фильтров:

```
mean(t) = IIR_mean[ x(t) ]
var(t)  = IIR_std [ (x(t) − mean(t))² ]
y(t)    = (x(t) − mean(t)) / √var(t)
```

ИИР-фильтр работает как «скользящее среднее» с экспоненциальным
затуханием, что обеспечивает постоянное слежение без задержки.

## LogAGC

Вместо квадратичной оценки энергии используется логарифм:

```
log_var(t) = IIR_std[ ln((x − mean)² + ε) ] / 2
y(t)        = (x − mean) / exp(log_var)
```

Логарифмическая шкала делает АРУ менее чувствительной к одиночным
выбросам — ближе к поведению слухового аппарата (закон Вебера–Фехнера).

## MinCombineAGC

Работает два АРУ параллельно (DirectAGC и LogAGC). На выход выбирается
тот, у которого **меньший** модуль выходного сигнала. Это сглаживает
переходные процессы: DirectAGC быстрее реагирует, LogAGC стабильнее
при импульсных помехах.

## Параметры

| Параметр | Описание |
|---|---|
| `TresholdAGC` | Жёсткое ограничение выходного сигнала (клиппинг) |
| `TresholdFilter` | Порог ИИР-фильтров (предотвращает взрыв при NaN/Inf) |

## Применение

- Аудиообработка: нормализация речи и музыки в реальном времени.
- Радиоприёмники: компенсация замирания сигнала в канале.
- Системы распознавания речи: выравнивание уровня перед фронтэндом.
