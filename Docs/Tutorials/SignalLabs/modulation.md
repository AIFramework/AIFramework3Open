# Цифровые квадратурные модуляции (BPSK / QPSK / QAM)

## Квадратурная модуляция: идея

Любой полосовой сигнал можно представить через синфазную (I) и квадратурную (Q) компоненты:

```
s(t) = I(t)·cos(2π·f₀·t) + Q(t)·sin(2π·f₀·t)
```

Точка (I, Q) на комплексной плоскости называется **созвездием**. Разные схемы
модуляции размещают точки созвездия по-разному.

## Схемы модуляции

| Схема | Бит/символ | Точек | Пример |
|---|---|---|---|
| BPSK | 1 | 2 | {−1, +1} на I |
| QPSK | 2 | 4 | Окружность единичного радиуса |
| 8-QAM | 3 | 8 | Смешанная сетка |
| 16-QAM | 4 | 16 | Сетка 4×4 |

Чем больше точек — тем выше спектральная эффективность (бит/Гц), но ниже
помехоустойчивость (точки расположены ближе).

## SRRC и нулевая МСИ

При высокой скорости символов импульсы перекрываются во времени, что вызывает
**межсимвольную интерференцию (МСИ)**. Формирующий фильтр **Root Raised Cosine (SRRC)**
решает эту проблему.

Пара SRRC (Tx + Rx) образует **полный RC-фильтр Найквиста**:

```
H_total(f) = H_SRRC(f)² = H_RC(f)
```

RC-фильтр обращается в ноль точно в моменты соседних символов — **МСИ = 0**.

## Процесс приёма

```
x(t) → ×cos(2π·f₀·t) → [SRRC Rx] → I
x(t) → ×sin(2π·f₀·t) → [SRRC Rx] → Q
```

Выборка в центре символа с компенсацией задержек Tx+Rx даёт чистую точку созвездия.
Декодирование — поиск ближайшей точки (Minimum Distance Decoding).

## Параметр roll-off β

- β=0: прямоугольный спектр, максимальная плотность, нереализуем физически.
- β=1: максимальная плавность, вдвое шире спектр.
- Практические значения: 0.2–0.5.

## Применение

- DVB-S2 (спутниковое ТВ): QPSK / 8PSK / 16APSK.
- Wi-Fi (802.11ax): 1024-QAM.
- LTE/5G: OFDM с QAM.
- Модемы: V.34 (QPSK), V.90.
