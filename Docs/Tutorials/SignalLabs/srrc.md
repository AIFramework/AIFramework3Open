# SRRC-фильтр (Square Root Raised Cosine)

## Проблема межсимвольной интерференции

При передаче символов с высокой скоростью прямоугольные импульсы перекрываются
во времени из-за ограниченной полосы канала. Это называется
**межсимвольной интерференцией (МСИ, ISI)** и приводит к ошибкам при приёме.

## Критерий Найквиста

Чтобы МСИ = 0, достаточно, чтобы общая передаточная функция канала обращалась
в ноль во всех моментах времени, кратных T (периоду символа), кроме t = 0:

```
h(kT) = 1  при k = 0
h(kT) = 0  при k ≠ 0
```

Фильтр приподнятого косинуса (RC) удовлетворяет этому критерию.

## SRRC как половина RC

Чтобы равномерно разделить фильтрацию между передатчиком и приёмником
(что обеспечивает оптимальный (согласованный) приём):

```
H_SRRC(f) = √H_RC(f)
H_total = H_SRRC(Tx) × H_SRRC(Rx) = H_RC(f)
```

## Импульсная характеристика SRRC

Для коэффициента скатывания β и периода символа T:

- При t = 0:        h(0) = (1 + β(4/π − 1)) / T
- При t = ±T/(4β): особая точка (формула с sin/cos)
- В остальных:      h(t) = num(t) / (den(t) · T)

Нормировка ядра к единичной энергии позволяет применять пару SRRC
без потери мощности сигнала.

## Параметр roll-off β

| β | Полоса (Hz) | Хвосты ИХ |
|---|---|---|
| 0.0 | 1/(2T) — минимальная | Медленно спадают (∝ 1/t) |
| 0.35 | 0.675/T | Компромисс |
| 1.0 | 1/T — максимальная | Быстро спадают |

Меньший β → уже спектр, но длиннее хвосты ИХ → чувствительнее к
тактовой синхронизации.

## Практические параметры

- `span`: длина фильтра в символах с каждой стороны (рекомендуется 4–8).
- Общая длина ядра: `2·span·(sr/symbol_rate) + 1` отсчётов.
- Секционная свёртка (FFT-overlap-add): O(N log N) вместо O(N²).

## Применение

Практически во всех современных системах цифровой связи:
LTE, DVB, Wi-Fi, кабельное ТВ (DOCSIS).
