# Оптимальная структура капитала

Кривая средневзвешенной стоимости капитала по доле долга: налоговый щит
против издержек финансовой неустойчивости, минимум WACC и выигрыш в стоимости
бизнеса от перехода к нему.

## Постановка задачи

Дано: стоимость собственного капитала без долга, базовая ставка по долгу,
ставка налога, операционная прибыль и текущая доля долга в капитале.

Требуется: доля долга, минимизирующая стоимость капитала, соответствующий
минимум WACC и прирост стоимости бизнеса при переходе от текущей структуры к
оптимальной.

Где встречается: политика заимствований, подготовка к размещению облигаций,
защита дивидендной политики, обсуждение выкупа акций за счёт долга.

## Теория

**Теорема Модильяни — Миллера с налогами** утверждает, что стоимость фирмы
растёт с долгом на величину налогового щита, а WACC монотонно убывает. Из
неё буквально следует, что оптимальная доля долга равна 100% — вывод,
противоречащий наблюдаемому поведению компаний.

Причина расхождения в том, что теорема игнорирует **издержки финансовой
неустойчивости**: с ростом долга кредиторы требуют премию, поставщики
сокращают отсрочки, клиенты уходят к устойчивым конкурентам, а менеджмент
отвлекается на переговоры с банками. Компромиссная теория добавляет эти
издержки явно.

**Стоимость долга** растёт с нагрузкой — кредитный спред расширяется
пропорционально доле долга $s$:

$$
K_d(s) \;=\; K_d^{0} + \kappa\,s .
$$

**Стоимость собственного капитала** растёт по формуле Хамады с бетой долга:
кредиторы принимают часть систематического риска, поэтому доходность
акционеров растёт медленнее, чем в классическом варианте.

**Безвозвратные потери** вносятся в WACC отдельным слагаемым, растущим
быстрее линейного:

$$
\mathrm{WACC}(s) \;=\; (1-s)\,K_e(s) + s\,K_d(s)\,(1-\tau) \;+\; \lambda\,s^{3}.
$$

Кубическая форма отражает эмпирику: до умеренной нагрузки издержки почти
незаметны, после порога растут стремительно. Именно это слагаемое создаёт
внутренний минимум — без него функция монотонна.

**Выигрыш в стоимости** при переходе от текущей структуры к оптимальной
оценивается через капитализацию операционной прибыли по обеим ставкам:

$$
\Delta V \;=\; \mathrm{EBIT}\,(1-\tau)\left(\frac{1}{\mathrm{WACC}^{*}} - \frac{1}{\mathrm{WACC}_{\text{now}}}\right).
$$

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(S)$ | $S$ точек сетки по доле долга |
| Память | $O(S)$ | кривая |

## API

| Метод | Описание |
|-------|----------|
| `BreakEven.OptimalStructure(company, ke0, kd0, tax, ebit, currentShare, distressSlope, steps)` | Кривая и оптимум |
| `CapitalStructureResult.Curve` | Точки: доля долга, стоимость капитала, долга и WACC |
| `CapitalStructureResult.OptimalDebtShare` / `MinimumWacc` | Оптимум |
| `CapitalStructureResult.CurrentWacc` / `CurrentDebtShare` | Текущее положение |
| `CapitalStructureResult.ValueGain` | Прирост стоимости бизнеса |

Исходники: `src/AI.Economics/Projects/BreakEven.cs`.

## Код

```csharp
using AI.Economics.Projects;

CapitalStructureResult structure = BreakEven.OptimalStructure(
    company: "Химическое производство",
    unleveredCostOfEquity: 0.18,
    baseCostOfDebt: 0.13,
    taxRate: 0.2,
    operatingProfit: 2_400_000_000,
    currentDebtShare: 0.25,
    distressSlope: 0.35,
    steps: 19);

Console.WriteLine($"Оптимальная доля долга {structure.OptimalDebtShare:P0} " +
                  $"при WACC {structure.MinimumWacc:P2}");
Console.WriteLine($"Сейчас {structure.CurrentDebtShare:P0} при WACC {structure.CurrentWacc:P2}");
Console.WriteLine($"Выигрыш в стоимости {structure.ValueGain:N0}");

foreach (CapitalStructurePoint point in structure.Curve)
{
    Console.WriteLine($"{point.DebtShare:P0}: Ke {point.CostOfEquity:P2}, " +
                      $"Kd {point.CostOfDebt:P2}, WACC {point.Wacc:P2}");
}
```

Оптимум целиком определяется предположением об издержках неустойчивости —
это надо показывать вместе с числом:

```csharp
foreach (double slope in new[] { 0.15, 0.35, 0.60 })
{
    CapitalStructureResult scenario = BreakEven.OptimalStructure(
        "Химическое производство", 0.18, 0.13, 0.2, 2_400_000_000, 0.25, slope);

    Console.WriteLine($"Издержки неустойчивости {slope:F2}: " +
                      $"оптимум {scenario.OptimalDebtShare:P0}, WACC {scenario.MinimumWacc:P2}");
}
```

Кривая почти плоская вокруг минимума — практический вывод важнее точки:

```csharp
double tolerance = structure.MinimumWacc * 1.005;
var plateau = structure.Curve.Where(point => point.Wacc <= tolerance).ToList();

Console.WriteLine($"WACC в пределах 0,5% от минимума при доле долга от " +
                  $"{plateau.Min(p => p.DebtShare):P0} до {plateau.Max(p => p.DebtShare):P0}");

Console.WriteLine(structure.Interpret().ToLlmText());
```

## Ограничения

- Наклон издержек неустойчивости не оценивается из данных — это экспертное
  суждение. Меняя его в разумных пределах, оптимум сдвигается на 10–20
  процентных пунктов, поэтому говорить надо о диапазоне, а не о точке.
- Кривая около минимума почти плоская: разница WACC между долей долга 35% и
  50% часто меньше погрешности оценки стоимости капитала. Радикальная
  перестройка баланса ради такой разницы не окупает транзакционных издержек.
- Модель статична и не учитывает порядок финансирования: на практике компании
  сначала используют нераспределённую прибыль, затем долг и лишь потом
  выпускают акции.
- Налоговый щит реализуется только у прибыльной компании. При нестабильной
  прибыли ожидаемая ценность щита ниже номинальной, а оптимальная доля долга —
  ниже расчётной.
- Отраслевые нормы и ковенанты существующих договоров ограничивают допустимый
  диапазон сильнее, чем экономика. Сверяйте оптимум с медианой отрасли.
