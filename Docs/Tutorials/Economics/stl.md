# STL-разложение ряда

Разделение ряда на тренд, сезонность и остаток локально взвешенной регрессией —
с сезонностью, меняющейся во времени, и устойчивостью к промо-выбросам.

## Постановка задачи

Дано: ряд продаж с трендом, сезонностью и разовыми всплесками.

Требуется: очищенный от сезонности ряд для отслеживания динамики, тренд для
планирования и список выбросов для разбора.

Где встречается: ежемесячная отчётность («выросли мы или это просто сезон»),
подготовка ряда к прогнозированию, поиск аномалий в продажах.

## Теория

Классическое разложение скользящим средним предполагает постоянный сезонный
профиль и ломается на выбросах. STL снимает оба ограничения.

**Внутренний цикл** повторяется дважды:

1. Ряд детрендируется: $y_t - T_t$.
2. Сезонные подряды — все январи, все феврали и так далее — сглаживаются
   локальной регрессией и продлеваются на цикл в каждую сторону.
3. Результат пропускается через низкочастотный фильтр: три скользящих средних
   и локальная регрессия.
4. Сезонная составляющая — разность продлённого ряда и низкочастотной части.
5. Ряд очищается от сезонности, и по нему строится тренд локальной регрессией.

**Внешний цикл** пересчитывает веса наблюдений бивесовой функцией Тьюки по
величине остатка: выброс получает нулевой вес и перестаёт влиять на оценку
тренда и сезонности. Без этого одна промоакция искажает сезонный профиль
соответствующего месяца на все годы.

Сила составляющих оценивается по Хиндману — как доля дисперсии, которую
составляющая убирает из остатка:

$$
F_T = \max\left(0,\ 1 - \frac{\mathrm{Var}(R_t)}{\mathrm{Var}(T_t + R_t)}\right),
\qquad
F_S = \max\left(0,\ 1 - \frac{\mathrm{Var}(R_t)}{\mathrm{Var}(S_t + R_t)}\right).
$$

Значения выше 0,6 означают выраженную составляющую, ниже 0,4 — что её
практически нет. Это прямой ответ на вопрос, нужна ли сезонная модель.

Выбросы определяются по остатку правилом трёх межквартильных размахов.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(R \cdot n \cdot q)$ | $R$ — внешних итераций, $q$ — окно локальной регрессии |
| Память | $O(n + m)$ | Составляющие и продлённый ряд |

## API

| Метод | Описание |
|-------|----------|
| `StlDecomposition.Decompose(series, period, seasonalSpan, trendSpan, robustIterations)` | Разложение |
| `StlResult.SeasonallyAdjusted` | Ряд без сезонности — для отслеживания динамики |
| `StlResult.TrendStrength` / `SeasonalStrength` | Сила составляющих по Хиндману |
| `StlResult.Outliers` | Индексы наблюдений с аномальным остатком |
| `StlResult.Remainder` | Остаток; сумма трёх составляющих равна исходному ряду |

Исходник: `src/AI.Economics/Forecasting/StlDecomposition.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Forecasting;

var random = new Random(13);
const int weeks = 156;
var sales = new Vector(weeks);

for (int t = 0; t < weeks; t++)
{
    double value = 1000 + (2.0 * t)
                 + (200 * Math.Sin(2 * Math.PI * t / 52.0))
                 + ((random.NextDouble() - 0.5) * 80);

    // Разовые промоакции: именно они ломают классическое разложение
    if (random.NextDouble() < 0.03) value *= 1.6;
    sales[t] = value;
}

StlResult decomposition = StlDecomposition.Decompose(sales, period: 52, robustIterations: 1);

Console.WriteLine($"Сила тренда: {decomposition.TrendStrength:F2}");
Console.WriteLine($"Сила сезонности: {decomposition.SeasonalStrength:F2}");
Console.WriteLine($"Тренд изменился на " +
                  $"{decomposition.Trend[weeks - 1] - decomposition.Trend[0]:N0}");
Console.WriteLine($"Найдено выбросов: {decomposition.Outliers.Count}");

// Составляющие складываются в исходный ряд
double check = decomposition.Trend[10] + decomposition.Seasonal[10] + decomposition.Remainder[10];
Console.WriteLine($"Проверка разложения: {check:F2} против {sales[10]:F2}");

Console.WriteLine(decomposition.Interpret().ToLlmText());
```

## Ограничения

- Разложение аддитивное. Если сезонный размах растёт вместе с уровнем ряда,
  прологарифмируйте ряд перед разложением и потенцируйте составляющие после.
- Нужно минимум два полных сезонных цикла, а для устойчивой оценки — три.
  На двух циклах каждый сезонный подряд состоит из двух точек.
- Метод описательный: он раскладывает наблюдавшийся ряд и не даёт прогноза.
  Для прогноза сезонно очищенный ряд подаётся в
  [сглаживание](ets.md) или [ARIMA](arima.md).
- Ширина окон сглаживания влияет на распределение дисперсии между трендом и
  остатком. Значения по умолчанию следуют исходной работе Кливленда, но на
  конкретных данных их стоит проверить.
- Выбросы находятся, но не объясняются. Промо, сбой учёта и разовый крупный
  контракт выглядят одинаково — разбирать приходится вручную.
