# Диагностика регрессии

Брёйш — Паган и Уайт на гетероскедастичность, Дарбин — Уотсон на
автокорреляцию, RESET на форму, Чоу на структурный сдвиг, Жарк — Бера на
нормальность и VIF на мультиколлинеарность.

## Постановка задачи

Дано: оценённая линейная регрессия — матрица регрессоров и отклик.

Требуется: проверить предпосылки МНК и понять, какие из них нарушены, — от
этого зависит, можно ли доверять стандартным ошибкам, нужна ли другая
спецификация и не разбиты ли данные структурным сдвигом.

Где встречается: обязательная часть любой эконометрической работы,
регламент валидации моделей в банке, подготовка отчёта для регулятора,
отладка модели перед публикацией.

## Теория

**Гетероскедастичность.** Тест Брёйша — Пагана регрессирует квадраты
остатков на регрессоры и проверяет значимость:

$$
e_i^2 = \gamma_0 + \gamma^{\top}x_i + u_i,
\qquad
\mathrm{LM} = n\,R^2_{\text{aux}} \sim \chi^2_k .
$$

Тест Уайта делает то же, но добавляет квадраты и попарные произведения
регрессоров. Разница принципиальна: Брёйш — Паган улавливает только
монотонную зависимость дисперсии, поэтому при симметричном
$\sigma \propto |x|$ он ничего не находит, а Уайт находит. Если тесты
расходятся, верьте Уайту.

**Автокорреляция.** Статистика Дарбина — Уотсона:

$$
d \;=\; \frac{\sum_{t=2}^{n}(e_t - e_{t-1})^2}{\sum_t e_t^2} \;\approx\; 2(1-\hat\rho).
$$

Значение около 2 означает отсутствие автокорреляции, ниже 1,5 —
положительную, выше 2,5 — отрицательную.

**Форма модели.** Тест Рамсея (RESET) добавляет в регрессию степени
расчётного значения $\hat y^2, \hat y^3$ и проверяет их значимость. Отклонение
означает пропущенную нелинейность или неверную функциональную форму.

**Структурный сдвиг.** Тест Чоу сравнивает сумму квадратов остатков общей
регрессии с суммой по двум подвыборкам:

$$
F \;=\; \frac{(\mathrm{RSS} - \mathrm{RSS}_1 - \mathrm{RSS}_2)/k}
{(\mathrm{RSS}_1 + \mathrm{RSS}_2)/(n - 2k)} \sim F_{k,\,n-2k}.
$$

**Нормальность.** Жарк — Бера проверяет асимметрию $S$ и эксцесс $K$:
$\mathrm{JB} = \frac{n}{6}\left(S^2 + \frac{(K-3)^2}{4}\right)\sim\chi^2_2$.
Нарушение нормальности не смещает оценки и на больших выборках не критично —
это самый безобидный из провалов.

**Мультиколлинеарность.** Фактор раздувания дисперсии показывает, во сколько
раз выросла дисперсия коэффициента из-за связи регрессора с остальными:

$$
\mathrm{VIF}_j = \frac{1}{1 - R_j^2},
$$

где $R_j^2$ — коэффициент детерминации регрессии $x_j$ на остальные
регрессоры. Значение 10 означает, что доверительный интервал шире в
$\sqrt{10}\approx 3{,}2$ раза.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(nk^2 + k\cdot nk^2)$ | VIF требует $k$ вспомогательных регрессий |
| Память | $O(nk)$ | матрица плана и остатки |

## API

| Метод | Описание |
|-------|----------|
| `Diagnostics.Run(x, y, names, breakPoint)` | Все тесты сразу |
| `Diagnostics.BreuschPagan(x, residuals)` / `White(x, residuals)` | Гетероскедастичность |
| `Diagnostics.DurbinWatsonStatistic(residuals)` | Автокорреляция |
| `Diagnostics.Reset(x, y)` / `Chow(x, y, breakPoint)` | Форма и структурный сдвиг |
| `Diagnostics.JarqueBera(residuals)` | Нормальность остатков |
| `Diagnostics.VarianceInflationFactors(x, names)` | Коллинеарность |
| `DiagnosticReport.Failed` | Только проваленные тесты |

Исходники: `src/AI.Economics/Econometrics/Diagnostics.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Econometrics;
using AI.Statistics;

Random gen = RandomEngine.Create(103);
int size = 500;

var design = new Matrix(size, 3);
var response = new Vector(size);

for (int i = 0; i < size; i++)
{
    double a = RandomEngine.NextGaussian(gen);
    double b = RandomEngine.NextGaussian(gen);
    double c = (0.7 * a) + (0.71 * RandomEngine.NextGaussian(gen)); // коллинеарен с a

    design[i, 0] = a;
    design[i, 1] = b;
    design[i, 2] = c;

    response[i] = 1 + (2 * a) - (0.5 * b) + (0.3 * c)
        + RandomEngine.NextGaussian(gen, 0, 0.5 * Math.Exp(0.7 * a / 2));
}

DiagnosticReport report = Diagnostics.Run(design, response, ["a", "b", "c"]);

foreach (DiagnosticTest test in report.Tests)
{
    Console.WriteLine($"{test.Name}: статистика {test.Statistic:F3}, p = {test.PValue:F4} — " +
                      (test.Rejected ? test.Consequence : "гипотеза не отвергается"));
}

Console.WriteLine($"Дарбин — Уотсон {report.DurbinWatson:F3}");
Console.WriteLine($"Провалено {report.Failed.Count} тестов из {report.Tests.Count}");
```

Коллинеарность выводится отдельно — она не тест, а предупреждение:

```csharp
foreach (VarianceInflation vif in report.Collinearity)
{
    Console.WriteLine($"{vif.Variable}: VIF {vif.Vif:F2}, R² {vif.RSquared:F3}, " +
                      $"интервал шире в {vif.IntervalInflation:F2} раза" +
                      (vif.IsSevere ? " — критично" : ""));
}
```

Проваленный тест на гетероскедастичность — это указание сменить тип ошибок:

```csharp
bool heteroskedastic = report.Failed.Any(t => t.Name.Contains("Уайт") || t.Name.Contains("Паган"));

RegressionResult corrected = LinearRegression.Fit(design, response, ["a", "b", "c"],
    new RegressionOptions
    {
        Variance = heteroskedastic ? RobustVariance.Hc3 : RobustVariance.Classical,
    });

Console.WriteLine($"Использованы ошибки: {corrected.Variance}");
Console.WriteLine(report.Interpret().ToLlmText());
```

## Ограничения

- Тесты проверяют предпосылки по одной, а нарушения приходят вместе. При
  одновременной гетероскедастичности и автокорреляции статистики смещены, и
  вывод по каждому тесту в отдельности ненадёжен.
- Мощность растёт с объёмом выборки: на 10 000 наблюдений отвергается почти
  любая гипотеза, включая экономически несущественные отклонения. Смотрите на
  величину эффекта, а не только на p-значение.
- Тест Чоу требует заранее известной точки сдвига. Если она подобрана по
  данным, распределение статистики другое, и нужны тесты с неизвестной точкой
  разрыва.
- Высокий VIF сам по себе не порок: он не смещает оценки и не мешает прогнозу.
  Он мешает только интерпретации отдельных коэффициентов.
- Дарбин — Уотсон неприменим, когда среди регрессоров есть лаг отклика — там
  нужна h-статистика Дарбина или тест Брёйша — Годфри.
