# Оптимизация цен товарной линейки

Выбор цен, максимизирующих прибыль по всей линейке сразу, с учётом
каннибализации между позициями и ограничений по марже и объёму.

## Постановка задачи

Дано: товары с текущими ценами, объёмами и переменными издержками, матрица
собственных и перекрёстных эластичностей, ограничения бизнеса.

Требуется: рекомендованные цены и оценка прироста прибыли.

Где встречается: ежегодный пересмотр прайса, запуск новой позиции в линейке,
реакция на изменение цен конкурента.

## Теория

Спрос описывается моделью постоянной эластичности с перекрёстными эффектами:

$$
q_i(p) = q_i^0 \prod_j \left(\frac{p_j}{p_j^0}\right)^{E_{ij}},
$$

где $E_{ii}$ — собственная эластичность (отрицательна), $E_{ij}$ —
перекрёстная: положительная у заменителей, отрицательная у дополняющих.

Максимизируется суммарная прибыль:

$$
\Pi(p) = \sum_i (p_i - c_i)\, q_i(p) \ \to\ \max.
$$

Для единственного товара задача решается в замкнутом виде — правило Лернера
$p^{*} = c\,e/(1+e)$, определённое при $e < -1$. Для линейки замкнутого решения
нет: целевая функция невыпукла, а ограничения связывают позиции между собой.
Задача решается симплекс-методом в пространстве логарифмов ценовых множителей.

**Ограничение на маржу задаётся границей цены, а не штрафом.** Требование
$m_i \ge \underline{m}$ эквивалентно $p_i \ge c_i/(1-\underline{m})$ и
выполняется точно. Штраф на границе всегда продавливается: выигрыш в прибыли
от малого нарушения растёт линейно, а квадратичный штраф вблизи нуля убывает
быстрее.

Ограничения на суммарный объём и выручку связывают позиции и потому остаются
штрафами — с линейным слагаемым, чтобы не повторить ту же ошибку.

Отдельно считается цена игнорирования каннибализации: разница между
оптимумом по всей линейке и результатом, который дало бы независимое
оптимизирование каждой позиции с последующей оценкой по настоящей матрице
эластичностей.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I \cdot k^2)$ | $I$ — итераций симплекса, $k$ — товаров |
| Память | $O(k^2)$ | Матрица эластичностей |

## API

| Метод | Описание |
|-------|----------|
| `PriceOptimizer.Optimize(products, elasticities, constraints)` | Оптимизация линейки |
| `PriceOptimizer.LernerPrice(unitCost, elasticity)` | Замкнутое решение для одного товара |
| `CrossElasticity.Estimate(prices, quantities)` | Матрица эластичностей по панели |
| `CrossElasticity.Diagonal(ownElasticities)` | Матрица без перекрёстных эффектов |
| `PriceConstraints.MinMarginRate` | Минимальная маржа; реализована границей цены |
| `PriceOptimizationResult.CannibalizationCost` | Цена игнорирования перекрёстных эффектов |

Исходники: `src/AI.Economics/Pricing/`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Pricing;

ProductPricing[] line =
[
    new() { Name = "Базовый", CurrentPrice = 1000, CurrentQuantity = 5000, UnitCost = 400 },
    new() { Name = "Стандарт", CurrentPrice = 1800, CurrentQuantity = 2500, UnitCost = 700 },
    new() { Name = "Премиум", CurrentPrice = 3200, CurrentQuantity = 800, UnitCost = 1200 },
];

// Товары-заменители: снижение цены одного забирает спрос у соседей
var elasticities = new Matrix(3, 3);
for (int i = 0; i < 3; i++)
    for (int j = 0; j < 3; j++) elasticities[i, j] = i == j ? -2.2 : 0.3;

var constraints = new PriceConstraints
{
    MaxPriceChange = 0.25,
    MinMarginRate = 0.30,
};

PriceOptimizationResult result = PriceOptimizer.Optimize(line, elasticities, constraints);

Console.WriteLine($"Прибыль: {result.CurrentProfit:N0} -> {result.OptimalProfit:N0} " +
                  $"({result.ProfitGainRate:P1})");

foreach (ProductPriceRecommendation row in result.Products)
{
    Console.WriteLine($"{row.Name,-10} {row.CurrentPrice,8:N0} -> {row.OptimalPrice,8:N0} " +
                      $"({row.PriceChange,7:P1}), маржа {row.NewMargin:P0}" +
                      (row.AtBound ? ", упёрлась в границу" : ""));
}

Console.WriteLine($"Игнорирование каннибализации стоило бы {result.CannibalizationCost:N0}");
Console.WriteLine(result.Interpret().ToLlmText());
```

## Ограничения

- Модель постоянной эластичности верна вблизи текущих цен. Ограничение
  `MaxPriceChange` не косметическое: оно удерживает решение внутри области,
  где модель проверена данными.
- Эластичности берутся как данность. Ошибка в них переносится в рекомендацию
  напрямую, поэтому оценивать их надо с поправкой на эндогенность — см.
  [эластичность спроса](elasticity.md).
- Реакция конкурентов не моделируется. Если они ответят на изменение цены,
  фактический результат окажется хуже расчётного.
- Задача невыпукла: симплекс-метод находит локальный оптимум. На типичных
  линейках из единиц позиций он совпадает с глобальным, но гарантии нет.
- Не учитываются психологические пороги цен и округление: рекомендацию
  в 1987 рублей на практике превращают в 1990 или 1999.
