# Конформные интервалы прогноза

Интервалы с гарантированным покрытием, полученные из фактических ошибок
модели — без предположений о распределении и без веры в правильность самой
модели.

## Постановка задачи

Дано: прогнозная модель и историческая выборка, на которой можно измерить
её фактические ошибки.

Требуется: интервалы прогноза, покрывающие факт с заявленной вероятностью,
и квантильные прогнозы для планирования.

Где встречается: планирование запаса под уровень сервиса, обязательства перед
клиентом, любое решение, где нужна не средняя оценка, а гарантия «не меньше X
с вероятностью 90 %».

## Теория

Интервалы, которые выдают ARIMA и экспоненциальное сглаживание, опираются на
два предположения: ошибки нормальны и модель верна. На практике нарушаются оба,
и заявленный 90-процентный интервал покрывает 70 % фактов. Планирование запаса
по таким интервалам даёт не тот уровень сервиса, на который рассчитывали.

Конформный метод берёт ошибки модели на отложенной части истории и строит
интервал как эмпирический квантиль их абсолютных величин:

$$
\hat C(x) = \left[\hat y - q_{1-\alpha},\ \hat y + q_{1-\alpha}\right],
\qquad
q_{1-\alpha} = \text{Quantile}\left(\{|e_i|\},\ (1-\alpha)\left(1 + \tfrac{1}{n}\right)\right).
$$

Поправка $(1 + 1/n)$ на конечность выборки обязательна: без неё покрытие
систематически ниже заявленного.

Единственное требование — обменность калибровочных и будущих ошибок. Никаких
предположений о виде распределения не нужно: гарантия покрытия выполняется
для любой модели, даже заведомо плохой. Плохая модель просто получит широкие
интервалы — и это честнее, чем узкие интервалы с ложной гарантией.

**Калибровка ведётся отдельно для каждого шага горизонта.** Ошибка прогноза
на месяц вперёд и на полгода вперёд имеет разный масштаб, и общий квантиль
был бы слишком широк для ближнего горизонта и слишком узок для дальнего.

Помимо симметричного интервала считаются квантили по знаковым ошибкам.
Именно они нужны для решений вида «сколько закупить, чтобы хватило
с вероятностью 95 %»: там нужен односторонний квантиль, а не половина
двустороннего интервала.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(F \cdot C + h\,n\log n)$ | $F$ — срезов калибровки, $C$ — стоимость обучения |
| Память | $O(h \cdot F)$ | Ошибки по шагам горизонта |

## API

| Метод | Описание |
|-------|----------|
| `ConformalPrediction.Calibrate(series, forecaster, horizon, level, folds, quantiles)` | Калибровка интервалов |
| `ConformalForecast.CalibrationCoverage` | Фактическое покрытие на калибровке |
| `ConformalForecast.ModelCoverage` | Что давали интервалы модели до калибровки |
| `ConformalForecast.Quantiles` | Квантильные прогнозы по запрошенным уровням |
| `ConformalForecast.Width` | Ширина интервала по шагам горизонта |

Исходник: `src/AI.Economics/Forecasting/ConformalPrediction.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Forecasting;

var random = new Random(41);
const int months = 180;
var demand = new Vector(months);

for (int t = 0; t < months; t++)
{
    double value = 1000 + (3.0 * t)
                 + (150 * Math.Sin(2 * Math.PI * t / 12.0))
                 + ((random.NextDouble() - 0.5) * 90);

    if (random.NextDouble() < 0.02) value *= 1.6;
    demand[t] = value;
}

ConformalForecast calibrated = ConformalPrediction.Calibrate(
    demand,
    (train, h) => ExponentialSmoothing.AutoFit(train, h, 12),
    horizon: 8,
    confidenceLevel: 0.9,
    calibrationFolds: 30,
    quantiles: [0.05, 0.5, 0.95]);

Console.WriteLine($"Покрытие после калибровки: {calibrated.CalibrationCoverage:P1}");
Console.WriteLine($"Покрытие интервалов модели: {calibrated.ModelCoverage:P1}");

for (int h = 0; h < calibrated.PointForecast.Count; h++)
{
    Console.WriteLine($"+{h + 1} мес.: прогноз {calibrated.PointForecast[h],8:N0}, " +
                      $"не меньше {calibrated.Quantiles[0.05][h],8:N0} с вероятностью 95 %, " +
                      $"ширина интервала {calibrated.Width[h]:N0}");
}

Console.WriteLine(calibrated.Interpret().ToLlmText());
```

## Ограничения

- Обменность нарушается при структурном сдвиге. Если после калибровки
  изменились цены, конкуренты или сезонный профиль, гарантия покрытия
  перестаёт действовать.
- Ошибки прогноза во временных рядах не независимы. Формальная гарантия
  конформного метода выведена для обменных величин, и на автокоррелированных
  ошибках она приближённая, хотя на практике работает заметно лучше
  модельных интервалов.
- Малая калибровочная выборка делает эмпирический квантиль нестабильным:
  минимум тридцать срезов, лучше пятьдесят.
- Калибровка требует многократного переобучения модели. Для тяжёлых моделей
  это дороже самого прогноза.
- Интервал симметричен вокруг точечного прогноза. При выраженной асимметрии
  ошибок пользуйтесь квантилями, а не границами интервала.
