# Сравнительная оценка по мультипликаторам

Отбор аналогов по драйверам стоимости, статистика мультипликаторов
EV/EBITDA, EV/Revenue и P/E, а также регрессия мультипликатора на рост и
рентабельность.

## Постановка задачи

Дано: финансовые показатели оцениваемой компании и набор публичных или
сделочных аналогов с известной стоимостью.

Требуется: диапазон стоимости бизнеса, полученный независимо от прогноза
денежных потоков, — и объяснение, почему компания должна торговаться с
премией или дисконтом к медиане отрасли.

Где встречается: проверка результата DCF, быстрая оценка при первичном
скрининге сделки, обоснование цены размещения, справедливая стоимость доли
для отчётности.

## Теория

**Мультипликатор** — отношение стоимости к показателю деятельности. Ключевое
требование к нему: числитель и знаменатель должны относиться к одному и тому
же кругу поставщиков капитала. Стоимость бизнеса $\mathrm{EV}$ доступна всем,
поэтому она делится на доналоговые показатели — выручку и EBITDA.
Капитализация принадлежит акционерам и делится на чистую прибыль:

$$
\frac{\mathrm{EV}}{\mathrm{EBITDA}},\qquad
\frac{\mathrm{EV}}{\mathrm{Revenue}},\qquad
\frac{P}{E} = \frac{\mathrm{MktCap}}{\mathrm{NetIncome}}.
$$

Смешение уровней (капитализация на EBITDA) даёт систематическую ошибку,
величина которой равна долговой нагрузке.

**Отбор аналогов** делается не по отрасли, а по драйверам стоимости — темпу
роста и рентабельности. Расстояние считается в стандартизованных единицах:

$$
d_j \;=\; \sqrt{\left(\frac{g_j - g_0}{s_g}\right)^2 + \left(\frac{m_j - m_0}{s_m}\right)^2},
$$

где $s_g$ и $s_m$ — разброс соответствующих драйверов по выборке. Компания с
ростом 30% не сопоставима с компанией с ростом 3% даже внутри одной отрасли.

**Медиана вместо среднего.** Выборки аналогов малы и содержат выбросы —
компанию накануне поглощения, компанию с околонулевой прибылью. Медиана и
квартили устойчивы к ним, среднее — нет.

**Регрессия мультипликатора** объясняет, почему аналоги торгуются по-разному:

$$
\frac{\mathrm{EV}}{\mathrm{EBITDA}}_j \;=\; a + b\,g_j + c\,m_j + \varepsilon_j .
$$

Подстановка драйверов оцениваемой компании даёт «заслуженный» мультипликатор.
Этот подход честнее медианы: он не требует, чтобы аналоги были похожи, а
явно корректирует на различия. Требование к выборке — не менее восьми-десяти
наблюдений на два регрессора.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(P\log P)$ | $P$ аналогов, сортировка для квартилей |
| Память | $O(P)$ | выборка и матрица регрессии |

## API

| Метод | Описание |
|-------|----------|
| `Comparables.Value(target, peers, peerCount)` | Оценка по всем мультипликаторам |
| `Comparables.Rank(target, peers)` | Ранжирование аналогов по близости драйверов |
| `ComparablesResult.Multiples` | Медиана, квартили и подразумеваемая стоимость |
| `ComparablesResult.RegressionValue` | Оценка по регрессии на драйверы |
| `ComparablesResult.MedianValue` / `ValuationSpread` | Итоговое число и разброс методов |
| `Peer.EvToEbitda` / `EvToRevenue` / `PriceToEarnings` | Мультипликаторы аналога |

Исходники: `src/AI.Economics/Corporate/Comparables.cs`.

## Код

```csharp
using AI.Economics.Corporate;

var peers = new List<Peer>
{
    new() { Name = "Аналог A", EnterpriseValue = 8_000_000_000, Revenue = 5_000_000_000,
            Ebitda = 1_000_000_000, NetIncome = 520_000_000,
            MarketCapitalization = 6_500_000_000, Growth = 0.10 },
    new() { Name = "Аналог B", EnterpriseValue = 12_600_000_000, Revenue = 7_000_000_000,
            Ebitda = 1_400_000_000, NetIncome = 700_000_000,
            MarketCapitalization = 10_000_000_000, Growth = 0.14 },
    new() { Name = "Аналог C", EnterpriseValue = 5_100_000_000, Revenue = 4_000_000_000,
            Ebitda = 600_000_000, NetIncome = 250_000_000,
            MarketCapitalization = 4_000_000_000, Growth = 0.05 },
    new() { Name = "Аналог D", EnterpriseValue = 15_000_000_000, Revenue = 6_000_000_000,
            Ebitda = 1_500_000_000, NetIncome = 810_000_000,
            MarketCapitalization = 12_500_000_000, Growth = 0.18 },
};

var target = new Peer
{
    Name = "Оцениваемая компания",
    Revenue = 5_500_000_000,
    Ebitda = 1_100_000_000,
    NetIncome = 560_000_000,
    Growth = 0.12,
};

ComparablesResult valuation = Comparables.Value(target, peers);

foreach (MultipleStatistic multiple in valuation.Multiples)
{
    Console.WriteLine($"{multiple.Name}: медиана {multiple.Median:F2} " +
                      $"[{multiple.LowerQuartile:F2}; {multiple.UpperQuartile:F2}] " +
                      $"→ {multiple.ImpliedValue:N0}");
}

Console.WriteLine($"Медианная оценка {valuation.MedianValue:N0}");
Console.WriteLine($"Оценка по регрессии {valuation.RegressionValue:N0}");
Console.WriteLine($"Разброс методов {valuation.ValuationSpread:P1}");
```

Когда выборка большая, имеет смысл сузить её до ближайших аналогов:

```csharp
IReadOnlyList<(string Peer, double Distance)> ranked = Comparables.Rank(target, peers);

foreach ((string name, double distance) in ranked)
    Console.WriteLine($"{name}: расстояние {distance:F2}");

ComparablesResult narrow = Comparables.Value(target, peers, peerCount: 2);
Console.WriteLine($"По двум ближайшим: {narrow.MedianValue:N0}");
```

Регрессия объясняет премию за рост — её коэффициенты стоит показывать
на комитете вместе с числом:

```csharp
if (valuation.Regression is { } model)
{
    foreach (var coefficient in model.Coefficients)
        Console.WriteLine($"{coefficient.Name}: {coefficient.Estimate:F2}{coefficient.Stars}");

    Console.WriteLine($"R² регрессии мультипликатора {model.RSquared:P0}");
}

Console.WriteLine(valuation.Interpret().ToLlmText());
```

## Ограничения

- Мультипликаторы отражают текущее настроение рынка, а не фундаментальную
  стоимость. В пик цикла сравнительный подход даёт завышенную оценку у всех
  участников одновременно.
- Выборка из трёх-четырёх аналогов не даёт устойчивой медианы, а регрессия на
  ней переобучается. Ниже восьми наблюдений полагайтесь только на медиану и
  трактуйте её как ориентир.
- Разные стандарты учёта, разовые статьи и капитализация аренды делают EBITDA
  несопоставимой. Нормализация показателя занимает больше времени, чем сам
  расчёт.
- Сделочные мультипликаторы включают премию за контроль, биржевые — нет.
  Смешивать их в одной выборке нельзя.
- Метод не отвечает на вопрос, справедлива ли оценка отрасли в целом. Всегда
  сверяйте результат с [DCF](dcf.md): систематическое расхождение указывает
  либо на ошибку прогноза, либо на переоценённость сектора.
