# Uplift-моделирование промо

Кому скидка действительно меняет поведение, а кому просто уменьшает чек —
и сколько денег экономит адресность.

## Постановка задачи

Дано: результаты промо-эксперимента с контрольной группой: признаки клиента,
факт воздействия и факт конверсии.

Требуется: предсказание индивидуального прироста вероятности покупки,
порог окупаемости промо и экономика адресного охвата.

Где встречается: рассылка скидок, программа удержания, персональные
предложения, любое промо с ограниченным бюджетом.

## Теория

Обычная модель отклика предсказывает, кто купит. Это не тот вопрос: среди
самых вероятных покупателей много тех, кто купил бы и без скидки — и скидка
им просто уменьшает чек. Uplift предсказывает **разницу** между поведением
с воздействием и без него:

$$
\tau(x) = P(Y=1 \mid T=1, X=x) - P(Y=1 \mid T=0, X=x).
$$

Реализован подход двух моделей: отдельная логистическая регрессия на группе
воздействия и на контроле, прирост равен разности предсказанных вероятностей.
Способ прост и прозрачен; его слабое место в том, что разность двух хорошо
подогнанных моделей может ранжировать хуже, чем каждая по отдельности.
Поэтому качество проверяется не посадкой моделей, а кривой Qini.

**Кривая Qini** показывает накопленный прирост конверсий при охвате клиентов
в порядке убывания предсказанного эффекта:

$$
Q(k) = Y_T(k) - Y_C(k)\,\frac{N_T(k)}{N_C(k)}.
$$

Масштабирование контрольных конверсий обязательно: без него кривая измеряла бы
разницу размеров групп, а не эффект. Коэффициент Qini — площадь между кривой
и диагональю случайного охвата, нормированная на площадь под диагональю.

**Порог окупаемости** следует из экономики: промо стоит давать клиенту,
если ожидаемая дополнительная прибыль превышает затраты,

$$
\tau(x) \cdot m > c \quad\Longleftrightarrow\quad \tau(x) > \frac{c}{m}.
$$

Отдельная категория — клиенты с отрицательным приростом. Для них верным
действием является отсутствие действия, и исключать их нужно явным правилом,
а не порогом.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Обучение | $O(I \cdot n k^2)$ | Две логистические регрессии |
| Кривая Qini | $O(n \log n)$ | Доминирует сортировка по приросту |
| Память | $O(n k)$ | Матрица признаков |

## API

| Метод | Описание |
|-------|----------|
| `UpliftModeling.Fit(observations, promoCost, marginPerConversion, groups)` | Модель и экономика охвата |
| `UpliftResult.QiniCoefficient` | Качество ранжирования; 0 — не лучше случайного |
| `UpliftResult.ProfitThreshold` | Минимальный прирост, при котором промо окупается |
| `UpliftResult.ProfitTargeted` | Прибыль при охвате только восприимчивых |
| `UpliftResult.ProfitTreatAll` | Прибыль при сплошном охвате |
| `UpliftResult.SleepingDogs` | Клиенты с отрицательным приростом |
| `UpliftDecile.ActualUplift` | Фактический прирост в группе, а не предсказанный |

Исходник: `src/AI.Economics/Marketing/UpliftModeling.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Marketing;

var random = new Random(13);
var experiment = new List<UpliftObservation>();

for (int i = 0; i < 8000; i++)
{
    double sensitivity = random.NextDouble();
    double loyalty = random.NextDouble();
    bool treated = random.NextDouble() < 0.5;

    // Восприимчивые откликаются, лояльные покупают и без скидки
    double baseRate = 0.10 + (0.25 * loyalty);
    double lift = (0.30 * sensitivity) - (0.10 * loyalty);
    double rate = Math.Clamp(baseRate + (treated ? lift : 0), 0.01, 0.95);

    experiment.Add(new UpliftObservation
    {
        Features = new Vector(sensitivity, loyalty),
        Treated = treated,
        Converted = random.NextDouble() < rate,
    });
}

UpliftResult result = UpliftModeling.Fit(experiment, promoCost: 60, marginPerConversion: 300);

Console.WriteLine($"Средний эффект: {result.AverageTreatmentEffect:P1}");
Console.WriteLine($"Коэффициент Qini: {result.QiniCoefficient:F3}");
Console.WriteLine($"Порог окупаемости: {result.ProfitThreshold:P1}");
Console.WriteLine($"Охватить стоит {result.TargetedShare:P0} базы");
Console.WriteLine($"Прибыль: адресно {result.ProfitTargeted:N0}, всем {result.ProfitTreatAll:N0}");

foreach (UpliftDecile group in result.Groups)
{
    Console.WriteLine($"Группа {group.Group}: предсказано {group.PredictedUplift:P1}, " +
                      $"фактически {group.ActualUplift:P1}");
}

Console.WriteLine(result.Interpret().ToLlmText());
```

## Ограничения

- Uplift — разность двух зашумлённых величин. На выборке меньше нескольких
  тысяч наблюдений оценка по группам неустойчива, а коэффициент Qini
  колеблется от выборки к выборке.
- Контрольная группа обязательна и должна формироваться случайно.
  Квазиэксперимент «сравним охваченных с неохваченными» даёт смещение,
  которое модель не исправит.
- Модель обучена на выборке конкретного эксперимента. Перенос на другую базу
  требует проверки: восприимчивость зависит от того, как клиент попал
  в выборку.
- Подход двух моделей чувствителен к дисбалансу групп: при сильно разных
  размерах разность вероятностей смещается.
- Экономика охвата считается по фактическому приросту в группах, а не по
  предсказанному. Это честнее, но требует достаточного контроля в каждой
  группе — минимум несколько десятков наблюдений.
