# Причинный лес: гетерогенность эффекта

Оценка индивидуального эффекта воздействия деревьями с честным расщеплением:
кому программа помогает, кому вредит и какие признаки это определяют.

## Постановка задачи

Дано: признаки объектов, индикатор воздействия и отклик — данные
эксперимента или квазиэксперимента.

Требуется: не средний эффект по выборке, а индивидуальный эффект как функция
признаков — чтобы направлять воздействие туда, где оно окупается.

Где встречается: таргетирование скидок и промо, отбор клиентов для
удержания, персонализация лечения, выбор сегментов для маркетинговой
кампании, приоритизация бюджета поддержки.

## Теория

**Зачем.** Средний эффект в 2% может складываться из +10% у четверти
аудитории и нуля у остальных. Раздавать скидку всем в такой ситуации — терять
деньги на трёх четвертях. Задача — найти эту четверть.

**Условный средний эффект:**

$$
\tau(x) \;=\; \mathbb E\left[y(1) - y(0)\mid X = x\right].
$$

Он не наблюдается ни для одного объекта: для каждого известен только один из
двух исходов. Оценивается он локально — по объектам с похожими признаками:

$$
\hat\tau(\text{лист}) = \bar y_{\text{возд}}^{\text{лист}} - \bar y_{\text{контр}}^{\text{лист}}.
$$

**Критерий расщепления.** Обычное дерево минимизирует разброс отклика.
Причинное дерево максимизирует **разброс эффекта** между потомками: полезно
то деление, которое разводит объекты с разным $\tau$, а не с разным $y$. Это
принципиальная разница — признак, сильно влияющий на уровень отклика, но не на
эффект, причинному дереву бесполезен.

**Честное расщепление** (Athey — Imbens) — ключевая идея, обеспечивающая
корректные оценки. Выборка делится пополам: одна половина используется для
выбора точек разбиения, другая — для оценки эффекта в листьях. Без этого
разделения оценка смещена: дерево находит лист там, где разность случайно
велика, и эта же случайность попадает в оценку.

**Лес.** Деревья строятся на бутстрап-подвыборках со случайным подмножеством
признаков; итоговый эффект — среднее по деревьям. Усреднение снижает
дисперсию, а случайность признаков декоррелирует деревья.

**Калибровка.** Качество проверяется регрессией фактического эффекта по
группам на предсказанный. Наклон около единицы означает, что модель
предсказывает эффект в правильном масштабе; наклон, близкий к нулю, — что
найденная гетерогенность иллюзорна.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(B\,n\log n\cdot k)$ | $B$ деревьев, $k$ признаков |
| Память | $O(B\cdot\text{узлов} + n)$ | лес и предсказания |

## API

| Метод | Описание |
|-------|----------|
| `CausalForest.Fit(features, treatment, outcome, names, trees, minLeaf, maxDepth, seed)` | Обучение леса |
| `CausalForestResult.Effects` | Индивидуальные эффекты |
| `CausalForestResult.AverageEffect` / `EffectSpread` | Средний эффект и его разброс |
| `CausalForestResult.Groups` | Группы по предсказанному эффекту с фактическим |
| `CausalForestResult.Importance` | Вклад признаков в разбиения |
| `CausalForestResult.CalibrationSlope` / `HasHeterogeneity` | Проверка качества |

Исходники: `src/AI.Economics/Econometrics/CausalForest.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Econometrics;
using AI.Statistics;

Random rng = RandomEngine.Create(157);
int n = 4000;

var features = new Matrix(n, 3);
var treatment = new Vector(n);
var outcome = new Vector(n);

for (int i = 0; i < n; i++)
{
    double sensitivity = rng.NextDouble();   // истинный драйвер эффекта
    double noise = rng.NextDouble();
    double background = RandomEngine.NextGaussian(rng);

    features[i, 0] = sensitivity;
    features[i, 1] = noise;
    features[i, 2] = background;

    bool treated = rng.NextDouble() < 0.5;   // рандомизация
    treatment[i] = treated ? 1 : 0;

    // Эффект есть только у половины выборки с высокой чувствительностью
    double individualEffect = sensitivity > 0.5 ? 2.0 : 0.0;

    outcome[i] = 1 + (0.5 * sensitivity) + (0.3 * background)
        + (treated ? individualEffect : 0)
        + RandomEngine.NextGaussian(rng, 0, 0.5);
}

CausalForestResult forest = CausalForest.Fit(
    features, treatment, outcome,
    names: ["чувствительность", "шум", "фон"],
    trees: 120, minLeaf: 25, maxDepth: 3, seed: 11);

Console.WriteLine($"Средний эффект {forest.AverageEffect:F4} (истинный 1,00 в среднем)");
Console.WriteLine($"Разброс индивидуальных эффектов {forest.EffectSpread:F4}");
Console.WriteLine($"Калибровка {forest.CalibrationSlope:F3}");
Console.WriteLine(forest.HasHeterogeneity
    ? "Гетерогенность обнаружена"
    : "Эффект однороден — таргетировать нечего");
```

Группы по предсказанному эффекту — прямая инструкция для маркетинга:

```csharp
foreach (EffectGroup group in forest.Groups)
{
    Console.WriteLine($"Группа {group.Group}: предсказано {group.PredictedEffect:F3}, " +
                      $"фактически {group.ActualEffect:F3} ({group.Size} объектов)");
}

EffectGroup best = forest.Groups.MaxBy(g => g.PredictedEffect)!;
EffectGroup worst = forest.Groups.MinBy(g => g.PredictedEffect)!;

Console.WriteLine($"Лучшая группа даёт {best.ActualEffect:F3}, худшая {worst.ActualEffect:F3}");
```

Важность признаков указывает, что именно определяет отклик на воздействие:

```csharp
foreach ((string variable, double importance) in forest.Importance)
    Console.WriteLine($"{variable}: {importance:P1} разбиений");

Console.WriteLine($"Деревьев {forest.Trees}, наблюдений {forest.Observations}");
Console.WriteLine(forest.Interpret().ToLlmText());
```

## Ограничения

- Метод требует **рандомизации** или условной независимости воздействия. На
  наблюдательных данных с самоотбором лес честно найдёт гетерогенность
  смещения, а не эффекта.
- Обнаружение гетерогенности требует больших выборок. При $n < 1000$ и слабом
  эффекте лес обычно находит шум; проверяйте калибровку.
- Индивидуальные предсказания зашумлены. Надёжны выводы о группах (квинтилях
  по предсказанному эффекту), а не о конкретных объектах.
- Важность признаков в причинном лесу не имеет строгой статистической
  интерпретации. Это диагностика, а не тест на значимость.
- Найденная гетерогенность требует подтверждения на новых данных или в
  проспективном эксперименте. Таргетирование по неподтверждённой модели
  зачастую хуже равномерного воздействия.
