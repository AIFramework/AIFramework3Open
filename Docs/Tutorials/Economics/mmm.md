# Маркетинг-микс модель

Разложение продаж на вклад рекламных каналов и базовой линии с учётом двух
эффектов, которых нет в обычной регрессии: отложенного действия рекламы и
убывающей отдачи бюджета.

## Постановка задачи

Дано: недельный ряд продаж, затраты по каналам и контрольные переменные —
цена, дистрибуция, активность конкурентов.

Требуется: вклад каждого канала в продажи, возврат на вложенное и предельная
отдача следующего рубля.

Где встречается: годовое планирование бюджета, защита маркетинговых расходов
перед финансовым директором, спор о том, работает ли телевидение.

## Теория

Две нелинейности отличают модель от регрессии на затраты.

**Adstock** описывает отложенный эффект: реклама этой недели работает и на
следующей. Накопленный эффект задаётся геометрическим затуханием:

$$
a_t = x_t + \lambda\,a_{t-1}, \qquad
T_{1/2} = \frac{\ln 0{,}5}{\ln \lambda}.
$$

Для телевидения период полураспада обычно составляет одну-три недели, для
контекстной рекламы — доли недели. Оценивать телевидение по продажам той же
недели бессмысленно: основной эффект придёт позже.

**Насыщение** по кривой Хилла описывает убывающую отдачу:

$$
h(a) = \frac{a^{\alpha}}{a^{\alpha} + \gamma^{\alpha}}.
$$

Параметр $\gamma$ — точка половинного насыщения, $\alpha$ — крутизна. Без
насыщения модель предсказывает бесконечный рост продаж от бесконечного
бюджета и делает оптимизацию бессмысленной.

Итоговая модель:

$$
y_t = \beta_0 + \text{тренд} + \text{сезонность} + \sum_i \beta_i\,h_i(a_{i,t}) + \gamma^{\mathsf T} z_t + u_t.
$$

Параметры преобразований подбираются симплекс-методом, коэффициенты внутри
каждой итерации — гребневой регрессией. Регуляризация обязательна: бюджеты
каналов почти всегда движутся вместе, и без неё матрица регрессоров плохо
обусловлена.

Ключевое различие для решений о бюджете — между средним и предельным ROI.
Средний включает уже сделанные вложения и потому систематически завышает
привлекательность больших каналов, давно вышедших на плато. Перераспределять
бюджет надо по предельному.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I \cdot (nk^2 + k^3))$ | $I$ — итераций подбора, $n$ — периодов, $k$ — регрессоров |
| Память | $O(nk)$ | Матрица плана |

## API

| Метод | Описание |
|-------|----------|
| `MarketingMixModel.Fit(input)` | Оценка модели и декомпозиция продаж |
| `MarketingMixModel.Adstock(spend, decay)` | Накопленный эффект по геометрической схеме |
| `MarketingMixModel.Hill(value, halfPoint, shape)` | Кривая насыщения |
| `ChannelEffect.MarginalRoi` | Прибыль от следующего рубля в канал |
| `ChannelEffect.HalfLife` | Период полураспада эффекта |
| `ChannelEffect.SaturationLevel` | Насколько канал близок к плато |
| `MmmResult.MediaShare` | Доля продаж, объяснённая рекламой |

Исходник: `src/AI.Economics/Marketing/MarketingMixModel.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Marketing;

var random = new Random(3);
const int weeks = 156;

var tv = new Vector(weeks);
var digital = new Vector(weeks);
var sales = new Vector(weeks);
double tvCarry = 0, digitalCarry = 0;

for (int t = 0; t < weeks; t++)
{
    tv[t] = t % 8 < 3 ? 800_000 * (0.7 + (random.NextDouble() * 0.6)) : 0;
    digital[t] = 300_000 * (0.6 + (random.NextDouble() * 0.8));

    tvCarry = tv[t] + (0.6 * tvCarry);
    digitalCarry = digital[t] + (0.2 * digitalCarry);

    sales[t] = 8_000_000 + (12_000 * t)
             + (900_000 * Math.Sin(2 * Math.PI * t / 52.0))
             + (4_000_000 * MarketingMixModel.Hill(tvCarry, 1_500_000, 1.5))
             + (2_000_000 * MarketingMixModel.Hill(digitalCarry, 400_000, 1.2));
}

MmmResult result = MarketingMixModel.Fit(new MmmInput
{
    Sales = sales,
    Channels =
    [
        new MediaChannel { Name = "ТВ", Spend = tv },
        new MediaChannel { Name = "Digital", Spend = digital },
    ],
    SeasonalPeriod = 52,
    FourierTerms = 2,
    MarginRate = 0.4,
});

Console.WriteLine($"R2 = {result.RSquared:F3}, реклама объясняет {result.MediaShare:P0} продаж");

foreach (ChannelEffect channel in result.Channels)
{
    Console.WriteLine($"{channel.Name,-10} вклад {channel.TotalContribution,14:N0}  " +
                      $"ROI {channel.Roi,5:F2}  предельный {channel.MarginalRoi,5:F2}  " +
                      $"полураспад {channel.HalfLife:F1} нед.");
}

Console.WriteLine(result.Interpret().ToLlmText());
```

## Ограничения

- Модель корреляционная. Причинная интерпретация правомерна только при
  достаточной независимой вариации бюджетов; идеально — при наличии
  географических экспериментов, где часть регионов сознательно оставлена
  без рекламы.
- Для устойчивой оценки adstock и насыщения нужно минимум два года недельных
  данных. На годе показатели каналов оцениваются неустойчиво.
- Каналы, включаемые и выключаемые одновременно, разделить нельзя. Признак
  такой ситуации — отрицательный коэффициент у одного из них.
- Подозрительно высокий коэффициент детерминации обычно означает переобучение
  на тренде и сезонности при неустойчивой оценке рекламы.
- Вклад рекламы свыше половины продаж почти всегда означает забытую
  контрольную переменную — чаще всего цену или дистрибуцию.
