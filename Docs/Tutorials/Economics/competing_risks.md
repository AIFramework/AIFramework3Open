# Конкурирующие риски

Когда клиент может уйти по одной из нескольких взаимоисключающих причин,
обычная кривая дожития по каждой причине систематически завышает её долю.
Оценка Аалена — Йохансена свободна от этого дефекта.

## Постановка задачи

Дано: наблюдения дожития, у каждого события указана причина — ушёл из-за цены,
из-за продукта, закрылся сам. Часть наблюдений цензурирована.

Требуется: доля клиентов, ушедших к моменту $t$ по каждой причине, пригодная
для сравнения причин между собой и для планирования работы над ними.

Где встречается: разбор оттока по причинам, приоритизация продуктовых задач,
разделение управляемого и внешнего оттока.

## Теория

Причины конкурируют: наступившая первой лишает возможности наступить
остальные. Клиент, чья компания закрылась, уже не уйдёт из-за цены.

Соблазн посчитать по каждой причине обычную кривую Каплана — Мейера, считая
уходы по другим причинам цензурированием, приводит к оценке

$$
\tilde F_k(t) \;=\; 1 - \prod_{t_i \le t}\left(1 - \frac{d_{k,i}}{n_i}\right).
$$

Она неявно предполагает, что клиент, ушедший по другой причине, «мог бы» уйти
по нашей позже. Он не мог — его уже нет. Результат: каждая доля завышена, а их
сумма превышает долю ушедших вообще и может превысить единицу.

Корректная оценка — кумулятивная функция инцидентности Аалена — Йохансена:

$$
\hat F_k(t) \;=\; \sum_{t_i \le t} \hat S(t_{i-1}) \, \frac{d_{k,i}}{n_i},
$$

где $\hat S$ — общая кривая дожития по всем причинам сразу. Прирост доли
взвешивается вероятностью дожить **до** момента $t_i$, поэтому конкурирующие
уходы учтены честно, и выполняется тождество

$$
\sum_k \hat F_k(t) \;=\; 1 - \hat S(t).
$$

Практический вывод: сравнивать причины и планировать работу по ним можно только
по $\hat F_k$. Разница между $\tilde F_k$ и $\hat F_k$ растёт с интенсивностью
конкурирующих рисков и на длинных горизонтах достигает десятков процентных
пунктов.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(K \cdot n \cdot m)$ | $K$ — причин, $m$ — моментов событий |
| Память | $O(K \cdot m)$ | Функции инцидентности по причинам |

## API

| Метод | Описание |
|-------|----------|
| `CompetingRisks.Analyze(data, causeNames)` | Функции инцидентности по всем причинам |
| `SurvivalRecord.Cause` | Номер причины; 0 означает цензурирование |
| `CumulativeIncidence.Incidence` | Оценка Аалена — Йохансена |
| `CumulativeIncidence.NaiveIncidence` | Наивная оценка $1-KM$ для сравнения |
| `CumulativeIncidence.FinalIncidence` | Итоговая доля причины на горизонте |

Исходник: `src/AI.Economics/Survival/CompetingRisks.cs`.

## Код

```csharp
using AI.Economics.Survival;

var random = new Random(13);
var data = new List<SurvivalRecord>();

double[] rates = [0.04, 0.03, 0.02];

for (int i = 0; i < 600; i++)
{
    double bestTime = double.MaxValue;
    int bestCause = 0;

    for (int cause = 0; cause < rates.Length; cause++)
    {
        double time = -Math.Log(1.0 - random.NextDouble()) / rates[cause];
        if (time < bestTime)
        {
            bestTime = time;
            bestCause = cause + 1;
        }
    }

    bool observed = bestTime <= 24;
    data.Add(new SurvivalRecord
    {
        Time = observed ? bestTime : 24,
        Event = observed,
        Cause = observed ? bestCause : 0,
    });
}

var names = new Dictionary<int, string>
{
    [1] = "Цена",
    [2] = "Продукт",
    [3] = "Закрылся сам",
};

IReadOnlyList<CumulativeIncidence> incidence = CompetingRisks.Analyze(data, names);

foreach (CumulativeIncidence cause in incidence)
{
    Console.WriteLine($"{cause.Name,-14} CIF={cause.FinalIncidence:P1}  " +
                      $"наивно={cause.FinalNaiveIncidence:P1}");
}

Console.WriteLine($"Сумма CIF:    {incidence.Sum(c => c.FinalIncidence):P1}");
Console.WriteLine($"Сумма наивно: {incidence.Sum(c => c.FinalNaiveIncidence):P1}");
```

## Ограничения

- Причина должна быть единственной и определяться однозначно. Уход «из-за цены
  и продукта одновременно» модель не описывает — назначайте главную причину
  правилом, зафиксированным заранее.
- Модель ничего не говорит о том, что было бы, если бы конкурирующую причину
  удалось устранить: такие контрфактические вопросы требуют дополнительных
  допущений, которые данными не проверяются.
- Как и Каплан — Мейер, метод предполагает неинформативное цензурирование.
- Оценка непараметрическая и за горизонт наблюдений не экстраполируется.
