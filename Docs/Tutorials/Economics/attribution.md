# Атрибуция Бринсона

Разложение активной доходности на три источника: решение о распределении по
сегментам, выбор бумаг внутри сегмента и их взаимодействие.

## Постановка задачи

Дано: веса и доходности портфеля по сегментам (отраслям, странам, классам
активов) и такие же данные по эталону.

Требуется: ответ на вопрос, за счёт чего портфель обогнал или отстал от
эталона — за счёт того, что управляющий выбрал правильные сегменты, или того,
что внутри сегментов он выбрал правильные бумаги.

Где встречается: ежеквартальный отчёт управляющего, оценка команд
портфельных менеджеров, разделение вознаграждения между аллокатором и
селектором, объяснение результата инвестору.

## Теория

Активная доходность — разница между портфелем и эталоном:

$$
R_A \;=\; \sum_i w_i r_i \;-\; \sum_i W_i R_i,
$$

где $w_i, r_i$ — вес и доходность сегмента в портфеле, $W_i, R_i$ — в
эталоне. Модель Бринсона — Хувера — Бибауэра раскладывает эту разницу
тождественно на три слагаемых.

**Эффект распределения** — вклад решения держать в сегменте больше или
меньше эталона, при доходности сегмента как в эталоне:

$$
A_i \;=\; (w_i - W_i)\,(R_i - R_B),
$$

где $R_B = \sum_j W_j R_j$ — доходность эталона в целом. Вычитание $R_B$
принципиально: перевес в сегменте вознаграждается только тогда, когда
сегмент обогнал рынок, а не когда он просто вырос.

**Эффект выбора** — вклад отбора бумаг внутри сегмента при весе как в
эталоне:

$$
S_i \;=\; W_i\,(r_i - R_i).
$$

**Взаимодействие** — остаточный член, возникающий, когда управляющий
одновременно перевесил сегмент и удачно выбрал в нём бумаги:

$$
I_i \;=\; (w_i - W_i)\,(r_i - R_i).
$$

Тождество $\sum_i (A_i + S_i + I_i) = R_A$ выполняется точно — это и делает
разложение убедительным для инвестора.

**Интерпретация взаимодействия** спорна. Часть индустрии присоединяет его к
эффекту выбора (двухфакторная модель Бринсона — Фахлера), часть показывает
отдельно. Крупное по модулю взаимодействие означает, что решения об
аллокации и о выборе принимались согласованно — это либо признак хорошего
процесса, либо признак концентрации риска.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(m)$ | $m$ — число сегментов |
| Память | $O(m)$ | разложение по сегментам |

## API

| Метод | Описание |
|-------|----------|
| `FactorModels.BrinsonAttribution(segments, pWeights, bWeights, pReturns, bReturns, name)` | Полное разложение |
| `AttributionResult.Segments` | Три эффекта по каждому сегменту |
| `AttributionResult.TotalAllocation` / `TotalSelection` / `TotalInteraction` | Итоги |
| `AttributionResult.ActiveReturn` | Активная доходность (сумма эффектов) |
| `BrinsonSegment.Total` | Суммарный вклад сегмента |

Исходники: `src/AI.Economics/Portfolio/FactorModels.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Portfolio;

string[] segments = ["Нефть и газ", "Финансы", "Металлургия", "Технологии", "Потребительский"];

var portfolioWeights = new Vector(0.32, 0.14, 0.18, 0.24, 0.12);
var benchmarkWeights = new Vector(0.40, 0.20, 0.15, 0.15, 0.10);

var portfolioReturns = new Vector(0.062, 0.031, 0.118, 0.205, 0.044);
var benchmarkReturns = new Vector(0.055, 0.038, 0.102, 0.180, 0.049);

AttributionResult attribution = FactorModels.BrinsonAttribution(
    segments, portfolioWeights, benchmarkWeights,
    portfolioReturns, benchmarkReturns, portfolio: "Фонд акций");

Console.WriteLine($"Портфель {attribution.PortfolioReturn:P2}, " +
                  $"эталон {attribution.BenchmarkReturn:P2}, " +
                  $"активная доходность {attribution.ActiveReturn:P2}");

foreach (BrinsonSegment segment in attribution.Segments)
{
    Console.WriteLine($"{segment.Segment}: распределение {segment.Allocation:P2}, " +
                      $"выбор {segment.Selection:P2}, " +
                      $"взаимодействие {segment.Interaction:P2}, " +
                      $"итого {segment.Total:P2}");
}
```

Три числа, ради которых считается атрибуция:

```csharp
Console.WriteLine($"Эффект распределения {attribution.TotalAllocation:P2}");
Console.WriteLine($"Эффект выбора {attribution.TotalSelection:P2}");
Console.WriteLine($"Взаимодействие {attribution.TotalInteraction:P2}");

double check = attribution.TotalAllocation + attribution.TotalSelection
    + attribution.TotalInteraction;
Console.WriteLine($"Сумма эффектов {check:P2} — совпадает с активной доходностью");
```

Ранжирование сегментов показывает, где управляющий добавил и где потерял:

```csharp
foreach (BrinsonSegment segment in attribution.Segments.OrderByDescending(s => s.Total).Take(2))
    Console.WriteLine($"Лучший вклад: {segment.Segment} ({segment.Total:P2})");

foreach (BrinsonSegment segment in attribution.Segments.OrderBy(s => s.Total).Take(2))
    Console.WriteLine($"Худший вклад: {segment.Segment} ({segment.Total:P2})");

Console.WriteLine(attribution.Interpret().ToLlmText());
```

## Ограничения

- Модель однопериодная. Сложение эффектов за несколько кварталов не даёт
  разложения годовой доходности из-за геометрического наращения — для этого
  нужны методы сглаживания (Карино, Меншеро).
- Разложение чувствительно к выбору сегментации. Одни и те же решения выглядят
  как эффект распределения при отраслевой разбивке и как эффект выбора при
  страновой.
- Эффекты валютной переоценки не выделяются. Для международного портфеля
  нужна расширенная модель с отдельным валютным слагаемым, иначе валютная
  ставка маскируется под выбор бумаг.
- Атрибуция не учитывает риск. Управляющий с положительным эффектом выбора и
  вдвое большей волатильностью не создал стоимости — смотрите её вместе с
  [метриками портфеля](portfolio_metrics.md).
- Веса берутся на начало периода. При активной торговле внутри периода
  разложение теряет точность; корректно — на основе ежедневных весов.
