# Квантильная регрессия

Оценка влияния регрессоров не на среднее, а на квантили отклика: медианная
регрессия, устойчивая к выбросам, и квантильный процесс, показывающий, как
эффект меняется вдоль распределения.

## Постановка задачи

Дано: регрессоры и отклик, распределение которого асимметрично, содержит
выбросы или меняет разброс с ростом регрессора.

Требуется: описание влияния регрессора на разные части распределения — не
только на «типичное» наблюдение, но и на нижние и верхние квантили.

Где встречается: анализ заработных плат, оценка сроков доставки (важен не
средний, а 90-й перцентиль), время отклика сервиса, распределение расходов
клиентов, оценка риска (VaR — это и есть квантиль).

## Теория

**Условное среднее скрывает главное.** МНК даёт один коэффициент, описывающий
сдвиг всего распределения. Но регрессор может не сдвигать распределение, а
растягивать его: увеличивать верхние квантили и не менять нижние. Для
управленческих решений вторая ситуация принципиально иная.

**Определение.** Квантильная регрессия уровня $\tau$ минимизирует
асимметричную функцию потерь:

$$
\hat\beta(\tau) \;=\; \arg\min_{\beta}\sum_i \rho_\tau\!\left(y_i - x_i^{\top}\beta\right),
\qquad
\rho_\tau(u) = u\,(\tau - \mathbf 1\{u < 0\}).
$$

При $\tau = 0{,}5$ это минимизация суммы модулей — медианная регрессия. При
$\tau = 0{,}9$ недооценка штрафуется в девять раз сильнее переоценки, поэтому
линия проходит так, что 90% точек оказываются под ней.

**Решение.** Задача сводится к линейному программированию, но на практике
удобнее итеративно перевзвешенный МНК: веса $w_i = \tau/|e_i|$ для
положительных остатков и $(1-\tau)/|e_i|$ для отрицательных. Метод сходится за
десятки итераций.

**Стандартные ошибки** аналитически зависят от плотности ошибок в точке
квантиля, которую трудно оценить. Надёжнее парный бутстрап: выборка
пересобирается с возвращением, регрессия переоценивается, и разброс оценок
даёт ошибку.

**Псевдо-$R^2$** для квантильной регрессии:
$1 - \sum\rho_\tau(e_i)/\sum\rho_\tau(y_i - \hat q_\tau)$, где $\hat q_\tau$ —
безусловный квантиль.

**Устойчивость.** Медианная регрессия имеет точку излома 50%: половина
наблюдений может быть произвольно испорчена, а оценка останется разумной. У
МНК точка излома нулевая — одного выброса достаточно.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(Ink^2)$ на квантиль, $\times B$ на бутстрап | $I$ итераций IRLS |
| Память | $O(nk)$ | матрица плана |

## API

| Метод | Описание |
|-------|----------|
| `QuantileRegression.Fit(x, y, quantile, names, bootstrap, seed)` | Один квантиль |
| `QuantileRegression.FitProcess(x, y, quantiles, names, bootstrap, seed)` | Набор квантилей и МНК |
| `QuantileRegressionResult.PseudoRSquared` / `Objective` | Качество подгонки |
| `QuantileProcessResult.Path(variable)` | Траектория коэффициента по квантилям |
| `QuantileProcessResult.LeastSquares` | МНК-оценка для сравнения |

Исходники: `src/AI.Economics/Econometrics/QuantileRegression.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Econometrics;
using AI.Statistics;

Random rng = RandomEngine.Create(131);
int n = 800;

var experience = new Matrix(n, 1);
var wage = new Vector(n);

for (int i = 0; i < n; i++)
{
    double years = rng.NextDouble() * 20;
    experience[i, 0] = years;

    // Разброс зарплат растёт со стажем: у опытных потолок выше, пол тот же
    wage[i] = 40_000 + (2_000 * years)
        + RandomEngine.NextGaussian(rng, 0, 8_000 * (1 + (0.15 * years)));
}

QuantileProcessResult process = QuantileRegression.FitProcess(
    experience, wage, [0.1, 0.25, 0.5, 0.75, 0.9], ["стаж"], bootstrapSamples: 150, seed: 7);

Vector path = process.Path("стаж");
double ols = process.LeastSquares.First(c => c.Name == "стаж").Estimate;

for (int q = 0; q < process.Quantiles.Count; q++)
{
    QuantileRegressionResult item = process.Quantiles[q];
    Console.WriteLine($"Квантиль {item.Quantile:F2}: отдача от стажа {path[q]:N0} " +
                      $"± {item.Coefficients[1].StandardError:N0}, " +
                      $"псевдо-R² {item.PseudoRSquared:F3}");
}

Console.WriteLine($"МНК даёт единственное число: {ols:N0}");
Console.WriteLine($"Разброс по квантилям: от {path.Min():N0} до {path.Max():N0}");
```

Медианная регрессия — рабочий инструмент при выбросах:

```csharp
var contaminated = new Vector(n);
for (int i = 0; i < n; i++)
    contaminated[i] = wage[i] + (rng.NextDouble() < 0.03 ? 900_000 : 0);

QuantileRegressionResult median = QuantileRegression.Fit(
    experience, contaminated, quantile: 0.5, names: ["стаж"], bootstrapSamples: 100);

RegressionResult leastSquares = LinearRegression.Fit(experience, contaminated, ["стаж"]);

Console.WriteLine($"С выбросами — медиана: {median.Coefficients[1].Estimate:N0}");
Console.WriteLine($"С выбросами — МНК: {leastSquares.Coefficients[1].Estimate:N0}");
```

Практический вывод формулируется через квантили, а не через среднее:

```csharp
QuantileRegressionResult top = process.Quantiles.Last();
QuantileRegressionResult bottom = process.Quantiles.First();

Console.WriteLine($"Каждый год стажа добавляет {bottom.Coefficients[1].Estimate:N0} " +
                  $"низкооплачиваемым и {top.Coefficients[1].Estimate:N0} " +
                  $"высокооплачиваемым — неравенство растёт со стажем");

Console.WriteLine(process.Interpret().ToLlmText());
```

## Ограничения

- Квантильные линии могут пересекаться при экстраполяции: предсказанный 90-й
  перцентиль оказывается ниже 75-го. Это артефакт раздельной оценки; для
  прогноза нужны методы, обеспечивающие монотонность.
- Стандартные ошибки требуют бутстрапа, что умножает время расчёта на число
  повторов. Меньше 100 повторов дают неустойчивую оценку ошибки.
- Крайние квантили (0,01 и 0,99) оцениваются по немногим наблюдениям и крайне
  неточны. Для настоящих хвостов используйте
  [теорию экстремальных значений](extreme_value.md).
- Коэффициент квантильной регрессии описывает условный квантиль, а не
  положение конкретного человека в распределении. Индивид на 90-м перцентиле
  условного распределения не обязан быть на 90-м безусловном.
- Метод не решает проблему эндогенности. При коррелированном с ошибкой
  регрессоре смещены все квантили, а не только среднее.
