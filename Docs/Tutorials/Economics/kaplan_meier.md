# Кривая Каплана — Мейера

Непараметрическая оценка доли доживших с учётом цензурирования и лог-ранговый
критерий сравнения двух групп клиентов.

## Постановка задачи

Дано: по каждому клиенту длительность наблюдения и признак того, чем оно
закончилось — уходом или тем, что клиент всё ещё активен на момент выгрузки.

Требуется: кривая доживания $S(t)$ с доверительным коридором, медианное время
жизни и ответ на вопрос, различаются ли кривые двух групп значимо.

Где встречается: сравнение тарифов и каналов по качеству клиентов, оценка
эффекта продуктового изменения, обоснование срока жизни в модели LTV.

## Теория

Главная сложность — цензурирование. Клиент, пришедший месяц назад и пока
активный, не является ни ушедшим, ни дожившим до года: он даёт информацию
только о первом месяце жизни. Выбросить таких клиентов — сместить оценку в
сторону быстро уходящих, посчитать их выжившими — в обратную.

Оценка Каплана — Мейера решает это, перемножая условные вероятности пережить
каждый момент события:

$$
\hat S(t) \;=\; \prod_{t_i \le t} \left( 1 - \frac{d_i}{n_i} \right),
$$

где $d_i$ — число ушедших в момент $t_i$, $n_i$ — число под риском
непосредственно перед ним. Цензурированный клиент не создаёт ступеньку, но
уменьшает $n_i$ для последующих моментов.

Дисперсия по формуле Гринвуда:

$$
\widehat{\mathrm{Var}}\bigl(\hat S(t)\bigr) \;=\; \hat S(t)^2 \sum_{t_i \le t} \frac{d_i}{n_i (n_i - d_i)}.
$$

Доверительный интервал строится в лог-логарифмическом преобразовании — так он
гарантированно остаётся внутри отрезка $[0; 1]$, в отличие от наивного
«оценка плюс-минус два стандартных отклонения».

Лог-ранговый критерий сравнивает наблюдённое число уходов в первой группе с
ожидаемым при гипотезе одинаковых кривых:

$$
\chi^2 \;=\; \frac{\bigl(O_A - E_A\bigr)^2}{V}, \qquad
E_A = \sum_i d_i \frac{n_{A,i}}{n_i}, \qquad
V = \sum_i \frac{d_i\, n_{A,i}\, n_{B,i}\, (n_i - d_i)}{n_i^2 (n_i - 1)}.
$$

Отдельно полезно ограниченное среднее время жизни — площадь под кривой до
момента $\tau$. В отличие от медианы оно определено всегда, даже если кривая ни
разу не опустилась до половины.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n \cdot m)$ | $n$ — наблюдений, $m$ — различных моментов событий |
| Память | $O(m)$ | Точки кривой |

## API

| Метод | Описание |
|-------|----------|
| `KaplanMeier.Fit(data, confidenceLevel)` | Построение кривой и коридора |
| `SurvivalCurve`, `Lower`, `Upper` | Оценка и границы интервала в моменты событий |
| `SurvivalAt(time)` | Значение ступенчатой функции в произвольный момент |
| `MedianSurvivalTime` | Медианное время жизни; `NaN`, если кривая не дошла до 0,5 |
| `RestrictedMeanSurvival(tau)` | Ограниченное среднее время жизни |
| `KaplanMeier.LogRankTest(data, groupA, groupB)` | Статистика и p-значение сравнения групп |

Исходник: `src/AI.Economics/Survival/KaplanMeier.cs`.

## Код

```csharp
using AI.Economics.Survival;

var random = new Random(5);
var data = new List<SurvivalRecord>();

for (int group = 0; group < 2; group++)
{
    double rate = group == 0 ? 0.05 : 0.09;

    for (int i = 0; i < 150; i++)
    {
        double lifetime = -Math.Log(1.0 - random.NextDouble()) / rate;
        data.Add(new SurvivalRecord
        {
            Time = Math.Min(lifetime, 24),
            Event = lifetime <= 24,
            Group = group,
        });
    }
}

var km = new KaplanMeier();
km.Fit(data);

Console.WriteLine($"Медиана: {km.MedianSurvivalTime:F1} мес.");
Console.WriteLine($"S(12) = {km.SurvivalAt(12):P1}");
Console.WriteLine($"RMST за 24 мес.: {km.RestrictedMeanSurvival(24):F1} мес.");

(double chi, double pValue) = KaplanMeier.LogRankTest(data);
Console.WriteLine($"Лог-ранг: chi2={chi:F2}, p={pValue:F4}");
```

## Ограничения

- Кривая не экстраполируется за горизонт наблюдений: правее последнего события
  она просто продолжается горизонтально. Для прогноза нужна параметрическая
  подгонка — см. [подгонку кривой удержания](retention_fit.md).
- Метод предполагает неинформативное цензурирование: причина, по которой
  наблюдение оборвалось, не должна быть связана с риском ухода.
- Лог-ранговый критерий чувствителен к пропорциональности рисков; при
  пересекающихся кривых он теряет мощность и может не заметить различий.
- Правый конец кривой опирается на малое число клиентов под риском и потому
  нестабилен — смотрите на ширину коридора, а не на саму оценку.
