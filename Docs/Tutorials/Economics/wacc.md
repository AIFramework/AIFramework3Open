# Стоимость капитала: CAPM, Хамада и WACC

Ставка дисконтирования для оценки бизнеса: стоимость собственного капитала по
модели CAPM с премиями за страну и размер, рычаговая бета по Хамаде и
средневзвешенная стоимость капитала.

## Постановка задачи

Дано: безрисковая ставка, премия за рыночный риск, отраслевая бета без учёта
долга, структура капитала компании, стоимость долга и ставка налога.

Требуется: ставка, по которой дисконтируются свободные денежные потоки, —
и понимание, из чего она сложилась.

Где встречается: любая оценка бизнеса методом DCF, обоснование барьерной
ставки для инвестиционного комитета, расчёт экономической добавленной
стоимости, спор с аудитором о справедливой стоимости актива.

## Теория

**Стоимость собственного капитала** строится наращиванием премий:

$$
K_e \;=\; R_f \;+\; \beta_L\,\mathrm{ERP} \;+\; \mathrm{CRP} \;+\; \mathrm{SP} \;+\; \mathrm{Spec},
$$

где $R_f$ — безрисковая ставка, $\mathrm{ERP}$ — премия за рыночный риск,
$\mathrm{CRP}$ — страновая премия, $\mathrm{SP}$ — премия за размер,
$\mathrm{Spec}$ — специфическая надбавка.

**Рычаговая бета** получается из отраслевой безрычаговой по формуле Хамады.
В классическом виде долг считается безрисковым, но у реальной компании
$K_d > R_f$, и часть систематического риска несут кредиторы. Поэтому
используется расширенная форма с бетой долга:

$$
\beta_D = \frac{K_d - R_f}{\mathrm{ERP}},
\qquad
\beta_L \;=\; \beta_U + (\beta_U - \beta_D)\,(1 - t)\,\frac{D}{E}.
$$

Без слагаемого $\beta_D$ модель завышает рост стоимости капитала с ростом
долга: она приписывает акционерам риск, который на самом деле уже переложен
на кредиторов.

**Средневзвешенная стоимость** складывается по рыночным весам, причём долг
входит после налога — проценты уменьшают налогооблагаемую базу:

$$
\mathrm{WACC} \;=\; \frac{E}{D+E}\,K_e \;+\; \frac{D}{D+E}\,K_d\,(1 - t).
$$

**Обратная задача** — снять рычаг с наблюдаемой беты публичного аналога,
чтобы применить её к своей структуре капитала:

$$
\beta_U \;=\; \frac{\beta_L + \beta_D\,(1-t)\,D/E}{1 + (1-t)\,D/E}.
$$

**Кривая WACC.** В чистой теории Модильяни — Миллера налоговый щит делает
WACC монотонно убывающей по доле долга, и оптимума внутри отрезка нет. Он
появляется только тогда, когда в модель явно вносятся издержки финансовой
неустойчивости — рост требуемой доходности кредиторов и безвозвратные потери,
растущие быстрее линейного по долговой нагрузке.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(1)$ | одна точка; $O(S)$ на кривую из $S$ шагов |
| Память | $O(S)$ | хранится только кривая |

## API

| Метод | Описание |
|-------|----------|
| `CostOfCapital.Compute(input)` | Бета, стоимость капитала и её разложение |
| `CostOfCapital.Unlever(beta, debtToEquity, tax, debtBeta)` | Снятие рычага с наблюдаемой беты |
| `CostOfCapital.WaccCurve(input, steps, spreadSlope, distressSlope)` | Кривая WACC по доле долга |
| `CostOfCapitalResult.EquityBuildUp` | Разложение стоимости капитала по премиям |
| `CostOfCapitalResult.TaxShieldBenefit` | Вклад налогового щита в снижение ставки |

Исходники: `src/AI.Economics/Corporate/CostOfCapital.cs`.

## Код

```csharp
using AI.Economics.Corporate;

var company = new CostOfCapitalInput
{
    Name = "Производственная компания",
    RiskFreeRate = 0.09,
    EquityRiskPremium = 0.07,
    UnleveredBeta = 0.85,
    CountryRiskPremium = 0.02,
    SizePremium = 0.015,
    EquityValue = 6_000_000_000,
    DebtValue = 3_000_000_000,
    CostOfDebt = 0.13,
    TaxRate = 0.2,
};

CostOfCapitalResult capital = CostOfCapital.Compute(company);

Console.WriteLine($"Рычаговая бета {capital.LeveredBeta:F3}");
Console.WriteLine($"Стоимость капитала {capital.CostOfEquity:P2}");
Console.WriteLine($"Долг после налога {capital.AfterTaxCostOfDebt:P2}");
Console.WriteLine($"WACC {capital.Wacc:P2}");

foreach ((string component, double value) in capital.EquityBuildUp)
    Console.WriteLine($"  {component}: {value:P2}");
```

Отраслевая бета обычно берётся из наблюдаемых бет публичных аналогов, с
которых предварительно снимается их собственный рычаг:

```csharp
double peerUnlevered = CostOfCapital.Unlever(
    leveredBeta: 1.25, debtToEquity: 0.8, taxRate: 0.2, debtBeta: 0.4);

Console.WriteLine($"Безрычаговая бета аналога {peerUnlevered:F3}");
```

Кривая WACC отвечает на вопрос «сколько долга оптимально» — но только если в
неё заложены издержки неустойчивости:

```csharp
IReadOnlyList<(double DebtShare, double Wacc)> curve =
    CostOfCapital.WaccCurve(company, steps: 17, creditSpreadSlope: 0.12, distressSlope: 0.25);

(double bestShare, double bestWacc) = curve.MinBy(point => point.Wacc);
Console.WriteLine($"Минимум WACC {bestWacc:P2} при доле долга {bestShare:P0}");

Console.WriteLine(capital.Interpret().ToLlmText());
```

## Ограничения

- Бета оценивается с большой ошибкой. Отраслевая медиана по группе аналогов
  устойчивее регрессии по собственной акции, особенно на коротких историях и
  неликвидных бумагах.
- Формула Хамады выведена для постоянной долговой нагрузки. Если компания
  планирует гасить долг по графику, корректнее модель скорректированной
  приведённой стоимости, где щит дисконтируется отдельно.
- Веса $D$ и $E$ должны быть рыночными, а не балансовыми. Подстановка
  балансового капитала систематически завышает долю долга у прибыльных
  компаний.
- Оптимум на кривой WACC полностью определяется предположением о темпе роста
  издержек неустойчивости. Это параметр суждения, а не оценки: относитесь к
  оптимуму как к диапазону, а не к числу.
- Страновая премия учитывается один раз — либо в ставке, либо в потоках.
  Двойной учёт занижает стоимость бизнеса на десятки процентов.
