# Value at Risk и Expected Shortfall

Три способа посчитать потери, которые не будут превышены с заданной
вероятностью: исторический, параметрический и по методу Монте-Карло, — плюс
условные потери в хвосте и поправка Корниша — Фишера на асимметрию.

## Постановка задачи

Дано: ряд доходностей портфеля, его стоимость, уровень доверия и горизонт
удержания.

Требуется: величина потерь, которая не будет превышена с заданной
вероятностью (VaR), и средние потери в тех случаях, когда порог всё-таки
пробит (Expected Shortfall).

Где встречается: лимиты на торговые книги, отчётность перед регулятором,
расчёт достаточности капитала, риск-аппетит инвестиционного комитета, оценка
маржинальных требований.

## Теория

**Определение.** VaR уровня $\alpha$ — квантиль распределения убытков:

$$
\mathrm{VaR}_\alpha \;=\; -\,q_{1-\alpha}(R),
\qquad
\mathrm{ES}_\alpha \;=\; -\,\mathbb E\!\left[R \mid R \le q_{1-\alpha}(R)\right].
$$

Expected Shortfall отвечает на вопрос, который VaR оставляет без ответа:
«а если порог всё-таки пробит, сколько мы потеряем». Он же обладает
свойством субаддитивности — риск объединённого портфеля не превышает суммы
рисков частей, — которого у VaR нет. Именно поэтому Базель III перешёл с VaR
на ES.

**Исторический метод** берёт эмпирический квантиль ряда. Он не делает
предположений о распределении и автоматически воспроизводит толстые хвосты,
но целиком зависит от того, попал ли кризис в окно наблюдения.

**Параметрический метод** предполагает нормальность:

$$
\mathrm{VaR}_\alpha \;=\; -\left(\mu + \sigma\,z_{1-\alpha}\right),
\qquad
\mathrm{ES}_\alpha \;=\; -\mu + \sigma\,\frac{\varphi(z_{1-\alpha})}{1-\alpha}.
$$

Он устойчив на коротких выборках, но систематически занижает риск: реальные
доходности имеют эксцесс 5–10 против 3 у нормального распределения.

**Поправка Корниша — Фишера** сохраняет простоту параметрического подхода, но
корректирует квантиль на асимметрию $S$ и избыточный эксцесс $K$:

$$
z^{*} = z + \frac{z^2-1}{6}S + \frac{z^3-3z}{24}K - \frac{2z^3-5z}{36}S^2 .
$$

**Монте-Карло** моделирует будущие доходности: волатильность прогнозируется
GARCH-моделью, а стандартизованные остатки берутся из истории. Так
воспроизводится и кластеризация волатильности, и форма хвоста.

**Масштабирование на горизонт** делается по корню из времени:
$\mathrm{VaR}(h) = \sqrt h\,\mathrm{VaR}(1)$. Правило верно только для
независимых доходностей; при автокорреляции оно занижает риск.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n\log n)$ | сортировка для эмпирического квантиля |
| Память | $O(n)$ | ряд доходностей |

## API

| Метод | Описание |
|-------|----------|
| `ValueAtRisk.Compute(returns, value, confidence, horizon, method, portfolio)` | Все методы и сравнение |
| `ValueAtRisk.HistoricalVar` / `HistoricalShortfall` | Эмпирические оценки |
| `ValueAtRisk.ParametricVar` / `ParametricShortfall` | Нормальное приближение |
| `ValueAtRisk.CornishFisherVar(mean, sigma, skew, kurtosis, confidence)` | Поправка на форму |
| `VarResultSet.Comparison` | Все методы рядом |
| `VarResultSet.TailRatio` | Отношение ES к VaR — толщина хвоста |

Исходники: `src/AI.Economics/Risk/ValueAtRisk.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Risk;
using AI.Statistics;

Random rng = RandomEngine.Create(3);
var returns = new Vector(1250);

for (int i = 0; i < returns.Count; i++)
{
    // Смесь двух режимов даёт реалистичный толстый хвост
    bool stress = rng.NextDouble() < 0.05;
    returns[i] = RandomEngine.NextGaussian(rng, stress ? -0.004 : 0.0006, stress ? 0.045 : 0.011);
}

VarResultSet risk = ValueAtRisk.Compute(
    returns, portfolioValue: 500_000_000, confidence: 0.99, horizon: 1,
    method: VarMethod.Historical, portfolio: "Торговая книга");

Console.WriteLine($"VaR {risk.ValueAtRisk:P2} = {risk.ValueAtRiskAmount:N0}");
Console.WriteLine($"ES {risk.ExpectedShortfall:P2} = {risk.ExpectedShortfallAmount:N0}");
Console.WriteLine($"Отношение ES к VaR {risk.TailRatio:F2}");
Console.WriteLine($"Асимметрия {risk.Skewness:F2}, эксцесс {risk.Kurtosis:F2}");
```

Расхождение методов — сам по себе диагностический сигнал:

```csharp
foreach ((VarMethod method, double var, double shortfall) in risk.Comparison)
    Console.WriteLine($"{method}: VaR {var:P2}, ES {shortfall:P2}");
```

Поправка на форму распределения применяется, когда выборка коротка для
исторического метода, но нормальность явно нарушена:

```csharp
double mean = returns.Average();
double sigma = Math.Sqrt(returns.Sum(r => (r - mean) * (r - mean)) / (returns.Count - 1));

double plain = ValueAtRisk.ParametricVar(mean, sigma, 0.99);
double adjusted = ValueAtRisk.CornishFisherVar(mean, sigma, risk.Skewness, risk.Kurtosis, 0.99);

Console.WriteLine($"Нормальный VaR {plain:P2}, с поправкой {adjusted:P2}");
Console.WriteLine(risk.Interpret().ToLlmText());
```

## Ограничения

- Исторический метод не может показать потерю, которой не было в выборке.
  После долгого спокойного периода он даёт опасно низкие значения — ровно
  перед тем, как они понадобятся.
- Параметрический метод занижает риск тем сильнее, чем выше уровень доверия.
  На 99,9% расхождение с эмпирическим квантилем достигает двух раз.
- Поправка Корниша — Фишера немонотонна при сильной асимметрии: при
  $|S| > 1{,}5$ она может дать квантиль, убывающий по уровню доверия.
  Реализация ограничивает поправку, но проверяйте разумность результата.
- Масштабирование корнем из времени неприменимо к портфелям с опционами и к
  автокоррелированным стратегиям. Для горизонта свыше десяти дней считайте
  напрямую.
- VaR — не максимальный убыток. Он ничего не говорит о том, что происходит за
  порогом; для этого существует ES, а для проверки самой модели —
  [бэктестирование](var_backtest.md).
