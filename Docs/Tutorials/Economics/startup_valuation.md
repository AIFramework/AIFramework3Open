# Оценка стартапа: VC, Беркус, Scorecard, First Chicago

Четыре классических метода оценки компании на ранней стадии. Считать стоит
всеми сразу: расхождение результатов показывает, какое допущение управляет
ценой.

## Постановка задачи

Дано: прогноз выручки на горизонте выхода, требуемая доходность инвестора,
средняя оценка по сопоставимым сделкам и качественная оценка компании по
факторам.

Требуется: оценка до денег каждым методом и понимание, чем вызвано их
расхождение.

Где встречается: переговоры о раунде, внутренняя оценка инвестиционного
комитета, обоснование цены в term sheet.

## Теория

**Метод венчурного капитала** идёт от стоимости выхода назад. Инвестор
требует, чтобы вложение выросло в $(1+IRR)^n$ раз, значит его доля на момент
выхода:

$$
f_{exit} \;=\; \frac{I \,(1+IRR)^n}{V_{exit}}.
$$

Будущие раунды разводнят инвестора, поэтому сегодня доля должна быть больше:

$$
f_{now} \;=\; \frac{f_{exit}}{1 - \delta},
\qquad
V_{post} = \frac{I}{f_{now}},
\qquad
V_{pre} = V_{post} - I.
$$

Метод целиком определяется двумя допущениями — требуемой доходностью и
будущим разводнением. Это его сила: допущения хотя бы явные.

**Метод Беркуса** оценивает пять качественных факторов, каждый с денежным
потолком: идея, прототип, команда, стратегические связи, продажи. Сумма и
есть оценка. Метод сознательно не претендует на точность — он ограничивает
оценку сверху для компании без выручки.

**Scorecard** берёт среднюю оценку по рынку и корректирует её взвешенной
суммой отклонений:

$$
V \;=\; \bar V_{market} \sum_i w_i \, r_i,
$$

где $r_i = 1$ означает «как у типичной компании». Компания ровно средняя
получает ровно рыночную оценку.

**First Chicago** считает оценку как математическое ожидание по сценариям:

$$
V \;=\; \sum_i p_i V_i.
$$

Полезен не столько результат, сколько доля лучшего сценария в нём: если 80 %
ожидаемой стоимости даёт исход с вероятностью 10 %, то спорить надо об этой
вероятности, а не об оценке.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(k)$ | $k$ — факторов или сценариев |
| Память | $O(k)$ | Разбивка по вкладам |

## API

| Метод | Описание |
|-------|----------|
| `StartupValuation.VcMethod(input)` | Оценка до и после денег, требуемая доля |
| `StartupValuation.Berkus(factors)` | Сумма вкладов пяти факторов |
| `StartupValuation.BerkusDefaults(max, scores)` | Канонический набор факторов |
| `StartupValuation.Scorecard(marketAverage, factors)` | Рынок с поправкой на качество |
| `StartupValuation.ScorecardDefaults(ratios)` | Веса Билла Пейна |
| `StartupValuation.FirstChicago(scenarios)` | Ожидаемая оценка и вклад сценариев |
| `ScenarioValuationResult.BestCaseShare` | Доля стоимости, создаваемая одним сценарием |

Исходник: `src/AI.Economics/Valuation/StartupValuation.cs`.

## Код

```csharp
using AI.Economics.Valuation;

VcMethodResult vc = StartupValuation.VcMethod(new VcMethodInput
{
    Investment = 50_000_000,
    ExitRevenue = 1_500_000_000,
    ExitMultiple = 4,
    YearsToExit = 5,
    TargetIrr = 0.5,
    ExpectedFutureDilution = 0.4,
});

Console.WriteLine($"VC: до денег {vc.PreMoneyValuation:N0}, доля сегодня {vc.OwnershipNow:P1}");

double berkus = StartupValuation.Berkus(
    StartupValuation.BerkusDefaults(24_000_000, 0.9, 0.7, 0.65, 0.5, 0.3));

double scorecard = StartupValuation.Scorecard(
    120_000_000, StartupValuation.ScorecardDefaults(1.3, 1.2, 1.0, 0.9, 0.8, 1.0, 1.0));

ScenarioValuationResult chicago = StartupValuation.FirstChicago(
[
    new ValuationScenario("Прорыв", 0.10, 800_000_000),
    new ValuationScenario("База", 0.35, 200_000_000),
    new ValuationScenario("Провал", 0.55, 0),
]);

Console.WriteLine($"Беркус:        {berkus:N0}");
Console.WriteLine($"Scorecard:     {scorecard:N0}");
Console.WriteLine($"First Chicago: {chicago.ExpectedValuation:N0}, " +
                  $"на лучший сценарий приходится {chicago.BestCaseShare:P0}");
```

## Ограничения

- Ни один метод не даёт «правильной» цифры: у компании без выручки её не
  существует. Методы задают рамку переговоров.
- Метод венчурного капитала крайне чувствителен к требуемой доходности:
  изменение с 40 % до 60 % годовых при горизонте пять лет меняет оценку
  примерно втрое.
- Беркус и Scorecard опираются на субъективные баллы. Их ценность в том, что
  спор смещается с абстрактной цены на конкретный фактор.
- First Chicago показывает ожидание, а не типичный исход. При вероятности
  провала 55 % медианный результат равен нулю, и ожидаемая оценка о нём молчит.
- Все методы игнорируют структуру сделки: те же деньги при разных
  преференциях стоят по-разному — см. [каскад выплат](exit_waterfall.md).
