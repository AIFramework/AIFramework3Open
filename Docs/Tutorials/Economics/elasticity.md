# Эластичность спроса по цене

Оценка того, на сколько процентов изменится спрос при изменении цены на один
процент — и почему наивная регрессия почти всегда даёт неверный ответ.

## Постановка задачи

Дано: история наблюдений «цена — объём», по возможности с контрольными
переменными и инструментом для цены.

Требуется: причинная оценка эластичности, пригодная для решения об изменении
цены, а не только для описания прошлого.

Где встречается: пересмотр прайса, оценка эффекта промо, расчёт оптимальной
наценки, защита ценового решения перед коммерческим директором.

## Теория

Модель постоянной эластичности линейна в логарифмах:

$$
\ln q_t = \alpha + e \ln p_t + \gamma^{\mathsf T} x_t + u_t.
$$

Коэффициент $e$ и есть эластичность. Проблема в том, что $p_t$
коррелирует с $u_t$: цену поднимают тогда, когда спрос и так высок —
перед праздниками, при дефиците, на растущем рынке. Оценка обычным МНК
смещена на величину

$$
\mathrm{plim}\ \hat e_{OLS} - e = \frac{\mathrm{Cov}(\ln p, u)}{\mathrm{Var}(\ln p)} > 0,
$$

то есть систематически завышена (смещена к нулю для отрицательной
эластичности), а в тяжёлых случаях положительна — «чем дороже, тем больше
покупают».

Два способа справиться.

**Панельная модель.** Двустороннее внутригрупповое преобразование убирает всё
постоянное внутри товара и внутри периода. Помогает против ненаблюдаемого
качества товара и общих шоков спроса, но не против факторов, меняющихся
вместе с ценой.

**Инструментальные переменные.** Нужна величина $z$, влияющая на цену и не
влияющая на спрос напрямую: себестоимость, курс валюты, логистическая ставка.
Первая ступень объясняет цену инструментом, вторая подставляет прогноз:

$$
\ln p_t = \pi_0 + \pi_1 \ln z_t + \dots, \qquad
\ln q_t = \alpha + e\, \widehat{\ln p_t} + \dots
$$

Сила инструмента проверяется F-статистикой первой ступени. Значение ниже 10
означает слабый инструмент: оценка IV в этом случае смещена сильнее наивной.

Из эластичности сразу следуют два практических числа. Оптимальная наценка по
правилу Лернера $p^{*} = c\,e/(1+e)$ и валовая маржа $1/|e|$, при которой
снижение цены на процент окупается ростом объёма.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n k^2 + k^3)$ | $n$ — наблюдений, $k$ — регрессоров |
| Память | $O(n k)$ | Матрица плана |

## API

| Метод | Описание |
|-------|----------|
| `DemandElasticity.Estimate(observations, estimator)` | Оценка выбранным способом |
| `DemandElasticity.EstimateAll(observations)` | Все три оценки для сравнения |
| `DemandElasticity.DemandAt(basePrice, baseQuantity, e, newPrice)` | Прогноз спроса при новой цене |
| `ElasticityResult.NaiveElasticity` | Что дал бы обычный МНК — всегда рядом для сравнения |
| `ElasticityResult.FirstStageF` | Сила инструмента; порог надёжности — 10 |
| `ElasticityResult.OptimalMarkup` | Наценка по правилу Лернера |
| `ElasticityResult.Interpret()` | Разбор результата словами с предупреждениями |

Исходники: `src/AI.Economics/Pricing/`.

## Код

```csharp
using AI.Economics.Pricing;

var random = new Random(11);
var observations = new List<PriceObservation>();

for (int i = 0; i < 400; i++)
{
    double cost = Math.Exp(-0.2 + (random.NextDouble() * 0.7));
    double demandShock = random.NextDouble() - 0.5;

    // Цена реагирует и на издержки, и на ненаблюдаемый спрос
    double price = Math.Exp(2.0 + (0.7 * Math.Log(cost)) + (0.8 * demandShock));
    double quantity = Math.Exp(6.0 - (1.8 * Math.Log(price)) + demandShock);

    observations.Add(new PriceObservation
    {
        Price = price,
        Quantity = quantity,
        Instrument = cost,
        Unit = i % 5,
        Period = i / 5,
    });
}

foreach (ElasticityResult estimate in DemandElasticity.EstimateAll(observations))
{
    Console.WriteLine($"{estimate.Estimator,-24} e = {estimate.Elasticity:F3} " +
                      $"[{estimate.ConfidenceLow:F2}; {estimate.ConfidenceHigh:F2}]");
}

ElasticityResult iv = DemandElasticity.Estimate(
    observations, ElasticityEstimator.InstrumentalVariables);

Console.WriteLine($"F первой ступени: {iv.FirstStageF:F1}");
Console.WriteLine($"Оптимальная наценка: {iv.OptimalMarkup:P0}");
Console.WriteLine(iv.Interpret().ToLlmText());
```

## Ограничения

- Модель постоянной эластичности верна вблизи наблюдавшихся цен. Изменения
  свыше 20–30 % экстраполируют её за пределы данных.
- Инструмент должен влиять на цену и не влиять на спрос напрямую. Это
  допущение данными не проверяется — только F-статистику первой ступени
  можно посчитать, обоснованность самого инструмента остаётся на аналитике.
- Панельная модель требует, чтобы цена менялась внутри групп. Если цена
  постоянна для товара, внутригрупповое преобразование обнуляет регрессор.
- Промоакции обычно нарушают модель: они меняют не только цену, но и
  выкладку, и коммуникацию. Их стоит включать отдельным контролем.
