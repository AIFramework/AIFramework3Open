# Коэффициентный анализ отчётности

Полный набор коэффициентов по пяти группам — ликвидность, рентабельность,
оборачиваемость, долговая нагрузка и денежный поток — с ориентирами и
направлением улучшения.

## Постановка задачи

Дано: баланс, отчёт о прибылях и убытках и отчёт о движении денежных средств
за период; при наличии — те же формы за предыдущий период.

Требуется: набор коэффициентов, каждый со своим ориентиром и с указанием, в
какую сторону он улучшается, чтобы вывод читался без внешнего справочника.

Где встречается: кредитный анализ, due diligence при сделке, ковенантный
мониторинг, управленческая отчётность, подготовка к переговорам с банком.

## Теория

Коэффициенты не самоценны — каждый отвечает на один вопрос.

**Ликвидность** — хватит ли оборотных активов на краткосрочные обязательства.
Текущая ликвидность, быстрая (без запасов) и абсолютная (только деньги)
различаются тем, насколько быстро актив превращается в платёж.

**Рентабельность** — сколько прибыли приносит рубль выручки, активов и
собственного капитала. Разложение соотношения между ними даёт
[модель Дюпона](dupont.md).

**Оборачиваемость** — как быстро деньги проходят цикл. Здесь принципиально,
что срок сбора дебиторской задолженности считается от выручки, а сроки запасов
и кредиторской задолженности — от себестоимости:

$$
\mathrm{DSO} = \frac{\mathrm{AR}}{\mathrm{Revenue}}\cdot 365,
\quad
\mathrm{DIO} = \frac{\mathrm{Inventory}}{\mathrm{COGS}}\cdot 365,
\quad
\mathrm{DPO} = \frac{\mathrm{AP}}{\mathrm{COGS}}\cdot 365 .
$$

**Долговая нагрузка** — способность обслуживать долг. Покрытие процентов
операционной прибылью — самый ранний по значимости признак приближающихся
проблем с ликвидностью, раньше любого коэффициента структуры баланса.

**Денежный поток** — подтверждена ли прибыль деньгами. Отношение операционного
потока к чистой прибыли, устойчиво меньшее единицы, указывает на проблемы с
[качеством прибыли](earnings_quality.md).

Если передана отчётность предыдущего периода, показатели оборачиваемости
считаются по средним остаткам баланса, а не по остаткам на конец периода.
Разница существенна для растущих компаний: расчёт по конечным остаткам
систематически занижает оборачиваемость.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(1)$ | фиксированный набор формул |
| Память | $O(1)$ | около тридцати коэффициентов |

## API

| Метод | Описание |
|-------|----------|
| `FinancialRatios.Compute(current, previous)` | Все коэффициенты с ориентирами |
| `RatioReport.Group(group)` | Коэффициенты одной группы |
| `RatioReport.BenchmarkPassRate` | Доля показателей, укладывающихся в ориентиры |
| `FinancialRatio.MeetsBenchmark` / `Direction` | Соответствие ориентиру и направление улучшения |
| `FinancialStatement.Validate()` | Проверка внутренней согласованности отчётности |

Исходники: `src/AI.Economics/Statements/`.

## Код

```csharp
using AI.Economics.Statements;

var statement = new FinancialStatement
{
    Company = "Компания", Period = "2024",
    TotalAssets = 1_000_000_000, CurrentAssets = 450_000_000,
    Cash = 80_000_000, ShortTermInvestments = 20_000_000,
    AccountsReceivable = 180_000_000, Inventory = 150_000_000,
    PropertyPlantEquipment = 500_000_000, IntangibleAssets = 50_000_000,
    TotalLiabilities = 480_000_000, CurrentLiabilities = 240_000_000,
    AccountsPayable = 150_000_000, ShortTermDebt = 90_000_000,
    LongTermDebt = 240_000_000, RetainedEarnings = 312_000_000,
    Revenue = 1_000_000_000, CostOfGoodsSold = 600_000_000,
    OperatingExpenses = 180_000_000, Depreciation = 50_000_000,
    InterestExpense = 42_900_000, IncomeTax = 25_400_000, NetIncome = 101_700_000,
    OperatingCashFlow = 140_000_000, CapitalExpenditures = 60_000_000,
    DividendsPaid = 20_000_000, MarketCapitalization = 1_300_000_000,
};

Console.WriteLine($"Собственный капитал: {statement.Equity:N0}");
Console.WriteLine($"Прибыль до амортизации: {statement.Ebitda:N0}");
Console.WriteLine($"Нарушений согласованности: {statement.Validate().Length}");

RatioReport ratios = FinancialRatios.Compute(statement);

Console.WriteLine($"Ориентирам соответствует {ratios.BenchmarkPassRate:P0} показателей");
Console.WriteLine($"ROE {ratios.ReturnOnEquity:P2}, ROA {ratios.ReturnOnAssets:P2}");
Console.WriteLine($"Финансовый цикл {ratios.CashConversionCycle:F0} дн.");
```

Коэффициенты удобно смотреть по группам — так их и обсуждают с финансовым
директором:

```csharp
foreach (string group in new[] { "Ликвидность", "Долговая нагрузка", "Денежный поток" })
{
    Console.WriteLine($"--- {group} ---");

    foreach (FinancialRatio ratio in ratios.Group(group))
    {
        string verdict = ratio.MeetsBenchmark ? "в норме" : "хуже ориентира";
        Console.WriteLine($"{ratio.Name}: {ratio.Value:F2} (ориентир {ratio.Benchmark:F2}) — {verdict}");
    }
}
```

Сравнение с предыдущим периодом включает расчёт по средним остаткам:

```csharp
FinancialStatement previousYear = statement with
{
    Period = "2023",
    Revenue = 870_000_000,
    TotalAssets = 900_000_000,
    AccountsReceivable = 150_000_000,
};

RatioReport withHistory = FinancialRatios.Compute(statement, previousYear);

Console.WriteLine($"Оборачиваемость активов: {ratios.AssetTurnover:F2} → {withHistory.AssetTurnover:F2}");
Console.WriteLine(withHistory.Interpret().ToLlmText());
```

## Ограничения

- Ориентиры в отчёте усреднённые. Коэффициенты сопоставимы только внутри
  отрасли и только при одинаковой учётной политике: у ритейла и у
  машиностроения нормальные значения оборачиваемости различаются в разы.
- Расчёт по годовым данным сглаживает сезонность. Для сезонного бизнеса
  остатки на отчётную дату могут заметно расходиться со средними за период.
- Коэффициенты на одну дату говорят меньше, чем их динамика. Направление
  изменения информативнее уровня.
- Отчётность может быть искажена. Коэффициентный анализ этого не обнаруживает —
  для этого есть [M-score Бениша](beneish.md) и
  [закон Бенфорда](benford.md).
- Прибыль и денежный поток нужно смотреть вместе: расхождение между ними
  устойчиво предсказывает пересмотр отчётности, см.
  [качество прибыли](earnings_quality.md).
