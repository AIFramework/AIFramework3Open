# Модели банкротства: Альтман, Ольсон, Спрингейт, Таффлер, Пиотроски

Пять классических балльных моделей прогнозирования банкротства и девять
критериев фундаментального качества — вместе с честным разбором их пределов.

## Постановка задачи

Дано: отчётность компании за период, при наличии — за предыдущий.

Требуется: оценка риска банкротства по нескольким независимым моделям,
согласованный вывод и понимание того, какая часть отчётности эту оценку
формирует.

Где встречается: кредитный анализ, отбор контрагентов, скрининг портфеля
акций, экспресс-проверка перед сделкой.

## Теория

**Z-счёт Альтмана** для публичных производственных компаний:

$$
Z = 1{,}2\,X_1 + 1{,}4\,X_2 + 3{,}3\,X_3 + 0{,}6\,X_4 + 0{,}999\,X_5,
$$

где $X_1$ — рабочий капитал к активам, $X_2$ — нераспределённая прибыль к
активам, $X_3$ — операционная прибыль к активам, $X_4$ — капитализация к
обязательствам, $X_5$ — оборачиваемость активов. Зоны: выше 2,99 —
устойчивость, ниже 1,81 — риск банкротства.

**Z''-счёт** убирает оборачиваемость и заменяет капитализацию балансовым
капиталом, поэтому применим к непубличным и непроизводственным компаниям.

**O-счёт Ольсона** — единственная здесь модель с явной вероятностной шкалой:
девять показателей складываются в пробит-индекс, вероятность банкротства равна
$1/(1+e^{-O})$. Модель учитывает масштаб активов, отрицательный капитал,
убыток два года подряд и динамику прибыли.

**Спрингейт** — четыре показателя и единственный порог 0,862, ниже которого
компания относится к банкротам.

**Таффлер** — британская модель, в которой есть бескредитный интервал: за
сколько компания продержится на ликвидных активах без новых поступлений.

**F-счёт Пиотроски** устроен иначе: это девять бинарных критериев улучшения —
четыре по прибыльности, три по структуре баланса и ликвидности, два по
операционной эффективности. Балл 8–9 означает, что фундаментальные показатели
улучшаются одновременно по всем направлениям, а такое совпадение редко бывает
случайным.

Модели построены на разных выборках и в разные эпохи, поэтому расходятся между
собой закономерно. Ценность даёт не отдельный балл, а согласие или расхождение
нескольких моделей и направление изменения балла во времени.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(1)$ | пять формул с фиксированным числом слагаемых |
| Память | $O(1)$ | около сорока слагаемых суммарно |

## API

| Метод | Описание |
|-------|----------|
| `DistressScores.Evaluate(current, previous, assetDeflator)` | Все пять моделей и балл Пиотроски |
| `DistressScores.Altman(s)` / `AltmanDoublePrime(s)` | Z и Z'' по отдельности |
| `DistressScores.Ohlson(current, previous, deflator)` | O-счёт с вероятностью банкротства |
| `DistressScores.Springate(s)` / `Taffler(s)` | Две другие балльные модели |
| `DistressScores.Piotroski(current, previous)` | Девять критериев с пояснениями |
| `DistressReport.Consensus` / `DistressVotes` | Согласованный вывод по большинству моделей |

Исходники: `src/AI.Economics/Statements/DistressScores.cs`.

## Код

```csharp
using AI.Economics.Statements;

var company = new FinancialStatement
{
    Company = "Компания", Period = "2024",
    TotalAssets = 1_000_000_000, CurrentAssets = 450_000_000,
    Cash = 80_000_000, AccountsReceivable = 180_000_000, Inventory = 150_000_000,
    PropertyPlantEquipment = 500_000_000, IntangibleAssets = 50_000_000,
    TotalLiabilities = 480_000_000, CurrentLiabilities = 240_000_000,
    AccountsPayable = 150_000_000, ShortTermDebt = 90_000_000, LongTermDebt = 240_000_000,
    RetainedEarnings = 312_000_000,
    Revenue = 1_000_000_000, CostOfGoodsSold = 600_000_000,
    OperatingExpenses = 180_000_000, Depreciation = 50_000_000,
    InterestExpense = 42_900_000, IncomeTax = 25_400_000, NetIncome = 101_700_000,
    OperatingCashFlow = 140_000_000, CapitalExpenditures = 60_000_000,
    MarketCapitalization = 1_300_000_000,
};

DistressReport distress = DistressScores.Evaluate(company);

foreach (DistressScore score in distress.Scores)
    Console.WriteLine($"{score.Model}: {score.Value:F3} — {score.Zone}");

Console.WriteLine($"Голосов за риск: {distress.DistressVotes} из {distress.Scores.Count}");
Console.WriteLine($"Согласованный вывод: {distress.Consensus}");
Console.WriteLine($"Балл Пиотроски: {distress.PiotroskiScore} из 9");
```

Слагаемые модели показывают, что именно тянет балл вниз:

```csharp
DistressScore altman = DistressScores.Altman(company);

foreach (ScoreComponent component in altman.Components)
{
    Console.WriteLine($"{component.Name}: {component.Value:F3} " +
                      $"x {component.Weight:F3} = {component.Contribution:F3}");
}
```

Модель Ольсона даёт вероятность, а Пиотроски — разбор по критериям:

```csharp
FinancialStatement priorYear = company with
{
    Period = "2023", Revenue = 870_000_000, NetIncome = 67_000_000,
    TotalAssets = 900_000_000, OperatingCashFlow = 110_000_000,
    CostOfGoodsSold = 530_000_000, LongTermDebt = 260_000_000,
};

DistressScore ohlson = DistressScores.Ohlson(company, priorYear);
Console.WriteLine($"O-счёт {ohlson.Value:F3}, вероятность {ohlson.ProbabilityOfDefault:P2}");

(int fScore, var criteria) = DistressScores.Piotroski(company, priorYear);
Console.WriteLine($"F-счёт: {fScore}");

foreach ((string criterion, bool passed, string comment) in criteria)
    Console.WriteLine($"  {(passed ? "+" : "-")} {criterion}: {comment}");

Console.WriteLine(DistressScores.Evaluate(company, priorYear).Interpret().ToLlmText());
```

## Ограничения

- Коэффициенты моделей оценивались на исторических выборках США и
  Великобритании 1960–1980-х годов и на других стандартах учёта. Абсолютные
  значения баллов для российской отчётности смещены; надёжнее сравнивать
  компании между собой и следить за динамикой.
- Доля ложных срабатываний у всех этих моделей заметно выше доли пропусков.
  Балл в зоне риска — повод для углублённой проверки, а не прогноз банкротства.
- Модель Альтмана требует рыночной капитализации. Для непубличных компаний она
  вырождается: вклад четвёртого слагаемого обнуляется, и нужно использовать Z''.
- Балл Пиотроски требует предыдущего периода. Без него шесть из девяти
  критериев сравнивают период сам с собой и выполняются автоматически.
- Все модели построены на достоверной отчётности, и ни одна не устойчива к её
  искажению. Для этого служат [M-score Бениша](beneish.md) и
  [закон Бенфорда](benford.md).
