# Матрица миграции рейтингов

Оценка вероятностей перехода между рейтинговыми классами, кумулятивная
вероятность дефолта на любом горизонте и стационарное распределение портфеля.

## Постановка задачи

Дано: наблюдённые переходы заёмщиков между рейтингами за период — пары
«рейтинг на начало, рейтинг на конец» с весом (число заёмщиков или сумма
экспозиции).

Требуется: матрица вероятностей перехода, кривая накопленной вероятности
дефолта для каждого класса и равновесная структура портфеля.

Где встречается: расчёт убытков за весь срок по МСФО 9, валидация рейтинговой
шкалы, стресс-тестирование, оценка портфеля облигаций.

## Теория

Матрица миграции $P$ задаёт вероятность того, что заёмщик класса $i$ окажется
через период в классе $j$. Частотная оценка:

$$
\hat p_{ij} \;=\; \frac{n_{ij}}{\sum_k n_{ik}} .
$$

Дефолт трактуется как поглощающее состояние: $p_{DD}=1$, из него нет выхода.
Тогда вероятность дефолта на горизонте $T$ читается прямо из столбца дефолта
матрицы, возведённой в степень:

$$
\mathrm{PD}_i(T) \;=\; \bigl(P^{T}\bigr)_{i,D} .
$$

Это стандартный способ получить кривую PD для расчёта убытков за весь срок,
когда прямых наблюдений на длинном горизонте недостаточно: пятилетняя
вероятность дефолта оценивается по годовым переходам.

Полезны три производные характеристики каждого класса: устойчивость
(диагональный элемент), вероятность повышения и понижения без дефолта.
Перевес понижений над повышениями по всей шкале — ранний индикатор ухудшения
портфеля, который виден задолго до роста просрочки.

Стационарное распределение (без поглощения) показывает, к какой структуре
сойдётся портфель, если наблюдённые интенсивности переходов сохранятся. Оно
считается степенным методом и полезно для проверки: если равновесная доля
низких классов заметно выше текущей, портфель ещё не «дозрел».

Ключевое ограничение — предпосылка марковости и однородности во времени.
На практике заметны эффекты инерции: недавно понижённые заёмщики понижаются
чаще, чем следует из матрицы. Кроме того, матрица, усреднённая по фазам цикла,
недооценивает дефолты в спад и переоценивает в рост, поэтому регуляторные
расчёты обычно требуют отдельных матриц по состояниям экономики.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(N + T k^3)$ | $N$ наблюдений, $T$ возведений матрицы $k\times k$ |
| Память | $O(k^2 + kT)$ | матрицы и кривые дефолтов |

## API

| Метод | Описание |
|-------|----------|
| `MigrationMatrix.Estimate(ratings, transitions, periods)` | Частотная оценка матрицы |
| `MigrationMatrix.MultiPeriod(result, periods)` | Матрица перехода за несколько периодов |
| `MigrationMatrix.CumulativeDefault(result, horizon)` | Кривые накопленной PD по классам |
| `MigrationMatrix.StationaryDistribution(result, iterations)` | Равновесная структура портфеля |
| `MigrationMatrixResult.Profiles` | Устойчивость, повышения, понижения, PD по классам |
| `MigrationMatrixResult.NetDowngradeDrift` | Перевес понижений над повышениями |

Исходники: `src/AI.Economics/Credit/MigrationMatrix.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Credit;

string[] ratings = ["AAA", "A", "BBB", "BB", "D"];

double[][] truth =
[
    [0.90, 0.08, 0.015, 0.004, 0.001],
    [0.05, 0.85, 0.080, 0.015, 0.005],
    [0.01, 0.07, 0.830, 0.080, 0.010],
    [0.00, 0.02, 0.100, 0.820, 0.060],
];

var observedTransitions = new List<RatingTransition>();
var migrationRng = new Random(11);

for (int i = 0; i < 20_000; i++)
{
    int from = i % 4;
    double draw = migrationRng.NextDouble();
    double cumulative = 0;
    int to = 4;

    for (int j = 0; j < 5; j++)
    {
        cumulative += truth[from][j];
        if (draw <= cumulative) { to = j; break; }
    }

    observedTransitions.Add(new RatingTransition(ratings[from], ratings[to]));
}

MigrationMatrixResult migration = MigrationMatrix.Estimate(ratings, observedTransitions);

Console.WriteLine($"Средняя устойчивость {migration.AverageStability:P1}");

foreach (RatingProfile profile in migration.Profiles)
    Console.WriteLine($"{profile.Rating}: устойчивость {profile.Stability:P1}, PD {profile.DefaultRate:P2}");
```

Кривая накопленной вероятности дефолта — прямой вход в расчёт убытков за весь
срок:

```csharp
IReadOnlyList<Vector> curves = MigrationMatrix.CumulativeDefault(migration, 10);

for (int rating = 0; rating < 4; rating++)
{
    Console.WriteLine($"{ratings[rating]}: PD(1) = {curves[rating][0]:P2}, " +
                      $"PD(5) = {curves[rating][4]:P2}, PD(10) = {curves[rating][9]:P2}");
}
```

Матрица за несколько периодов и равновесная структура портфеля:

```csharp
Matrix threeYear = MigrationMatrix.MultiPeriod(migration, 3);
Vector equilibrium = MigrationMatrix.StationaryDistribution(migration);

Console.WriteLine($"За три года из BBB в дефолт: {threeYear[2, 4]:P2}");

for (int i = 0; i < ratings.Length; i++)
    Console.WriteLine($"Равновесная доля {ratings[i]}: {equilibrium[i]:P1}");

Console.WriteLine(migration.Interpret().ToLlmText());
```

## Ограничения

- Предпосылка марковости нарушается на практике: история рейтинга влияет на
  вероятность следующего перехода. Для точности приходится расширять состояние
  признаком «недавно понижен».
- Матрица, усреднённая по нескольким годам, не описывает ни одну фазу цикла.
  Для стресс-тестирования нужны отдельные матрицы по состояниям экономики.
- Редкие переходы (например, из AAA в дефолт) оцениваются несколькими
  наблюдениями или не наблюдаются вовсе. Нулевая оценка в матрице означает
  «не видели», а не «невозможно», и её обычно сглаживают.
- Возведение в степень усиливает ошибку оценки: неточность в годовой матрице
  на десятилетнем горизонте может изменить PD в разы.
- Кумулятивные вероятности из матрицы стоит сверять с фактическими дефолтами
  винтажей — см. [винтажный анализ](vintage.md).
