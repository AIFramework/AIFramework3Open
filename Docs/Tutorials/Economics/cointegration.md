# Коинтеграция Йохансена и модель коррекции ошибок

Поиск долгосрочных равновесных связей между нестационарными рядами: тест
следа и максимального собственного числа, коинтеграционные векторы,
коэффициенты приспособления и период полувозврата к равновесию.

## Постановка задачи

Дано: несколько нестационарных рядов, каждый из которых по отдельности —
случайное блуждание: цены связанных товаров, спот и фьючерс, курс и паритет
покупательной способности, потребление и доход.

Требуется: выяснить, существует ли между ними устойчивое долгосрочное
соотношение, оценить его и измерить скорость возврата к нему после
отклонения.

Где встречается: парный трейдинг, проверка закона одной цены, оценка
равновесного курса, связь зарплат и производительности, ценовые
взаимоотношения на цепочке поставок.

## Теория

**Коинтеграция.** Ряды интегрированы порядка один, но существует их линейная
комбинация, стационарная сама по себе:

$$
z_t \;=\; \beta^{\top}y_t \sim I(0).
$$

Экономически это означает наличие равновесия: ряды могут блуждать сколь угодно
далеко, но не расходятся друг от друга — их удерживает механизм коррекции.

**Модель коррекции ошибок** — эквивалентная форма записи:

$$
\Delta y_t \;=\; \alpha\,\beta^{\top}y_{t-1} + \sum_{i=1}^{p-1}\Gamma_i\Delta y_{t-i} + \varepsilon_t,
$$

где $\Pi = \alpha\beta^{\top}$. Матрица $\beta$ задаёт равновесные
соотношения, $\alpha$ — скорость приспособления. Ранг $\Pi$ равен числу
коинтеграционных связей: ноль означает отсутствие связи (тогда правильна
модель в разностях), полный ранг — стационарность всех рядов.

**Процедура Йохансена.** Ранг определяется из собственных чисел матрицы

$$
S_{11}^{-1/2}S_{10}S_{00}^{-1}S_{01}S_{11}^{-1/2},
$$

где $S_{ij}$ — моментные матрицы остатков вспомогательных регрессий $\Delta
y_t$ и $y_{t-1}$ на лаги разностей. Проверяются две статистики:

$$
\lambda_{\text{trace}}(r) = -T\sum_{i=r+1}^{k}\ln(1-\hat\lambda_i),
\qquad
\lambda_{\max}(r) = -T\ln(1-\hat\lambda_{r+1}).
$$

Критические значения нестандартны (таблицы Остервальда-Ленума) и зависят от
спецификации детерминированных компонент.

**Коэффициент приспособления** $\alpha$ должен быть **отрицательным** для
переменной, возвращающейся к равновесию: положительное отклонение вызывает
снижение. Положительный значимый $\alpha$ означает расхождение и указывает на
ошибку спецификации.

**Период полувозврата** — время, за которое отклонение сокращается вдвое:

$$
t_{1/2} \;=\; \frac{\ln 0{,}5}{\ln(1 + \alpha)} .
$$

Это самая практичная величина модели: она прямо говорит трейдеру, на каком
горизонте держать парную позицию.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(nk^2p + k^3)$ | обобщённая задача на собственные числа |
| Память | $O(nkp)$ | матрицы вспомогательных регрессий |

## API

| Метод | Описание |
|-------|----------|
| `Cointegration.Johansen(data, lags, names)` | Ранг, собственные числа, векторы |
| `Cointegration.ErrorCorrection(data, rank, lags, names)` | Модель коррекции ошибок |
| `JohansenResult.Rows` | Статистики следа и максимума с критическими значениями |
| `JohansenResult.CointegratingVectors` | Равновесные соотношения |
| `VecmResult.AdjustmentCoefficients` | Скорость приспособления с оценкой значимости |
| `VecmResult.EquilibriumError` / `HalfLife` | Отклонение от равновесия и полувозврат |

Исходники: `src/AI.Economics/Econometrics/Cointegration.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Econometrics;
using AI.Statistics;

Random rng = RandomEngine.Create(173);
int n = 500;

var prices = new Matrix(n, 2);
double spot = 0, futures = 0;

for (int t = 0; t < n; t++)
{
    // Спот — случайное блуждание, фьючерс притягивается к удвоенному споту
    spot += RandomEngine.NextGaussian(rng);
    futures += (0.3 * ((2 * spot) - futures)) + RandomEngine.NextGaussian(rng, 0, 0.4);

    prices[t, 0] = spot;
    prices[t, 1] = futures;
}

JohansenResult johansen = Cointegration.Johansen(prices, lags: 1, names: ["спот", "фьючерс"]);

Console.WriteLine($"Ранг коинтеграции {johansen.Rank}");

foreach (JohansenRow row in johansen.Rows)
{
    Console.WriteLine($"r ≤ {row.Rank}: λ = {row.Eigenvalue:F4}, " +
                      $"след {row.TraceStatistic:F2} против {row.TraceCritical:F2} " +
                      (row.TraceRejected ? "— отвергается" : "— не отвергается") +
                      $", максимум {row.MaxEigenStatistic:F2} против {row.MaxEigenCritical:F2}");
}

Console.WriteLine($"Коинтеграционный вектор: [{johansen.CointegratingVectors[0, 0]:F3}, " +
                  $"{johansen.CointegratingVectors[1, 0]:F3}]");
```

Модель коррекции ошибок даёт число, полезное на практике:

```csharp
VecmResult vecm = Cointegration.ErrorCorrection(prices, rank: 1, lags: 1, names: ["спот", "фьючерс"]);

for (int i = 0; i < vecm.AdjustmentCoefficients.Count; i++)
{
    Coefficient alpha = vecm.AdjustmentCoefficients[i];
    Console.WriteLine($"{alpha.Name}: α = {alpha.Estimate:F4} (p = {alpha.PValue:F4}) — " +
                      (alpha.Estimate < 0 ? "возвращается к равновесию" : "расходится"));
}

Console.WriteLine($"Период полувозврата {vecm.HalfLife:F2} периодов");
Console.WriteLine($"Наблюдений в модели {vecm.Observations}, лагов {vecm.Lags}");
```

Отклонение от равновесия — торговый сигнал в парной стратегии:

```csharp
Vector spread = vecm.EquilibriumError;
double mean = spread.Average();
double sd = Math.Sqrt(spread.Sum(z => (z - mean) * (z - mean)) / Math.Max(spread.Count - 1, 1));

int signals = spread.Count(z => Math.Abs(z - mean) > 2 * sd);
Console.WriteLine($"Отклонений больше двух сигм: {signals} из {spread.Count}");
Console.WriteLine($"Текущее отклонение {spread[^1]:F3} ({(spread[^1] - mean) / sd:F2} сигм)");

Console.WriteLine(johansen.Interpret().ToLlmText());
Console.WriteLine(vecm.Interpret().ToLlmText());
```

## Ограничения

- Перед тестом обязательно убедитесь, что все ряды интегрированы порядка
  один — [проверьте стационарность](stationarity.md). Смесь $I(0)$ и $I(1)$
  даёт бессмысленный результат.
- Тесты чувствительны к числу лагов и к спецификации детерминированных
  компонент. Разные разумные варианты нередко дают разный ранг; выбирайте по
  информационным критериям и проверяйте устойчивость.
- Мощность теста низка на выборках короче 100 наблюдений — коинтеграция не
  обнаруживается, даже когда она есть.
- Структурный сдвиг в равновесном соотношении разрушает тест: связь,
  изменившаяся в середине выборки, выглядит как её отсутствие.
- Коинтеграция — статистическое свойство, а не экономический закон. Пара
  рядов может показать коинтеграцию случайно; требуйте содержательного
  обоснования равновесия перед торговлей на нём.
