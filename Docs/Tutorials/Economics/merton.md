# Модель Мертона и KMV: вероятность дефолта из цены акции

Восстановление рыночной стоимости и волатильности активов по капитализации,
расстояние до дефолта, вероятность дефолта и кредитный спред.

## Постановка задачи

Дано: рыночная капитализация публичной компании, годовая волатильность её
акции, структура долга по срочности и безрисковая ставка.

Требуется: вероятность дефолта на заданном горизонте и кредитный спред,
вытекающий из рыночной оценки, — без использования отчётности и без
рейтингового агентства.

Где встречается: лимиты на публичных контрагентов, мониторинг эмитентов
облигаций, раннее предупреждение по портфелю корпоративных кредитов,
проверка адекватности присвоенного рейтинга.

## Теория

Собственный капитал компании — это опцион колл на её активы с ценой
исполнения, равной долгу. Если стоимость активов в момент погашения ниже
долга, акционеры не исполняют опцион и компания уходит в дефолт. Отсюда
система из двух уравнений, связывающая наблюдаемые величины (капитализацию и
волатильность акции) с ненаблюдаемыми (стоимостью и волатильностью активов):

$$
E \;=\; V\,N(d_1) \;-\; D\,e^{-rT} N(d_2),
\qquad
\sigma_E E \;=\; N(d_1)\,\sigma_V V,
$$

$$
d_1 = \frac{\ln(V/D) + \bigl(r + \tfrac{1}{2}\sigma_V^2\bigr)T}{\sigma_V\sqrt{T}},
\qquad
d_2 = d_1 - \sigma_V\sqrt{T} .
$$

Система решается итерационно: при фиксированной $\sigma_V$ первое уравнение
монотонно по $V$ и решается делением отрезка пополам, после чего второе
уравнение обновляет $\sigma_V$.

**Точка дефолта** берётся по правилу KMV: краткосрочный долг плюс половина
долгосрочного. Эмпирически компании уходят в дефолт именно на этом уровне, а не
при падении активов ниже полного долга, поскольку долгосрочные обязательства
обычно удаётся рефинансировать.

**Расстояние до дефолта** — на сколько стандартных отклонений стоимость активов
превышает точку дефолта:

$$
\mathrm{DD} \;=\; \frac{\ln(V/D) + \bigl(\mu - \tfrac{1}{2}\sigma_V^2\bigr)T}{\sigma_V\sqrt{T}},
\qquad
\mathrm{PD} = N(-\mathrm{DD}).
$$

При $\mu = r$ получается риск-нейтральная вероятность — та, что заложена в цены
облигаций; при ожидаемой доходности активов — «реальная». Разница между ними и
есть премия за риск, которую требуют держатели долга.

Главное практическое достоинство модели: она извлекает кредитный риск из рынка
акций, а не из отчётности, и потому реагирует на новости в тот же день, тогда
как рейтинг и коэффициенты отчётности отстают на кварталы.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I\,B)$ | $I$ итераций по волатильности, $B$ шагов бисекции |
| Память | $O(1)$ | состояние из двух чисел |

## API

| Метод | Описание |
|-------|----------|
| `MertonModel.Estimate(input)` | Решение системы и все производные величины |
| `MertonResult.AssetValue` / `AssetVolatility` | Восстановленные стоимость и волатильность активов |
| `MertonResult.DefaultPoint` / `Leverage` | Точка дефолта KMV и долговая нагрузка |
| `MertonResult.DistanceToDefault` | Расстояние до дефолта в стандартных отклонениях |
| `MertonResult.ProbabilityOfDefault` / `RiskNeutralProbability` | Реальная и риск-нейтральная оценки |
| `MertonResult.ImpliedCreditSpread` | Кредитный спред, вытекающий из модели |

Исходники: `src/AI.Economics/Credit/MertonModel.cs`.

## Код

```csharp
using AI.Economics.Credit;

var company = new MertonInput
{
    Company = "Публичная компания",
    EquityValue = 5_000_000_000,
    EquityVolatility = 0.35,
    ShortTermDebt = 1_200_000_000,
    LongTermDebt = 2_800_000_000,
    RiskFreeRate = 0.07,
    AssetDrift = 0.09,
    Horizon = 1,
};

MertonResult merton = MertonModel.Estimate(company);

Console.WriteLine($"Активы {merton.AssetValue:N0} при волатильности {merton.AssetVolatility:P1}");
Console.WriteLine($"Точка дефолта {merton.DefaultPoint:N0} ({merton.Leverage:P1} активов)");
Console.WriteLine($"Расстояние до дефолта {merton.DistanceToDefault:F2}");
Console.WriteLine($"Вероятность дефолта {merton.ProbabilityOfDefault:P3}, " +
                  $"риск-нейтральная {merton.RiskNeutralProbability:P3}");
Console.WriteLine($"Кредитный спред {merton.ImpliedCreditSpread:P2}");
```

Чувствительность к долговой нагрузке — основной сценарий использования, когда
обсуждается новый выпуск облигаций:

```csharp
foreach (double factor in new[] { 0.5, 1.0, 1.5, 2.0 })
{
    MertonResult scenario = MertonModel.Estimate(company with
    {
        ShortTermDebt = company.ShortTermDebt * factor,
        LongTermDebt = company.LongTermDebt * factor,
    });

    Console.WriteLine($"Долг x{factor:F1}: DD {scenario.DistanceToDefault:F2}, " +
                      $"PD {scenario.ProbabilityOfDefault:P3}, спред {scenario.ImpliedCreditSpread:P2}");
}

Console.WriteLine(merton.Interpret().ToLlmText());
```

Полученную вероятность можно сразу подставить в расчёт резерва:

```csharp
var exposure = new CreditExposure
{
    Id = "Кредит эмитенту",
    ExposureAtDefault = 500_000_000,
    ProbabilityOfDefault = merton.ProbabilityOfDefault,
    ProbabilityOfDefaultAtOrigination = merton.ProbabilityOfDefault,
    LossGivenDefault = 0.45,
    EffectiveInterestRate = 0.12,
    RemainingMonths = 24,
};

EclResult provision = Ifrs9.Compute([exposure]);
Console.WriteLine($"Резерв по кредиту: {provision.TotalEcl:N0}");
```

## Ограничения

- Модель предполагает единственную выплату долга в конце горизонта и
  логнормальную динамику активов. Она системно недооценивает вероятность
  дефолта качественных заёмщиков на коротких горизонтах, поскольку не
  допускает скачков стоимости активов.
- Абсолютное значение вероятности требует калибровки на исторической частоте
  дефолтов. Устойчиво здесь именно ранжирование компаний по расстоянию до
  дефолта, а не сама вероятность.
- Точка дефолта влияет на результат сильнее волатильности. Правило «короткий
  долг плюс половина длинного» — эмпирика, а не теорема, и для компаний с
  необычной структурой долга её надо пересматривать.
- Модель применима только к публичным компаниям с ликвидной акцией. Для
  непубличных используйте [скоркарту](scorecard.md) или
  [скоринг контрагента](counterparty.md).
- Волатильность акции берётся как постоянная. В периоды стресса она резко
  растёт, и оценка вероятности реагирует с запозданием на длину окна расчёта.
