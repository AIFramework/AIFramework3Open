# Ценовой раунд и разводнение

Расчёт раунда с конвертацией SAFE и займов, пополнением опционного пула и
честной оценкой того, во сколько всё это обошлось основателям.

## Постановка задачи

Дано: таблица капитализации до раунда, оценка до денег, сумма инвестиции,
целевой размер опционного пула и конвертируемые инструменты.

Требуется: цена акции, число акций инвестора, новая таблица капитализации и
разводнение по каждому держателю.

Где встречается: подготовка к раунду, проверка term sheet, моделирование
альтернативных условий сделки.

## Теория

Доля основателей после раунда почти всегда меньше ожидаемой, и на то три
причины.

**Pool shuffle.** Пополнение опционного пула по стандартным условиям делается
«до денег», то есть размывает только существующих акционеров, а не инвестора.
Если инвестор берёт долю $f_{inv}$, а целевой пул равен $f_{pool}$ от капитала
после раунда, то общее число акций находится из условия

$$
T \,\bigl(1 - f_{pool} - f_{inv}\bigr) \;=\; S_{issued} + S_{safe},
$$

и пул в 10 % при инвесторской доле 20 % стоит основателям около 8 процентных
пунктов.

**Конвертация SAFE.** Инструмент конвертируется по цене
$\min\bigl(\text{cap}/S_{pre},\; P \cdot (1-\text{discount})\bigr)$, то есть
ниже раундовой, и даёт больше акций, чем «та же сумма по цене раунда».
Post-money SAFE трактуется по стандарту YC: доля инвестора считается от
капитала после конвертации всех инструментов, но до новых денег.

**Циклическая зависимость.** Число акций SAFE зависит от цены раунда,
а цена раунда $P = \text{post-money}/T$ — от общего числа акций. Уравнение
решается итеративно; прикидка на салфетке систематически занижает разводнение.

Эффективная оценка до денег с точки зрения существующих акционеров — их доля
после раунда, умноженная на оценку после денег. Расхождение с заявленной
оценкой и есть цена пула и скидок, о которой в term sheet не сказано ни слова.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I \cdot k + n)$ | $I$ — итераций неподвижной точки, $k$ — инструментов |
| Память | $O(n)$ | Держатели в новой таблице |

## API

| Метод | Описание |
|-------|----------|
| `FundingRound.Execute(table, round)` | Проводит раунд, возвращает новую таблицу |
| `RoundInput.TargetOptionPoolPost` | Целевая доля пула после раунда; 0 — не трогать |
| `RoundInput.ConvertingNotes` | SAFE и конвертируемые займы |
| `RoundResult.PricePerShare` | Цена акции раунда |
| `RoundResult.Dilution` | Доли до и после по каждому держателю |
| `RoundResult.EffectivePreMoneyForFounders` | Оценка, которую фактически получили основатели |
| `SafeNote.AmountWithInterest` | Сумма займа с накопленными процентами |

Исходники: `src/AI.Economics/Equity/`.

## Код

```csharp
using AI.Economics.Equity;

var table = new CapTable()
    .AddHolding("Основатель 1", 6_000_000)
    .AddHolding("Основатель 2", 4_000_000);

var round = new RoundInput
{
    RoundName = "Series A",
    InvestorName = "Фонд",
    PreMoneyValuation = 400_000_000,
    Investment = 100_000_000,
    TargetOptionPoolPost = 0.10,
    ConvertingNotes =
    [
        new SafeNote { Holder = "Ангел", Amount = 20_000_000, ValuationCap = 120_000_000, Discount = 0.2 },
    ],
};

RoundResult result = FundingRound.Execute(table, round);

Console.WriteLine($"Цена акции:        {result.PricePerShare:F2}");
Console.WriteLine($"Доля фонда:        {result.InvestorOwnership:P1}");
Console.WriteLine($"Новых опционов:    {result.NewPoolShares:N0}");
Console.WriteLine($"Эффективная оценка: {result.EffectivePreMoneyForFounders:N0} " +
                  $"против заявленной {round.PreMoneyValuation:N0}");

foreach (DilutionRow row in result.Dilution)
    Console.WriteLine($"{row.Holder,-16} {row.Before:P1} -> {row.After:P1} (потеря {row.RelativeDilution:P0})");

foreach (NoteConversion conversion in result.Conversions)
    Console.WriteLine($"{conversion.Holder}: {conversion.PriceDriver}, цена {conversion.ConversionPrice:F2}, " +
                      $"доля {conversion.OwnershipAfter:P1}");
```

## Ограничения

- Потолок оценки для pre-money SAFE считается от капитала до раунда, включая
  существующий свободный пул. В договорах встречаются иные определения
  «company capitalization» — сверяйтесь с текстом конкретного документа.
- Антиразводняющие оговорки (full ratchet, weighted average) не моделируются:
  они срабатывают на понижающем раунде и требуют отдельного расчёта.
- Проценты по займу считаются простыми, без капитализации.
- Вестинг и незакрытые опционы учитываются как обычные акции: цена исполнения
  в расчёте доли не участвует.
- Оговорка о наиболее благоприятных условиях раскрывается только среди
  инструментов, конвертирующихся в этом же раунде.
