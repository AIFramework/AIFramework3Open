# Критерии оценки инвестиционного проекта

NPV, IRR и MIRR, индекс прибыльности, простой и дисконтированный срок
окупаемости, а также XNPV и XIRR для потоков с произвольными датами.

## Постановка задачи

Дано: денежный поток проекта по периодам (или с привязкой к календарным
датам) и ставка дисконтирования.

Требуется: принять или отвергнуть проект, а при сравнении нескольких —
расставить приоритеты; понимать, когда критерии противоречат друг другу и
какому из них верить.

Где встречается: инвестиционный комитет, бюджет капитальных вложений,
сравнение конкурирующих технических решений, обоснование гранта или субсидии.

## Теория

**Чистая приведённая стоимость** — единственный критерий, прямо измеряющий
прирост богатства:

$$
\mathrm{NPV} \;=\; \sum_{t=0}^{N} \frac{C_t}{(1+r)^t}.
$$

Правило: принимать при $\mathrm{NPV} > 0$. Все остальные критерии —
вспомогательные, они отвечают на дополнительные вопросы.

**Внутренняя норма доходности** — ставка, обнуляющая NPV:

$$
\sum_{t=0}^{N} \frac{C_t}{(1+\mathrm{IRR})^t} \;=\; 0 .
$$

У IRR два известных дефекта. Первый: при нескольких сменах знака потока
уравнение имеет несколько корней — по правилу Декарта их столько же, сколько
смен знака. Второй: IRR неявно предполагает реинвестирование промежуточных
поступлений по самой ставке IRR, что нереалистично для проектов с высокой
доходностью.

**Модифицированная норма** устраняет второй дефект, разделяя ставку
финансирования оттоков и ставку реинвестирования притоков:

$$
\mathrm{MIRR} \;=\; \left(\frac{\sum_t C_t^{+}\,(1+r_{\text{re}})^{N-t}}{-\sum_t C_t^{-}\,(1+r_{\text{fin}})^{-t}}\right)^{1/N} - 1 .
$$

MIRR всегда единственна и обычно заметно ниже IRR — это и есть честная
доходность.

**Индекс прибыльности** $\mathrm{PI} = \mathrm{PV}(\text{притоки}) /
|C_0|$ отвечает на вопрос отдачи на рубль вложений и потому нужен при
ограниченном бюджете: при выборе из проектов с положительным NPV
ранжирование по PI даёт максимум суммарного NPV.

**Сроки окупаемости** — простой и дисконтированный — измеряют не
эффективность, а риск ликвидности. Дисконтированный всегда длиннее простого;
если он не наступает до конца проекта, проект не окупается вовсе.

**Потоки с датами.** Когда поступления неравномерны, дисконтирование ведётся
по фактическому числу дней:

$$
\mathrm{XNPV} \;=\; \sum_i \frac{C_i}{(1+r)^{(d_i - d_0)/365}} .
$$

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(N)$ на NPV, $O(N\log(1/\varepsilon))$ на IRR | бисекция по ставке |
| Память | $O(N)$ | поток и накопленные суммы |

## API

| Метод | Описание |
|-------|----------|
| `InvestmentCriteria.Appraise(flows, rate, reinvestRate, name)` | Все критерии сразу |
| `InvestmentCriteria.NetPresentValue(flows, rate)` | Только NPV |
| `InvestmentCriteria.InternalRateOfReturn(flows)` | IRR бисекцией |
| `InvestmentCriteria.ModifiedInternalRateOfReturn(flows, fin, reinvest)` | MIRR |
| `InvestmentCriteria.ExtendedNetPresentValue(dated, rate)` | XNPV по датам |
| `InvestmentCriteria.ExtendedInternalRateOfReturn(dated)` | XIRR по датам |
| `InvestmentAppraisal.NpvProfile` | Кривая NPV по ставке |

Исходники: `src/AI.Economics/Projects/InvestmentCriteria.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Projects;

var flows = new Vector(-100_000_000, 25_000_000, 35_000_000, 45_000_000, 50_000_000);

InvestmentAppraisal appraisal = InvestmentCriteria.Appraise(
    flows, discountRate: 0.15, reinvestmentRate: 0.10, name: "Линия розлива");

Console.WriteLine($"NPV {appraisal.NetPresentValue:N0}");
Console.WriteLine($"IRR {appraisal.InternalRateOfReturn:P2}, MIRR {appraisal.ModifiedIrr:P2}");
Console.WriteLine($"Индекс прибыльности {appraisal.ProfitabilityIndex:F2}");
Console.WriteLine($"Окупаемость {appraisal.PaybackPeriod:F2} года, " +
                  $"дисконтированная {appraisal.DiscountedPayback:F2}");
Console.WriteLine(appraisal.IsAccepted ? "Проект принимается" : "Проект отклоняется");
```

Профиль NPV показывает, насколько решение устойчиво к ставке:

```csharp
foreach ((double rate, double npv) in appraisal.NpvProfile)
    Console.WriteLine($"r = {rate:P0}: NPV {npv:N0}");

Console.WriteLine($"Смен знака в потоке: {appraisal.SignChanges}");
```

Для неравномерных поступлений считаются XNPV и XIRR:

```csharp
var dated = new List<DatedCashFlow>
{
    new(new DateOnly(2026, 1, 15), -100_000_000),
    new(new DateOnly(2026, 7, 1), 30_000_000),
    new(new DateOnly(2027, 3, 20), 45_000_000),
    new(new DateOnly(2028, 2, 10), 60_000_000),
};

double xnpv = InvestmentCriteria.ExtendedNetPresentValue(dated, 0.15);
double xirr = InvestmentCriteria.ExtendedInternalRateOfReturn(dated);

Console.WriteLine($"XNPV {xnpv:N0} при ставке 15%, XIRR {xirr:P2}");
Console.WriteLine(appraisal.Interpret().ToLlmText());
```

## Ограничения

- IRR нельзя сравнивать между проектами разного масштаба и срока. Проект с
  IRR 40% на 10 млн беднее проекта с IRR 20% на 500 млн; для выбора служит
  NPV, а при ограниченном бюджете — индекс прибыльности.
- При нескольких сменах знака IRR не определена однозначно. Реализация
  возвращает первый найденный корень и сообщает число смен знака —
  если оно больше единицы, используйте MIRR.
- Срок окупаемости игнорирует всё, что происходит после его наступления.
  Проект с быстрой окупаемостью и последующей рекультивацией по этому
  критерию выглядит отлично.
- Постоянная ставка на весь горизонт — упрощение. Для проектов с меняющимся
  риском (стадия строительства против стадии эксплуатации) дисконтируйте
  этапы разными ставками.
- Все критерии молчат о гибкости: право свернуть проект или расширить его
  стоит денег и оценивается [реальными опционами](real_options_lsm.md).
