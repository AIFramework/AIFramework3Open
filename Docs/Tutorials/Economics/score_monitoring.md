# Мониторинг модели: Джини, KS и PSI

Разделяющая способность, калибровка и индекс стабильности популяции — три
независимых вопроса к работающей скоринговой модели, которые нельзя смешивать.

## Постановка задачи

Дано: прогнозные вероятности дефолта по выборке и фактические исходы, а также
распределение баллов на эталонном и на текущем периоде.

Требуется: ответить, ранжирует ли модель заёмщиков, соответствуют ли её
вероятности фактической частоте событий и не сместилась ли популяция заявителей.

Где встречается: ежемесячный отчёт валидации модели, приёмка модели в
эксплуатацию, обоснование пересмотра отсечки перед кредитным комитетом.

## Теория

**Разделяющая способность.** Площадь под ROC-кривой равна вероятности того, что
случайно взятый дефолтный заёмщик получит более высокую оценку риска, чем
случайно взятый исправный. Считается через ранги (статистика Манна — Уитни),
что даёт точный результат при совпадающих значениях:

$$
\mathrm{AUC} = \frac{\sum_{i \in B} r_i - \frac{|B|(|B|+1)}{2}}{|B|\cdot|G|},
\qquad
\mathrm{Gini} = 2\,\mathrm{AUC} - 1 .
$$

Статистика Колмогорова — Смирнова — максимальный разрыв между накопленными
долями дефолтных и исправных: она указывает, на каком именно балле модель
разделяет выборку лучше всего, и потому напрямую подсказывает отсечку.

**Калибровка.** Ранжирование и калибровка — разные свойства. Модель может
идеально упорядочивать заёмщиков и при этом систематически завышать
вероятности. Проверяется регрессией исхода на логит прогноза:

$$
\mathrm{logit}\,\Pr(y=1) = a + b\cdot\mathrm{logit}\,\hat p .
$$

Идеал — $a=0$, $b=1$. Наклон меньше единицы означает, что модель переоценивает
разброс риска; сдвиг говорит о смещении уровня. Дополнительно считается счёт
Брайера — средний квадрат ошибки вероятности.

**Стабильность популяции.** Индекс PSI сравнивает распределение баллов на новом
периоде с эталонным по фиксированным интервалам:

$$
\mathrm{PSI} = \sum_i (a_i - e_i)\,\ln\frac{a_i}{e_i}.
$$

Отраслевые пороги: до 0,1 — популяция стабильна, 0,1–0,25 — заметный сдвиг,
выше 0,25 — модель работает не на той популяции, на которой обучалась.
Важно, что PSI не требует знания исходов и потому доступен сразу, а падение
Джини становится видимым только после созревания выданных кредитов.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n \log n)$ | сортировка для рангов и для границ интервалов |
| Память | $O(n)$ | ранги и накопленные доли |

## API

| Метод | Описание |
|-------|----------|
| `ScoreMetrics.Evaluate(probabilities, defaults, calibrationBins)` | AUC, Джини, KS, Брайер, калибровка |
| `ScoreMetrics.PopulationStability(expected, actual, bins, variable)` | Индекс стабильности популяции |
| `ScoreQuality.RocFalsePositive` / `RocTruePositive` | Точки ROC-кривой |
| `ScoreQuality.CalibrationSlope` / `CalibrationIntercept` | Наклон и сдвиг калибровки |
| `PsiResult.Psi` / `Contributions` / `Verdict` | Индекс, вклад интервалов и словесная оценка |

Исходники: `src/AI.Economics/Credit/ScoreMetrics.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Credit;

const int size = 2_000;
var predicted = new Vector(size);
var observed = new List<bool>(size);
var monitorRng = new Random(13);

for (int i = 0; i < size; i++)
{
    double latent = monitorRng.NextDouble();
    double probability = 0.02 + (0.35 * latent * latent);

    predicted[i] = probability;
    observed.Add(monitorRng.NextDouble() < probability);
}

ScoreQuality quality = ScoreMetrics.Evaluate(predicted, observed);

Console.WriteLine($"AUC {quality.Auc:F3}, Джини {quality.Gini:F3}, KS {quality.Ks:F3}");
Console.WriteLine($"Калибровка: наклон {quality.CalibrationSlope:F2}, сдвиг {quality.CalibrationIntercept:F2}");
Console.WriteLine($"Средний прогноз {quality.MeanPredicted:P2} против факта {quality.MeanObserved:P2}");
```

Дрейф популяции проверяется отдельно и без знания исходов:

```csharp
var reference = new Vector(size);
var currentPeriod = new Vector(size);
var driftRng = new Random(29);

for (int i = 0; i < size; i++)
{
    reference[i] = 600 + (40 * (driftRng.NextDouble() - 0.5) * 4);

    // Новая популяция сместилась вниз на половину стандартного отклонения
    currentPeriod[i] = 580 + (40 * (driftRng.NextDouble() - 0.5) * 4);
}

PsiResult stability = ScoreMetrics.PopulationStability(reference, currentPeriod);

Console.WriteLine($"PSI {stability.Psi:F4} — {stability.Verdict}");
Console.WriteLine(stability.Interpret().ToLlmText());
```

Полный разбор качества модели одним текстом — в таком виде его можно отдать
языковой модели или вставить в отчёт валидации:

```csharp
Console.WriteLine(quality.Interpret().ToLlmText());
```

## Ограничения

- Коэффициент Джини зависит от того, на какой популяции он посчитан. Сравнивать
  модели можно только на одной выборке: на «чистом» портфеле после отсечки он
  всегда ниже, чем на выборке всех поступивших заявок.
- Калибровка ломается раньше ранжирования — при первом же изменении
  макроусловий. Поэтому наклон и сдвиг нужно проверять чаще, чем Джини.
- PSI не отвечает на вопрос, стала ли модель хуже. Он говорит только о том, что
  популяция изменилась; вывод о качестве требует созревших исходов.
- Расчёт по обучающей выборке даёт систематически завышенные оценки — для
  честной цифры нужна отложенная выборка или скользящий контроль, как в
  [предсказании банкротства](bankruptcy_ml.md).
- Границы интервалов PSI строятся по эталонной выборке и должны быть
  зафиксированы: пересчёт границ каждый период превращает индекс в шум.
