# Готовность платить: Ван Вестендорп и Габор — Грейнджер

Два опросных метода определения цены для товара, у которого ещё нет истории
продаж, и того, что каждый из них умеет и не умеет.

## Постановка задачи

Дано: ответы респондентов о приемлемых для них ценах.

Требуется: коридор допустимых цен и оценка спроса, пригодная для расчёта
выручки и прибыли.

Где встречается: запуск нового продукта, выход на новый рынок, проверка
гипотезы о премиальном позиционировании.

## Теория

**Ван Вестендорп** задаёт четыре вопроса: при какой цене товар кажется
слишком дешёвым, выгодным, дорогим и неприемлемо дорогим. По ответам строятся
четыре кумулятивные кривые — две убывающие и две возрастающие — и берутся их
пересечения:

| Точка | Пересечение | Смысл |
|-------|-------------|-------|
| Нижняя граница | «слишком дёшево» и «дорого» | ниже неё сомневаются в качестве |
| Оптимальная цена | «слишком дёшево» и «слишком дорого» | минимум суммарного отказа |
| Точка безразличия | «выгодно» и «дорого» | обычно цена лидера рынка |
| Верхняя граница | «выгодно» и «слишком дорого» | выше неё отказ становится массовым |

Ответы с нарушенным порядком цен отбраковываются: соотношение
«слишком дёшево $\le$ выгодно $\le$ дорого $\le$ слишком дорого» следует
из смысла вопросов, и его нарушение означает, что респондент их не понял.

**Габор — Грейнджер** предъявляет лестницу цен и спрашивает о готовности
купить по каждой. Получается кривая спроса $a(p)$, из которой прямо считаются
выручка и прибыль на респондента:

$$
R(p) = p\,a(p), \qquad \Pi(p) = (p - c)\,a(p).
$$

Оптимум по прибыли всегда не ниже оптимума по выручке: при положительных
переменных издержках часть дешёвых продаж не окупается. Локальная
эластичность в окрестности оптимума считается по соседним точкам сетки.

Методы дополняют друг друга: первый очерчивает коридор и хорош для продукта
без аналогов, второй даёт кривую спроса, но требует, чтобы респондент понимал,
что именно покупает.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n g)$ | $n$ — респондентов, $g$ — точек сетки цен |
| Память | $O(g)$ | Четыре кривые |

## API

| Метод | Описание |
|-------|----------|
| `WillingnessToPay.VanWestendorp(answers, gridPoints)` | Четыре кривые и точки пересечения |
| `WillingnessToPay.GaborGranger(prices, acceptance, unitCost, respondents)` | Кривая спроса, выручки и прибыли |
| `VanWestendorpResult.OptimalPricePoint` | Точка минимального суммарного отказа |
| `VanWestendorpResult.InconsistentAnswers` | Сколько ответов отброшено по порядку цен |
| `GaborGrangerResult.ProfitOptimalPrice` | Цена, максимизирующая прибыль |
| `GaborGrangerResult.ElasticityAtOptimum` | Локальная эластичность спроса |

Исходник: `src/AI.Economics/Pricing/WillingnessToPay.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Pricing;

var random = new Random(21);
var answers = new List<VanWestendorpAnswer>();

for (int i = 0; i < 300; i++)
{
    double personal = 1000 * Math.Exp((random.NextDouble() - 0.5) * 0.5);
    answers.Add(new VanWestendorpAnswer(
        TooCheap: personal * 0.45,
        Cheap: personal * 0.75,
        Expensive: personal * 1.25,
        TooExpensive: personal * 1.85));
}

VanWestendorpResult range = WillingnessToPay.VanWestendorp(answers);

Console.WriteLine($"Приемлемый коридор: {range.PointOfMarginalCheapness:N0} " +
                  $"- {range.PointOfMarginalExpensiveness:N0}");
Console.WriteLine($"Оптимальная точка: {range.OptimalPricePoint:N0}");
Console.WriteLine($"Точка безразличия: {range.IndifferencePricePoint:N0}");

// Проверка коридора лестницей цен: она даёт выручку и прибыль
var prices = new Vector(600.0, 800, 1000, 1200, 1400, 1600);
var acceptance = new Vector(0.88, 0.74, 0.55, 0.36, 0.21, 0.11);

GaborGrangerResult ladder = WillingnessToPay.GaborGranger(
    prices, acceptance, unitCost: 300, respondents: 300);

Console.WriteLine($"Максимум прибыли при {ladder.ProfitOptimalPrice:N0}, " +
                  $"конверсия {ladder.AcceptanceAtProfitOptimum:P0}");
Console.WriteLine($"Максимум выручки при {ladder.RevenueOptimalPrice:N0}");
Console.WriteLine(ladder.Interpret().ToLlmText());
```

## Ограничения

- Оба метода измеряют декларируемую готовность платить. Респондент ничего
  не платит, поэтому верхнюю границу он занижает, а согласие купить завышает.
  Ожидайте, что фактическая конверсия окажется ниже опросной.
- Ван Вестендорп не даёт объёма продаж: он очерчивает коридор, внутри которого
  цену надо выбирать по экономике.
- Габор — Грейнджер чувствителен к порядку предъявления цен. Предъявление
  по возрастанию систематически завышает приемлемую цену.
- Широкий коридор — признак неоднородной аудитории. Единая цена для такой
  аудитории оставляет деньги на столе: сегментируйте выборку.
- Малая выборка сдвигает пересечения кривых на десятки процентов: минимум
  сто респондентов на сегмент.
