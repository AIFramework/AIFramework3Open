# Винтажный анализ портфеля

Сравнение когорт выдач на одинаковом возрасте, кривая созревания потерь и
тренд качества выдач — то, что видно за год до роста портфельной просрочки.

## Постановка задачи

Дано: накопленная доля потерь по месяцам жизни для каждой когорты выдач и
сумма выдач когорты. Когорты имеют разный возраст: старшие наблюдаются дольше.

Требуется: сопоставимая оценка качества каждой когорты, прогноз потерь за весь
срок для незрелых когорт и ответ на вопрос, ухудшается ли политика выдач.

Где встречается: управление кредитным риском розничного портфеля, отчётность
перед инвесторами по секьюритизации, оценка эффекта изменения скоринговой
отсечки.

## Теория

Портфельная доля просрочки смешивает два эффекта — качество выдач и возрастную
структуру портфеля. Быстро растущий портфель выглядит здоровым просто потому,
что большая часть договоров ещё не дожила до возраста, на котором происходят
дефолты. Винтажный анализ разделяет эти эффекты: каждая когорта наблюдается по
возрасту от момента выдачи, а не по календарю.

**Кривая созревания** — усреднённая по когортам (с весом по объёму выдач)
накопленная доля потерь по возрасту $a$:

$$
M(a) \;=\; \frac{\sum_v V_v \, L_v(a)}{\sum_v V_v},
\qquad a = 1,\dots,A_{\max}.
$$

Кривая монотонна по построению: накопленные потери не возвращаются. Приростная
кривая $M(a) - M(a-1)$ показывает, в каком возрасте портфель теряет деньги —
и одновременно, с какого момента винтаж можно оценивать.

**Экстраполяция.** Молодая когорта, наблюдённая до возраста $a_v$,
достраивается по форме кривой созревания:

$$
\widehat L_v \;=\; L_v(a_v)\cdot \frac{M(A_{\max})}{M(a_v)} .
$$

**Тренд качества** оценивается регрессией потерь на общем возрасте по номеру
винтажа. Значимый положительный наклон означает, что политика выдач
ослабевает. Именно эта величина информативнее любого портфельного показателя:
она видна за год до того, как ухудшение проявится в отчётности.

Главное правило анализа: сравнивать винтажи можно только на одинаковом
возрасте. Сравнение накопленных потерь у выдач разной зрелости — самая частая
ошибка в отчётности по портфелю, и она всегда работает в пользу новых выдач.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(V\,A)$ | $V$ винтажей, $A$ месяцев наблюдения |
| Память | $O(V\,A)$ | треугольник потерь |

## API

| Метод | Описание |
|-------|----------|
| `VintageAnalysis.Analyze(cohorts)` | Кривая созревания, тренд качества и прогноз |
| `VintageAnalysis.Triangle(cohorts)` | Матрица «винтаж x возраст» для тепловой карты |
| `VintageResult.MaturityCurve` / `MarginalCurve` | Накопленная и приростная кривые |
| `VintageResult.CommonAge` / `HalfLossAge` | Возраст сопоставления и срок созревания риска |
| `VintageResult.QualityTrend` / `TrendPValue` | Наклон качества выдач и его значимость |
| `VintageProfile.ProjectedLifetimeLoss` | Прогноз потерь когорты за весь срок |

Исходники: `src/AI.Economics/Credit/VintageAnalysis.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Credit;

var cohorts = new List<VintageCohort>();
int[] ages = [24, 21, 18, 15, 12, 9];

for (int v = 0; v < ages.Length; v++)
{
    // Каждый следующий винтаж чуть хуже предыдущего
    double terminal = 0.05 + (0.004 * v);
    var curve = new List<double>(ages[v]);

    for (int age = 1; age <= ages[v]; age++)
        curve.Add(terminal * (1 - Math.Exp(-age / 8.0)));

    cohorts.Add(new VintageCohort($"2023-{v + 1:00}", 100_000_000 * (1 + (0.05 * v)), curve));
}

VintageResult vintages = VintageAnalysis.Analyze(cohorts);

Console.WriteLine($"Возраст сопоставления: {vintages.CommonAge} мес.");
Console.WriteLine($"Половина потерь реализуется к {vintages.HalfLossAge} месяцу");
Console.WriteLine($"Тренд качества: {vintages.QualityTrend:P3} за винтаж " +
                  $"(значимость {vintages.TrendPValue:F4})");

foreach (VintageProfile profile in vintages.Vintages)
{
    Console.WriteLine($"{profile.Name}: возраст {profile.Age} мес., " +
                      $"потери на общем возрасте {profile.LossAtCommonAge:P2}, " +
                      $"прогноз за срок {profile.ProjectedLifetimeLoss:P2}");
}
```

Кривая созревания отвечает на вопрос, с какого месяца винтаж вообще можно
оценивать:

```csharp
for (int age = 0; age < vintages.MaturityCurve.Count; age++)
{
    Console.WriteLine($"{age + 1} мес.: накоплено {vintages.MaturityCurve[age]:P3}, " +
                      $"прирост {vintages.MarginalCurve[age]:P3}");
}

Console.WriteLine($"Прогноз потерь по всем выдачам: {vintages.ProjectedPortfolioLoss:N0}");
Console.WriteLine(vintages.Interpret().ToLlmText());
```

Треугольник потерь удобно отдавать в тепловую карту:

```csharp
Matrix triangle = VintageAnalysis.Triangle(cohorts);

Console.WriteLine($"Матрица {triangle.Height} x {triangle.Width}, " +
                  $"незаполненные ячейки помечены NaN: {double.IsNaN(triangle[5, 23])}");
```

## Ограничения

- Кривая созревания усредняет винтажи с разной макросредой. Если условия
  кредитования резко менялись, форма кривой у новых выдач будет другой, и
  экстраполяция даст смещённый прогноз.
- Возраст сопоставления определяется самой молодой когортой. Если она совсем
  свежая, сравнение проводится на возрасте, где различия ещё не проявились.
- Тренд качества оценивается по нескольким точкам, поэтому его значимость
  надо проверять, а не принимать наклон за факт.
- Ухудшение почти всегда локализовано в одном сегменте. Разложение винтажей по
  каналам и продуктам обязательно, иначе средняя когорта скроет проблему.
- Метод показывает, что качество упало, но не говорит почему. Ответ обычно
  находится в [мониторинге модели](score_monitoring.md): сдвиг популяции
  заявителей виден раньше, чем реализованные потери.
