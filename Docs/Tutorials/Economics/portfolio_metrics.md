# Метрики эффективности портфеля

Шарп, Сортино, Кальмар и Омега, максимальная просадка и время восстановления,
бета и альфа, ошибка следования и информационный коэффициент.

## Постановка задачи

Дано: ряд доходностей портфеля, при необходимости — доходности эталона и
безрисковая ставка.

Требуется: набор показателей, позволяющих сравнить стратегию с эталоном и с
другими стратегиями, и понимание, какой из них уместен для данного профиля
доходностей.

Где встречается: отчётность управляющего перед инвестором, отбор фондов,
сравнение торговых стратегий, система вознаграждения за результат.

## Теория

**Коэффициент Шарпа** — избыточная доходность на единицу общего риска:

$$
\mathrm{Sharpe} \;=\; \frac{\bar r - r_f}{\sigma}\sqrt{m},
$$

где $m$ — число периодов в году. Его слабость в том, что он штрафует
волатильность вверх наравне с волатильностью вниз — а инвестора беспокоит
только вторая.

**Коэффициент Сортино** исправляет это, деля на полудисперсию:

$$
\mathrm{Sortino} \;=\; \frac{\bar r - r_f}{\sqrt{\frac{1}{n}\sum_t \min(r_t - r_f, 0)^2}}\sqrt{m}.
$$

**Максимальная просадка** — наибольшее падение от предыдущего максимума:

$$
\mathrm{MDD} \;=\; \max_{t}\left(1 - \frac{V_t}{\max_{s\le t} V_s}\right).
$$

Это единственная метрика, которую инвестор чувствует физически. Вместе с ней
имеет смысл **время восстановления** — сколько периодов понадобилось, чтобы
вернуться к максимуму.

**Коэффициент Кальмара** соотносит годовую доходность с максимальной
просадкой. В отличие от Шарпа, он наказывает за длинные однонаправленные
падения, которые волатильность не улавливает.

**Омега** — отношение вероятностно-взвешенных выигрышей к проигрышам
относительно порога $\theta$:

$$
\Omega(\theta) = \frac{\sum_t \max(r_t - \theta, 0)}{\sum_t \max(\theta - r_t, 0)}.
$$

Он использует всё распределение, а не два первых момента, и потому корректен
для асимметричных стратегий.

**Относительно эталона** считаются бета (чувствительность к рынку), альфа
(доходность сверх объяснённой бетой), ошибка следования $\mathrm{TE} =
\sigma(r_p - r_b)$ и информационный коэффициент
$\mathrm{IR} = \overline{(r_p - r_b)}/\mathrm{TE}$. Информационный
коэффициент выше 0,5 считается хорошим результатом активного управления.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n)$ | один проход по ряду |
| Память | $O(n)$ | ряд просадок |

## API

| Метод | Описание |
|-------|----------|
| `PortfolioMetrics.Compute(returns, benchmark, rf, periodsPerYear, omegaThreshold, name)` | Все метрики |
| `PortfolioMetrics.DrawdownProfile(returns)` | Просадки, максимум, длительность, восстановление |
| `PortfolioMetrics.PortfolioReturns(weights, assetReturns)` | Свёртка активов в портфель |
| `PerformanceMetrics.Sharpe` / `Sortino` / `Calmar` / `Omega` | Коэффициенты качества |
| `PerformanceMetrics.Beta` / `Alpha` / `TrackingError` / `InformationRatio` | Относительно эталона |
| `PerformanceMetrics.Drawdowns` | Ряд просадок для графика |

Исходники: `src/AI.Economics/Portfolio/PortfolioMetrics.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Portfolio;
using AI.Statistics;

Random rnd = RandomEngine.Create(21);
var market = new Vector(120);
var strategy = new Vector(120);

for (int i = 0; i < market.Count; i++)
{
    double factor = RandomEngine.NextGaussian(rnd, 0.008, 0.042);
    market[i] = factor;

    // Стратегия с бетой 1,2 и небольшой альфой
    strategy[i] = 0.002 + (1.2 * factor) + RandomEngine.NextGaussian(rnd, 0, 0.018);
}

PerformanceMetrics metrics = PortfolioMetrics.Compute(
    strategy, benchmark: market, riskFreeRate: 0.06,
    periodsPerYear: 12, omegaThreshold: 0, portfolio: "Активная стратегия");

Console.WriteLine($"Годовая доходность {metrics.AnnualReturn:P2} при волатильности {metrics.Volatility:P2}");
Console.WriteLine($"Шарп {metrics.Sharpe:F2}, Сортино {metrics.Sortino:F2}, Кальмар {metrics.Calmar:F2}");
Console.WriteLine($"Омега {metrics.Omega:F2}, доля прибыльных периодов {metrics.HitRate:P1}");
```

Просадка — то, о чём инвестор спрашивает первым:

```csharp
Console.WriteLine($"Максимальная просадка {metrics.MaxDrawdown:P1}, " +
                  $"длилась {metrics.MaxDrawdownLength} периодов");
Console.WriteLine($"Восстановление заняло {metrics.RecoveryPeriods} периодов");

(Vector drawdowns, double worst, int length, int recovery) = PortfolioMetrics.DrawdownProfile(strategy);
Console.WriteLine($"Периодов в просадке глубже 10%: {drawdowns.Count(d => d > 0.10)}");
```

Метрики относительно эталона отвечают на вопрос, за что платят управляющему:

```csharp
if (metrics.HasBenchmark)
{
    Console.WriteLine($"Бета {metrics.Beta:F2}, альфа {metrics.Alpha:P2} годовых");
    Console.WriteLine($"Ошибка следования {metrics.TrackingError:P2}, " +
                      $"информационный коэффициент {metrics.InformationRatio:F2}");
}

Console.WriteLine(metrics.Interpret().ToLlmText());
```

## Ограничения

- Шарп оценивается со стандартной ошибкой около $\sqrt{(1+0{,}5\,S^2)/n}$.
  На трёх годах месячных данных различие между Шарпом 0,8 и 1,3 статистически
  незначимо — а именно на нём строятся решения о выборе фонда.
- Все коэффициенты предполагают независимость доходностей. Сглаженные оценки
  неликвидных активов (недвижимость, частный капитал) занижают волатильность
  и завышают Шарп в разы.
- Максимальная просадка зависит от длины истории: чем дольше наблюдаем, тем
  глубже найденная просадка. Сравнивать её можно только на одинаковых окнах.
- Альфа и бета оценены по одному фактору. Стратегия, зарабатывающая на
  стоимости или размере, покажет ложную альфу — нужна
  [многофакторная модель](factor_model.md).
- Годовое приведение через $\sqrt{m}$ корректно лишь при отсутствии
  автокорреляции. Для трендовых стратегий оно завышает волатильность.
