# Векторная авторегрессия

Совместная модель нескольких временных рядов: причинность по Гренджеру,
функции отклика на импульс с разложением Холецкого и разложение дисперсии
ошибки прогноза.

## Постановка задачи

Дано: несколько взаимосвязанных стационарных рядов — продажи и реклама, цена
и объём, ставка и инфляция.

Требуется: модель их совместной динамики, ответ на вопрос «кто на кого
влияет», оценка реакции системы на шок и разложение неопределённости прогноза
по источникам.

Где встречается: анализ трансмиссии рекламы в продажи, макроэкономические
сценарии, взаимное влияние цен на связанных рынках, оценка задержки эффекта.

## Теория

**Модель.** Каждый ряд объясняется лагами всех рядов системы:

$$
y_t \;=\; c + A_1 y_{t-1} + \dots + A_p y_{t-p} + \varepsilon_t,
\qquad \mathbb E[\varepsilon_t\varepsilon_t^{\top}] = \Sigma .
$$

Уравнения оцениваются раздельным МНК: поскольку в правой части у всех
уравнений одни и те же регрессоры, обобщённый МНК совпадает с обычным.

**Выбор порядка** по информационным критериям. AIC склонен переоценивать
порядок, BIC — недооценивать; для прогнозирования обычно берут AIC, для
структурного анализа — BIC.

**Устойчивость.** Система устойчива, если все корни характеристического
уравнения лежат внутри единичного круга, то есть спектральный радиус
сопровождающей матрицы меньше единицы. Неустойчивая система даёт расходящиеся
прогнозы и бессмысленные отклики.

**Причинность по Гренджеру** — не причинность в философском смысле, а
проверка прогнозной полезности: улучшают ли лаги ряда $x$ прогноз ряда $y$
сверх собственных лагов $y$. Проверяется F-тестом на совместную незначимость
соответствующих коэффициентов. Двусторонняя причинность встречается часто и
означает обратную связь.

**Функции отклика на импульс** показывают реакцию системы на единичный шок.
Проблема в том, что шоки $\varepsilon_t$ коррелированы, и «шок только в
первом ряду» — не наблюдаемое событие. Разложение Холецкого
$\Sigma = PP^{\top}$ ортогонализует их, но результат **зависит от порядка
переменных**: первая переменная влияет на все мгновенно, последняя — ни на
кого. Порядок задаётся содержательно: медленнее реагирующие переменные
ставятся раньше.

**Разложение дисперсии ошибки прогноза** отвечает, какая доля
неопределённости прогноза каждой переменной на горизонте $h$ порождена шоками
каждой из переменных. Доли суммируются в единицу по строке.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(k(np)^2 + (kp)^3)$ | $k$ рядов, $p$ лагов |
| Память | $O(nkp)$ | матрица лагов |

## API

| Метод | Описание |
|-------|----------|
| `VectorAutoregression.Fit(data, order, names)` | Оценка системы и тесты Гренджера |
| `VectorAutoregression.SelectOrder(data, maxOrder, names)` | Выбор порядка по критериям |
| `VectorAutoregression.ImpulseResponse(result, horizon)` | Отклики `[шок][переменная][шаг]` |
| `VectorAutoregression.VarianceDecomposition(result, horizon)` | Разложение дисперсии |
| `VarResult.Granger` | Тесты причинности по всем парам |
| `VarResult.SpectralRadius` / `IsStable` | Устойчивость системы |

Исходники: `src/AI.Economics/Econometrics/VectorAutoregression.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Econometrics;
using AI.Statistics;

Random rng = RandomEngine.Create(167);
int n = 600;

var data = new Matrix(n, 2);
double advertising = 0, sales = 0;

for (int t = 0; t < n; t++)
{
    // Реклама влияет на продажи, обратной связи нет
    double nextAdvertising = (0.6 * advertising) + RandomEngine.NextGaussian(rng, 0, 0.5);
    double nextSales = (0.3 * sales) + (0.7 * advertising) + RandomEngine.NextGaussian(rng, 0, 0.5);

    advertising = nextAdvertising;
    sales = nextSales;

    data[t, 0] = advertising;
    data[t, 1] = sales;
}

VarResult varModel = VectorAutoregression.Fit(data, order: 1, names: ["реклама", "продажи"]);

Console.WriteLine($"Наблюдений {varModel.Observations}, порядок {varModel.Order}");
Console.WriteLine($"Спектральный радиус {varModel.SpectralRadius:F4} — " +
                  (varModel.IsStable ? "система устойчива" : "система неустойчива"));
Console.WriteLine($"AIC {varModel.Aic:F2}, BIC {varModel.Bic:F2}");

foreach (GrangerTest test in varModel.Granger)
{
    Console.WriteLine($"{test.From} → {test.To}: F = {test.FStatistic:F2}, " +
                      $"p = {test.PValue:F5} — " +
                      (test.Causes ? "лаги улучшают прогноз" : "улучшения нет"));
}
```

Порядок модели подбирается по критериям, а не по интуиции:

```csharp
VarResult selected = VectorAutoregression.SelectOrder(data, maxOrder: 4, names: ["реклама", "продажи"]);
Console.WriteLine($"Выбранный порядок {selected.Order} (AIC {selected.Aic:F2})");
```

Функции отклика — главный результат для управленческого решения:

```csharp
double[][][] responses = VectorAutoregression.ImpulseResponse(varModel, horizon: 15);

Console.WriteLine("Отклик продаж на шок рекламы:");
for (int h = 0; h < 8; h++)
    Console.WriteLine($"  через {h} периодов: {responses[0][1][h]:F4}");

double cumulative = responses[0][1].Sum();
Console.WriteLine($"Накопленный отклик {cumulative:F4}");

Matrix decomposition = VectorAutoregression.VarianceDecomposition(varModel, horizon: 15);

for (int i = 0; i < varModel.Variables.Count; i++)
{
    Console.WriteLine($"Дисперсия прогноза {varModel.Variables[i]}: " +
                      string.Join(", ", Enumerable.Range(0, varModel.Variables.Count)
                          .Select(j => $"{decomposition[i, j]:P1} от шока {varModel.Variables[j]}")));
}

Console.WriteLine(varModel.Interpret().ToLlmText());
```

## Ограничения

- Ряды должны быть стационарны. Для нестационарных рядов VAR в уровнях даёт
  ложные связи, а VAR в разностях теряет долгосрочную информацию — тогда
  нужна [модель коррекции ошибок](cointegration.md).
- Число параметров растёт как $k^2p$. Система из пяти рядов с четырьмя лагами
  требует сотни наблюдений на уравнение; иначе модель переобучена.
- Отклики зависят от порядка переменных в разложении Холецкого. Всегда
  показывайте результат при альтернативном порядке — если выводы меняются,
  структурная интерпретация невозможна без дополнительных ограничений.
- Причинность по Гренджеру не есть причинность. Переменная, опережающая
  другую, может быть их общим предвестником, а не причиной.
- Пропущенная переменная искажает всю систему сразу. Отсутствие важного
  фактора порождает ложные связи между включёнными.
