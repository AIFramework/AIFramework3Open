# Регрессия Кокса

Модель пропорциональных рисков: какие признаки клиента ускоряют его уход, во
сколько раз и кто из действующих клиентов сейчас в зоне риска.

## Постановка задачи

Дано: наблюдения дожития клиентов с цензурированием и набор признаков —
интенсивность использования продукта, число обращений в поддержку, тариф,
размер компании.

Требуется: отношения рисков по каждому признаку с доверительными интервалами,
индивидуальная кривая дожития и ранжирование действующих клиентов по риску.

Где встречается: приоритизация работы отдела удержания, поиск причин оттока,
оценка эффекта продуктовых изменений на срок жизни.

## Теория

Модель задаёт интенсивность ухода клиента как базовую, умноженную на множитель
от признаков:

$$
h(t \mid x) \;=\; h_0(t)\, e^{\beta^{\mathsf T} x}.
$$

Базовая интенсивность $h_0(t)$ остаётся непараметрической — форму кривой оттока
угадывать не нужно, оцениваются только относительные эффекты. В этом
устойчивость метода.

Коэффициенты оцениваются максимизацией частичного правдоподобия. В приближении
Бреслоу для совпадающих моментов событий:

$$
\ln L(\beta) \;=\; \sum_{j} \left[ \sum_{i \in D_j} \beta^{\mathsf T} x_i
\;-\; d_j \ln \sum_{i \in R_j} e^{\beta^{\mathsf T} x_i} \right],
$$

где $D_j$ — множество ушедших в момент $t_j$, $R_j$ — множество под риском.
Максимум ищется методом Ньютона — Рафсона; обратная информационная матрица даёт
стандартные ошибки.

Экспонента коэффициента — отношение рисков: $e^{\beta} = 2$ означает удвоение
мгновенной интенсивности оттока при росте признака на единицу.

Базовый накопленный риск оценивается по Бреслоу, и отсюда индивидуальная кривая
дожития:

$$
\hat H_0(t) = \sum_{t_j \le t} \frac{d_j}{\sum_{i \in R_j} e^{\beta^{\mathsf T} x_i}},
\qquad
\hat S(t \mid x) = \exp\!\left(-\hat H_0(t)\, e^{\beta^{\mathsf T} x}\right).
$$

Качество ранжирования измеряется индексом конкордации Харрелла — долей
сравнимых пар, в которых клиент с большим риском действительно ушёл раньше.
Значение 0,5 означает предсказание не лучше монетки.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I \cdot n \cdot p^2)$ | $I$ — итераций Ньютона, $p$ — признаков |
| Память | $O(n \cdot p)$ | Матрица признаков |

Индекс конкордации считается за $O(n^2)$ и на выборках свыше десятков тысяч
наблюдений заметно дороже самой подгонки.

## API

| Метод | Описание |
|-------|----------|
| `CoxProportionalHazards.Fit(data, names, maxIterations, tolerance)` | Оценка коэффициентов |
| `Coefficients` | Оценки, стандартные ошибки, отношения рисков, p-значения |
| `RiskScore(covariates)` | Линейный предиктор — логарифм относительного риска |
| `PredictSurvival(covariates)` | Индивидуальная кривая дожития |
| `BaselineCumulativeHazard` | Базовый накопленный риск по Бреслоу |
| `ConcordanceIndex` | Качество ранжирования клиентов по риску |

Исходник: `src/AI.Economics/Survival/CoxProportionalHazards.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Survival;

var random = new Random(11);
var data = new List<SurvivalRecord>();

for (int i = 0; i < 400; i++)
{
    double usage = random.NextDouble();
    double tickets = Math.Round(random.NextDouble() * 4) / 4.0;

    double rate = 0.05 * Math.Exp((-1.2 * usage) + (0.8 * tickets));
    double lifetime = -Math.Log(1.0 - random.NextDouble()) / rate;

    data.Add(new SurvivalRecord
    {
        Id = $"c{i:D3}",
        Time = Math.Min(lifetime, 24),
        Event = lifetime <= 24,
        Covariates = new Vector(usage, tickets),
    });
}

var cox = new CoxProportionalHazards();
cox.Fit(data, ["Использование", "Обращения"]);

foreach (CoxCoefficient coefficient in cox.Coefficients)
{
    Console.WriteLine($"{coefficient.Name,-16} HR={coefficient.HazardRatio:F2} " +
                      $"[{coefficient.HazardRatioLower:F2}; {coefficient.HazardRatioUpper:F2}] " +
                      $"p={coefficient.PValue:F4}");
}

Console.WriteLine($"C-index: {cox.ConcordanceIndex:F3}");

Vector risky = cox.PredictSurvival(new Vector(0.1, 1.0));
Vector safe = cox.PredictSurvival(new Vector(0.9, 0.0));
Console.WriteLine($"Дожитие к концу наблюдения: риск {risky[risky.Count - 1]:P1}, норма {safe[safe.Count - 1]:P1}");
```

## Ограничения

- Название модели содержит её главное допущение: риски пропорциональны, то есть
  отношение интенсивностей между двумя клиентами постоянно во времени. Если
  признак работает только в первые месяцы, оценка усредняет эффект и занижает
  его.
- При полном разделении данных (признак безошибочно предсказывает, кто уйдёт
  раньше) частичное правдоподобие монотонно, и оценка уходит в бесконечность.
  Реализация демпфирует шаг Ньютона, но коэффициент и его стандартная ошибка в
  таком случае интерпретации не подлежат.
- Коэффициенты отражают связь, а не причину. Рост числа обращений в поддержку
  перед уходом — симптом, и «запретить обращения» отток не снизит.
- Признаки берутся на момент входа в наблюдение; изменяющиеся во времени
  ковариаты не поддерживаются.
