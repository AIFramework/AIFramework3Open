# Теория экстремальных значений: метод превышений порога

Обобщённое распределение Парето для хвоста убытков: оценка формы и масштаба,
квантили далеко за пределами выборки и условные потери, устойчивые к
предположению о нормальности.

## Постановка задачи

Дано: ряд доходностей и высокий порог убытка (например, 95-й перцентиль).

Требуется: оценка вероятности потерь, которых в выборке не было, — квантили
уровня 99,5% и 99,9% и соответствующие условные потери, а также ответ на
вопрос, конечны ли у распределения среднее и дисперсия.

Где встречается: капитал на покрытие катастрофических убытков,
перестрахование, лимиты на редкие события, обоснование запаса прочности
перед регулятором, оценка операционного риска.

## Теория

Нормальное распределение отводит событию «минус десять сигм» вероятность
$10^{-23}$ — раз в возрасте Вселенной. На финансовых рынках такие дни
случаются раз в десятилетие. Теория экстремальных значений описывает хвост
напрямую, не делая предположений о центре распределения.

**Теорема Пикандса — Балкемы — де Хаана.** Для широкого класса распределений
превышения над достаточно высоким порогом $u$ сходятся к обобщённому
распределению Парето:

$$
\Pr(X - u \le y \mid X > u) \;\to\; 1 - \left(1 + \frac{\xi y}{\beta}\right)^{-1/\xi},
\qquad y > 0 .
$$

Форма важнее масштаба. Параметр $\xi$ определяет тип хвоста: $\xi > 0$ —
степенной (тяжёлый, как у финансовых рядов), $\xi = 0$ — экспоненциальный,
$\xi < 0$ — конечный. Все финансовые данные дают $\xi$ в диапазоне 0,1–0,4.

**Квантиль хвоста** выводится в замкнутом виде:

$$
\mathrm{VaR}_\alpha \;=\; u + \frac{\beta}{\xi}\left[\left(\frac{n}{N_u}(1-\alpha)\right)^{-\xi} - 1\right],
$$

где $N_u$ — число превышений из $n$ наблюдений. Условные потери получаются
из свойства «отсутствия памяти» распределения Парето:

$$
\mathrm{ES}_\alpha \;=\; \frac{\mathrm{VaR}_\alpha + \beta - \xi u}{1 - \xi},\qquad \xi < 1 .
$$

**Моменты.** Среднее конечно при $\xi < 1$, дисперсия — при $\xi < 1/2$.
Оценка $\xi > 0{,}5$ означает, что выборочная дисперсия не сходится и все
основанные на ней метрики (волатильность, Шарп, параметрический VaR)
бессмысленны.

**Выбор порога** — компромисс: слишком низкий нарушает предельную теорему и
смещает оценку, слишком высокий оставляет мало наблюдений и раздувает
дисперсию. Практическое правило — 5–10% выборки; проверяется графиком
среднего превышения, который должен быть линеен выше правильного порога.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n\log n + I N_u)$ | сортировка и $I$ итераций оптимизации |
| Память | $O(n)$ | ряд и превышения |

## API

| Метод | Описание |
|-------|----------|
| `ExtremeValue.Fit(returns, thresholdQuantile, levels, series)` | Оценка хвоста и квантили |
| `ExtremeValue.TailQuantile(threshold, shape, scale, rate, confidence)` | Квантиль по параметрам |
| `ExtremeValue.MeanExcessPlot(returns, points)` | График среднего превышения для выбора порога |
| `ExtremeValueResult.Shape` / `Scale` | Параметры $\xi$ и $\beta$ |
| `ExtremeValueResult.TailQuantiles` | VaR и ES по уровням доверия |
| `ExtremeValueResult.HasFiniteMean` / `HasFiniteVariance` | Существуют ли моменты |

Исходники: `src/AI.Economics/Risk/ExtremeValue.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Risk;
using AI.Statistics;

Random generator = RandomEngine.Create(5);
var series = new Vector(2000);

for (int i = 0; i < series.Count; i++)
{
    // Стьюдент с четырьмя степенями свободы — реалистичный тяжёлый хвост
    double z = RandomEngine.NextGaussian(generator);
    double chi = 0;
    for (int k = 0; k < 4; k++)
    {
        double g = RandomEngine.NextGaussian(generator);
        chi += g * g;
    }

    series[i] = 0.0005 + (0.012 * z / Math.Sqrt(chi / 4));
}

ExtremeValueResult tail = ExtremeValue.Fit(
    series, thresholdQuantile: 0.95, confidenceLevels: [0.99, 0.995, 0.999], series: "Убытки книги");

Console.WriteLine($"Порог {tail.Threshold:P2}, превышений {tail.Exceedances} " +
                  $"({tail.ExceedanceRate:P1} выборки)");
Console.WriteLine($"Форма ξ = {tail.Shape:F3}, масштаб β = {tail.Scale:F4}");
Console.WriteLine($"Среднее {(tail.HasFiniteMean ? "конечно" : "не существует")}, " +
                  $"дисперсия {(tail.HasFiniteVariance ? "конечна" : "не существует")}");
```

Сравнение с эмпирическими квантилями показывает, где заканчиваются данные и
начинается экстраполяция:

```csharp
foreach ((double confidence, double var, double shortfall) in tail.TailQuantiles)
{
    double empirical = tail.EmpiricalQuantiles
        .FirstOrDefault(q => Math.Abs(q.Confidence - confidence) < 1e-9).Empirical;

    Console.WriteLine($"{confidence:P1}: модель VaR {var:P2}, ES {shortfall:P2}, " +
                      $"эмпирика {empirical:P2}");
}
```

График среднего превышения помогает выбрать порог: он должен стать линейным:

```csharp
foreach ((double threshold, double meanExcess) in ExtremeValue.MeanExcessPlot(series, 12))
    Console.WriteLine($"Порог {threshold:P2}: среднее превышение {meanExcess:P3}");

Console.WriteLine(tail.Interpret().ToLlmText());
```

## Ограничения

- Оценка $\xi$ на 100 превышениях имеет стандартную ошибку порядка 0,1. Это
  значит, что квантиль уровня 99,9% определён с точностью до десятков
  процентов — сообщайте его как диапазон.
- Результат чувствителен к выбору порога сильнее, чем к методу оценки.
  Проверяйте устойчивость: сдвиг порога с 95-го на 97-й перцентиль не должен
  менять $\xi$ вдвое.
- Метод предполагает независимость превышений. Финансовые убытки приходят
  кластерами, поэтому эффективное число наблюдений меньше номинального, а
  доверительные интервалы шире расчётных.
- Экстраполяция за пределы выборки правомерна на порядок по вероятности, но
  не на три. Уровень 99,99% по двум тысячам наблюдений — это уже вера в
  модель, а не оценка.
- Модель описывает хвост в стационарном режиме. Структурный сдвиг —
  смена регулирования, изменение состава портфеля — обнуляет её применимость.
