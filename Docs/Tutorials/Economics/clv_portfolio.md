# CLV портфеля

Сборка пожизненной ценности из двух моделей — числа покупок и их размера — с
дисконтированием по шагам и разбором концентрации ценности.

## Постановка задачи

Дано: сводки RFM по клиентам, обученная модель частоты покупок (BG/NBD либо
Pareto/NBD) и модель среднего чека (Gamma-Gamma).

Требуется: дисконтированная ценность каждого клиента на заданном горизонте,
суммарная ценность портфеля и оценка того, насколько неравномерно она
распределена.

Где встречается: бюджет программы удержания, приоритизация клиентов для
персонального менеджера, оценка клиентской базы при продаже компании.

## Теория

Ценность клиента складывается из трёх независимо оцениваемых частей:

$$
CLV \;=\; \sum_{k=1}^{K} \Delta E[Y(t_k)] \cdot E[M \mid x, \bar m] \cdot g \cdot (1+d)^{-k},
$$

где $\Delta E[Y(t_k)]$ — прирост ожидаемого числа покупок на шаге $k$,
$E[M]$ — ожидаемый чек из модели Gamma-Gamma, $g$ — доля маржи, $d$ — ставка
дисконтирования за шаг.

Разделение частоты и суммы не техническая деталь: этими величинами управляют
разные механизмы, и их независимость — то самое допущение Gamma-Gamma, которое
надо проверять на данных.

Дисконтирование ведётся по шагам, а не разом на конец горизонта. Покупка на
24-м месяце стоит сегодня заметно меньше покупки на первом, и при ставке 1 % в
месяц разница между двумя способами превышает десятую часть результата.

Концентрация ценности измеряется долей суммарного CLV, приходящейся на верхний
дециль клиентов. Значение сильно выше 0,1 означает, что равномерная скидка всем
клиентам оплачивается прибылью небольшой группы — и бюджет удержания надо
тратить адресно.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n \cdot K)$ | $n$ — клиентов, $K$ — шагов дисконтирования |
| Память | $O(n)$ | Результат по каждому клиенту |

## API

| Метод | Описание |
|-------|----------|
| `ClvCalculator.Compute(freq, money, customers, horizon, steps, discount, margin)` | Расчёт по портфелю |
| `ClvPortfolio.Customers` | Клиенты, отсортированные по убыванию CLV |
| `ClvPortfolio.TotalClv` | Суммарная дисконтированная ценность |
| `ClvPortfolio.Top10PercentShare` | Доля ценности у верхнего дециля |
| `ITransactionModel` | Общий интерфейс BG/NBD и Pareto/NBD |

Исходник: `src/AI.Economics/Clv/ClvCalculator.cs`.

## Код

```csharp
using AI.Economics.Clv;

var random = new Random(11);
var customers = new List<CustomerSummary>();

for (int i = 0; i < 500; i++)
{
    bool loyal = random.NextDouble() < 0.6;
    double age = 18;

    customers.Add(new CustomerSummary
    {
        Id = $"c{i:D3}",
        Frequency = loyal ? 4 + random.Next(12) : random.Next(3),
        Recency = loyal ? age * (0.7 + (random.NextDouble() * 0.3)) : age * random.NextDouble() * 0.4,
        Age = age,
        MonetaryValue = 2_000 + (random.NextDouble() * 8_000),
    });
}

var frequency = new BgNbdModel();
frequency.Fit(customers);

var monetary = new GammaGammaModel();
monetary.Fit(customers);

ClvPortfolio portfolio = ClvCalculator.Compute(
    frequency, monetary, customers,
    horizon: 12, steps: 12, discountRatePerStep: 0.01, marginRate: 0.4);

Console.WriteLine($"CLV портфеля: {portfolio.TotalClv:N0}");
Console.WriteLine($"Средний CLV:  {portfolio.MeanClv:N0}");
Console.WriteLine($"Верхние 10 %: {portfolio.Top10PercentShare:P1} всей ценности");

foreach (CustomerClv top in portfolio.Customers.Take(5))
{
    Console.WriteLine($"{top.Id}: P(жив)={top.ProbabilityAlive:P0}  " +
                      $"покупок={top.ExpectedTransactions:F1}  CLV={top.Clv:N0}");
}
```

## Ограничения

- Обе модели обучаются на исторических данных и предполагают неизменность
  условий. Смена ассортимента, цен или каналов делает прогноз недействительным.
- Маржа задаётся одним числом на весь портфель. Если она различается по
  товарным группам, считайте CLV по сегментам отдельно.
- Дисконтирование по шагам требует, чтобы `steps` соответствовал единице
  времени моделей: при горизонте в 12 месяцев и месячной ставке `steps = 12`.
- Прогноз не учитывает будущие маркетинговые воздействия: это оценка
  «если ничего не делать», база для сравнения, а не план.
