# Когортная матрица

Треугольник «когорта × возраст» и сводная кривая удержания, построенная без
смещения от ещё не наступивших наблюдений.

## Постановка задачи

Дано: клиенты, сгруппированные по месяцу привлечения, и число активных в каждой
когорте по месяцам её жизни.

Требуется: кривая удержания каждой когорты, корректная сводная кривая и
понимание, сколько данных стоит за каждой её точкой.

Где встречается: ежемесячный когортный отчёт, сравнение качества привлечения
между периодами, подготовка данных для подгонки кривой.

## Теория

Когортная матрица треугольна: когорта, привлечённая месяц назад, физически не
может иметь наблюдения на возрасте двенадцати месяцев. Такие ячейки помечаются
как непронаблюдённые (`NaN`), и это не формальность.

Правильная сводная кривая суммирует по каждому возрасту только те когорты,
которые до него дожили:

$$
S(t) \;=\; \frac{\sum_{c \,\in\, O_t} n_{c,t}}{\sum_{c \,\in\, O_t} n_{c,0}},
\qquad
O_t = \{ c : \text{когорта } c \text{ пронаблюдена в возрасте } t \}.
$$

Ошибка, встречающаяся в большинстве самодельных отчётов, — суммировать по всем
когортам, считая пустые ячейки нулями:

$$
\tilde S(t) \;=\; \frac{\sum_{c} n_{c,t} \cdot [c \in O_t]}{\sum_{c} n_{c,0}}
\;\le\; S(t).
$$

Знаменатель включает молодые когорты, числитель — нет, и кривая «обваливается»
на длинных возрастах просто из-за нехватки данных. При быстром росте компании
эффект особенно силён: молодые когорты крупнее старых и сильнее тянут
знаменатель вниз.

Второй важный показатель — база наблюдений $\sum_{c \in O_t} n_{c,0}$. Она
падает с возрастом, и именно она, а не общее число клиентов, определяет
надёжность правого конца кривой.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(C \cdot A)$ | $C$ — когорт, $A$ — возрастов |
| Память | $O(C \cdot A)$ | Хранение матрицы |

## API

| Метод | Описание |
|-------|----------|
| `new CohortMatrix(Matrix)` | Матрица «когорта × возраст»; `NaN` — не пронаблюдено |
| `CohortMatrix.Triangular(Matrix)` | Обрезает прямоугольную матрицу до треугольника |
| `PooledRetention()` | Сводная кривая без смещения |
| `ObservationBase()` | Сколько клиентов стоит за каждой точкой кривой |
| `EffectiveCohortSize()` | Консервативный размер когорты для подгонки |
| `RetentionOf(cohort)` | Кривая одной когорты |
| `RetentionMatrix()` | Матрица долей; непронаблюдённое остаётся `NaN` |

Исходник: `src/AI.Economics/Cohorts/CohortMatrix.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Cohorts;

var counts = new Matrix(4, 4);
double[] shape = [1.00, 0.58, 0.47, 0.42];

for (int cohort = 0; cohort < 4; cohort++)
{
    double size = 500 * Math.Pow(1.1, cohort);
    for (int age = 0; age < 4; age++) counts[cohort, age] = Math.Round(size * shape[age]);
}

CohortMatrix matrix = CohortMatrix.Triangular(counts);

Vector pooled = matrix.PooledRetention();
Vector observations = matrix.ObservationBase();

for (int age = 0; age < pooled.Count; age++)
    Console.WriteLine($"возраст {age}: удержание {pooled[age]:P1}, база {observations[age]:N0}");

Console.WriteLine($"Эффективный размер когорты: {matrix.EffectiveCohortSize():N0}");
```

Сводная кривая напрямую подаётся в подгонку:

```csharp
RetentionFitResult fit = RetentionFitter.Fit(
    pooled, matrix.EffectiveCohortSize(), RetentionModel.ShiftedBetaGeometric, horizon: 24);

Console.WriteLine($"Ожидаемый срок жизни: {fit.ExpectedLifetime:F1} мес.");
```

## Ограничения

- Матрица считает клиента активным или неактивным; частичное снижение выручки
  она не отражает. Для денежного удержания используйте
  [MRR-мостик](mrr_bridge.md).
- Возвраты клиентов (реактивация) в модели не предусмотрены: вернувшийся клиент
  ломает монотонность строки.
- Сводная кривая корректна при однородности когорт. Если качество привлечения
  дрейфует, усреднение по когортам скрывает тренд — сравнивайте строки
  напрямую.
- `EffectiveCohortSize()` берёт базу самого старшего возраста и потому
  консервативен: доверительные интервалы подгонки получатся скорее широкими,
  чем узкими.
