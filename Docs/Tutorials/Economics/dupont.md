# Разложение Дюпона

Рентабельность собственного капитала как произведение маржи, оборачиваемости и
рычага — и точный вклад каждого множителя в её изменение за период.

## Постановка задачи

Дано: отчётность компании за два периода.

Требуется: понять, из чего складывается доходность собственника — из маржи, из
скорости оборота или из долга, — и какой именно множитель объясняет изменение
рентабельности капитала за год.

Где встречается: разбор результатов на совете директоров, сравнение компаний с
одинаковой рентабельностью, но разными бизнес-моделями, обоснование программы
повышения эффективности.

## Теория

**Трёхфакторная модель** раскладывает рентабельность капитала на маржу,
оборачиваемость активов и финансовый рычаг:

$$
\mathrm{ROE} \;=\; \underbrace{\frac{\mathrm{NI}}{\mathrm{Revenue}}}_{\text{маржа}}
\cdot \underbrace{\frac{\mathrm{Revenue}}{\mathrm{Assets}}}_{\text{оборачиваемость}}
\cdot \underbrace{\frac{\mathrm{Assets}}{\mathrm{Equity}}}_{\text{рычаг}} .
$$

**Пятифакторная** дополнительно отделяет налоговое и процентное бремя от
операционной эффективности:

$$
\mathrm{ROE} \;=\;
\frac{\mathrm{NI}}{\mathrm{EBT}}\cdot
\frac{\mathrm{EBT}}{\mathrm{EBIT}}\cdot
\frac{\mathrm{EBIT}}{\mathrm{Revenue}}\cdot
\frac{\mathrm{Revenue}}{\mathrm{Assets}}\cdot
\frac{\mathrm{Assets}}{\mathrm{Equity}} .
$$

Это разделение принципиально. Первый множитель говорит о налоговом режиме,
второй — о цене долга, третий — о собственно операционной эффективности. Рост
рентабельности за счёт второго множителя (снижение процентного бремени) и за
счёт третьего (рост операционной маржи) — совершенно разные новости, хотя в
трёхфакторной модели они сливаются в один показатель.

**Вклад в изменение** считается методом последовательной подстановки:
множители заменяются на новые значения по одному, и прирост произведения на
каждом шаге относится к соответствующему фактору:

$$
\Delta_j \;=\; \prod_{i<j} f_i^{\text{new}} \cdot f_j^{\text{new}} \prod_{i>j} f_i^{\text{old}}
\;-\;
\prod_{i<j} f_i^{\text{new}} \cdot f_j^{\text{old}} \prod_{i>j} f_i^{\text{old}} .
$$

Сумма вкладов точно равна изменению рентабельности, что делает разложение
пригодным для управленческой отчётности. Плата за точность — зависимость от
порядка подстановки: перестановка множителей слегка меняет распределение
вкладов между ними при неизменной сумме.

Практический вывод, ради которого разложение и делается: одинаковая
рентабельность капитала у двух компаний может означать совершенно разные
бизнес-модели и совершенно разный риск. Высокий рычаг повышает и доходность, и
чувствительность к падению выручки, поэтому такие компании сопоставимы только
по рентабельности активов или инвестированного капитала.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(k^2)$ | $k=5$ множителей, подстановка с пересчётом произведения |
| Память | $O(k)$ | множители и вклады |

## API

| Метод | Описание |
|-------|----------|
| `DuPontAnalysis.Analyze(current, previous)` | Трёх- и пятифакторное разложение |
| `DuPontResult.ThreeFactor` / `FiveFactor` | Множители со значениями и вкладами |
| `DuPontResult.Change` | Изменение рентабельности капитала за период |
| `DuPontFactor.Contribution` | Вклад множителя в изменение |
| `DuPontFactor.RelativeChange` | Относительное изменение самого множителя |

Исходники: `src/AI.Economics/Statements/DuPontAnalysis.cs`.

## Код

```csharp
using AI.Economics.Statements;

var current = new FinancialStatement
{
    Company = "Компания", Period = "2024",
    TotalAssets = 1_000_000_000, CurrentAssets = 450_000_000,
    Cash = 80_000_000, AccountsReceivable = 180_000_000, Inventory = 150_000_000,
    PropertyPlantEquipment = 500_000_000, IntangibleAssets = 50_000_000,
    TotalLiabilities = 480_000_000, CurrentLiabilities = 240_000_000,
    AccountsPayable = 150_000_000, ShortTermDebt = 90_000_000, LongTermDebt = 240_000_000,
    RetainedEarnings = 312_000_000,
    Revenue = 1_000_000_000, CostOfGoodsSold = 600_000_000,
    OperatingExpenses = 180_000_000, Depreciation = 50_000_000,
    InterestExpense = 42_900_000, IncomeTax = 25_400_000, NetIncome = 101_700_000,
    OperatingCashFlow = 140_000_000, CapitalExpenditures = 60_000_000,
};

FinancialStatement previous = current with
{
    Period = "2023",
    Revenue = 870_000_000, CostOfGoodsSold = 530_000_000,
    OperatingExpenses = 165_000_000, Depreciation = 45_000_000,
    InterestExpense = 45_000_000, IncomeTax = 17_000_000, NetIncome = 67_000_000,
    TotalAssets = 900_000_000, TotalLiabilities = 460_000_000,
};

DuPontResult dupont = DuPontAnalysis.Analyze(current, previous);

Console.WriteLine($"ROE: {dupont.PreviousReturnOnEquity:P2} → {dupont.ReturnOnEquity:P2} " +
                  $"(изменение {dupont.Change:P2})");
```

Пятифакторное разложение показывает, какой именно множитель двинул результат:

```csharp
foreach (DuPontFactor factor in dupont.FiveFactor)
{
    Console.WriteLine($"{factor.Name}: {factor.Previous:F3} → {factor.Value:F3}, " +
                      $"вклад {factor.Contribution:P2} ({factor.Meaning})");
}

double total = dupont.FiveFactor.Sum(f => f.Contribution);
Console.WriteLine($"Сумма вкладов {total:P2} — совпадает с изменением по построению");
```

Трёхфакторная версия короче и подходит для регулярной отчётности:

```csharp
foreach (DuPontFactor factor in dupont.ThreeFactor)
    Console.WriteLine($"{factor.Name}: {factor.Value:F3} (вклад {factor.Contribution:P2})");

Console.WriteLine(dupont.Interpret().ToLlmText());
```

## Ограничения

- Разложение мультипликативно, поэтому вклады зависят от порядка подстановки.
  Сумма при любом порядке равна изменению, но распределение между множителями
  сдвигается — сравнивать вклады между периодами можно только при одинаковом
  порядке.
- При отрицательном собственном капитале рентабельность капитала не
  интерпретируется, и расчёт отклоняет такие данные.
- Модель работает с балансовыми остатками на конец периода. Для компаний с
  сильным ростом внутри года точнее использовать средние остатки, как в
  [коэффициентном анализе](financial_ratios.md).
- Высокий рычаг делает рентабельность капитала плохой метрикой сравнения:
  сопоставлять такие компании нужно по рентабельности активов.
- Разложение объясняет арифметику изменения, но не его причину. Ответ на
  вопрос «почему упала маржа» лежит вне отчётности.
