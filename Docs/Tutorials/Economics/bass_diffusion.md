# Диффузия Басса

Модель проникновения продукта на рынок: подгонка коэффициентов инновации и
имитации по истории продаж и прогноз момента, после которого поток новых
клиентов начнёт падать сам.

## Постановка задачи

Дано: накопленное число принявших продукт по месяцам за короткий период
наблюдений.

Требуется: потенциал рынка, коэффициенты диффузии, прогноз на длинном
горизонте и момент пика продаж.

Где встречается: планирование найма и производства, прогноз выручки нового
продукта, проверка гипотезы о размере рынка фактическими продажами.

## Теория

Модель делит покупателей на две группы. Новаторы принимают продукт независимо
от других с интенсивностью $p$; имитаторы — под влиянием уже принявших, с
интенсивностью, пропорциональной их доле, коэффициент $q$:

$$
\frac{dN}{dt} \;=\; \left( p + q\,\frac{N(t)}{m} \right)\bigl(m - N(t)\bigr).
$$

Решение даёт S-образную кривую:

$$
N(t) \;=\; m\,\frac{1 - e^{-(p+q)t}}{1 + \frac{q}{p}\,e^{-(p+q)t}}.
$$

Два следствия важнее самой кривой.

**Момент пика продаж:**

$$
t^{*} \;=\; \frac{\ln(q/p)}{p+q},
\qquad
n(t^{*}) \;=\; \frac{m\,(p+q)^2}{4q}.
$$

После $t^{*}$ число новых клиентов падает, даже если маркетинг не меняется.
Не зная этого, падение выручки легко принять за ухудшение работы команды.

**Потолок $m$.** Если подогнанный потенциал заметно меньше заявленного SAM,
значит гипотеза о рынке не подтверждается фактическими продажами.

Подгонка идёт в два шага. Сначала регрессия Басса: приращения объясняются
накопленным числом и его квадратом,

$$
n_t \;=\; a + b\,N_{t-1} + c\,N_{t-1}^2,
$$

откуда $m$ — положительный корень квадратного уравнения, $p = a/m$,
$q = -cm$. Эта оценка смещена, но служит начальным приближением для
нелинейного метода наименьших квадратов: без неё безградиентная оптимизация
уходит в локальный минимум.

Типичные значения по разным категориям товаров: $p$ около 0,01–0,03,
$q$ около 0,3–0,5.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I \cdot T)$ | $I$ — итераций симплекса, $T$ — наблюдений |
| Память | $O(T + H)$ | Наблюдения и горизонт прогноза |

## API

| Метод | Описание |
|-------|----------|
| `BassDiffusion.Fit(cumulativeAdopters)` | Подгонка $m$, $p$, $q$ по накопленным принявшим |
| `BassDiffusion.SetParameters(m, p, q)` | Задание параметров без подгонки |
| `Cumulative(periods)` | Накопленное число принявших |
| `Adopters(periods)` | Новые клиенты по периодам |
| `PeakTime`, `PeakAdopters` | Момент и величина пика продаж |
| `RSquared` | Качество подгонки по накопленным принявшим |

Исходник: `src/AI.Economics/Market/BassDiffusion.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Market;

var truth = new BassDiffusion();
truth.SetParameters(marketPotential: 200_000, innovation: 0.02, imitation: 0.4);

Vector history = truth.Cumulative(14);

var model = new BassDiffusion();
model.Fit(history);

Console.WriteLine($"m={model.MarketPotential:N0} p={model.Innovation:F4} q={model.Imitation:F4}");
Console.WriteLine($"R2={model.RSquared:F4}");
Console.WriteLine($"Пик продаж: месяц {model.PeakTime:F1}, {model.PeakAdopters:N0} клиентов");

Vector forecast = model.Adopters(48);

for (int month = 0; month < forecast.Count; month += 6)
    Console.WriteLine($"месяц {month + 1,3}: новых {forecast[month],10:N0}");
```

## Ограничения

- Подгонка по данным до пика неустойчива: одна и та же начальная часть кривой
  описывается разными парами $(m, q)$ почти одинаково хорошо. Пока пик не
  пройден, оценка потенциала рынка — ориентир, а не число.
- Модель описывает первую покупку и ничего не говорит о повторных: для выручки
  её надо совмещать с моделью удержания.
- Предполагается неизменность рынка: цена, конкуренты и маркетинговое давление
  в базовую модель не входят. Резкая смена цены ломает подгонку.
- Модель не знает об оттоке. Накопленное число принявших не убывает, тогда как
  реальная база клиентов может сокращаться — сравнивайте с
  [кривой удержания](retention_fit.md).
