# Марковиц: эффективная граница с ограничениями

Оптимизация «доходность против риска» с ограничениями на веса, лотность и
число активов, эффективная граница, портфель минимальной дисперсии и
максимального коэффициента Шарпа.

## Постановка задачи

Дано: ожидаемые доходности активов, ковариационная матрица их доходностей,
безрисковая ставка и практические ограничения — запрет коротких позиций,
максимальная доля одного актива, размер лота, транзакционные издержки.

Требуется: веса портфеля, эффективная граница и вклад каждого актива в риск.

Где встречается: формирование модельного портфеля, распределение активов
пенсионного фонда, ребалансировка мандата, обоснование стратегической
аллокации перед инвестиционным комитетом.

## Теория

**Задача Марковица** в форме максимизации полезности:

$$
\max_{w}\;\; w^{\top}\mu \;-\; \frac{\lambda}{2}\,w^{\top}\Sigma w
\qquad\text{при}\qquad
\sum_i w_i = 1,\;\; l_i \le w_i \le u_i .
$$

Без ограничений решение выражается в замкнутом виде через $\Sigma^{-1}$, но
именно ограничения делают результат применимым: неограниченная оптимизация
почти всегда выдаёт экстремальные позиции — плюс 300% в одном активе и минус
200% в другом.

**Эффективная граница** — множество портфелей, у которых нельзя увеличить
доходность без роста риска. Она строится перебором целевой доходности; две
точки на ней имеют собственные имена: портфель минимальной дисперсии и
портфель максимального коэффициента Шарпа (касательный).

**Вклад в риск.** Разложение волатильности портфеля по активам:

$$
\mathrm{RC}_i \;=\; \frac{w_i\,(\Sigma w)_i}{w^{\top}\Sigma w},
\qquad \sum_i \mathrm{RC}_i = 1 .
$$

Оно вскрывает главную ловушку: портфель «60% акций, 40% облигаций» по весам
на деле состоит из акций на 90% по риску.

**Ограничение на число активов** (кардинальность) делает задачу
комбинаторной. Практическое решение — сначала оптимизировать без него, затем
обнулить наименьшие веса и переоптимизировать на оставшемся множестве.

**Лотность** округляет веса до кратных размеру лота. Округление всегда
ухудшает целевую функцию, но на реальных портфелях потеря составляет доли
процента.

**Сжатие ковариации.** Выборочная ковариационная матрица на $n$ активах и $T$
наблюдениях содержит $n(n+1)/2$ параметров и при $T \sim n$ вырождена.
Сжатие к диагональной матрице по Ледуа — Вольфу стабилизирует её:
$\Sigma^{*} = (1-\delta)\hat\Sigma + \delta\,\mathrm{diag}(\hat\Sigma)$.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I n^2 + P I n^2)$ | $I$ итераций проекции, $P$ точек границы |
| Память | $O(n^2 + Pn)$ | ковариация и граница |

## API

| Метод | Описание |
|-------|----------|
| `MeanVariance.Optimize(returns, covariance, assets, rf, constraints, frontierPoints)` | Оптимальный портфель и граница |
| `MeanVariance.RiskBudget(weights, covariance, assets)` | Вклад активов в риск |
| `MeanVariance.Covariance(returns, shrinkage)` | Ковариация со сжатием |
| `OptimizationResult.Frontier` | Точки эффективной границы |
| `OptimizationResult.MinimumVariance` / `MaximumSharpe` | Именованные портфели |
| `PortfolioConstraints` | Границы весов, лот, число активов, издержки |

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Portfolio;
using AI.Statistics;

Random source = RandomEngine.Create(31);
var history = new Matrix(180, 4);

double[] drift = [0.004, 0.010, 0.008, 0.006];
double[] noise = [0.010, 0.055, 0.038, 0.025];

for (int t = 0; t < history.Height; t++)
{
    double common = RandomEngine.NextGaussian(source);

    for (int j = 0; j < history.Width; j++)
    {
        history[t, j] = drift[j] + (noise[j] * ((0.6 * common) + (0.8 * RandomEngine.NextGaussian(source))));
    }
}

Matrix covariance = MeanVariance.Covariance(history, shrinkage: 0.15);
var expected = new Vector(0.05, 0.14, 0.11, 0.08);
string[] assets = ["Облигации", "Акции", "Недвижимость", "Золото"];

OptimizationResult optimum = MeanVariance.Optimize(
    expected, covariance, assets, riskFreeRate: 0.06,
    constraints: new PortfolioConstraints { MinimumWeight = 0, MaximumWeight = 0.45 });

for (int i = 0; i < assets.Length; i++)
    Console.WriteLine($"{assets[i]}: {optimum.Weights[i]:P1}");

Console.WriteLine($"Доходность {optimum.ExpectedReturn:P2}, риск {optimum.Risk:P2}, " +
                  $"Шарп {optimum.Sharpe:F2}");
Console.WriteLine($"Эффективное число активов {optimum.EffectiveAssets:F2}");
```

Вклад в риск почти никогда не совпадает с весами — это главный
диагностический вывод:

```csharp
foreach ((string asset, double weight, double contribution) in optimum.RiskBudget)
    Console.WriteLine($"{asset}: вес {weight:P1}, вклад в риск {contribution:P1}");
```

Практические ограничения — лот и число позиций — меняют результат:

```csharp
OptimizationResult constrained = MeanVariance.Optimize(
    expected, covariance, assets, 0.06,
    new PortfolioConstraints
    {
        MinimumWeight = 0,
        MaximumWeight = 0.45,
        MaximumAssets = 3,
        LotSize = 0.05,
        TransactionCost = 0.002,
        CurrentWeights = [0.4, 0.3, 0.2, 0.1],
    });

Console.WriteLine($"С ограничениями: Шарп {constrained.Sharpe:F2}, " +
                  $"издержки перехода {constrained.TransactionCost:P2}");

if (optimum.MinimumVariance is { } safest)
    Console.WriteLine($"Минимальная дисперсия: риск {safest.Risk:P2} при доходности {safest.Return:P2}");

Console.WriteLine(optimum.Interpret().ToLlmText());
```

## Ограничения

- Оптимизация Марковица максимально чувствительна к ожидаемым доходностям:
  ошибка в 1 процентный пункт меняет веса на десятки процентов. Риск
  оценивается надёжнее доходности примерно в десять раз — отсюда популярность
  [паритета риска](risk_parity.md), не использующего прогнозы доходности.
- Выборочная ковариация на коротких историях плохо обусловлена. Всегда
  применяйте сжатие: коэффициент 0,1–0,3 почти всегда улучшает результат вне
  выборки.
- Модель однопериодная и предполагает нормальность. Для активов с
  асимметричным распределением корректнее [оптимизация по
  CVaR](cvar_portfolio.md).
- Ограничение на число активов решается эвристикой, а не точно. При жёстких
  требованиях проверяйте результат перебором на малых размерностях.
- Историческая ковариация не воспроизводит рост корреляций в кризис —
  диверсификация исчезает именно тогда, когда нужна. Проверяйте портфель
  [стресс-тестом](var_backtest.md).
