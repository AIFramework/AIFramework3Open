# Экономическая добавленная стоимость по подразделениям

Сравнение возврата на инвестированный капитал со стоимостью этого капитала:
кто в компании создаёт стоимость, кто её уничтожает и сколько даст
перераспределение капитала.

## Постановка задачи

Дано: выручка, операционная прибыль и инвестированный капитал по
подразделениям, ставка налога и стоимость капитала компании.

Требуется: экономическая прибыль каждого подразделения, спред между
рентабельностью и стоимостью капитала, а также оценка выигрыша от переноса
капитала из разрушающих подразделений в создающие.

Где встречается: бюджетирование капитальных вложений, система мотивации
руководителей бизнес-единиц, решение о выделении или продаже направления,
защита стратегии перед акционерами.

## Теория

Бухгалтерская прибыль игнорирует стоимость собственного капитала: она
вычитает проценты по долгу, но не вычитает требуемую доходность акционеров.
Подразделение с прибылью 100 млн на капитале 2 млрд при стоимости капитала
18% формально прибыльно и экономически убыточно.

**Экономическая прибыль** исправляет это:

$$
\mathrm{EVA} \;=\; \mathrm{NOPAT} - \mathrm{WACC}\cdot \mathrm{IC}
\;=\; (\mathrm{ROIC} - \mathrm{WACC})\cdot \mathrm{IC},
$$

где $\mathrm{NOPAT} = \mathrm{EBIT}(1-\tau)$ — прибыль после налога, но до
процентов, а $\mathrm{IC}$ — инвестированный капитал.

Вторая форма записи важнее первой: она разделяет **качество** бизнеса (спред
$\mathrm{ROIC} - \mathrm{WACC}$) и его **масштаб** ($\mathrm{IC}$). Небольшое
подразделение с огромным спредом создаёт меньше стоимости, чем крупное со
скромным, — но именно первое заслуживает дополнительного капитала.

**Стоимость капитала по подразделениям** различается: розничное направление и
инвестиционный проект несут разный риск. Единая ставка для всех подразделений
систематически субсидирует рискованные направления за счёт стабильных.

**Рыночная добавленная стоимость** — приведённая сумма будущих экономических
прибылей, растущих темпом $g$:

$$
\mathrm{MVA} \;=\; \frac{\mathrm{EVA}\,(1+g)}{\mathrm{WACC} - g}.
$$

Она показывает, какую премию к балансовому капиталу оправдывает текущая
экономика бизнеса.

**Выигрыш от перераспределения** оценивается переносом капитала из
подразделений с отрицательным спредом в подразделение с максимальным: разница
спредов, умноженная на переносимый капитал. Это верхняя граница — она не
учитывает, что масштабирование обычно снижает предельную доходность.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(U)$ | $U$ — число подразделений |
| Память | $O(U)$ | свод по подразделениям |

## API

| Метод | Описание |
|-------|----------|
| `EconomicValueAdded.Compute(company, units, wacc)` | Экономическая прибыль по подразделениям |
| `EconomicValueAdded.MarketValueAdded(eva, growth, wacc, horizon)` | Капитализация экономической прибыли |
| `EconomicProfitResult.Units` | Разбивка: NOPAT, ROIC, спред, доля капитала |
| `EconomicProfitResult.Spread` / `Roic` | Показатели компании в целом |
| `EconomicProfitResult.CapitalDestroying` | Доля капитала в разрушающих подразделениях |
| `EconomicProfitResult.ReallocationUpside` | Оценка выигрыша от перераспределения |

Исходники: `src/AI.Economics/Corporate/EconomicValueAdded.cs`.

## Код

```csharp
using AI.Economics.Corporate;

var units = new List<BusinessUnit>
{
    new() { Name = "Розница", Revenue = 6_000_000_000, OperatingProfit = 900_000_000,
            InvestedCapital = 3_000_000_000, TaxRate = 0.2, CostOfCapital = 0.17 },
    new() { Name = "Опт", Revenue = 9_000_000_000, OperatingProfit = 540_000_000,
            InvestedCapital = 4_500_000_000, TaxRate = 0.2, CostOfCapital = 0.15 },
    new() { Name = "Онлайн", Revenue = 2_000_000_000, OperatingProfit = 400_000_000,
            InvestedCapital = 800_000_000, TaxRate = 0.2, CostOfCapital = 0.21 },
    new() { Name = "Логистика", Revenue = 1_500_000_000, OperatingProfit = 120_000_000,
            InvestedCapital = 2_200_000_000, TaxRate = 0.2, CostOfCapital = 0.14 },
};

EconomicProfitResult economics = EconomicValueAdded.Compute("Группа компаний", units, wacc: 0.16);

Console.WriteLine($"ROIC группы {economics.Roic:P1} при WACC {economics.Wacc:P1}");
Console.WriteLine($"Спред {economics.Spread:P1}, экономическая прибыль {economics.TotalEconomicProfit:N0}");

foreach (UnitEconomicProfit unit in economics.Units)
{
    Console.WriteLine($"{unit.Name}: ROIC {unit.Roic:P1}, спред {unit.Spread:P1}, " +
                      $"EVA {unit.EconomicProfit:N0} ({unit.CapitalShare:P0} капитала)");
}
```

Два вопроса, ради которых расчёт и делается:

```csharp
Console.WriteLine($"В разрушающих подразделениях {economics.CapitalDestroying:P0} капитала");
Console.WriteLine($"Выигрыш от перераспределения {economics.ReallocationUpside:N0}");
```

Капитализация текущей экономической прибыли даёт премию к балансу:

```csharp
double mva = EconomicValueAdded.MarketValueAdded(
    economics.TotalEconomicProfit, growth: 0.03, wacc: economics.Wacc);

Console.WriteLine($"Рыночная добавленная стоимость {mva:N0}");
Console.WriteLine($"Оправданная стоимость бизнеса {economics.TotalCapital + mva:N0}");

Console.WriteLine(economics.Interpret().ToLlmText());
```

## Ограничения

- Инвестированный капитал берётся из учёта и потому занижен для компаний с
  большими нематериальными вложениями: расходы на разработку и бренд списаны в
  прибыль, а не капитализированы. Это завышает ROIC технологических
  подразделений в разы.
- Показатель годовой и штрафует инвестиции: новый завод сначала увеличивает
  капитал и только потом прибыль. Оценивать по EVA молодое направление —
  верный способ его закрыть.
- Распределение общекорпоративных затрат и капитала между подразделениями
  произвольно. Спред меняется на несколько процентных пунктов в зависимости от
  базы распределения, а решения принимаются по знаку спреда.
- Выигрыш от перераспределения — верхняя граница. Он предполагает, что
  доходность лучшего подразделения не снижается при удвоении его капитала, что
  почти никогда не верно.
- Отрицательный спред не означает «закрыть». Он означает «либо повысить
  доходность, либо высвободить капитал» — и второе часто достигается продажей
  активов, а не прекращением деятельности.
