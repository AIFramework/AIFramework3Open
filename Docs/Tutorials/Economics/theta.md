# Метод Theta

Победитель соревнования прогнозов M3 и до сих пор один из самых сильных
базовых методов — при том, что у него ровно один настраиваемый параметр.

## Постановка задачи

Дано: короткий или шумный ряд, на котором подбор порядка ARIMA был бы гаданием.

Требуется: прогноз, который трудно превзойти без существенно больших данных.

Где встречается: массовое прогнозирование по тысячам SKU, ряды длиной
в полтора-два года, базовая линия для сравнения более сложных моделей.

## Теория

Ряд раскладывается на две «тета-линии». Линия с параметром $\theta = 0$ —
обычная линейная регрессия на время, она описывает долгосрочный тренд.
Линия с $\theta = 2$ удваивает кривизну ряда и прогнозируется простым
экспоненциальным сглаживанием. Итоговый прогноз — среднее двух экстраполяций.

Результат эквивалентен сглаживанию с добавленным полутрендом:

$$
\hat y_{t+h} = \ell_t + \frac{b}{2}\left(h - 1 + \frac{1}{\alpha} - \frac{(1-\alpha)^n}{\alpha}\right),
$$

где $b$ — наклон линейной регрессии на всю историю, $\alpha$ — параметр
сглаживания, $\ell_t$ — последний уровень.

Половина наклона вместо целого — ключевая деталь. Полный тренд на длинном
горизонте уводит прогноз слишком далеко, отсутствие тренда — недооценивает
рост. Половина оказывается практичным компромиссом, который на реальных рядах
регулярно обыгрывает обе крайности.

Сезонность снимается перед применением метода и возвращается после.
Наличие сезонности проверяется автокорреляцией на сезонном лаге с порогом
$1{,}645/\sqrt{n}$: если она незначима, сезонная корректировка не делается —
лишнее преобразование на несезонном ряде только добавляет шума.

Единственный подбираемый параметр — $\alpha$; он оценивается минимизацией
суммы квадратов однодневных ошибок.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I \cdot n)$ | $I$ — итераций подбора alpha, обычно менее сотни |
| Память | $O(n + m)$ | Ряд и сезонные индексы |

## API

| Метод | Описание |
|-------|----------|
| `ThetaMethod.Fit(series, horizon, season, confidenceLevel)` | Прогноз с интервалами |
| `ForecastResult.Parameters` | Оценённые alpha, drift и наклон тренда |
| `ForecastResult.SeasonalPeriod` | 1, если сезонность признана незначимой |
| `ForecastResult.InSampleMase` | Сравнение с наивным прогнозом |

Исходник: `src/AI.Economics/Forecasting/ThetaMethod.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Forecasting;

var random = new Random(23);
const int months = 96;
var series = new Vector(months);

for (int t = 0; t < months; t++)
{
    series[t] = 800 + (3.0 * t)
              + (120 * Math.Sin(2 * Math.PI * t / 12.0))
              + ((random.NextDouble() - 0.5) * 80);
}

ForecastResult theta = ThetaMethod.Fit(series, horizon: 18, season: 12);

Console.WriteLine($"Модель: {theta.Model}");
Console.WriteLine($"alpha = {theta.Parameters["alpha"]:F4}, drift = {theta.Parameters["drift"]:F3}");
Console.WriteLine($"MASE = {theta.InSampleMase:F3}");

// Сравнение с базовыми альтернативами на той же истории
ForecastResult smoothing = ExponentialSmoothing.AutoFit(series, 18, 12);
Vector naive = ForecastMetrics.Naive(series, 18, 12);

Console.WriteLine($"Theta:       {theta.PointForecast[17]:N0}");
Console.WriteLine($"Сглаживание: {smoothing.PointForecast[17]:N0}");
Console.WriteLine($"Наивный:     {naive[17]:N0}");
Console.WriteLine(theta.Interpret().ToLlmText());
```

## Ограничения

- Метод предполагает линейный долгосрочный тренд. На рядах с переломом тренда
  он экстраполирует усреднённый наклон и систематически ошибается.
- Сезонная корректировка мультипликативная и требует положительного ряда.
- Интервалы прогноза приближённые: они получены из накопления дисперсии
  сглаживания и не учитывают неопределённость оценки наклона.
- Метод не принимает внешние регрессоры и не описывает промо. Для рядов,
  где они значимы, нужен [SARIMAX](arima.md).
- Отсутствие параметров — сила на коротких рядах и слабость на длинных:
  при достаточной истории более гибкие модели обыгрывают Theta.
