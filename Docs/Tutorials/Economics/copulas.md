# Копулы и хвостовая зависимость

Гауссова копула, копула Стьюдента, Клейтона и Гумбеля: моделирование
структуры зависимости отдельно от распределений и оценка вероятности того,
что активы обвалятся одновременно.

## Постановка задачи

Дано: два ряда доходностей — например, акции и облигации, два кредитных
портфеля, две валюты.

Требуется: описание их совместного поведения, пригодное для симуляции, и
ответ на главный вопрос риск-менеджмента: усиливается ли зависимость в
кризис, когда она особенно опасна.

Где встречается: агрегирование рисков по портфелю, оценка эффекта
диверсификации, моделирование корреляции дефолтов, требования к капиталу
по нескольким факторам риска.

## Теория

**Теорема Склара.** Любое совместное распределение раскладывается на
одномерные маргиналы и копулу — функцию зависимости на единичном квадрате:

$$
F(x,y) \;=\; C\bigl(F_1(x),\,F_2(y)\bigr).
$$

Практическая ценность в том, что маргиналы и зависимость оцениваются
раздельно: хвост каждого актива можно описать [распределением
Парето](extreme_value.md), а связь между ними — копулой.

**Псевдонаблюдения** получаются переходом к рангам:
$u_i = \mathrm{rank}(x_i)/(n+1)$. Так теряется вся информация о маргиналах и
остаётся только зависимость.

**Семейства.** Гауссова копула симметрична и не имеет хвостовой зависимости:
как бы ни была высока корреляция, вероятность совместного экстремума стремится
к нулю. Именно это свойство сделало её печально известной в кризис 2008 года,
когда на ней строились оценки траншей ипотечных бумаг.

Копула Стьюдента добавляет симметричную хвостовую зависимость через число
степеней свободы. Клейтон концентрирует зависимость в **нижнем** хвосте —
это модель совместных обвалов. Гумбель — в верхнем.

**Коэффициенты хвостовой зависимости** — предельные условные вероятности:

$$
\lambda_L = \lim_{q\to 0^{+}}\Pr\!\left(U_2 \le q \mid U_1 \le q\right),
\qquad
\lambda_U = \lim_{q\to 1^{-}}\Pr\!\left(U_2 > q \mid U_1 > q\right).
$$

Для Клейтона $\lambda_L = 2^{-1/\theta}$, для Гумбеля
$\lambda_U = 2 - 2^{1/\theta}$, для гауссовой обе равны нулю. Разница между
$\lambda_L = 0$ и $\lambda_L = 0{,}5$ — это разница между «раз в тысячу лет»
и «раз в десять лет» для сценария одновременного обвала.

**Тау Кендалла** — мера зависимости, инвариантная к монотонным
преобразованиям, — служит начальным приближением при подгонке:
$\theta = 2\tau/(1-\tau)$ для Клейтона, $\theta = 1/(1-\tau)$ для Гумбеля.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n^2)$ на тау Кендалла, $O(In)$ на подгонку | $I$ итераций оптимизации |
| Память | $O(n)$ | псевдонаблюдения |

## API

| Метод | Описание |
|-------|----------|
| `Copulas.Fit(first, second, family, names)` | Подгонка и сравнение семейств |
| `Copulas.Simulate(family, parameter, count, df, seed)` | Симуляция пар из копулы |
| `Copulas.KendallTau(first, second)` | Ранговая мера зависимости |
| `CopulaResult.LowerTailDependence` / `UpperTailDependence` | Коэффициенты хвостов |
| `CopulaResult.Comparison` | Правдоподобие и AIC всех семейств |
| `CopulaResult.EmpiricalLowerTail` | Наблюдаемая доля совместных обвалов |

Исходники: `src/AI.Economics/Risk/Copulas.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Risk;
using AI.Statistics;

Random source = RandomEngine.Create(9);
var first = new Vector(1500);
var second = new Vector(1500);

for (int i = 0; i < first.Count; i++)
{
    double common = RandomEngine.NextGaussian(source);
    double shockA = RandomEngine.NextGaussian(source);
    double shockB = RandomEngine.NextGaussian(source);

    // В спокойном режиме связь слабая, в стрессе — сильная
    bool crisis = source.NextDouble() < 0.1;
    double weight = crisis ? 0.9 : 0.3;

    first[i] = (weight * common) + (Math.Sqrt(1 - (weight * weight)) * shockA);
    second[i] = (weight * common) + (Math.Sqrt(1 - (weight * weight)) * shockB);
}

CopulaResult copula = Copulas.Fit(first, second, CopulaFamily.Clayton, ("Акции", "Кредит"));

Console.WriteLine($"Семейство {copula.Family}, параметр {copula.Parameter:F3}");
Console.WriteLine($"Тау Кендалла {copula.KendallTau:F3}, корреляция {copula.PearsonCorrelation:F3}");
Console.WriteLine($"Нижняя хвостовая зависимость {copula.LowerTailDependence:F3}");
Console.WriteLine($"Верхняя хвостовая зависимость {copula.UpperTailDependence:F3}");
Console.WriteLine($"Эмпирическая доля совместных обвалов {copula.EmpiricalLowerTail:F3}");
```

Выбор семейства делается по правдоподобию, но проверяется по хвосту:

```csharp
foreach ((CopulaFamily family, double logLikelihood, double aic) in copula.Comparison)
    Console.WriteLine($"{family}: логарифм правдоподобия {logLikelihood:F1}, AIC {aic:F1}");
```

Симуляция из подобранной копулы даёт сценарии для расчёта совокупного риска:

```csharp
Matrix draws = Copulas.Simulate(copula.Family, copula.Parameter, count: 10_000, seed: 3);

int jointCrash = 0;
for (int i = 0; i < draws.Height; i++)
    if (draws[i, 0] < 0.05 && draws[i, 1] < 0.05) jointCrash++;

Console.WriteLine($"Совместный обвал за порог 5% в {(double)jointCrash / draws.Height:P2} сценариев");
Console.WriteLine($"При независимости было бы {0.05 * 0.05:P2}");

Console.WriteLine(copula.Interpret().ToLlmText());
```

## Ограничения

- Оценка хвостовой зависимости требует данных именно в хвосте. На двух годах
  дневных наблюдений в 1% хвосте оказывается пять точек — вывод о $\lambda_L$
  по ним ненадёжен.
- Двумерный случай легко обобщается на многомерный только для эллиптических
  копул. Иерархические архимедовы конструкции для десятков активов требуют
  отдельного аппарата.
- Подгонка по псевдонаблюдениям игнорирует ошибку оценки маргиналов. При малой
  выборке двухшаговая процедура смещает параметр копулы.
- Копула описывает статическую зависимость. Если связь усиливается в кризис,
  правильнее динамическая модель, а не одна копула на всю историю — статическая
  оценка усредняет два режима и не годится ни для одного.
- Гауссова копула кажется безобидной, потому что воспроизводит корреляцию.
  Именно поэтому её опасно применять к кредитным портфелям: она обнуляет
  вероятность каскадных дефолтов.
