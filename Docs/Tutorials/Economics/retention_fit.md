# Подгонка кривой удержания

Оценка параметрической кривой удержания по когортным данным с доверительным
интервалом на экстраполяцию хвоста — вместо единственного числа «средний отток».

## Постановка задачи

Дано: наблюдённая доля доживания когорты по месяцам, $S(0)=1, S(1), \dots, S(T)$,
и размер когорты.

Требуется: кривая $S(t)$ на горизонте, заметно превышающем $T$, вместе с
интервалом неопределённости, и ожидаемое время жизни клиента.

Где встречается: расчёт LTV, обоснование срока окупаемости перед инвестором,
сравнение качества трафика между каналами и периодами.

## Теория

Наблюдаемая доля удержания почти никогда не постоянна: слабые клиенты уходят
первыми, оставшиеся живут дольше, и мгновенное удержание
$r(t) = S(t)/S(t-1)$ монотонно растёт. Модуль поддерживает четыре семейства:

| Модель | Кривая доживания | Параметры |
|--------|------------------|-----------|
| Экспоненциальная | $S(t) = e^{-\lambda t}$ | $\lambda$ |
| Степенная | $S(t) = (1+t)^{-\alpha}$ | $\alpha$ |
| Вейбулла | $S(t) = e^{-(t/\lambda)^k}$ | $k, \lambda$ |
| sBG | $S(t) = S(t-1)\dfrac{\beta+t-1}{\alpha+\beta+t-1}$ | $\alpha, \beta$ |

Модель sBG (Fader — Hardie) выводится из предположения, что вероятность ухода
$p$ у клиента постоянна, но различается между клиентами и распределена по
бета-закону. Гетерогенность и даёт растущее удержание: к месяцу $t$ доживают
те, у кого $p$ мал.

Оценка ведётся методом максимального правдоподобия по дискретной модели с
правым цензурированием: ушедшие в период $t$ дают вклад $S(t-1)-S(t)$, дожившие
до конца наблюдения — вклад $S(T)$:

$$
\ln L \;=\; \sum_{t=1}^{T} d_t \ln\bigl(S(t-1)-S(t)\bigr) \;+\; n_T \ln S(T).
$$

Постановка одинакова для всех четырёх семейств, поэтому их AIC сравним напрямую.

Доверительный интервал строится параметрическим бутстрапом: из подогнанной
модели генерируются синтетические когорты того же размера, каждая
переподгоняется, по разбросу кривых берутся процентили. Такой интервал честно
расширяется за границей наблюдений — экстраполяция на 36-й месяц по шести
месяцам данных получает широкий коридор, а не иллюзию точности.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(B \cdot I \cdot T)$ | $B$ — повторов бутстрапа, $I$ — итераций симплекса |
| Память | $O(B \cdot H)$ | $H$ — горизонт экстраполяции |

## API

| Метод | Описание |
|-------|----------|
| `RetentionFitter.Fit(survival, cohortSize, model, horizon, level, boot, seed)` | Подгонка одного семейства |
| `RetentionFitter.FitAll(survival, cohortSize, horizon, level, boot, seed)` | Все четыре, отсортированы по AIC |
| `RetentionFitResult.Survival` | Кривая на горизонте: подгонка плюс экстраполяция |
| `RetentionFitResult.SurvivalLower` / `SurvivalUpper` | Границы доверительного интервала |
| `RetentionFitResult.ExpectedLifetime` | Ожидаемое время жизни в периодах |
| `RetentionFitResult.RetentionRates` | Мгновенное удержание $r(t)$ |

Исходники: `src/AI.Economics/Cohorts/`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Cohorts;

var observed = new Vector(1.00, 0.58, 0.47, 0.42, 0.39, 0.37, 0.36);

IReadOnlyList<RetentionFitResult> ranked =
    RetentionFitter.FitAll(observed, cohortSize: 2_000, horizon: 36);

RetentionFitResult best = ranked[0];

Console.WriteLine($"Лучшая модель: {best.Model}, AIC={best.Aic:F1}");
Console.WriteLine($"Срок жизни: {best.ExpectedLifetime:F1} мес. " +
                  $"({best.ExpectedLifetimeLower:F1}-{best.ExpectedLifetimeUpper:F1})");
Console.WriteLine($"S(36) = {best.Survival[36]:P1} " +
                  $"[{best.SurvivalLower[36]:P1}; {best.SurvivalUpper[36]:P1}]");
Console.WriteLine($"Удержание r(2)={best.RetentionRates[2]:P1}, r(24)={best.RetentionRates[24]:P1}");
```

Готовую кривую можно сразу подставить в расчёт LTV:

```csharp
using AI.Economics.UnitEconomics;

double ltv = UnitEconomicsCalculator.LtvFromCurve(4_800, best.Survival, 0.01);
Console.WriteLine($"LTV по подогнанной кривой: {ltv:N0}");
```

## Ограничения

- Экстраполяция за горизонт наблюдений остаётся экстраполяцией: шесть месяцев
  данных не позволяют уверенно судить о третьем годе, и ширина интервала
  сообщает об этом честно.
- Подгонка предполагает однородность условий: смена продукта или тарифов внутри
  наблюдаемого периода нарушает модель. Такие когорты надо разделять.
- Метод не различает добровольный и вынужденный отток; для этого используйте
  [конкурирующие риски](competing_risks.md).
- Сводная кривая по нескольким когортам должна строиться без учёта
  непронаблюдённых ячеек, иначе подгонка получит смещённые данные — см.
  [когортную матрицу](cohort_matrix.md).
