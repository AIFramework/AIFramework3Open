# Монте-Карло вокруг DCF

Оценка бизнеса не числом, а распределением: случайные возмущения роста
выручки, рентабельности и ставки дисконтирования дают перцентили стоимости и
вероятность того, что сделка окажется убыточной.

## Постановка задачи

Дано: базовый прогноз DCF и представление о том, насколько неопределённы его
ключевые допущения — темп роста выручки, операционная рентабельность и ставка
дисконтирования.

Требуется: распределение стоимости собственного капитала, доверительный
диапазон вокруг оценки и вероятность того, что справедливая стоимость окажется
ниже цены сделки.

Где встречается: обоснование диапазона цены в переговорах, инвестиционный
меморандум, оценка риска мажоритарного пакета, стресс-тест сделки перед
одобрением советом директоров.

## Теория

Детерминированный DCF возвращает одно число, которое воспринимается как
точное, хотя оно является функцией нескольких субъективных допущений.
Монте-Карло заменяет допущения распределениями и переносит их
неопределённость на результат.

На каждой итерации $i$ разыгрываются возмущения:

$$
g^{(i)} \sim \mathcal N(0, \sigma_g), \qquad
\Delta m^{(i)} \sim \mathcal N(0, \sigma_m), \qquad
\Delta r^{(i)} \sim \mathcal N(0, \sigma_r),
$$

после чего каждый год прогноза пересчитывается: выручка умножается на
накопленный множитель $(1 + g^{(i)})^t$, маржа сдвигается на $\Delta m^{(i)}$,
ставка — на $\Delta r^{(i)}$. Возмущение выручки накапливается по годам
именно потому, что ошибка в темпе роста не разовая, а систематическая:
промах на один процентный пункт в первый год к пятому превращается в пять.

Из выборки $\{V^{(1)},\dots,V^{(S)}\}$ считаются:

$$
\hat V = \frac{1}{S}\sum_i V^{(i)},
\qquad
\Pr(\text{убыток}) = \frac{1}{S}\sum_i \mathbf 1\{V^{(i)} < 0\},
$$

а также медиана и перцентили $q_{0.05}$, $q_{0.95}$, задающие практический
диапазон переговоров.

Распределение стоимости почти всегда **правоскошено**: ставка входит в
знаменатель, поэтому её снижение поднимает оценку сильнее, чем такой же рост
её опускает. Отсюда важное следствие — среднее значение оценки систематически
выше медианы, и опираться в переговорах надо на медиану.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(S\,N)$ | $S$ итераций по $N$ годам прогноза |
| Память | $O(S)$ | хранится выборка стоимостей |

## API

| Метод | Описание |
|-------|----------|
| `DiscountedCashFlow.Simulate(input, revVol, marginVol, rateVol, simulations, seed)` | Распределение стоимости |
| `DcfSimulationResult.MeanEquityValue` / `MedianEquityValue` | Среднее и медиана |
| `DcfSimulationResult.LowerPercentile` / `UpperPercentile` | Границы диапазона |
| `DcfSimulationResult.ProbabilityOfLoss` | Вероятность отрицательной стоимости капитала |
| `DcfSimulationResult.Distribution` | Полная выборка для построения гистограммы |

Исходники: `src/AI.Economics/Corporate/DiscountedCashFlow.cs`.

## Код

```csharp
using AI.Economics.Corporate;

var years = new List<ForecastYear>();
double baseRevenue = 3_000_000_000;

for (int year = 1; year <= 5; year++)
{
    baseRevenue *= 1.10;
    years.Add(new ForecastYear(baseRevenue, 0.16, 0.2,
        baseRevenue * 0.05, baseRevenue * 0.07, baseRevenue * 0.015));
}

var project = new DcfInput
{
    Name = "Промышленный актив",
    Forecast = years,
    DiscountRate = 0.16,
    TerminalGrowth = 0.03,
    NetDebt = 900_000_000,
};

DcfSimulationResult simulation = DiscountedCashFlow.Simulate(
    project,
    revenueVolatility: 0.12,
    marginVolatility: 0.025,
    rateVolatility: 0.015,
    simulations: 20_000,
    seed: 7);

Console.WriteLine($"База {simulation.BaseCase:N0}");
Console.WriteLine($"Среднее {simulation.MeanEquityValue:N0}, медиана {simulation.MedianEquityValue:N0}");
Console.WriteLine($"Диапазон {simulation.LowerPercentile:N0} — {simulation.UpperPercentile:N0}");
Console.WriteLine($"Вероятность убытка {simulation.ProbabilityOfLoss:P1}");
```

Практический вопрос переговоров — какая доля исходов оправдывает
предложенную цену:

```csharp
double askingPrice = simulation.MedianEquityValue * 1.15;
int above = simulation.Distribution.Count(value => value >= askingPrice);

Console.WriteLine($"Цена {askingPrice:N0} оправдана в " +
                  $"{(double)above / simulation.Simulations:P1} сценариев");
```

Сравнение волатильностей показывает, снижение какой неопределённости стоит
денег на due diligence:

```csharp
foreach (double marginVol in new[] { 0.01, 0.025, 0.05 })
{
    DcfSimulationResult scenario = DiscountedCashFlow.Simulate(
        project, 0.12, marginVol, 0.015, 5000, 7);

    Console.WriteLine($"Разброс маржи {marginVol:P1}: " +
                      $"диапазон {scenario.UpperPercentile - scenario.LowerPercentile:N0}");
}

Console.WriteLine(simulation.Interpret().ToLlmText());
```

## Ограничения

- Возмущения разыгрываются независимо, тогда как в реальности рост выручки и
  рентабельность связаны, а ставка растёт именно в те периоды, когда падает
  спрос. Независимость занижает ширину распределения.
- Нормальное распределение возмущений не воспроизводит редкие катастрофы —
  потерю ключевого клиента, регуляторный запрет. Для них нужен отдельный
  сценарный анализ, а не разброс вокруг базы.
- Результат наследует все ограничения базового [DCF](dcf.md): если терминальная
  стоимость даёт 70% оценки, распределение в основном отражает
  неопределённость одного допущения о вечности.
- Число итераций влияет на устойчивость хвостовых перцентилей сильнее, чем на
  среднее. Для 5-го и 95-го перцентилей берите не менее 10 000 итераций.
- Вероятность убытка считается относительно нулевой стоимости капитала, а не
  относительно цены сделки. Порог сравнения задавайте явно, как в примере выше.
