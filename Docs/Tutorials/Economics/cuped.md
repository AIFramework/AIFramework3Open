# CUPED: снижение дисперсии эксперимента

Использование предэкспериментальных данных для уточнения оценки эффекта.
Метод сокращает требуемую выборку в полтора-два раза и не требует никаких
изменений в дизайне эксперимента.

## Постановка задачи

Дано: метрика участников в период эксперимента и та же метрика за период
до его начала.

Требуется: несмещённая оценка эффекта с меньшей дисперсией.

Где встречается: любой эксперимент, где у участников есть история —
выручка, число сессий, глубина просмотра.

## Теория

Идея: пользователи различались между собой ещё до эксперимента, и эта часть
разброса не имеет отношения к тестируемому изменению. Если вычесть
предсказуемую по прошлому часть, оценка эффекта останется несмещённой,
а дисперсия упадёт.

$$
Y^{adj}_i = Y_i - \theta\,(X_i - \bar X), \qquad
\theta = \frac{\mathrm{Cov}(Y, X)}{\mathrm{Var}(X)}.
$$

Ключевое свойство: $\mathbb{E}[Y^{adj}] = \mathbb{E}[Y]$, потому что
$\mathbb{E}[X - \bar X] = 0$. Коэффициент $\theta$ оценивается на объединённой
выборке обеих групп и не зависит от того, кто в какую группу попал, — поэтому
коррекция не может создать эффект там, где его нет.

Снижение дисперсии равно квадрату корреляции:

$$
\frac{\mathrm{Var}(Y^{adj})}{\mathrm{Var}(Y)} = 1 - \rho^2_{XY}.
$$

Для выручки и числа сессий корреляция с прошлым периодом обычно составляет
0,5–0,7, что даёт сокращение дисперсии на 25–50 % и эквивалентный рост
выборки в 1,3–2 раза — бесплатно.

Эквивалентный рост выборки считается как $1/(1-\text{снижение})$: чтобы
получить тот же выигрыш увеличением трафика, его пришлось бы нарастить
во столько раз.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n)$ | Один проход по объединённой выборке |
| Память | $O(n)$ | Скорректированные значения |

## API

| Метод | Описание |
|-------|----------|
| `Cuped.Apply(controlPre, controlPost, treatmentPre, treatmentPost)` | Коррекция и сравнение с обычным критерием |
| `CupedResult.VarianceReduction` | Доля снижения дисперсии |
| `CupedResult.EffectiveSampleGain` | Во сколько раз эквивалентно выросла выборка |
| `CupedResult.Correlation` | Связь метрики с предэкспериментальной |
| `CupedResult.RawPValue` / `AdjustedPValue` | p-значение до и после коррекции |

Исходник: `src/AI.Economics/Experiments/Cuped.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Experiments;

var random = new Random(31);
const int size = 3000;

var controlBefore = new Vector(size);
var controlAfter = new Vector(size);
var treatmentBefore = new Vector(size);
var treatmentAfter = new Vector(size);

for (int i = 0; i < size; i++)
{
    // Уровень пользователя сохраняется между периодами — эту часть
    // разброса метод и убирает
    double levelA = 10 + ((random.NextDouble() - 0.5) * 6);
    double levelB = 10 + ((random.NextDouble() - 0.5) * 6);

    controlBefore[i] = levelA + (random.NextDouble() - 0.5);
    controlAfter[i] = levelA + (random.NextDouble() - 0.5);
    treatmentBefore[i] = levelB + (random.NextDouble() - 0.5);
    treatmentAfter[i] = levelB + 0.5 + (random.NextDouble() - 0.5);
}

CupedResult result = Cuped.Apply(
    controlBefore, controlAfter, treatmentBefore, treatmentAfter);

Console.WriteLine($"Корреляция с прошлым: {result.Correlation:F3}");
Console.WriteLine($"Снижение дисперсии: {result.VarianceReduction:P0}");
Console.WriteLine($"Эквивалентный рост выборки: {result.EffectiveSampleGain:F2} раза");
Console.WriteLine($"Эффект: {result.RawEffect:F4} -> {result.AdjustedEffect:F4}");
Console.WriteLine($"p-значение: {result.RawPValue:F4} -> {result.AdjustedPValue:F4}");
Console.WriteLine(result.Interpret().ToLlmText());
```

## Ограничения

- Ковариата обязана быть измерена **до** начала эксперимента. Любая метрика
  периода эксперимента сама подвержена воздействию и внесёт смещение.
- Выигрыш определяется корреляцией. При корреляции ниже 0,3 сокращение
  дисперсии меньше 10 %, и метод почти ничего не даёт — подбирайте ковариату
  ближе к целевой метрике, обычно это она же за прошлый период.
- Новые пользователи не имеют истории. Их либо исключают из коррекции, либо
  подставляют среднее — второе снижает выигрыш.
- Заметный сдвиг оценки после коррекции — признак того, что группы неслучайно
  различались ещё до эксперимента. Это повод проверить рандомизацию,
  а не радоваться новому результату.
- Метод снижает дисперсию, но не защищает от подглядывания: при
  последовательном анализе он комбинируется с
  [последовательным критерием](sequential_testing.md), а не заменяет его.
