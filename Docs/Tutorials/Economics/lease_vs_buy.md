# Лизинг, кредит или покупка

Сравнение трёх способов приобретения актива по приведённой стоимости затрат с
учётом налогового щита амортизации, процентов и лизинговых платежей.

## Постановка задачи

Дано: стоимость актива, срок использования, ставка налога на прибыль, ставка
дисконтирования, условия кредита (ставка, первоначальный взнос) и условия
лизинга (удорожание, аванс, выкупной платёж, коэффициент ускоренной
амортизации).

Требуется: приведённая стоимость затрат по каждому варианту, выбор лучшего и
величина преимущества, а также предельное удорожание лизинга, при котором он
перестаёт быть выгоднее.

Где встречается: закупка транспорта и оборудования, решение казначейства о
структуре финансирования, переговоры с лизинговой компанией, обоснование
выбора для налоговой проверки.

## Теория

Сравнивать нужно **приведённую стоимость оттоков после налога**, а не сумму
платежей. Актив во всех трёх случаях один и тот же, поэтому выручка сокращается
и остаются только затраты.

**Покупка за свои.** Единовременный отток $C$ компенсируется щитом
амортизации и остаточной стоимостью:

$$
\mathrm{PV}_{\text{buy}} \;=\; C \;-\; \sum_{t=1}^{N}\frac{\tau\,D_t}{(1+r)^t} \;-\; \frac{R}{(1+r)^N}.
$$

**Кредит** добавляет к этому проценты, но и их щит:

$$
\mathrm{PV}_{\text{credit}} \;=\; C_0 + \sum_{t=1}^{N}\frac{A_t - \tau I_t}{(1+r)^t} \;-\; \sum_{t}\frac{\tau D_t}{(1+r)^t} \;-\; \frac{R}{(1+r)^N},
$$

где $A_t$ — платёж по графику, $I_t$ — его процентная часть.

**Лизинг** устроен иначе: платёж целиком уменьшает базу по налогу на прибыль,
а амортизация начисляется лизингодателем — но по ускоренной схеме с
коэффициентом до трёх, и этот щит закладывается в цену договора:

$$
\mathrm{PV}_{\text{lease}} \;=\; \sum_{t}\frac{L_t\,(1 - \tau)}{(1+r)^t} \;+\; \frac{B\,(1-\tau)}{(1+r)^N}.
$$

**Ключ к сравнению** — кто эффективнее использует налоговый щит. Лизинг
выигрывает, когда лизингодатель может применить ускоренную амортизацию, а
лизингополучатель — нет, и делится частью выгоды. Он проигрывает, когда
удорожание превышает эту выгоду.

**Предельное удорожание** — та надбавка лизинговой компании, при которой
приведённые стоимости лизинга и лучшей альтернативы совпадают. Это готовая
переговорная позиция: выше неё договор подписывать не нужно.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(N)$ на вариант, $O(N\log(1/\varepsilon))$ на предельное удорожание |
| Память | $O(N)$ | потоки по трём вариантам |

## API

| Метод | Описание |
|-------|----------|
| `LeaseVsBuy.Compare(input)` | Три варианта, лучший и преимущество |
| `LeaseVsBuyResult.Options` | Приведённая стоимость, отток, щит и поток по каждому |
| `LeaseVsBuyResult.Best` / `Advantage` | Победитель и отрыв от второго места |
| `LeaseVsBuyResult.BreakEvenLeaseMarkup` | Предельное удорожание лизинга |
| `AcquisitionOption.CashFlows` | Поток варианта для подстановки в модель |

Исходники: `src/AI.Economics/Projects/LeaseVsBuy.cs`.

## Код

```csharp
using AI.Economics.Projects;

var acquisition = new LeaseVsBuyInput
{
    Asset = "Автопарк",
    AssetCost = 60_000_000,
    Years = 5,
    TaxRate = 0.2,
    DiscountRate = 0.16,
    DepreciationLife = 7,
    LeaseDepreciationFactor = 3,
    ResidualValue = 12_000_000,
    CreditRate = 0.17,
    CreditDownPayment = 0.2,
    LeaseMarkup = 0.09,
    LeaseAdvance = 0.15,
    LeaseBuyout = 0.01,
};

LeaseVsBuyResult comparison = LeaseVsBuy.Compare(acquisition);

foreach (AcquisitionOption option in comparison.Options.OrderBy(o => o.PresentValueOfCost))
{
    Console.WriteLine($"{option.Mode}: приведённые затраты {option.PresentValueOfCost:N0}, " +
                      $"номинальный отток {option.TotalOutflow:N0}, щит {option.TaxShield:N0}");
}

Console.WriteLine($"Лучший вариант: {comparison.Best}");
Console.WriteLine($"Преимущество над вторым местом {comparison.Advantage:N0}");
Console.WriteLine($"Предельное удорожание лизинга {comparison.BreakEvenLeaseMarkup:P1}");
```

Решение переворачивается при изменении налоговых условий — проверить это
стоит до подписания:

```csharp
foreach (double tax in new[] { 0.0, 0.10, 0.20 })
{
    LeaseVsBuyResult scenario = LeaseVsBuy.Compare(acquisition with { TaxRate = tax });
    Console.WriteLine($"Ставка налога {tax:P0}: выигрывает {scenario.Best}");
}
```

Коэффициент ускоренной амортизации у лизингодателя — главный источник выгоды
лизинга:

```csharp
foreach (double factor in new[] { 1.0, 2.0, 3.0 })
{
    LeaseVsBuyResult scenario = LeaseVsBuy.Compare(
        acquisition with { LeaseDepreciationFactor = factor });

    Console.WriteLine($"Коэффициент {factor:F0}: предельное удорожание " +
                      $"{scenario.BreakEvenLeaseMarkup:P1}");
}

Console.WriteLine(comparison.Interpret().ToLlmText());
```

## Ограничения

- Расчёт применим к прибыльной компании. При убытке налоговые щиты не
  реализуются, и лизинг с его немедленным списанием платежей теряет главное
  преимущество — а иногда становится единственным способом вообще получить щит.
- Модель предполагает, что актив нужен ровно на заданный срок. Лизинг с
  возвратом даёт гибкость выхода, которая здесь не оценивается и является
  самостоятельной ценностью.
- Ставка дисконтирования для всех вариантов одна. Строго говоря, лизинговые
  платежи — почти безрисковое обязательство и должны дисконтироваться по
  ставке долга, а остаточная стоимость — по более высокой.
- Балансовые эффекты не учитываются: перевод лизинга на баланс по МСФО 16
  меняет ковенанты и коэффициенты, даже когда денежные потоки идентичны.
- НДС в модели отсутствует. Для плательщика НДС он в основном нейтрален, но
  различия в моменте зачёта могут менять решение на коротких сроках.
