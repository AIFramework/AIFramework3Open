# Реальные опционы для НИОКР

Оценка проектов, которые можно отложить: сколько стоит право подождать там, где
обычный NPV уже отрицателен.

## Постановка задачи

Дано: приведённая стоимость будущих денежных потоков проекта, стоимость его
запуска, срок, в течение которого решение можно отложить, и неопределённость
стоимости.

Требуется: стоимость проекта с учётом права выбрать момент запуска, премия за
гибкость и порог, начиная с которого ждать уже не выгодно.

Где встречается: портфель НИОКР, лицензии и права на разработку, выход на
новый рынок, инвестиции в производственные мощности с опцией расширения.

## Теория

Классический NPV отвечает на вопрос «делать или не делать прямо сейчас» и
потому систематически недооценивает исследовательские проекты: он игнорирует,
что через год станет известно больше, а обязательства пока не приняты. Проект
с отрицательным NPV и высокой неопределённостью может иметь положительную
стоимость именно из-за права подождать.

Аналогия с финансовым опционом прямая:

| Реальный проект | Опцион |
|-----------------|--------|
| Приведённая стоимость проекта $S$ | Цена базового актива |
| Стоимость запуска $K$ | Цена исполнения |
| Срок принятия решения $T$ | Время до экспирации |
| Неопределённость $\sigma$ | Волатильность |
| Потери от прихода конкурента $q$ | Дивидендная доходность |

Европейский случай — формула Блэка — Шоулза с поправкой на утечку стоимости:

$$
C \;=\; S e^{-qT} N(d_1) - K e^{-rT} N(d_2),
\qquad
d_1 = \frac{\ln(S/K) + \left(r - q + \tfrac{\sigma^2}{2}\right)T}{\sigma\sqrt{T}},
\qquad
d_2 = d_1 - \sigma\sqrt{T}.
$$

Право запустить проект в любой момент до конца срока оценивается биномиальным
деревом Кокса — Росса — Рубинштейна: на каждом узле стоимость равна максимуму
из «подождать» и «запустить сейчас». При нулевой утечке стоимости досрочный
запуск невыгоден, и оба метода дают один ответ; при $q > 0$ дерево оценивает
проект дороже.

Премия за гибкость — разница между стоимостью с опционом и статическим
решением:

$$
\text{Premium} \;=\; C - \max(S - K, 0).
$$

Порог немедленного запуска — наименьшая стоимость проекта, при которой ждать
уже не имеет смысла. Он всегда выше $K$: пока неопределённость велика, право
подождать чего-то стоит, и запуск «в ноль» уничтожает эту стоимость.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n^2)$ | $n$ — шагов биномиального дерева |
| Память | $O(n)$ | Один слой дерева |

Порог запуска ищется делением отрезка пополам, каждая итерация строит дерево.

## API

| Метод | Описание |
|-------|----------|
| `RealOptionValuation.Evaluate(input)` | Обе оценки, премия за гибкость и порог |
| `RealOptionResult.StaticNpv` | Классический ответ «сейчас или никогда» |
| `RealOptionResult.BlackScholesValue` | Европейский опцион |
| `RealOptionResult.BinomialValue` | Американский опцион, право досрочного запуска |
| `RealOptionResult.FlexibilityPremium` | Сколько стоит право подождать |
| `RealOptionResult.ImmediateExerciseThreshold` | Порог немедленного запуска |

Исходник: `src/AI.Economics/Valuation/RealOptionValuation.cs`.

## Код

```csharp
using AI.Economics.Valuation;

var project = new RealOptionInput
{
    ProjectValue = 160_000_000,
    InvestmentCost = 200_000_000,
    YearsToDecision = 3,
    Volatility = 0.6,
    RiskFreeRate = 0.08,
    ValueLeakage = 0.05,
    Steps = 200,
};

RealOptionResult option = RealOptionValuation.Evaluate(project);

Console.WriteLine($"Статический NPV:     {option.StaticNpv:N0}");
Console.WriteLine($"Блэк — Шоулз:        {option.BlackScholesValue:N0}");
Console.WriteLine($"Биномиальное дерево: {option.BinomialValue:N0}");
Console.WriteLine($"Премия за гибкость:  {option.FlexibilityPremium:N0}");
Console.WriteLine($"Порог запуска:       {option.ImmediateExerciseThreshold:N0}");

foreach (double volatility in new[] { 0.2, 0.4, 0.6, 0.9 })
{
    RealOptionResult sensitivity = RealOptionValuation.Evaluate(project with { Volatility = volatility });
    Console.WriteLine($"sigma={volatility:F1}: стоимость {sensitivity.BinomialValue:N0}");
}
```

## Ограничения

- Волатильность стоимости непубличного проекта не наблюдаема и берётся из
  аналогов. Результат к ней очень чувствителен, а проверить допущение нечем —
  это главное ограничение метода, и цикл по `Volatility` в примере выше нужен
  именно для того, чтобы увидеть масштаб зависимости.
- Модель предполагает, что стоимость проекта меняется как геометрическое
  броуновское движение. Для НИОКР с дискретными вехами (испытание пройдено или
  не пройдено) ближе дерево решений с явными исходами.
- Право подождать в реальности не бесплатно: конкурент может занять рынок.
  Этот эффект задаётся параметром `ValueLeakage` и требует отдельной оценки.
- Метод оценивает один опцион. Портфель проектов с общими ресурсами и
  последовательными опционами требует более сложной постановки.
