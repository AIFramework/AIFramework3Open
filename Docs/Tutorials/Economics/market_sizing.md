# TAM / SAM / SOM с согласованием

Две независимые оценки объёма рынка — сверху вниз и снизу вверх — и главное,
что из них следует: величина расхождения между ними.

## Постановка задачи

Дано: объём рынка из отраслевого отчёта с фильтрами по географии и сегменту,
а также число потенциальных клиентов, средний контракт и параметры воронки.

Требуется: TAM, SAM и SOM обоими способами, согласованная оценка и вывод о том,
насколько модель рынка непротиворечива.

Где встречается: инвестиционная презентация, планирование территории продаж,
решение о выходе в новый сегмент.

## Теория

Оценка сверху вниз последовательно сужает общий рынок:

$$
TAM = M \cdot g_{geo},
\qquad
SAM = TAM \cdot g_{seg} \cdot g_{addr},
\qquad
SOM = SAM \cdot g_{achv}.
$$

Она не проверяема: один процент любого рынка звучит скромно и не следует ни
из чего.

Оценка снизу вверх строится от клиентов:

$$
TAM = N \cdot ARPA,
\qquad
SAM = TAM \cdot q_{fit} \cdot q_{reach},
\qquad
SOM = SAM \cdot w.
$$

Она проверяема, но систематически занижает — видит только известные сегодня
каналы и сегменты.

Согласование берёт среднее геометрическое:

$$
\hat V = \sqrt{V_{top} \cdot V_{bottom}}.
$$

Геометрическое, а не арифметическое: когда оценки различаются в разы,
арифметическое среднее почти повторяет большую из них и прячет проблему.

Практический вывод даёт не сама оценка, а расхождение
$D = \max(V_{top}, V_{bottom}) / \min(V_{top}, V_{bottom})$:

| Расхождение | Что это значит |
|-------------|----------------|
| до 1,5 | Модель рынка непротиворечива |
| до 3 | Проверьте долю сегмента и средний чек |
| до 10 | Одна из оценок опирается на неверное допущение |
| свыше 10 | Оценки несовместимы, считайте рынок заново |

Полезна и обратная проверка: подразумеваемая доля рынка $SOM/TAM$. Значение
выше нескольких процентов для нового игрока требует отдельного обоснования.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(1)$ | Замкнутые формулы |
| Память | $O(1)$ | Фиксированный набор величин |

## API

| Метод | Описание |
|-------|----------|
| `MarketSizing.Estimate(topDown, bottomUp)` | Обе оценки и согласование |
| `MarketSizingResult.TamDivergence` | Во сколько раз расходятся оценки TAM |
| `MarketSizingResult.ReconciledSom` | Согласованный достижимый объём |
| `MarketSizingResult.ImpliedMarketShare` | SOM делить на TAM — проверка на здравый смысл |
| `MarketSizingResult.Verdict` | Словесный вывод о согласованности |

Исходник: `src/AI.Economics/Market/MarketSizing.cs`.

## Код

```csharp
using AI.Economics.Market;

var topDown = new TopDownInput
{
    TotalMarketValue = 800_000_000_000,
    GeographyShare = 0.08,
    SegmentShare = 0.25,
    AddressableShare = 0.5,
    AchievableShare = 0.04,
};

var bottomUp = new BottomUpInput
{
    TargetAccounts = 12_000,
    QualifiedShare = 0.6,
    AnnualRevenuePerAccount = 1_200_000,
    ReachableShare = 0.5,
    WinRate = 0.06,
};

MarketSizingResult market = MarketSizing.Estimate(topDown, bottomUp);

Console.WriteLine($"TAM: {market.TamTopDown:N0} сверху / {market.TamBottomUp:N0} снизу");
Console.WriteLine($"Расхождение: {market.TamDivergence:F1}x");
Console.WriteLine($"Согласованный SOM: {market.ReconciledSom:N0}");
Console.WriteLine($"Подразумеваемая доля рынка: {market.ImpliedMarketShare:P2}");
Console.WriteLine(market.Verdict);
```

## Ограничения

- Обе оценки статичны: они описывают рынок сегодня и не учитывают его рост.
  Для прогноза проникновения используйте [диффузию Басса](bass_diffusion.md).
- Средний чек в оценке снизу вверх должен соответствовать сегменту из оценки
  сверху вниз. Смешение сегментов — самая частая причина расхождения в разы.
- Согласованная оценка не «правильнее» исходных: это компромисс, разумный
  только при умеренном расхождении. При разрыве свыше десяти раз усреднять
  нечего, надо искать ошибку.
- Конверсия воронки берётся как константа. На ранней стадии её значение обычно
  и есть главный источник неопределённости всей оценки.
