# Амортизация и налоговый щит

Линейный способ, уменьшаемый остаток, сумма чисел лет и удвоенный
уменьшаемый остаток с переходом на линейный: график начислений и приведённая
стоимость экономии на налоге.

## Постановка задачи

Дано: первоначальная стоимость актива, срок полезного использования,
ликвидационная стоимость, ставка налога на прибыль и ставка дисконтирования.

Требуется: график амортизационных начислений, налоговая экономия по годам и
её приведённая стоимость — а также ответ на вопрос, какой способ выгоднее.

Где встречается: расчёт денежного потока инвестиционного проекта, налоговое
планирование, сравнение лизинга с покупкой, учётная политика компании.

## Теория

Амортизация не является денежным расходом, но уменьшает налогооблагаемую
прибыль. Поэтому её экономическая ценность равна **налоговому щиту**:

$$
\mathrm{Shield}_t \;=\; \tau\,D_t,
\qquad
\mathrm{PV} \;=\; \sum_{t=1}^{N}\frac{\tau\,D_t}{(1+r)^t}.
$$

Сумма начислений одинакова при любом способе и равна амортизируемой стоимости
$C - S$. Различается только **распределение по времени**, а поскольку деньги
имеют стоимость, ускоренные способы дают большую приведённую экономию.

**Линейный способ** распределяет стоимость равномерно:

$$
D_t = \frac{C - S}{N}.
$$

**Уменьшаемый остаток** начисляет фиксированный процент от остаточной
стоимости:

$$
D_t = k\,\frac{V_{t-1}}{N},\qquad V_t = V_{t-1} - D_t,
$$

где $k$ — коэффициент ускорения (обычно 2). Метод никогда не доводит остаток
до нуля, поэтому на практике применяется **переход на линейный**: как только
равномерное списание остатка за оставшиеся годы превышает текущее начисление
по уменьшаемому остатку, способ переключается. Это даёт максимально быстрое
списание из допустимых.

**Сумма чисел лет** распределяет стоимость пропорционально убывающему
остатку срока:

$$
D_t = (C - S)\,\frac{N - t + 1}{N(N+1)/2}.
$$

**Показатель фронтальности** — доля стоимости, списанная в первой половине
срока. Для линейного способа он равен 0,5, для ускоренных — заметно больше;
именно он объясняет разницу в приведённой стоимости щита.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(N)$ | $N$ — срок полезного использования |
| Память | $O(N)$ | график по годам |

## API

| Метод | Описание |
|-------|----------|
| `Depreciation.Build(cost, life, method, salvage, tax, rate, factor)` | График одного способа |
| `Depreciation.CompareMethods(cost, life, salvage, tax, rate)` | Все способы сразу |
| `Depreciation.Charges(schedule)` | Начисления вектором для подстановки в поток |
| `DepreciationSchedule.PresentValueOfShield` | Приведённая экономия на налоге |
| `DepreciationSchedule.FrontLoading` | Доля стоимости, списанная в первой половине срока |

Исходники: `src/AI.Economics/Projects/Depreciation.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Projects;

DepreciationSchedule straight = Depreciation.Build(
    cost: 120_000_000,
    usefulLife: 8,
    method: DepreciationMethod.StraightLine,
    salvage: 12_000_000,
    taxRate: 0.2,
    discountRate: 0.14);

foreach (DepreciationPeriod period in straight.Periods)
{
    Console.WriteLine($"Год {period.Period}: начислено {period.Charge:N0}, " +
                      $"остаток {period.ClosingValue:N0}, щит {period.TaxShield:N0}");
}

Console.WriteLine($"Приведённый щит {straight.PresentValueOfShield:N0}");
```

Сравнение способов — основной сценарий использования: суммарное начисление
совпадает, приведённая экономия различается:

```csharp
IReadOnlyList<DepreciationSchedule> methods = Depreciation.CompareMethods(
    cost: 120_000_000, usefulLife: 8, salvage: 12_000_000, taxRate: 0.2, discountRate: 0.14);

foreach (DepreciationSchedule schedule in methods.OrderByDescending(s => s.PresentValueOfShield))
{
    Console.WriteLine($"{schedule.Method}: щит {schedule.PresentValueOfShield:N0}, " +
                      $"фронтальность {schedule.FrontLoading:P1}");
}

double gain = methods.Max(s => s.PresentValueOfShield) - straight.PresentValueOfShield;
Console.WriteLine($"Выигрыш ускоренного способа {gain:N0}");
```

Начисления подставляются прямо в денежный поток проекта:

```csharp
Vector charges = Depreciation.Charges(straight);
Console.WriteLine($"Начисления по годам: {string.Join(", ", charges.Select(c => $"{c:N0}"))}");

Console.WriteLine(straight.Interpret().ToLlmText());
```

## Ограничения

- Бухгалтерская и налоговая амортизация — разные вещи. Для расчёта щита
  берите налоговую: срок и способ задаются налоговым кодексом, а не учётной
  политикой.
- Ускоренная амортизация выгодна только прибыльной компании. При убытке щит
  переносится на будущее и обесценивается — иногда до нуля, если срок
  переноса ограничен.
- Ликвидационная стоимость в модели уменьшает амортизируемую базу. В налоговом
  учёте многих юрисдикций она не учитывается, и списывается вся стоимость —
  проверьте применимость.
- Переход на линейный способ внутри уменьшаемого остатка разрешён не везде.
  Без него метод не досписывает актив полностью.
- Модель не учитывает переоценку, модернизацию и досрочное выбытие — каждое из
  них перестраивает график с даты события.
