# Оптимизация портфеля по CVaR

Минимизация условных потерь в хвосте вместо дисперсии: формулировка
Рокафеллара — Урясева, сравнение с портфелем минимальной дисперсии и выигрыш
на хвосте.

## Постановка задачи

Дано: матрица сценариев доходностей активов (исторических или смоделированных),
уровень доверия и ограничения на веса.

Требуется: портфель, минимизирующий средние потери в худших сценариях, — и
оценка того, насколько он лучше портфеля минимальной дисперсии именно в
хвосте.

Где встречается: портфели с опционами и структурными продуктами, кредитные
портфели, стратегии с асимметричной отдачей, требования регулятора,
сформулированные через Expected Shortfall.

## Теория

Дисперсия наказывает отклонения в обе стороны и потому непригодна для
асимметричных распределений: стратегия «собирать премию, изредка теряя много»
имеет низкую дисперсию и катастрофический хвост.

**Условные потери** (CVaR, Expected Shortfall) измеряют средний убыток за
порогом VaR:

$$
\mathrm{CVaR}_\alpha(w) \;=\; \mathbb E\!\left[-r_w \mid -r_w \ge \mathrm{VaR}_\alpha(w)\right].
$$

Прямая минимизация этой величины сложна: она требует знания порога, который
сам зависит от весов.

**Приём Рокафеллара — Урясева** снимает эту трудность. Вводится
вспомогательная переменная $\zeta$ (кандидат в VaR), и минимизируется
функция:

$$
F_\alpha(w,\zeta) \;=\; \zeta + \frac{1}{(1-\alpha)S}\sum_{s=1}^{S}\left[-r_s^{\top}w - \zeta\right]^{+}.
$$

Доказано, что минимум $F$ по $(w,\zeta)$ равен минимуму CVaR по $w$, а
оптимальное $\zeta$ равно VaR. Ключевое свойство: $F$ **выпукла** по обоим
аргументам, поэтому задача решается стандартными методами и не имеет локальных
минимумов. При линейных ограничениях она сводится к задаче линейного
программирования.

**Субградиентный спуск.** Функция кусочно-линейна, её субградиент по весам
равен усреднению доходностей по хвостовым сценариям:

$$
\partial_w F \;=\; -\frac{1}{(1-\alpha)S}\sum_{s\,:\,-r_s^{\top}w > \zeta} r_s ,
$$

а по $\zeta$ — разности между единицей и долей хвостовых сценариев, делённой
на $1-\alpha$. Проекция на симплекс после каждого шага удерживает веса
допустимыми.

**Число хвостовых сценариев** равно $(1-\alpha)S$ и определяет качество
решения: при 500 сценариях и уровне 95% оптимизация опирается на 25
наблюдений. Это главное практическое ограничение метода.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(I\,S\,n)$ | $I$ итераций, $S$ сценариев, $n$ активов |
| Память | $O(Sn)$ | матрица сценариев |

## API

| Метод | Описание |
|-------|----------|
| `CvarOptimization.Optimize(scenarios, assets, confidence, minReturn, maxWeight)` | Оптимальный по CVaR портфель |
| `CvarOptimization.Evaluate(scenarios, weights, confidence)` | VaR и CVaR заданных весов |
| `CvarOptimizationResult.MeanVarianceWeights` / `MeanVarianceCvar` | Портфель сравнения |
| `CvarOptimizationResult.TailImprovement` | Выигрыш на хвосте в долях |
| `CvarOptimizationResult.TailScenarios` | Сколько сценариев формируют решение |

Исходники: `src/AI.Economics/Portfolio/CvarOptimization.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Portfolio;
using AI.Statistics;

Random draw = RandomEngine.Create(67);
var scenarios = new Matrix(1500, 4);
string[] book = ["Облигации", "Акции", "Опционная стратегия", "Золото"];

for (int s = 0; s < scenarios.Height; s++)
{
    double market = RandomEngine.NextGaussian(draw);
    bool crash = draw.NextDouble() < 0.03;

    scenarios[s, 0] = RandomEngine.NextGaussian(draw, 0.005, 0.010);
    scenarios[s, 1] = 0.008 + (0.045 * market) - (crash ? 0.12 : 0);

    // Продажа волатильности: обычно плюс, изредка обвал
    scenarios[s, 2] = crash ? -0.30 : RandomEngine.NextGaussian(draw, 0.014, 0.012);
    scenarios[s, 3] = RandomEngine.NextGaussian(draw, 0.004, 0.030) + (crash ? 0.05 : 0);
}

CvarOptimizationResult optimal = CvarOptimization.Optimize(
    scenarios, book, confidence: 0.95, maximumWeight: 0.6);

for (int i = 0; i < book.Length; i++)
{
    Console.WriteLine($"{book[i]}: CVaR-портфель {optimal.Weights[i]:P1}, " +
                      $"минимальная дисперсия {optimal.MeanVarianceWeights[i]:P1}");
}

Console.WriteLine($"CVaR {optimal.ConditionalValueAtRisk:P2} против " +
                  $"{optimal.MeanVarianceCvar:P2} у портфеля минимальной дисперсии");
Console.WriteLine($"Выигрыш на хвосте {optimal.TailImprovement:P1}");
Console.WriteLine($"Решение опирается на {optimal.TailScenarios} сценариев из {optimal.Scenarios}");
```

Разница между подходами видна именно на асимметричном активе — дисперсия его
не боится:

```csharp
Console.WriteLine($"Доходность {optimal.ExpectedReturn:P2}, волатильность {optimal.Volatility:P2}");
Console.WriteLine($"VaR {optimal.ValueAtRisk:P2} при уровне {optimal.Confidence:P0}");
```

Любые веса можно оценить в той же метрике — например, равновзвешенный
портфель:

```csharp
var equal = new Vector(0.25, 0.25, 0.25, 0.25);
(double var, double cvar) = CvarOptimization.Evaluate(scenarios, equal, 0.95);

Console.WriteLine($"Равновзвешенный: VaR {var:P2}, CVaR {cvar:P2}");
Console.WriteLine(optimal.Interpret().ToLlmText());
```

## Ограничения

- Качество решения определяется числом сценариев в хвосте. Для уровня 99%
  нужно не менее 2000–5000 сценариев, иначе оптимизация подгоняется под
  несколько случайных наблюдений.
- Исторические сценарии не содержат кризисов, которых не было. Дополняйте
  выборку смоделированными шоками — например, из
  [копул](copulas.md) с хвостовой зависимостью.
- CVaR — когерентная мера риска, но она игнорирует всё, что происходит внутри
  «нормальной» части распределения. Портфель может иметь отличный CVaR и
  посредственную повседневную доходность.
- Субградиентный метод сходится медленно и даёт решение с точностью до
  нескольких десятых процента по весам. Для точного решения нужен симплекс-метод.
- Оптимизация на исторических сценариях страдает от переобучения сильнее,
  чем оптимизация по дисперсии: хвост содержит меньше информации. Обязательно
  проверяйте портфель на отложенной выборке.
