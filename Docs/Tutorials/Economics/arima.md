# ARIMA и SARIMAX

Авторегрессия со скользящим средним, сезонной частью и внешними регрессорами —
рабочая лошадь прогнозирования спроса.

## Постановка задачи

Дано: исторический ряд спроса, при необходимости — внешние регрессоры: цена,
промо-флаг, праздники.

Требуется: прогноз на заданный горизонт с интервалами.

Где встречается: планирование закупок и производства, бюджет продаж,
прогноз выручки для финансовой модели.

## Теория

Модель $ARIMA(p,d,q)(P,D,Q)_s$ записывается через операторы:

$$
\phi(B)\,\Phi(B^s)\,(1-B)^d (1-B^s)^D\, y_t = \theta(B)\,\Theta(B^s)\,\varepsilon_t.
$$

Реализация разворачивает мультипликативную сезонную часть и оператор
дифференцирования в обычные многочлены. Прогноз тогда считается рекуррентно
прямо по исходному ряду, а веса представления скользящего среднего дают
дисперсию прогноза:

$$
\mathrm{Var}\!\left(\hat y_{t+h}\right) = \sigma^2 \sum_{j=0}^{h-1} \psi_j^2.
$$

Оценка ведётся условным методом наименьших квадратов: минимизируется сумма
квадратов однодневных ошибок. Метод уступает полному правдоподобию на коротких
рядах, но не требует фильтра Калмана и устойчив на данных планирования спроса.

**Стационарность и обратимость обеспечиваются параметризацией через частные
автокорреляции.** Оптимизатор работает с неограниченными переменными, а
преобразование гарантирует, что корни характеристического многочлена лежат
вне единичного круга. Без этого симплекс-метод регулярно уходит в область
нестационарности, где сумма квадратов формально меньше, а прогноз расходится.

**Без дифференцирования модель обязана учитывать уровень ряда.** Иначе
авторегрессия вынуждена воспроизводить среднее сама, и коэффициент уезжает
к единице независимо от истинной динамики. Ряд центрируется, что эквивалентно
свободному члену $(1-\sum\phi_i)\mu$ в разностном уравнении.

Внешние регрессоры входят как регрессия с ARIMA-ошибками: сначала оценивается
линейная связь, затем остатки описываются ARIMA. Это не то же самое, что
включить регрессоры внутрь разностного уравнения, но коэффициенты сохраняют
прямую интерпретацию.

Порядок дифференцирования при автоподборе выбирается по убыванию дисперсии,
а не тестом на единичный корень: на рядах длиной в пару лет тест почти всегда
неинформативен, а сравнение дисперсий устойчиво.

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Оценка | $O(I \cdot n\,(p^{*} + q^{*}))$ | $I$ — итераций симплекса, звёздочка — развёрнутые порядки |
| Автоподбор | $O(P_{max} Q_{max} \cdot \text{оценка})$ | Перебор по сетке |
| Память | $O(n + h)$ | Ряд и прогноз |

## API

| Метод | Описание |
|-------|----------|
| `Arima.Fit(series, order, horizon, exogenous, level)` | Оценка заданного порядка и прогноз |
| `Arima.AutoFit(series, horizon, season, maxOrder, level)` | Перебор по сетке с выбором по AIC |
| `ArimaOrder` | Порядки обычной и сезонной частей |
| `ForecastResult.Lower` / `Upper` | Интервалы прогноза по весам представления |
| `ForecastResult.ResidualAutocorrelation` | Проверка на неописанную структуру |
| `ForecastResult.InSampleMase` | Сравнение с наивным прогнозом |

Исходник: `src/AI.Economics/Forecasting/Arima.cs`.

## Код

```csharp
using AI.DataStructs.Algebraic;
using AI.Economics.Forecasting;

var random = new Random(7);
const int weeks = 156;
var demand = new Vector(weeks);

for (int t = 0; t < weeks; t++)
{
    demand[t] = 1000 + (2.0 * t)
              + (150 * Math.Sin(2 * Math.PI * t / 52.0))
              + ((random.NextDouble() - 0.5) * 80);
}

ForecastResult auto = Arima.AutoFit(demand, horizon: 26, season: 52);

Console.WriteLine($"Выбранная модель: {auto.Model}, AIC = {auto.Aic:F1}");
Console.WriteLine($"MASE на обучении: {auto.InSampleMase:F3}");

for (int h = 0; h < auto.Horizon; h += 6)
{
    Console.WriteLine($"+{h + 1,3} нед.: {auto.PointForecast[h],8:N0} " +
                      $"[{auto.Lower[h],8:N0}; {auto.Upper[h],8:N0}]");
}

// Явно заданный порядок, если он известен из предыдущего анализа
var manual = new Arima();
ForecastResult fixedOrder = manual.Fit(
    demand,
    new ArimaOrder { P = 1, D = 1, Q = 1, SeasonalP = 1, SeasonalD = 0, SeasonalQ = 0, Season = 52 },
    horizon: 26);

Console.WriteLine($"Ручной порядок: {fixedOrder.Model}, сигма = {fixedOrder.Sigma:F1}");
Console.WriteLine(auto.Interpret().ToLlmText());
```

## Ограничения

- Условный метод наименьших квадратов отбрасывает первые наблюдения. На рядах
  короче полутора-двух сезонных циклов это заметно ухудшает оценку.
- Автоподбор по AIC склонен к переобучению на коротких рядах: сравнивайте
  кандидатов бэктестом, а не только информационным критерием.
- Интервалы прогноза рассчитаны в предположении нормальности ошибок и
  правильности модели. На практике оба предположения нарушаются, и покрытие
  оказывается ниже заявленного — калибруйте
  [конформным предсказанием](conformal.md).
- Внешние регрессоры должны быть известны на горизонте прогноза. Для цены и
  промо это выполнимо, для погоды и курса — нет.
- Модель не умеет работать с прерывистым спросом: на рядах с большинством
  нулевых периодов используйте
  [специализированные методы](intermittent.md).
