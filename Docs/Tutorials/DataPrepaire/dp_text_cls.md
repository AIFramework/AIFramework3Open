# TextRuleClassifier (AI.DataPrepaire)

## Классификация текста по правилам

`TextRuleClassifier` — гибридный классификатор, сочетающий:
1. **Явные правила** (ключевые слова/фразы) → класс
2. **n-граммные признаки** → статистический классификатор

## Алгоритм

Для каждого входного текста:

$$
\hat{y} = \arg\max_k \left( \text{score}(x, k) \right)
$$

где $\text{score}$ учитывает:
- Совпадения с ключевыми словами класса $k$
- n-граммное сходство с обучающими примерами
- Пороговый параметр `top_p` для фильтрации

## Параметры

| Параметр | Описание |
|----------|----------|
| `count_of_classes` | Число классов |
| `top_p` | Порог для отсечения неуверенных предсказаний |
| `max_n_gramm` | Максимальный порядок n-граммы (1 = unigram, 2 = bigram, …) |

## API

```csharp
using AI.DataPrepaire.NLPUtils.TextClassification;

// Создание классификатора
var cls = new TextRuleClassifier(
    count_of_classes: 3,
    top_p: 0.5,
    max_n_gramm: 3
);

// Добавление явных правил (ключевое слово → класс)
cls.AddRule("футбол", 0);     // спорт
cls.AddRule("матч чемпионат", 0);
cls.AddRule("выборы", 1);     // политика
cls.AddRule("нейросеть", 2);  // технологии

// Обучение на примерах
string[] texts  = { "команда победила в матче", "закон принят думой", "ИИ обучился на данных" };
int[]    labels = { 0, 1, 2 };
cls.Train(texts, labels);

// Классификация
int predicted = cls.Predict("гол в финале чемпионата");
// → 0 (спорт)

Console.WriteLine($"Правил в модели: {cls.CountRules}");
```
