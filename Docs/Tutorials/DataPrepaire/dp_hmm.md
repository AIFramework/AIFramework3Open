# Марковская генерация текста — HMMFast (AI.DataPrepaire)

## Скрытые Марковские модели и n-граммы

`HMMFast` реализует **n-граммную языковую модель** на основе цепей Маркова. Вероятность следующего слова определяется последовательностью $n-1$ предыдущих:

$$
P(w_t \mid w_{t-n+1}, \ldots, w_{t-1}) = \frac{C(w_{t-n+1}, \ldots, w_t)}{C(w_{t-n+1}, \ldots, w_{t-1})}
$$

## Процесс обучения

1. Токенизировать корпус с помощью `WordTokenizer`
2. Подсчитать частоты всех n-грамм
3. Нормализовать → получить условные вероятности $P(w_t \mid \text{context})$

## Генерация

Алгоритм генерации (сэмплинг):
1. Задать начальный контекст (prompt)
2. Выбрать следующий токен согласно $P(w \mid \text{context})$
3. Добавить токен в контекст, сдвинуть окно
4. Повторить $N$ раз

## TextToVector

```
text → tokens → P(next_token | context)
```

Возвращает вектор вероятностей распределения по всему словарю.

## API

```csharp
using AI.DataPrepaire.NLPUtils.TextGeneration;

// Создание и обучение
var hmm = new HMMFast();
hmm.Train(corpusText, addStart: false);

// Генерация N слов
string generated = hmm.Generate(50);

// Генерация с начальным контекстом
string[] prompt = { "нейронная", "сеть" };
string withPrompt = hmm.Generate(30, prompt);

// Генерация с seed для воспроизводимости
var rng = new Random(42);
string seeded = hmm.Generate(20, prompt, rng);

// Вектор вероятностей для заданного контекста
Vector probs = hmm.TextToVector("машинное обучение");
// probs[i] = P(токен_i | "машинное обучение")
```
