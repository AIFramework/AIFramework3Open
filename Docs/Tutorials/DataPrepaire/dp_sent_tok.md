# Токенизация предложений (AI.DataPrepaire)

## Задача

Разбить сплошной текст на отдельные предложения, корректно обрабатывая:
- Аббревиатуры (`г.`, `т. е.`, `д-р`, `ул.`)
- Числа с точкой (`3.14`, `15.01.2025`)
- Инициалы (`И. И. Иванов`)
- Многоточия (`...`)

## Алгоритм `SentencesTokenizer`

Использует набор регулярных выражений для:
1. Замены аббревиатур на безопасные токены (чтобы точки не разрывали предложение)
2. Разбивки по границам предложений (`[.!?]` + пробел + заглавная)
3. Восстановления аббревиатур

## Статистика предложений

Для анализа качества токенизации полезны метрики:
- Среднее число слов на предложение (норма для русского: 12–15 слов)
- Длина в символах
- Доля коротких предложений (< 3 слов)
