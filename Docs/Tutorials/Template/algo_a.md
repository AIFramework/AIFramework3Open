# Алгоритм A — образец документа теории

Это файл-шаблон для модуля `Template`. Он одновременно служит **эталонным
примером канона** из [STRUCTURE.md](../STRUCTURE.md): скопируйте его при
создании нового раздела демо и замените содержимое, сохранив набор разделов.

## Постановка задачи

Начните с того, **что дано и что требуется найти**, в терминах предметной
области, а не кода. Читатель попал на страницу из каталога и ещё не знает,
зачем ему этот алгоритм.

Дано: выборка $x_1, \dots, x_n$ из неизвестного распределения.
Требуется: оценка параметра $\theta$, устойчивая к выбросам.

Где встречается: предобработка сигналов, робастная статистика,
инициализация итеративных методов.

## Теория

Формулы пишите в LaTeX. Строчные — `$\theta$`, выносные — `$$…$$`:

$$
\hat{\theta} \;=\; \arg\min_{\theta} \sum_{i=1}^{n} \rho\!\left(x_i - \theta\right),
$$

где $\rho$ — функция потерь. При $\rho(u) = u^2$ получается среднее
арифметическое, при $\rho(u) = |u|$ — медиана.

Если параметр демо участвует в формуле, **называйте его так же, как
`AlgoParam.Label`** — тогда читатель свяжет ползунок справа с математикой
слева. Здесь коэффициент $\alpha$ — это ползунок «Коэффициент α».

## Сложность

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| Время  | $O(n \log n)$ | Доминирует сортировка выборки |
| Память | $O(n)$ | Копия входного массива |

Указывайте, что означают обозначения: $n$ — размер выборки.

## API

| Метод | Описание |
|-------|----------|
| `AlgorithmA(double alpha)` | Конструктор, `alpha` — коэффициент регуляризации |
| `Estimate(Vector x)` | Возвращает оценку $\hat{\theta}$ |
| `EstimateWithCi(Vector x, double level)` | Оценка вместе с доверительным интервалом |

Исходник: `src/AI.Template/AlgorithmA.cs`.

## Код

Сниппет должен компилироваться после копирования — без псевдокода и
многоточий вместо тела метода:

```csharp
using AI.Template;
using AI.DataStructs.Algebraic;

var x = new Vector(new double[] { 1.2, 0.8, 1.1, 9.7, 1.0 });

var algo = new AlgorithmA(alpha: 0.5);
double theta = algo.Estimate(x);

// Выброс 9.7 почти не влияет на результат
Console.WriteLine($"theta = {theta:F4}");
```

## Ограничения

- Требует $n \ge 3$: на двух точках оценка вырождается.
- При $\alpha \to 0$ метод сходится к обычному среднему и теряет
  робастность — именно это видно на демо справа при сдвиге ползунка влево.
- Не предназначен для многомерных данных: используйте `AlgorithmB`.
