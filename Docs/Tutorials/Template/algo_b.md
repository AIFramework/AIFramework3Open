# Алгоритм B — образец документа без параметров

Второй файл-шаблон модуля `Template`. Показывает случай, когда у алгоритма
**нет настраиваемых параметров**: таблица «Параметры демо» под теорией тогда
не отображается, и всё объяснение ложится на текст.

## Постановка задачи

Дано: матрица наблюдений $X \in \mathbb{R}^{n \times m}$.
Требуется: разложение $X = U \Sigma V^{\top}$ без выбора гиперпараметров.

Алгоритмы без параметров удобны как эталон: с ними сравнивают методы,
у которых настройка есть.

## Теория

$$
X \;=\; U \Sigma V^{\top}, \qquad
U^{\top}U = I, \quad V^{\top}V = I, \quad
\Sigma = \operatorname{diag}(\sigma_1 \ge \dots \ge \sigma_r > 0).
$$

Сингулярные числа $\sigma_i$ задают энергию соответствующих компонент;
их убывание показывает, сколько компонент действительно нужно.

## Сложность

Время $O(n m \min(n, m))$, память $O(nm)$. Для $n \gg m$ выгоднее сначала
вычислить $X^{\top}X$ размера $m \times m$.

## API

| Метод | Описание |
|-------|----------|
| `AlgorithmB()` | Конструктор без параметров |
| `Decompose(Matrix x)` | Возвращает `(U, Sigma, V)` |
| `Rank(Matrix x, double eps)` | Численный ранг по порогу $\varepsilon$ |

Исходник: `src/AI.Template/AlgorithmB.cs`.

## Код

```csharp
using AI.Template;
using AI.DataStructs.Algebraic;

var x = new Matrix(4, 3);
// ... заполнение x ...

var algo = new AlgorithmB();
var (u, sigma, v) = algo.Decompose(x);

Console.WriteLine($"Численный ранг: {algo.Rank(x, 1e-9)}");
```

## Ограничения

- Плотное разложение: для разреженных матриц выше $10^4 \times 10^4$
  нужен итеративный метод.
- Знаки столбцов $U$ и $V$ определены с точностью до общего множителя
  $\pm 1$ — не сравнивайте их поэлементно между запусками.
