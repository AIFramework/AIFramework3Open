# KL-дивергенция Кульбака–Лейблера

**KL-дивергенция** измеряет, насколько одно распределение $p$ отличается от другого $q$:

$$
D_{\mathrm{KL}}(p \,\|\, q) \;=\; \int p(x) \log\frac{p(x)}{q(x)}\,dx.
$$

Для дискретных распределений интеграл заменяется суммой.

## Свойства

- $D_{\mathrm{KL}}(p \| q) \ge 0$, равенство ⇔ $p = q$ почти всюду (неравенство Гиббса);
- **Несимметрична**: $D_{\mathrm{KL}}(p \| q) \ne D_{\mathrm{KL}}(q \| p)$;
- Не метрика (не удовлетворяет треугольнику);
- Не определена, если $q(x) = 0$ в точке с $p(x) > 0$.

## Симметричные варианты

$$
D_{\mathrm{sym}}(p, q) \;=\; \tfrac{1}{2}\left(D_{\mathrm{KL}}(p \| q) + D_{\mathrm{KL}}(q \| p)\right).
$$

Популярнее — дивергенция Дженсена–Шеннона:
$D_{\mathrm{JS}}(p, q) = \tfrac{1}{2}\left(D_{\mathrm{KL}}(p \| m) + D_{\mathrm{KL}}(q \| m)\right)$, где $m = (p + q)/2$.

## KL для двух нормальных

Закрытая формула для $p = \mathcal{N}(\mu_1, \sigma_1^2), q = \mathcal{N}(\mu_2, \sigma_2^2)$:

$$
D_{\mathrm{KL}}(p \,\|\, q) \;=\; \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \tfrac{1}{2}.
$$

## Применения

- **Вариационный инференс**: минимизация $D_{\mathrm{KL}}(q \| p)$ по параметрам $q$;
- **Обучение с подкреплением**: регуляризация политики;
- **Классификация**: кросс-энтропия $= H(p) + D_{\mathrm{KL}}(p \| q)$;
- **Сжатие данных**: $D_{\mathrm{KL}}(p \| q)$ — избыточный в среднем код-длина при использовании $q$ вместо истинной $p$.

## Код

```csharp
using AI.Distances;

double kl     = ProbabilityDistances.DKL(p, q);
double klSym  = ProbabilityDistances.DKLSymmetrical(p, q);
```

В демо сравниваются аналитический результат (для двух гауссиан) и численный (по плотностям, вычисленным на сетке).
