# Матрица корреляций

Для набора $k$ случайных величин $X_1, \dots, X_k$ **матрица корреляций** — симметричная $k \times k$ матрица $R$ с $R_{ij} = \mathrm{corr}(X_i, X_j)$:

$$
R_{ii} = 1, \qquad R_{ij} = R_{ji} = \frac{\mathrm{cov}(X_i, X_j)}{\sigma_i \sigma_j}.
$$

## Свойства

- Симметричная, положительно полуопределённая;
- Диагональ всегда $= 1$;
- Собственные значения $\lambda_i \ge 0$ и $\sum \lambda_i = k$.

## Матрица ковариаций

Более общий объект: $\Sigma_{ij} = \mathrm{cov}(X_i, X_j)$; $R$ — это $\Sigma$ нормированная на диагональ.

## Применения

1. **Анализ главных компонент (PCA)** — разложение $R$ (или $\Sigma$) по собственным векторам.
2. **Проверка мультиколлинеарности** в регрессии.
3. **Кластеризация признаков** — группировка сильно коррелирующих переменных.
4. **Скрытые факторы** — сильные недиагональные элементы подсказывают общие источники вариации.

## Демо

Генерируется $k$ рядов через модель с **общим фактором**:

$$
X_i = s \cdot (-1)^{i} F + (1 - s) \varepsilon_i,
$$

где $F \sim \mathcal{N}(0, 1)$ — общий сигнал, $\varepsilon_i$ — независимый шум, $s \in [0, 1]$ — сила общего сигнала. При $s = 0$ матрица близка к $I$, при $s = 1$ — все корреляции $\pm 1$.

## Код

```csharp
Vector[] series = /* k рядов */;
Matrix R = Matrix.GetCorrelationMatrixNorm(series);
Matrix S = Matrix.GetCovMatrix(series);
// R[i, j] ∈ [-1, 1], R[i, i] = 1
```

На графике — тепловая карта с расходящейся цветовой шкалой (синий = отрицательная корреляция, белый = 0, красный = положительная).
