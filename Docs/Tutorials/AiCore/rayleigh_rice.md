# Распределения Релея и Райса

## Распределение Релея (Rayleigh)

Модуль двумерного гауссовского шума: если X, Y ~ N(0, σ²), то R = √(X² + Y²) ~ Rayleigh(σ).

### PDF

$$
f(x; \sigma) = \frac{x}{\sigma^2} \exp\left(-\frac{x^2}{2\sigma^2}\right), \quad x \geq 0
$$

### Моменты

- E[X] = σ√(π/2) ≈ 1.253σ
- Var[X] = (4 − π)/2 · σ² ≈ 0.429σ²
- Мода = σ

### Применения

- Моделирование огибающей шума в радиолокации и связи
- Анализ замираний (фединга) в канале без прямого луча
- Распределение скорости ветра

## Распределение Райса (Rice / Rician)

Модуль вектора с ненулевым средним: если X ~ N(ν, σ²), Y ~ N(0, σ²), то R = √(X² + Y²) ~ Rice(ν, σ).

### PDF

$$
f(x; \nu, \sigma) = \frac{x}{\sigma^2} \exp\left(-\frac{x^2 + \nu^2}{2\sigma^2}\right) I_0\left(\frac{x\nu}{\sigma^2}\right)
$$

где I₀ — модифицированная функция Бесселя первого рода нулевого порядка.

### Частные случаи

- ν = 0 → Rayleigh(σ)
- ν ≫ σ → ≈ N(ν, σ²)

### K-фактор Райса

$$
K = \frac{\nu^2}{2\sigma^2}
$$

K характеризует отношение мощности прямого луча к рассеянной мощности.

### Применения

- Канал связи с прямым лучом (Line-of-Sight) + рассеяние
- МРТ-визуализация (амплитудное изображение)
- Ультразвуковая диагностика

## Код

```csharp
using AI.Statistics;

var rng = new Random(42);
double r = RandomEngine.NextRayleigh(rng, sigma: 1.5);
double rice = RandomEngine.NextRice(rng, nu: 3.0, sigma: 1.0);
```
