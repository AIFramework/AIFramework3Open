# Доверительные интервалы для среднего

## Идея

Доверительный интервал (CI) — интервальная оценка параметра θ,
которая с заданной вероятностью (1−α) покрывает истинное значение.

Для среднего μ при выборке x₁, …, xₙ:

$$
\bar{x} \pm \text{margin}
$$

## z-интервал (σ известно)

Если дисперсия σ² известна, стандартизованная величина

$$
Z = \frac{\bar{x} - \mu}{\sigma / \sqrt{n}} \sim \mathcal{N}(0, 1)
$$

Квантиль z_{1−α/2} даёт

$$
\text{CI}_z = \bar{x} \pm z_{1-\alpha/2} \cdot \frac{\sigma}{\sqrt{n}}
$$

## t-интервал (σ неизвестно)

При замене σ на выборочное s используется распределение Стьюдента:

$$
T = \frac{\bar{x} - \mu}{s / \sqrt{n}} \sim t(n-1)
$$

$$
\text{CI}_t = \bar{x} \pm t_{1-\alpha/2,\, n-1} \cdot \frac{s}{\sqrt{n}}
$$

t-интервал всегда шире z-интервала (t-квантиль > z-квантиля),
но разница исчезает при n → ∞.

## Свойства

- **Ширина ∝ 1/√n** — чтобы уменьшить CI в 2 раза, нужно n × 4.
- **Покрытие** — в длинной серии экспериментов доля CI, содержащих μ, → (1−α).
- **Не вероятность**: "μ лежит в CI" — не случайное событие; случаен сам интервал.

## Код

```csharp
using AI.Statistics;

var (lo, hi) = StatInference.ConfidenceIntervalT(
    mean: 2.1, std: 0.9, n: 50, confidence: 0.95);
// lo ≈ 1.84, hi ≈ 2.36
```
