# Численное дифференцирование и интегрирование

## Дифференцирование конечными разностями

Простейшая схема первого порядка:

$$
f'(x_i) \;\approx\; \frac{f(x_{i+1}) - f(x_i)}{h}, \qquad h = x_{i+1} - x_i.
$$

Погрешность $O(h)$ — линейно убывает с измельчением сетки. Центральная разность $\dfrac{f_{i+1} - f_{i-1}}{2h}$ даёт погрешность $O(h^2)$.

В `AI.Functions.Diff`:

- `Diff(v)` — конечные разности;
- `Diff(v, fd)` — умножение на частоту дискретизации $f_d = 1/h$, чтобы получить производную по физической оси;
- `Diff(v, i)` — производная порядка $i$ (последовательное применение).

## Интегрирование

Метод прямоугольников (кумулятивная сумма):

$$
F(x_n) \;\approx\; h \sum_{k=0}^{n} f(x_k).
$$

Погрешность также $O(h)$. Для гладких функций использование трапеций ($\tfrac{h}{2}(f_k + f_{k+1})$) поднимает порядок до $O(h^2)$.

Функция `AI.Functions.IntegralInterp` использует интерполяционное улучшение и работает точнее.

## Контрольная пара sin <-> cos

Проверка численных схем на аналитически известных функциях:

$$
\frac{d}{dx}\sin(x) = \cos(x), \qquad \int \cos(x)\,dx = \sin(x) + C.
$$

В демо строятся обе пары; при $h \to 0$ наблюдается сходимость.

## Код

```csharp
using AI;

double h = 0.01;
double fd = 1 / h;

var x    = Vector.Seq(0, h, 2 * Math.PI);
var sin  = x.Transform(Math.Sin);

var derivative = Functions.Diff(sin, fd);       // ≈ cos(x)
var integral   = Functions.Integral(sin, fd);   // ≈ -cos(x) + 1
```

Для зашумлённых сигналов численные производные **амплифицируют шум** — следует предварительно сглаживать либо применять производные Савицкого–Голея.
