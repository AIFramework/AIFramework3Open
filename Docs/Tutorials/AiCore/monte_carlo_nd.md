# Многомерное интегрирование методом Монте-Карло

## Метод

Для интеграла по гиперпрямоугольнику $\Omega = [a_1, b_1] \times \ldots \times [a_d, b_d]$:

$$
I = \int_\Omega f(\mathbf{x})\,d\mathbf{x} \approx V \cdot \frac{1}{N}\sum_{i=1}^N f(\mathbf{x}_i),
$$

где $V = \prod_{j=1}^d (b_j - a_j)$ — объём области, $\mathbf{x}_i \sim U(\Omega)$.

## Преимущества

- **Скорость сходимости не зависит от размерности**: $O(1/\sqrt{N})$ независимо от $d$;
- Детерминированные методы (трапеции, Симпсон) требуют $O(N^d)$ точек — «проклятие размерности»;
- Для $d > 4$ Монте-Карло практически безальтернативен.

## Дисперсия оценки

$$
\mathrm{Var}[\hat{I}] = \frac{V^2}{N}\,\mathrm{Var}[f(\mathbf{x})].
$$

Уменьшается как $1/N$. Для повышения точности используют:
- **Стратификацию** (Latin Hypercube Sampling);
- **Importance sampling** (выборка по плотности, приближающей подынтегральную);
- **Антитетические переменные**.

## Реплики

Реализация в фреймворке запускает $R$ реплик параллельно (каждая со своим RNG), усредняет результаты. Это даёт:
- Линейное ускорение по ядрам;
- Оценку стандартной ошибки через разброс между репликами.

## Пример: ∫exp(−|x|²) по [−2, 2]^d

Аналитический результат: $(\sqrt{\pi} \cdot \mathrm{erf}(2))^d$.

Для $d = 3$: значение ≈ 5.568, сходимость при $N \sim 10^4$ уже даёт ошибку < 1%.

## Код

```csharp
Func<Vector, double> f = x =>
{
    double s = 0;
    for (int i = 0; i < x.Count; i++) s += x[i] * x[i];
    return Math.Exp(-s);
};

var lower = new Vector(new double[] { -2, -2, -2 });
var upper = new Vector(new double[] { 2, 2, 2 });

double result = Integration.CalcIntegralND(f, lower, upper,
    n: 50000, iter: 10, seed: 42);
```
