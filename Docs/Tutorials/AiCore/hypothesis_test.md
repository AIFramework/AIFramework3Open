# Тесты гипотез для среднего

## Формулировка

- **H₀** (нулевая гипотеза): μ = μ₀
- **H₁** (альтернатива): μ ≠ μ₀ (двусторонний тест)

## Процедура

1. Вычислить тестовую статистику (z или t).
2. Сравнить с критическим значением (или p-value с α).
3. Решение: если |stat| > crit или p < α — отвергнуть H₀.

## z-тест (σ известно)

$$
Z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}
$$

Под H₀: Z ~ N(0, 1). Критическая область: |Z| > z_{1−α/2}.

## t-тест (σ неизвестно)

$$
T = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}
$$

Под H₀: T ~ t(n−1). Критическая область: |T| > t_{1−α/2, n−1}.

## p-value

p-value — вероятность получить статистику не менее экстремальную, чем
наблюдаемая, при условии H₀. Чем меньше p — тем сильнее свидетельство
против H₀.

$$
p = 2 \cdot P(T > |t_{\text{obs}}|)
$$

## Ошибки

| Тип   | Описание                          | Вероятность |
|-------|-----------------------------------|-------------|
| I     | Отвергнуть H₀, когда она верна   | α           |
| II    | Не отвергнуть H₀, когда H₁ верна | β           |

**Мощность** = 1 − β: вероятность корректно обнаружить эффект.

## Двухвыборочный t-тест Уэлча

Сравнивает средние двух независимых выборок без предположения о
равенстве дисперсий:

$$
T = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}
$$

Степени свободы — формула Уэлча–Саттертуэйта.

## Код

```csharp
using AI.Statistics;

var result = StatInference.TTest(
    mean: 2.1, std: 0.9, n: 50, mu0: 0, alpha: 0.05);
// result.Statistic ≈ 16.5, result.PValue ≈ 0, result.Reject = true

var welch = StatInference.TTestTwoSample(
    mean1: 5.2, std1: 1.1, n1: 30,
    mean2: 4.8, std2: 1.3, n2: 35,
    alpha: 0.05);
```
