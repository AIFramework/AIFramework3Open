# Автокорреляционная функция

**АКФ** (Autocorrelation Function) измеряет сходство сигнала со своей же сдвинутой копией. Для ряда $\{x_n\}_{n=0}^{N-1}$:

$$
R(\tau) \;=\; \sum_{n} x_n \cdot x_{n + \tau}.
$$

Нормированная форма:

$$
\rho(\tau) \;=\; \frac{R(\tau)}{R(0)} \in [-1, 1].
$$

## Свойства

- $R(\tau) = R(-\tau)$ — симметрия;
- $R(0) = \|x\|^2$ — пик в нуле равен энергии сигнала;
- Для периодического сигнала $T$: $R(\tau)$ сама периодична с тем же $T$;
- Для белого шума: $R(\tau) \approx 0$ при $\tau \ne 0$.

## Что показывает демо

Сравниваются три сигнала:

1. **Синусоида** $\sin(2\pi f t)$ — АКФ также синусоида, пики на $\tau = k/f$.
2. **Белый шум** $\sim \mathcal{N}(0, 1)$ — АКФ ≈ $\delta(\tau)$, резкий пик в нуле.
3. **AR(1)-процесс** $x_n = \varphi x_{n-1} + \varepsilon_n$ — АКФ экспоненциально затухает: $\rho(\tau) = \varphi^{|\tau|}$.

## Применения

- **Оценка периодичности** без знания частоты дискретизации;
- **Выбор лага в AR-моделях** (частичная АКФ);
- **Отделение сигнала от шума** по скорости затухания АКФ.

## Код

```csharp
using AI;

Vector acf = Correlation.AutoCorrelation(signal);
// acf[N-1] соответствует нулевому лагу
```

В реализации `AI.Correlation.AutoCorrelation` сигнал предварительно **центрируется** (вычитание среднего) и нормируется по энергии.
