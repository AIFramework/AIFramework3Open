# Линейная свёртка

**Свёртка** двух дискретных сигналов $\{s_n\}, \{h_n\}$:

$$
(s * h)(n) \;=\; \sum_{k} s_k \cdot h_{n - k}.
$$

Длина результата при сигнале длиной $N$ и ядре $M$: $N + M - 1$.

## Что делает свёртка

Свёртка с **ядром** $h$ реализует линейно-инвариантный по сдвигу оператор. В частности:

| Ядро $h$ | Эффект |
|---|---|
| Гаусс $e^{-x^2/2\sigma^2}$ нормированный | Сглаживание (низкочастотный фильтр) |
| $[-1, 0, 1]$ | Численное дифференцирование |
| $[1/3, 1/3, 1/3]$ | Скользящее среднее по 3 |
| $\mathrm{sinc}$ | Идеальный низкочастотный фильтр |

## Связь с преобразованием Фурье

$$
\mathcal{F}[s * h] \;=\; \mathcal{F}[s] \cdot \mathcal{F}[h]
$$

— свёртка во временной области = умножение в частотной. Поэтому длинные свёртки быстро считают через FFT за $O(N \log N)$.

## Гауссово ядро

$$
h_k \;=\; \frac{1}{Z} \exp\!\left(-\frac{(k - k_0)^2}{2\sigma^2}\right), \qquad Z = \sum_k \exp(\cdot),
$$

где $k_0$ — центр ядра. Больший $\sigma$ — сильнее сглаживание, шире импульсный отклик. Частотный ответ — тоже гауссов: $H(\omega) \propto e^{-\sigma^2 \omega^2 / 2}$.

## Код

```csharp
using AI;

// Гауссово ядро
int kw = 15;
double sigma = 3.0;
var ker = new Vector(kw);
double sum = 0, mid = (kw - 1) / 2.0;
for (int i = 0; i < kw; i++)
{
    double x = i - mid;
    ker[i] = Math.Exp(-x * x / (2 * sigma * sigma));
    sum += ker[i];
}
ker /= sum;

Vector smoothed = Convolution.DirectConvolution(signal, ker);
```

В `AI.Convolution` есть также `ConvolutionNormal` (нормировка на $\|s\|\cdot\|h\|$) и перегрузка с частотой дискретизации для интерпретации результата как аналогового интеграла.
