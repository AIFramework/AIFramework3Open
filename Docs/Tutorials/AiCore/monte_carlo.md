# Интеграл методом Монте-Карло

## Идея

Интеграл $I = \int_a^b f(x)\,dx$ можно представить как математическое ожидание:

$$
I \;=\; (b - a)\,\mathbb{E}_{X \sim U[a,b]}[f(X)].
$$

Оценка по выборке $X_1, \dots, X_n \sim U[a, b]$:

$$
\hat I_n \;=\; \frac{b - a}{n} \sum_{i=1}^{n} f(X_i).
$$

## Скорость сходимости

По ЦПТ:

$$
\hat I_n - I \;\sim\; \frac{\sigma_f (b-a)}{\sqrt n}, \qquad \sigma_f^2 = \mathrm{Var}(f(X)).
$$

Ошибка убывает как $O(1/\sqrt n)$ — **независимо** от размерности! Этим метод Монте-Карло выгодно отличается от методов трапеций/Симпсона, у которых стоимость растёт экспоненциально по $d$.

## Многопоточная реализация

`AI.Statistics.MonteCarlo.Integration.CalcIntegral1D` выполняет `iter` реплик параллельно (каждая со своим `Random`) и усредняет результат. Это даёт:

- линейное ускорение по числу ядер;
- возможность оценить дисперсию по разбросу реплик.

## Демонстрация сходимости

В демо строится график $\hat I_n$ как функция $n$; линия стремится к эталонному значению, вычисленному методом трапеций на мелкой сетке.

## Код

```csharp
using AI.Statistics.MonteCarlo;

double I = Integration.CalcIntegral1D(
    func: x => Math.Sin(x) / x,
    a: 1, b: 10,
    n: 50_000,         // точек на реплику
    iter: 20,          // реплик (параллельно)
    seed: 42);         // воспроизводимость
```

Для гладких одномерных функций методы Гаусса/Симпсона точнее. Но для $d \ge 4$ и/или сложных областей Монте-Карло практически безальтернативен.
