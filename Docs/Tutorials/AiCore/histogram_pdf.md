# Гистограмма и плотность вероятности

**Гистограмма** — кусочно-постоянная оценка плотности вероятности $p(x)$ по выборке. Интервал значений разбивается на $K$ бинов одинаковой ширины $h$, и в каждом считается относительная частота, нормированная так, чтобы

$$
\sum_{k=1}^{K} \hat p_k \cdot h \;=\; 1.
$$

## Плотность нормального распределения

Для нормального (гауссова) распределения $\mathcal{N}(\mu, \sigma^2)$:

$$
p(x) \;=\; \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

Подгонка по выборке даёт оценки $\hat\mu, \hat\sigma$; тогда $p(x;\hat\mu,\hat\sigma)$ — восстановленная плотность.

## Число бинов

Популярные правила:

- Правило Стёрджеса: $K = \lceil \log_2 n + 1 \rceil$;
- Правило Скотта: $h = 3.5\,\hat\sigma / n^{1/3}$;
- Правило Фридмана–Диакониса: $h = 2\,\mathrm{IQR}\,/ n^{1/3}$ (робастнее).

Слишком мало бинов — высокая смещённость, слишком много — высокая дисперсия оценки.

## Код

```csharp
var stat = new Statistic(sample);
Histogramm h = stat.Histogramm(bins);
// h.X — левые границы бинов, h.Y — плотность в бине
```

Нормировка площади гарантирует, что при увеличении выборки $h$-гистограмма сходится к истинной $p(x)$.
