# Тесты на нормальность

## Задача

Проверка H₀: данные получены из нормального распределения.

## Тест Жарка-Бера (Jarque-Bera)

Основан на выборочных асимметрии S и эксцессе K:

$$
JB = \frac{n}{6}\left(S^2 + \frac{K^2}{4}\right)
$$

Под H₀: JB ~ χ²(2). Для нормального распределения S = 0, K = 0.

**Преимущества**: простота, быстрый расчёт.
**Недостатки**: низкая мощность при малых n; чувствителен к хвостам.

## Тест Андерсона-Дарлинга

Использует ECDF и взвешивает отклонения в хвостах:

$$
A^2 = -n - \frac{1}{n}\sum_{i=1}^{n}(2i-1)\left[\ln\Phi(z_i) + \ln(1-\Phi(z_{n+1-i}))\right]
$$

где $z_i = (x_{(i)} - \bar{x}) / s$ — стандартизованные порядковые статистики.

С поправкой Стефенса: $A^{*2} = A^2(1 + 0.75/n + 2.25/n^2)$.

Критические значения (оценённые параметры):
| α     | Крит. значение |
|-------|---------------|
| 15%   | 0.576         |
| 10%   | 0.656         |
| 5%    | 0.787         |
| 2.5%  | 0.918         |
| 1%    | 1.038         |

**Преимущества**: высокая мощность, особенно для тяжёлых хвостов.

## Q-Q plot

Визуальный метод: строим выборочные квантили против теоретических квантилей N(μ̂, σ̂).
Если данные нормальны — точки ложатся на прямую y = x.

Типичные отклонения:
- S-образная кривая → тяжёлые хвосты
- Вогнутость → правая асимметрия
- Ступеньки → дискретность данных

// jb.PValue > 0.05 → нет оснований отвергать нормальность
