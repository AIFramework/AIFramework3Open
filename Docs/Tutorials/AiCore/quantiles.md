# Квантили и эмпирическая функция распределения

**Квантиль уровня $q \in [0,1]$** — значение $x_q$, для которого доля выборки, не превосходящая $x_q$, равна $q$:

$$
x_q \;=\; \inf\{x : F(x) \ge q\}.
$$

Важные квантили:

- $Q_1 = x_{0.25}$ — нижний квартиль;
- $Q_2 = x_{0.5}$ — медиана;
- $Q_3 = x_{0.75}$ — верхний квартиль;
- $\mathrm{IQR} = Q_3 - Q_1$ — интерквартильный размах (устойчивая мера разброса).

## Эмпирическая функция распределения

$$
\hat F(x) \;=\; \frac{1}{n}\sum_{i=1}^{n} \mathbf{1}\{x_i \le x\}
$$

— ступенчатая, неубывающая, сходится к теоретической $F$ по теореме Гливенко–Кантелли со скоростью $O(1/\sqrt n)$.

## Алгоритмы в AI.Statistics

| Метод | Сложность | Комментарий |
|---|---|---|
| `Quantile(sample)` + `.GetQuantile(q)` | $O(n\log n)$ | Отсортированный массив; удобно для множественных запросов |
| `Quantile.FastQuantile(sample, q)` | $O(n)$ в среднем | Алгоритм порядковой статистики (Quickselect) без полной сортировки |

## Код

```csharp
var q = new Quantile(sample);
double med = q.GetQuantile(0.5);
double q1  = q.GetQuantile(0.25);
double q3  = q.GetQuantile(0.75);

// Быстро для одного запроса:
double med2 = Quantile.FastQuantile(sample, 0.5);
```

Медиана и IQR — **робастные** статистики: они устойчивы к выбросам, в отличие от среднего и дисперсии.
