# Взаимная корреляционная функция

**ВКФ** двух сигналов $\{x_n\}, \{y_n\}$ длины $N$:

$$
R_{xy}(\tau) \;=\; \sum_{n} x_n \cdot y_{n + \tau}.
$$

Значение $\tau^*$, на котором $R_{xy}$ максимален, даёт **оценку задержки** одного сигнала относительно другого.

## Применения

| Область | Что делает |
|---|---|
| Радиолокация, сонар | Измерение дальности по времени запаздывания эхо-сигнала |
| Стереопара | Вычисление глубины по сдвигу патчей между левым и правым кадрами |
| Распознавание образов | Template matching — поиск шаблона в сигнале/изображении |
| Сейсмология, гидроакустика | Пеленг источника по задержкам между приёмниками |

## Математически

Для сигналов с задержкой $\tau_0$:

$$
y_n = x_{n - \tau_0} + \eta_n \;\Rightarrow\; R_{xy}(\tau) \text{ имеет максимум в } \tau = \tau_0.
$$

Шум $\eta$ размывает пик, но не смещает его (для симметричного $\eta$).

## Демо

Генерируются два сигнала — сумма синусоид — где второй задержан на $\tau_0$ и зашумлён. Строится $R_{xy}(\tau)$, отмечается положение максимума и сравнивается с истинной задержкой.

## Код

```csharp
using AI;

Vector xcorr = Correlation.CrossCorrelation(a, b);
int argmax = 0; double mx = xcorr[0];
for (int i = 1; i < xcorr.Count; i++)
    if (xcorr[i] > mx) { mx = xcorr[i]; argmax = i; }
int estLag = argmax - xcorr.Count / 2;
```

Для субсемпловой точности используют интерполяцию максимума ВКФ квадратичной параболой по трём отсчётам.
