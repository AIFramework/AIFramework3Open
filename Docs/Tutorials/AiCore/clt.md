# Центральная предельная теорема

**ЦПТ** — фундамент всей статистики: **сумма** (или среднее) большого числа независимых одинаково распределённых случайных величин с конечной дисперсией распределена **приблизительно нормально**.

## Формулировка

Пусть $X_1, X_2, \dots$ — независимые, одинаково распределённые, $\mathbb{E}X = \mu$, $\mathrm{Var}\,X = \sigma^2 < \infty$. Тогда

$$
Z_k \;=\; \frac{\sum_{i=1}^{k} X_i - k\mu}{\sigma\sqrt{k}} \;\xrightarrow{d}\; \mathcal{N}(0, 1) \quad (k \to \infty).
$$

Сходимость **по распределению** — но не поточечно к плотности $\mathcal{N}(0,1)$.

## Демо: сумма равномерных

$X_i \sim U(0, 1)$: $\mu = 1/2$, $\sigma^2 = 1/12$. Тогда

$$
Z_k \;=\; \frac{S_k - k/2}{\sqrt{k / 12}}, \qquad S_k = X_1 + \dots + X_k.
$$

Уже при $k = 12$ распределение $Z_k$ практически неотличимо от нормального — это используется в `Statistic.RandNormP(n, iter=12)` как простейший генератор нормали.

## Код

```csharp
int k = 12;
var rng = new Random(42);
Vector z = new Vector(n);
for (int i = 0; i < n; i++)
{
    double s = 0;
    for (int j = 0; j < k; j++) s += rng.NextDouble();
    z[i] = (s - 0.5 * k) / Math.Sqrt(k / 12.0);
}
// распределение z ≈ N(0, 1)
```

## Следствия

- Оценки среднего приближённо нормальны при большом $n$;
- Можно строить доверительные интервалы: $\hat\mu \pm 1.96\,\sigma/\sqrt n$ для 95%;
- Почти любая линейная статистика асимптотически нормальна.
