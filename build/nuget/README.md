# AIFramework

Открытая библиотека на C# и .NET 9 для искусственного интеллекта и научных расчетов: языковые модели и автономные агенты, нейросети, машинное обучение, обработка сигналов и текстов, компьютерное зрение, решатели и численные методы.

Фреймворк разбит на отдельные пакеты, поэтому подключать стоит только нужные:

```bash
dotnet add package AI.LLM
dotnet add package AI.NeuralNetworks
dotnet add package AI.DSP
```

Исходный код, документация и примеры: <https://github.com/AIFramework/AIFramework3Open>

Лицензия Apache-2.0. Сторонний код и его лицензии перечислены в файле `THIRD-PARTY-NOTICES.md` внутри пакета.

## English

Open-source C# / .NET 9 library for artificial intelligence and scientific computing: LLM clients and autonomous agents, neural networks, machine learning, signal and text processing, computer vision, solvers and numerical methods. The framework is split into separate packages, so install only what you need.

Source code, documentation and samples: <https://github.com/AIFramework/AIFramework3Open>
