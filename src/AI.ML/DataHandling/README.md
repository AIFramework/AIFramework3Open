# DataHandling

Наборы данных (`DataSets`), кодирование признаков (`DataEncoding`), преобразования (`FeaturesTransforms`), градиентный спуск (`GradientDescent`, `GradientDescentDataset`).

Базовые типы для классификации: `VectorDataset`, `VectorDatasetItem`; для пар «матрица–вектор»: `MatrixVector`, `MatrixVectorSample`.
