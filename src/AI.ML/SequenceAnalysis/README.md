# SequenceAnalysis

Подпространства:

- `AI.ML.SequenceAnalysis.HMM` — скрытые марковские модели и быстрые марковские цепи.
- `AI.ML.SequenceAnalysis.SeqAnalyze` — анализ последовательностей.
- `AI.ML.SequenceAnalysis.SeqPredict` — прогнозирование рядов.

NLP-обёртка `HMMFast` в сборке `AI.DataPrepaire` использует типы из `HMM` и не дублирует алгоритм (см. ADR-004).
