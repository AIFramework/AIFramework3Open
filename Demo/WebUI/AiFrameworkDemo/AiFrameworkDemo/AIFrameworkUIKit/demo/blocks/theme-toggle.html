Превью — тёмная и светлая темы

Тёмная тема (dark)
Светлая тема (light)

Акцентный цвет (#6366f1) одинаков в обеих темах — меняются только фон, поверхности и текст

Ключевые токены светлой темы ([data-theme="light"])

Токен Тёмная тема Светлая тема
--aif-bg-void #02030a #f0f2fc
--aif-bg #080b17 #e2e5f2
--aif-card-bg gradient dark gradient white
--aif-text-1 #f8fafc #0f172a
--aif-text-3 #94a3b8 #334155
--aif-border rgba(255,255,255,.08) rgba(0,0,40,.10)
--aif-accent #6366f1 #6366f1 (без изм.)

Акцентные цвета, радиусы, шрифты и z-индексы не меняются между темами

JS API — utils/theme.js

window.aifTheme 
aifTheme.get()      // → 'dark' | 'light'
aifTheme.set('light') // применяет тему и сохраняет в localStorage
aifTheme.toggle()   // переключает, возвращает новую тему
aifTheme.apply()    // читает localStorage и применяет

Тема сохраняется в localStorage['aif-theme']. Anti-flash: inline-скрипт в <head> применяет тему до первой отрисовки.

Разметка переключателя

<!-- В <head>: anti-flash -->
<script>(function(){
  var t = localStorage.getItem('aif-theme') || 'dark';
  document.documentElement.setAttribute('data-theme', t);
})();</script>

<!-- Перед </body> -->
<script src="AIFrameworkUIKit/utils/theme.js"></script>

<!-- Кнопка -->
<button class="aif-theme-toggle"
        onclick="aifTheme.toggle()"
        title="Переключить тему">
  <svg class="aif-theme-icon aif-theme-icon--sun" ...>...</svg>
  <svg class="aif-theme-icon aif-theme-icon--moon" ...>...</svg>
</button>
