Параграф с жирным текстом и курсивом. Многослойный перцептрон (MLP) — классическая нейросеть с несколькими полносвязными слоями. Функция активации ReLU и оптимизатор Adam обеспечивают быстрое обучение.

Инлайн-код: var model = new Sequential(); — создание модели.

Блок кода

var model = new Sequential(
    new Linear(inputSize: 2, outputSize: hidden),
    new ReLU(),
    new Linear(inputSize: hidden, outputSize: 2)
);

var optimizer = new Adam(model.Parameters, lr: 0.01);

for (int epoch = 0; epoch < 80; epoch++)
{
    var loss = model.TrainStep(data, labels, optimizer);
    Console.WriteLine($"Epoch {epoch}: Loss = {loss:F4}");
}
Универсальная теорема аппроксимации: MLP с одним скрытым слоем может аппроксимировать любую непрерывную функцию на компактном множестве.

Маркированный список

  • Слои: Linear → ReLU → Linear → Softmax
  • Оптимизатор: Adam
  • Функция потерь: CrossEntropy

Нумерованный список

  1. Инициализация весов
  2. Прямой проход (forward pass)
  3. Вычисление функции потерь
  4. Обратное распространение (backpropagation)
  5. Обновление параметров

Математика

Кросс-энтропия: $$L = -\sum_{c=1}^{C} y_c \log(\hat{y}_c)$$

Инлайн: $\sigma(x) = \frac{1}{1+e^{-x}}$ — сигмоида.

L = -\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{C} y_{ic}\log(\hat{y}_{ic})
